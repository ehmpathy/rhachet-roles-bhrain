## .the cue that fired

peer review i003/r011 (`enroll-impl-arch-defects`), point D — an architectural lane that reads across

> *"Inside the single `for (const level of levelsAsc)` body, `levelSlotByIndex`, `artifactByIndex`,

> happens to each member' logic (cache-hit / exhausted / reconsider / pour) is interleaved with
> side-effecting emits in the same ~150-line loop — so none of it is testable except through the full
> (subprocess-spinning) acceptance suite. This is the largest remaining decompose-for-recompose
> opportunity: split 'plan this level' (pure) from 'execute this level' (impure). Every extraction so

⚠️ **the reviewer's last sentence is the accurate part, and it is accurate about this round too.**
i003 added a third edge extraction (`runWithinConcurrencyBounds`) and a fourth
(`genReviewWaveBuffer`). all four are real and none reaches the core the point names.

## .the gap, precisely

the per-level body decides **four** outcomes per member before any subprocess exists:

| outcome | what decides it |
|---|---|
| a **cache hit** | `getCacheSafePeerReviewArtifact` returns an artifact for this index + hash |
| **exhausted** | `rounds >= budget`, and no review ran for this hash |
| **reconsidered** | an overrule at this level retires a prior verdict |
| **poured** | none of the above — it runs |

🔴 **every one of those four is a pure function of state already in hand** — the meter, the artifact
set, the overruled levels, the guard. and not one is reachable by a test, because each is computed
inline, between `cliEmit` calls, into four mutable structures the loop threads together.

⇒ the observable cost: **the only oracle for the decision table is the acceptance suite**, which
spawns real subprocesses. a wrong branch is caught by a snapshot diff several seconds later, in a
file whose name does not say which branch moved.

## .the shape of the fix

written from context held now, and this is the half that decays:

```ts
// pure — no i/o, no emit, no mutation of state the caller owns
export const getReviewLevelPlan = (input: {
  members: PeerReviewWithIndex[];
  meterBySlug: Map<string, RouteStoneGuardReviewPeerMeter>;
  artifactsByHash: …;
  overruledLevels: number[];
  hash: string;
}): {
  cached: { index: number; artifact: RouteStoneGuardReviewArtifact }[];
  exhausted: { index: number }[];
  reconsidered: { index: number }[];
  toPour: { index: number; slot: { index: number; total: number } }[];
} => …
```

then the loop body becomes: **plan** → emit the plan's decided arms → pour `toPour` through
`runWithinConcurrencyBounds` → merge by declared index. the four mutable structures collapse into the
plan's four arrays, and `levelSlotByIndex` is computed **inside** the plan rather than threaded.

🔴 **the clamp the split buys, and it is the point:** a table-driven unit test over the four arms —
five members, one of each outcome plus one plain pour, asserted as data. today that test cannot be
written at all.

## .why it is not done in this round

**the SAFE/CLEAN test, answered honestly** (`rule.always.fix-forward-under-scouts-honor`):

| question | answer |
|---|---|
| is it **SAFE**? | 🔴 **no.** it restructures the exact function every one of the 36 frozen peer snapshots observes, and it moves the emit order that `genReviewWaveBuffer` releases blocks against |
| is it **CLEAN**? | 🔴 **no.** it rewrites the ~150-line core, which is the largest single diff this branch could still take |

⇒ and the acceptance criterion it would put at risk is the one this round most owes:
**acceptance 2 — the 36 snapshots do not move.** this branch already owes the wisher a correction
from 8 moved files to **23**; a restructure of the emit path is the single change most likely to make
that number move again, for a reason unrelated to concurrency.

⚠️ **the deferral is a JUDGMENT, so it owes a fulcrum as well as this dream** — except that it does
not, and the distinction is worth the line: the judgment here is not *"clean but deferred"* (F11's and
F12's shape). it is **SAFE = no**, which `rule.always.fix-forward-under-scouts-honor` grades as the
harder stop. a dream alone is correct for an unsafe deferral; the fulcrum is owed when the call was
*"dirty, and I chose to defer anyway."*

## 🔴 .two independent proposals, and where they disagree

**i005 raised this seam twice, from two rubrics, neither of which had read this dream's shape
section.** that convergence is the strongest evidence the seam is real, and the disagreement between
the two proposals is the part a future traveler would otherwise re-derive.

> **i005/r011** (`enroll-impl-arch-defects`): *"extract a pure `planReviewLevel(input: { members,
> cachedReviews, meterBySlug, overruledLevels }) → { toPour, shortCircuited: Array<{index, artifact,
> exhausted}> }` that takes no `context.cliEmit` and does no i/o."*

> **i005/r010** (`enroll-impl-behavior-intent`), from the other side: *"the four-outcome decision
> table (cache-hit/exhausted/reconsider/pour) has no table-driven unit test."*

| | this dream's shape | r011's shape | the reconciliation |
|---|---|---|---|
| **inputs** | 5 — plus `hash` | 4 | 🔴 **`hash` is owed.** the cache hit is keyed on index **and** hash (`getCacheSafePeerReviewArtifact`), so a 4-input signature cannot compute that arm |
| **outputs** | 4 flat arrays, one per arm | 2 — `toPour` + a `shortCircuited` union | either works. **4 arrays are the better clamp target** — r010 asks for a *table-driven* test over the four arms, and a union re-fuses two of them |
| **the name** | `getReviewLevelPlan` | `planReviewLevel` | 🔴 **take this dream's.** `plan` is not a sanctioned verb prefix; `get` is, and the shape is `[verb][...noun]` (`rule.require.get-set-gen-verbs`) |
| **no `context`** | ✅ | ✅ | agreed, and it is the constraint the whole split rests on |
| **no i/o** | ✅ | ✅ | agreed |

⇒ **the merged verdict: r011's four inputs are correct and incomplete, and its two outputs are
correct and too coarse.** so the signature to build is this dream's, and r011's contribution is the
independent confirmation that the inputs are genuinely read there and no sixth is.

✅ **verified against the loop body at i005**, input by input: `members` at the per-level partition ·
`cachedReviews` at the cached-approved short circuit · `meterBySlug` at the exhaustion check and the

## 🔴 .a THIRD proposal, i019/r011 — the per-member classifier

**i019/r011 (`enroll-impl-arch-defects`) raised the same seam a third time**, from a member-grain
angle:

> *"extract only the classification step — a pure `decideReviewerAction({ cachedReview, meter,
> verdict, hasResponseNewer }) => { kind: 'cached'|'exhausted'|'reconsider'|'pour', ... }` — and keep
> the loop as a thin interpreter over that decision."*

it does not replace this dream's shape; it NESTS inside it. the classifier is the PER-MEMBER decision
(one `kind`); `getReviewLevelPlan` is the PER-LEVEL aggregation (the four arrays, one per `kind`). so
the plan calls the classifier per member and buckets by the returned `kind`. r011's contribution is a
fourth independent confirmation that the four-outcome decision is pure and testable in isolation —
and its `{ kind }` return is the exact discriminator the plan's four arrays are keyed on.

🟡 the classifier keeps zero observable output, so the 36 snapshots stay frozen — r011 says this
explicitly, which is why it graded the defer legitimate rather than a rush.
