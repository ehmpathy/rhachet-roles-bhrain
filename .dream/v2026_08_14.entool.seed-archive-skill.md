**status:** caught here, **not built**. the bound wish forbids new skills outright (*"no new

**owner:** this repo — the driver or learner skills dir. it is not a peer-repo ask.

## .the split — which half is entoolable

`rule.always.archive-the-wishers-words-verbatim` (driver) + the learner's `archive the source
BEFORE you distill it` cue together cover the act. only part of it needs a brain:

| the step | rung | why |
|---|---|---|
| notice the utterance changed the work | 📚 **1** — stays a brief | genuine judgment; no tool reads intent |
| write `.settled` — what changed and why | 📚 **1** — stays a brief | genuine judgment |
| compute the bound route from `.bind/*.flag` | 💪🪨 **4** | one read, same every time |
| compute `$route/.seeds/inventory.of=seeds.case=S$n-$topic.md` | 💪🪨 **4** | pure path arithmetic |
| allocate the next `S$n` ordinal from the extant set | 💪🪨 **4** | a glob and a max; same every time |
| findsert the file with the `.said` / `.settled` / `.landed` template | 💪🪨 **4** | scaffold, deterministic |
| **upsert the summary row** into `inventory.of=seeds._.md` | 💪🪨 **4** | the census the inventory form owes |
| **append** a new utterance to an extant seed rather than overwrite | 💪🪨 **4** | idempotency, and the one currently done by hand |

⇒ **the leftover brain work is the tell.** each archival this round meant: recall the route path,
recall the filename convention, re-read the extant seed, hand-place a quote block in the right
section. every one of those is a step, never a judgment
(`rule.always.entool-the-skills-you-touch`'s second test).

## .the ask

```sh
rhx seed.archive --topic <slug> --said @stdin          # findsert; append if the seed exists
rhx seed.archive --topic <slug> --said @stdin --settled @stdin
```

what it owes on arrival:

- **idempotent** — a re-run appends rather than duplicates (`rule.require.idempotent-procedures`)
- **route-aware** — reads the bound route; errors loud with the exact fix if none is bound
- **`--said` is byte-exact** — 🔴 the skill must **never** reflow, spellcheck, or reformat the
  quote. verbatim is the contract, and a tool that tidies it silently defeats the whole artifact
- **coordinates, never prose** — `inventory.of=seeds.case=S$n-$slug.md`, and both halves of the id
  (`rule.forbid.itemization-without-coordinates`). no `[` anywhere
  (`rule.forbid.brackets-in-filenames`)
- **the summary is owed too** — an entry with no row in `inventory.of=seeds._.md` voids the census

## ⚠️ .the hazard that makes this worth a tool rather than a brief

the prose rules the repo enforces are **hostile to a verbatim block**, and the conflict is live:

> the gerund hook blocked this exact archival because the wisher's own sentence contained
> *"a brief may encode anything"*. the correct resolution is to keep the quote unedited — but that
> resolution had to be reasoned out **in the moment**, against a hook that is right everywhere else.

⇒ a tool settles this once: it writes the `.said` block as opaque bytes, so the question never
reaches a brain again. **that is the strongest argument for rung 4 here** — not the keystrokes
saved, but the repeated judgment retired.

## .the evidence

on route `v2026_08_12.feat-adopt-seeded-briefs`, seed archival ran by hand across several rounds.
the sequence was identical each time, and the second run was already the evidence
(`rule.always.enskill-the-tactics-you-discover` — *"the repeat already proved it"*).
