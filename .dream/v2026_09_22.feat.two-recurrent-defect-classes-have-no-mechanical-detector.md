`enroll-impl-arch-defects` closed its i022 review with a meta-observation rather than a defect —
that the most useful result of a 22-round trail is not any single item but a recurrent **class**,
and that the class is what deserves the next investment:

| the class | instances on this branch |
|---|---|
| **an extraction binds only the call sites someone remembered to wire** | 7 — `isTargetDiffSent`, `isTargetPayloadSent`, `getOneTargetRenderPlan`, `ReviewTokens`, the grove × absent cell, `pourInBoundedWaves` at `getAllReviewTrees`, `asGradeCensus` at `meter/` |

🔴 **every one of the thirteen was found by a human-grade read, and every one was cheap to spot

there is **no detector** for any of the three. the branch's only defense is that a reviewer happens to
read two files in one session and notices they rhyme — which is exactly what failed six times
before it worked the seventh.

🟡 **and the inventory already knows the shape of the answer, for a THIRD class.**

## .the shape of the fix

### class 1 — the unwired call site

the signal is a **named decision with an arity mismatch**: a module exported for reuse whose
importer count is lower than the count of call sites that perform the same act inline.

- a `grep` for the extracted symbol gives the WIRED set
- a `grep` for the shape it replaced (`Promise.all(`, a repeated `.filter().length` triple, a
  literal `'metered'` comparison) gives the CANDIDATE set
- ⇒ the defect is `candidates − wired`, and it is a set difference rather than a judgment

🟡 the honest limit: the "shape it replaced" is not always greppable. `pourInBoundedWaves` is
(`Promise.all(` over a mapped array), `asGradeCensus` is (`=== 'metered'`), `isTargetDiffSent` is
not. so the detector catches a **subset** — which still beats zero, and the subset is the half that
recurred most.

### class 2 — write/read shape drift

**this one has a real mechanical answer and it is a TYPE, never a lint.** a hand-listed field set
over a closed union compiles clean when the union grows; a `Record<TheUnion, T>` does not.

- the detector is a `grep` for an interface whose fields are exactly the members of a declared
  union type in the same package
- the repair is the `Record` — the `KEY_OF_AXIS` / `LABEL_OF_ABSENT_KEY` shape this repo already
  uses for `GroveAxis`, and which `GradeCensus` took at i022

⇒ so class 2 is not a lint that reports; it is a **codemod that prevents**. that is a stronger
outcome than class 1 can reach, and it is the one worth the first day of work.

### 🔴 class 3 — the untested communicator (added 2026-09-25)

**the cheapest detector of the three, and the only one with no heuristic in it:** count the source
files in a directory against the test files, and read the difference.

⇒ found by the tenth warmer audit pass, which ran the traversal BACKWARD — code → bar, where nine
prior passes ran bar → code. `rhx globsafe` on one directory returned **14 sources, 13 tests**, and
the one file of 14 with no test carried a race (`existsSync` then `readFileSync`) that the file
**beside it forbids by name** in a comment. no bar in `0.wish` says *"read the pid file safely"*, so
the defect was unreachable by every bar-first pass, however sharp its instrument.

**it is a class, and it is measured rather than inferred** (`rule.require.enumerate-before-you-name`):

| the corpus | count |
|---|---|
| source files under `src/` | 573 |
| test files | 409 |
| 🟡 sources with no test at their own stem | **218** — and a bare count here is NOT the class |
| 🔴 of those, files that import `fs` / `fs/promises` / `child_process` | **27** |
| minus test infrastructure (`.test/setup`, `__test_assets__`) and cli entrypoints whose acceptance suites sit at a different stem | **~18 candidates** |

🟡 **the grain filter is what makes it a class rather than a number.** 218 is 38% of the repo and most
of it is legitimately untested — type-only files, constants, domain objects. what
`rule.require.test-coverage-by-grain` grades a **BLOCKER** is narrower: a *communicator* — raw i/o —
with no integration test. so the detector is `no-test ∩ does-i/o`, and that intersection is 27.

**the shape of the fix:** a `Glob` per directory, a stem-match, and an import filter — no judgment,
no false-positive heuristic to tune. it is the same set-difference shape as class 1 and it lacks
class 1's honest limit, because *"does this file do i/o"* is greppable where *"the shape it replaced"*
is not.

🔴 **the honest limit is at the other end: a candidate is not yet a defect.** a communicator may be
covered transitively by its orchestrator's integration test, which
`rule.require.test-coverage-by-grain` does not forbid. so the 18 are a **review queue**, exactly as
class 1's `candidates − wired` is — and a queue of 18 that costs one command still beats a class
found by a reviewer who happened to count.

🟡 **and the rule was never the gap.** `rule.require.test-coverage-by-grain` already says a
communicator without an integration test is a blocker. what was absent is the one part that makes a
rule fire with no reader present: **a mechanism.** that is this dream's whole thesis, and class 3 is
its cheapest instance.

### where it would live

a skill, not a brief — this is rung 3 at best and rung 4 at the `Record` half
(`philosophy.entoolment-is-the-pinnacle`). a `rhx lint.recurrent-classes` that emits a treestruct
of candidate sites, run from the same place `git.repo.test --what lint` runs.

## .why it is not done in this round

**SAFE — yes.** a detector reads; it changes no shipped behavior.

**CLEAN — no.** it is a new skill, a new glob corpus, and a set of heuristics that each need their
own false-positive clamp — in a round whose open work is three peer nitpicks and a stone that has
been blocked for two generations. ⇒ it would be a second feature ridden along inside a review
round, which is the smuggled-refactor shape `rule.always.fix-forward-under-scouts-honor` refuses.

🟡 **and the scope is genuinely repo-wide, not branch-wide.** both classes are named from evidence
on `beav/feat-review-cost-meter`, and neither is a property of that branch — they are properties of
how this repo extracts. a detector scoped to one behavior's diff would measure the wrong corpus.

⇒ no fulcrum is owed beside this dream, because **no design call was made**: the work is deferred
for SIZE rather than for dirt, and the shape of the fix above is the record that matters.
