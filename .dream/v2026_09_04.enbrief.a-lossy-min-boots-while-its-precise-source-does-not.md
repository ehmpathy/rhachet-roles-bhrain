# 🌙 dream: a lossy `.md.min` boots, and its precise source does not

**kind**: enbrief · **owner**: this repo (`rhachet-roles-bhrain`) — telepath's canon, plus a check
· **caught** 2026-09-04

## .the cue that fired

a first-party probe of `--optional rules` measured that a skip **does** write its `review:`
artifact. that contradicted a line in the booted reviewer contract:

| artifact | what it says | precise? |
|---|---|---|
| `contract.reviewer-output.md:102` — the source | *"a skip writes no **log** artifacts, so it advertises no log dir"* | |
| `contract.reviewer-output.md.min:77` — the sidecar | *"a skip writes no artifacts"* | 🔴 no |

the condense dropped one word — `log` — and the word carried the whole distinction. the same cut
also dropped the `review:` line from the rendered example, so the min's transcript did not match
what the command emits.

## .the gap, precisely

**the min is what BOOTS. so when a cut is lossy, the repo reaches a state where the source is
correct and every reader is wrong** — and no reader can tell, because the source is exactly the
file they do not open.

⇒ that is the property `v2026_08_31.fix.a-symlinked-brief-loses-its-min-sidecar.md:59` already
names from the other side: *"a min does not merely shrink a brief — it REPLACES the text boot
emits."* that dream is about a sidecar that is *absent*; this one is about a sidecar that is
*present and wrong*, which is the worse of the two — an absent min falls back to correct text.

## 🔴 .the drift runs BOTH ways, and this filename names only the sharper one

the cue above is a min that lost a distinction its full kept. **the inverse is live in this repo
too, and the convention makes it worse than it sounds:** a `.md` is the *dereference target* — the
file a reader opens precisely when they want the authoritative depth.

| direction | which file is right | what a reader gets |
|---|---|---|
| the min is **lossy** — a cut dropped a distinction | the full | every reader is wrong, and the right file sits unread beside it |
| the min is **ahead** — an edit landed on the sidecar alone | the min | every reader is right, and whoever dereferences for depth gets the older, worse file |

⇒ **measured 2026-09-07:** `rule.forbid.domain-term-ambiguity.md.min` was *larger than its own
source* — 1,630 bytes against 1,574. it was no bloated min. the min carried a claim the full
lacked outright: *where the two senses differ by context rather than by concept, the repair is a
boundary, never a second word.*

so the sidecar had become the better artifact, and the citation chain pointed away from it.

### 🟡 the two directions need DIFFERENT checks, which is why one rule cannot carry both

| | how it is found |
|---|---|
| **lossy** | a read of both files against each other, claim by claim. dirty — invisible to a grep |
| **ahead** | 🟡 `wc -c` on the pair. **a min at or above its full's size is the tell**, and it is mechanical |

⇒ that asymmetry is the useful half: the *cheap* check catches the direction nobody looks for, so
it belongs in a skill rather than in a habit. a min larger than its full is not merely suspicious —
it is a contradiction of what a min IS, and no legitimate case produces it.

⇒ **walked 2026-09-07 across 85 source-side pairs, 0 orphans: exactly one hit, and it is the
instance above.** so the check is precise as well as cheap — it is no heuristic with a false-positive
tail to triage, and its denominator is small enough to re-run on every round.

🟡 **and the repairs are opposite.** a lossy min is repaired by a restore *into the min*; an
ahead min is repaired by a back-port *into the full*. a rule that names only *"keep them in sync"*
leaves the author to guess which file is authoritative, and the guess is wrong half the time.

### the cost, measured on this route

the imprecise form was about to become a design input:

- `case=11` proposes the `logs:` line as the one discriminator between a real pass and a skip
- read *"a skip writes no artifacts"*, and the obvious repair is *"check the output file exists"*
  - 🟡 the output file exists in **both** cases
  - ⇒ so that repair tallies every skip as a pass — the exact failure it was built to catch

⇒ **a lossy cut in a contract brief does not merely mislead. it proposes the wrong fix.**

## .why this is telepath's, and not merely a typo

the wisher settled the claim this rests on (`S11`):

> *"this is false; lossless compression does not increase ambiguity. infact, rambled prose
> increases ambiguity"*

**lossless compression cannot add ambiguity, by construction** — it removes the words that carried
no distinction. so a word that carried one was never surplus, and a cut that drops it was
**lossy**: a defect of the cut, never a property of density.

⇒ **this is the first measured instance of that claim in this repo, and it cuts both ways:** it
confirms density is not the culprit, and it shows the failure mode a condense pass must be graded
against. `rule.forbid.subversive-prose` carries the claim; no rule yet carries the **check**.

## .the shape of the fix

1. **the rule** — telepath owes `rule.require.lossless-condense` (or a clause in the density root),
   and it must bind **both** directions:
   - *a `.md.min` may drop words that carry no distinction and no others. the test is not a line
     count — it is whether a claim in the source is unrecoverable from the min.*
   - *and a claim authored into a min is back-ported to its full before the round closes. the full
     is the dereference target, so it may never trail the sidecar that abbreviates it.*
2. **the cheap check** — 🪨 mechanical, and it catches the *ahead* direction outright: flag any
   pair whose `.md.min` is at or above its `.md` in bytes. no legitimate case produces one
3. **the dear check** — a condense is a **step**, so it is owed a tool rather than a habit
   (`rule.always.entool-the-skills-you-touch`)
   - the cheapest form: after a condense, name each claim the source makes, and confirm the min
     still makes it
   - ⇒ that is a rubric, in the same `review.by` shape this behavior already builds
4. **the sweep** — this repo has many `.md.min` sidecars and few have been checked. the byte check
   in step 2 sorts them: it settles the *ahead* half in one pass, and what remains is the *lossy*
   half, which is a read per pair.

## 🟡 .why it is not done in this round

the immediate defect is repaired — `contract.reviewer-output.md.min:71-77` now carries the
`review:` line and the word `log`. that was safe and clean, so it was fixed rather than caught
(`rule.always.fix-forward-under-scouts-honor`).

what is caught is the durable half, and it is deferred for one reason: the rule belongs to
telepath's canon, which is this behavior's primary deliverable and sits behind `1.vision`
approval. to author a canon rule mid-vision would start the deliverable before its shape is ruled.

🟡 **the sweep is deferred on a different ground — it is DIRTY: a lossy min is invisible to a
grep.** it is found only by a read of both files against each other, and a fix changes booted text
for every role that carries the brief. that is the same integration-run cost the 2026-08-31
sidecar dream records.

## .the fulcrum

> **a min replaces the text boot emits, so a `.md`/`.md.min` pair is two artifacts that must state
> one set of claims — and when they disagree, which of the two is right depends on the direction of
> the drift, not on which file is the source.**
> rework: **clean** for the rule and the byte check; **dirty** for the read-per-pair sweep.
