# case 5: a clone that ran `cd` is still guarded

row 27.

## .narrative

a clone runs `cd src/domain.operations` to look around, then tries `echo x > ~/.claude/projects/p/memory/x.md`. claude code runs the hook in that subdir. a hook that looked for `.agent/…` relative to the cwd would find no skill, raise its notice, and let the memory write through — a fail-open that quietly becomes a fail-off. the hook anchors on `CLAUDE_PROJECT_DIR`, finds the skill at the project root, and halts the write with the owl nudge.

## .bdd sketch

```
given a tree with the learner linked, CLAUDE_PROJECT_DIR = the root, cwd = a subdir
  when [t0] Bash `echo x > ~/.claude/projects/p/memory/x.md` fires the hook
    then exit 2
    then stderr holds the owl nudge
  when [t1] Bash `ls` fires the hook
    then exit 0, silent (no notice: the guard ran)
```
