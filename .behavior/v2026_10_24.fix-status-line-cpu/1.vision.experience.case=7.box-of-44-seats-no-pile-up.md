# case=7 — a box of 44 seats, no pile-up (happy · critipath, actor = box)

## .narrative

the box runs 44 claude seats at load 56 over 12 cores. a burst of agent messages arrives, and
the harness repaints every seat's status line inside the same second — some seats several times,
faster than the prior repaint can exit. today that burst stacks: 9 status-line processes hold
491% cpu, each one a full module-graph boot plus a repo-wide glob, and the crews' test suites
starve and time out.

with the fix, the same burst lands on warm caches. each repaint boots bare node, imports only
`fs` and `path`, reads the git HEAD file and a handful of stats, matches the fingerprint, prints
the cached line, and exits — in about the time bare node takes to start. a repaint is done before
the next one fires, so processes do not overlap; `top` on the box amid the burst shows no
status-line process above the node-boot floor, and the process count never climbs past the
number of seats that repaint at once.

several seats in one worktree share one cache file per branch. when a passage lands, the next
repaint of each such seat misses at once — a small herd. each recomputes the identical line from
identical inputs and writes it via temp file + rename; whichever rename lands last wins, and since
every writer wrote the same bytes, the race loses naught. a reader that opens the file mid-rename
gets the old file or the new one, never a half. one herd per passage change, not per repaint, is
the whole fresh-work bill.

a `route.bind.set` that races a repaint is the same shape: the bind op drops the cache file and
writes the flag; a repaint that read the old cache before the drop prints the prior line once,
and the next repaint sees the flag's mtime in its fingerprint, misses, and shows the new route —
inside the 1–2s the wish allows.

## .bdd sketch

```
given('[case7] a box with N seats on one bound route, caches warm')
  when('[t0] all N seats repaint at once, with no passage change')
    then('the render runs zero times across the N repaints')
    then('each repaint exits before the next on its seat fires — no overlap')
    then('the summed cpu stays at N × the bare node boot floor')
  when('[t1] a passage lands, then all N seats repaint at once')
    then('every seat shows the new stone')
    then('the cache file holds one valid record, never a torn one')
  when('[t2] route.bind.set races a repaint')
    then('at most one repaint shows the prior line')
    then('the next repaint shows the new route')
```
