# case=8 — a transcript on a model no rate spec names (happy, unpriced)

cell: any selector · one · metered · rates = unpriced · feel = happy · care = critipath ·
boundaries = 6 + rate lookup

## .narrative

a clone ran on a model the installed brain packages carry no rate spec for — today that is every
opus 5.x session on this machine. a human audits it.

the token counts are all measured, so the report still answers where the context went. only the
dollar is absent. a `$0.00` would read as *"this session was free"*, and a guessed rate would be a
number nobody measured. so each priced cell reads `unpriced`, and the total says why, what still
holds, and what lifts it.

the proposal still ranks: by tokens, since a rank by price over unpriced rows would compare
absences.
