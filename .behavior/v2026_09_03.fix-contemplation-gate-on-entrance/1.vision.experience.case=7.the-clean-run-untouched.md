the no-regression case. it earns critipath on **frequency**: most guard runs owe no answer, and
this behavior adds a check to the entrance of every one of them.

## .the narrative

*driver, on a stone whose reviewers said their piece and it was clean*

I run `--as passed`. the reviewers run, the judges run, the stone passes. **that is the whole
story, and that is the point** — no new gate, no new prompt, no new pause. the entrance check read
a directory, found no unanswered blocker, and said naught.

**the aha:** a gate you feel on the clean path is a tax on every honest run. this one is invisible
unless you owe an answer.

## 🔴 .the three regressions this pins

| `[tn]` | the mistake it catches |
|---|---|
| `[t1]` | a gate that reads *any* verdict rather than *blockers* holds every run that carries a nitpick. reuse `getAllRouteGuardReviewPeersUncontemplated.ts:17`'s `blockers > 0` filter; never re-derive it |
| `[t2]` | a hash-agnostic enumerate over an absent directory must yield `[]`, never throw. the taken-side read already crosses this path (`getAllRouteGuardReviewPeerTakenMetas`) |
| `[t3]` | the gate must sit **after** the zero-reviewer auto-pass (`setStoneAsPassed.ts:257-289`), or a guard with artifacts alone pays for a check it can never fail |

**the cost budget:** two directory enumerates plus a read of the givens that match — **no**
subprocess, **no** brain call. if it costs more than the `review.self` gate beside it at `:195-255`,
it is in the wrong shape.

⇒ **case=1 says the gate must bite; this says it must bite ONLY when it should.** the natural
over-correction — hold whenever any prior given exists — passes every test in cases 1–6 and makes
the common path miserable.
