# 🌙 dream: a guard round reads a tree that is still under edit

- **kind** = fix
- **owner** = `ehmpathy/rhachet-roles-bhrain`
- **caught** 2026-09-04, at stone `5.3.verification` of
  `v2026_09_03.fix-contemplation-gate-on-entrance`

## .the cue that fired

round `i002` of stone `5.3.verification` returned a blocker from `r009 mech-test-scope-purity`:

> *"new acceptance test references undefined `asStableGuardEmit` — the suite cannot compile or run"*

it was **correct for the bytes it read** and **false by the time i read it**. i had made a
three-step edit — delete the local normalizer, add the shared call, add the import — and the
reviewer subprocess read the file between step 2 and step 3.

so a peer reviewer spent a full round, and its budget, to grade a state that existed for a few
seconds and was never a state i intended to submit.

## .the gap, precisely

`runStoneGuardReviews` spawns each peer reviewer as a subprocess that reads the **live tree**. no
snapshot, no copy, no lock. the guard already computes a whole-artifact hash
(`computeStoneReviewInputHash`) at the start of a round — so it **knows** what it intended to
grade — but the reviewers do not read from that; they read whatever is on disk when they get
scheduled.

⇒ the hash and the bytes graded can therefore **disagree**, and the round is recorded under the
hash. that is the sharp part: the artifact of a round claims a provenance the round did not have.

### why it is worse than a wasted round

| cost | detail |
|---|---|
| a spent budget | the reviewer's round is consumed on a phantom |
| a **debt** minted | under this behavior's own P2, that blocker is now keyed to the reviewer and survives the edit — so the driver must answer a critique of a file state that never existed |
| a corrupted signal | the driver's honest reply is *"this is not real"*, which is the exact shape of the excuse `rule.forbid.unanswered-exits-from-a-blocker` forbids. a **true** instance of it teaches the wrong reflex |

🔴 that third row is why this is worth a mechanism rather than a note. this behavior exists to make
*"the reviewer is wrong"* an unavailable exit. a defect that makes it **occasionally true** erodes
precisely the discipline the behavior installs.

## .the shape of the fix

the guard already holds all it needs:

1. **grade a snapshot, not the live tree.** at spawn, materialize the artifact set the hash was
   computed over into a temp dir, and point each reviewer's `--paths` at that. the round then
   grades exactly what its hash names, by construction. this is the rung-4 fix.
2. or, cheaper: **re-compute the hash after the round and discard the verdict if it moved.** that
   detects the race rather than prevents it, and costs one hash per round. it would have caught
   this instance.
3. or, cheapest: a **driver-side cue** — the stophook warns when a guard round is in flight and the
   live tree has changed since spawn.

⇒ (1) is the mechanism; (3) relies on a reader in a hurry. per
`philosophy.entoolment-is-the-pinnacle`, prefer (1), and note that (2) is a real intermediate rung
rather than a consolation — it converts a silent wrong answer into a loud retry.

## .why it is not done in this round

**safe? no.** it changes how every peer reviewer in the repo receives its target files — the
blast radius is every guarded stone in every route, not this one.

**clean? no.** a snapshot dir changes the paths reviewers cite in their findings, which changes
every `.given` body and several snapshots. that is a contract change on a verification stone.

⇒ so it is caught rather than fixed (`rule.always.catch-dreams-for-followups`). the discipline i
apply meanwhile — quiesce the tree, run the gates, write the takens, then re-arrive — is stated in
the taken at
`.reviews/peer/5.3.verification._.review.i002.7b3e5095a245d2aa27.r009._.taken.by_self.mech-test-scope-purity.md`.

## .the honest bound

this is **not** a defence of the driver. the discipline is mine to keep and i broke it. the dream
exists because a rule that depends on a human's edit order is a rule with a known failure rate,
and the guard is in a position to make the failure impossible.
