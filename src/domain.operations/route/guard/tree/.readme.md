# route/guard/tree — its declared shared exposure

`route/guard/tree/` renders the guard's stdout trees. most of it is private to the route. one
renderer is read across a context line, and the read is sanctioned.

## .the contract

| export | grain | sanctioned consumer | why it reads it |
|---|---|---|---|
| `formatGuardReviewerTree` | transformer | `review.by/` | the `review.by` row and the route peer row render through ONE reviewer formatter, so the two cannot drift (`rule.forbid.duplicate-format-tree-operations`) |
| `ReviewerTreeState` | type | `review.by/` | the render shape both rows fill |

⇒ a reshape of either export changes what BOTH rows render; read each call site before you
make one. an import of any OTHER module here from outside `route/` is an undeclared reach-in —
declare it here with its reason, or lift it to a neutral home.
