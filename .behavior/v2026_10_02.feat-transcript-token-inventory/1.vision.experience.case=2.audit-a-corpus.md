# case=2 — audit a corpus

cell 2: glob · many · metered (the unmetered files the glob also matches are skipped and counted) · feel = happy · care = critipath · boundaries = 6 + corpus merge

also demos cell 22 in `[case2b]`: glob · many · one file malformed-mid-file · feel = sharp · care = alterpath

## .narrative

one session proves naught about a distribution. the foreman wants to know whether the boot is
46% everywhere or only in that one bloated session. they run:

```sh
rhx reflect.tokens --from '~/.claude/projects/*rhachet-roles-bhrain*/*.jsonl'
```

the tool streams 212 files. it reports `198 metered · 14 skipped (no usage)` up front, so the
foreman knows the shares are over 198, not 212. the inventory now shows each category as a
**share of the corpus**, plus its spread across sessions: `boot.instructions 41.3% (p10 22% ·
p50 43% · p90 61%)`. the proposal is the same shape as case=1, ranked over the whole corpus.

the foreman sees the boot share is wide — some sessions are 22%, some 61% — and asks the next
question the tool cannot answer alone: which roles boot heavy. that is a dispatch, not a defect.

## .timeline

```ts
given('[case2] a glob that matches 212 transcripts, 14 of them with no usage records', () => {
  when('[t0] the foreman runs `rhx reflect.tokens --from <glob>`', () => {
    then('exit 0');
    then('the header reads: matched 212 · metered 198 · skipped 14 (no usage)');
    then('efficiency sums across the 198, and still parts cache.read from cache.write');
    then('each inventory row shows a corpus share plus p10 · p50 · p90 across sessions');
    then('the proposal ranks over corpus-wide repaid');
    then('memory stays bounded across the run — each file is read and folded, never held whole');
  });
});
given('[case2b] the same glob, where one of the 212 files is torn mid-file', () => {
  when('[t0] the foreman runs `rhx reflect.tokens --from <glob>`', () => {
    then('exit 0 — the corpus report stands over the files that parsed');
    then('the header adds skipped (malformed) = 1, and names that path + line beneath it');
    then('the shares are over the files read, and the header says so — never a silent gap');
  });
});
```
