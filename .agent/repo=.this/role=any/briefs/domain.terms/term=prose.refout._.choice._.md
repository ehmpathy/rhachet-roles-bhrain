# domain.term: refout

term.chosen   = refout
term.kind     = verb
term.boundary = prose
term.synonyms.forbidden:
- externalize
- eject
- demote
- offload

## .what

to move a passage out of a **resident** artifact into a **referenced** one, and leave a pointer by
path. the passage keeps its full depth; the resident file keeps only the pointer.

⇒ the passage is not cut. a refout is a **move**, and it is available only where a dereference target
already exists.
