## .the gap, precisely

`[case10]` spawns the REAL `rhx clone whoami` and asserts it settles inside `WHOAMI_TIMEOUT_MS`
(2_000). it is the 20th of 22 tests in one jest worker, and several of the tests ahead of it spawn
their own children. so the measured elapsed carries the worker's contention as well as the
binary's boot.

**measured 2026-09-18, this worktree, six runs, no production edit between them:**

| what ran | wall | `[case10]` |
|---|---|---|
| the 7-file brain suite | 61s | 🔴 red, `timed-out` |
| this file alone, 22 tests | 29s | 🔴 red, `timed-out` |
| this file alone, 22 tests | 13s | ✅ green |
| `[case10]` alone, 3 tests | 5s | ✅ green |

| the 7-file brain suite, after the repair | 68s | ✅ green |

🔴 **row 5 is what settled the diagnosis, and it is the whole value of the elapsed instrument.**
2032 against a 2000 cap is **1.6% over** — a binary too slow for the hook's budget does not miss by
32ms. ⇒ the red measured the HOST, and the host is not under test.

🟡 row 6 carries a heavier load than row 5 and it is green, which is the repair at work rather than
luck.

## .what i038 took, and what it left owed

**taken** — the overrun is admitted as a THIRD determinate arm, which is a repair at cause rather
than a loosen:

- `timed-out` is a path `getCloneAddress.ts:162-165` **deliberately provides** — it kills the child,
  settles `{ address: null, cause: 'timed-out' }`, and releases the hook's event loop
- so the test forbade a designed render, which is why it flaked
- the arm now asserts that render's own contract: `address === null` AND `took >= cap`
- and the wall-clock row that remains asserts the **bound** (`took < 2×cap`) — a property of the
  CODE, where `took < cap` was a property of the HOST

⚠️ **still owed, and stated rather than smoothed:** a rhachet regression that made `whoami` genuinely
slow would now land on the overrun arm and stay green. the `took < 2×cap` row bounds the drift and
no further. **a true budget clamp needs the probe to run alone.**

⚠️ and the overrun arm has **not been observed to fire** — every green run so far took the
`unenrolled` path, so its assertions are unexercised.

## .the shape of the fix

1. ~~**assert the elapsed, never the word**~~ — ✅ taken at i038. it did not stop the red; it made the
   red **sortable**, which is what produced the repair above.
2. **warm the binary once** before the measured spawn, so module resolution and the FS cache are
   already hot. ⚠️ it removes a cost the LIVE hook does pay on a cold boot, so it trades one
   inaccuracy for another.
3. **move `[case10]` into its own file**, so jest gives it a worker with no peers. that matches the
   live hook's condition exactly, and it costs one file plus the header that says why it is split
   out. ⇒ **the honest repair, and the only one that restores a true budget clamp.**

## .why it is not done in this round

- **SAFE?** yes — a file split touches no production code.
- **CLEAN?** 🔴 **no.** the split ripples: `[case10]`'s header cites `[case1]`'s fixture row as its
  twin at two grains, `[case8]` binds `WHOAMI_TIMEOUT_MS` to the settings, and both citations
  become cross-file. it also lands in an i038 diff that 12 review lanes are mid-round on, and a new
  test file re-scopes every one of them.

⇒ so a fulcrum is owed beside this dream, per `rule.always.fix-forward-under-scouts-honor` — the
deferral is a JUDGMENT about ripple cost rather than about size.
