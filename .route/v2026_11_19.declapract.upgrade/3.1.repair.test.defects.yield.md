## .defects

### D1 — `test:lint:cycles` fails on 27 cycles in dependencies
- **what**: the new dpdm check (`exclude: []`, node_modules included) reds on cycles inside rhachet, declastruct-aws, @aws-sdk, helpful-errors 1.5.x, domain-objects 0.31.x, bottleneck, readable-stream. none in `src/`
- **how**: the upgrade adds `test:lint:cycles` to `test:lint` and adds `.dpdmrc.yaml`; main had no cycle check
- **why**: the cycles always shipped; the check is what is new
- **fix**: the org cycles are eliminated: `pnpm.overrides` pins every transitive `helpful-errors@<1.7` to 1.7.5 and `domain-objects@<0.34` to 0.34.0 (a bump of the direct deps alone cleared none). the third-party cycles are eliminated by replacement: `wrapper-fns` (`withRetry`, `withTimeout`) and `@ehmpathy/as-command` (one codegen wrapper) carried `bottleneck`, now local operations and a plain command; `archiver` carried `readable-stream`, now `fflate`. `.dpdmrc.yaml` excludes only the three dev packages. fulcrum F4

### D2 — suites the repo keeps as records fail to load
- **what**: three sets fail with `Could not locate module` or import a retired api:
  - `.behavior/v2026_09_20.review-cost-meter/archive/warmer/**/*.test.ts`
  - `src/domain.roles/thinker/.scratch/**/*.integration.test.ts`
  - `src/domain.roles/thinker/skills/**/step*.integration.test.ts`
- **how**: main's configs cut `.behavior/`, `.scratch/`, and the thinker stitch suites; the practice configs cut only `.agent/`
- **why**: each is a record of code the repo retired or never shipped, never a suite
- **fix**: new repo skill `rhx retire.suites` appends `.retired` to each such `*.test.ts` and its snapshot (73 files; contents byte-identical), so jest, tsc, and biome all skip them. the `.behavior/` + `.scratch/` haste cuts return too (D7)

### D3 — `repeatablyAbsorbsFailedAttempts.test.ts` fails (2 cases)
- **what**: a setup that throws on attempt 1, and an attempt past the jest timeout, red the file though attempt 2 passes
- **how**: the practice bumps `test-fns` 1.15.7 → 1.17.0; the patch stayed keyed `test-fns@1.15.7`, and the practice's `allowUnusedPatches` + `ignorePatchFailures` let the miss pass in silence
- **why**: the repo's test-fns patch (`runAttemptWithinBudget`, ehmpathy/test-fns#71) no longer applied
- **fix**: rekeyed the patch to `patches/test-fns@1.17.0.patch` (the 1.17.0 dist matches every hunk). the installed dist holds `runAttemptWithinBudget` at all 4 sites; the clamp test went red before, green after

### D4 — the `.log/` haste cut is gone
- **what**: `jestScratchExclusion.test.ts` reds: a stray `.snap` in `.log/` reaches the haste map, and reads as obsolete
- **how**: main's unit + integration configs listed `<rootDir>/\.log/`; the practice configs do not
- **why**: the practice owns the configs byte for byte
- **fix**: the seam restores the cut (D7). the clamp grows into `src/.test/jestRepoSeam.test.ts`, which pins every seam behavior per suite

### D5 — `stepRouteDrive` integration snapshots mismatch on temp dir paths
- **what**: 9 mask sites in `stepRouteDrive.simple.integration.test.ts` (6) and `stepRouteDrive.integration.test.ts` (3) leave the genTempDir path unmasked
- **how**: test-fns 1.17.0 names a temp dir `<ts>Z.r<hex>.<slug>.<hash>`; 1.15.7 named it `<ts>Z.<slug>.<hash>`
- **why**: the mask regex had no slot for the `r<hex>` segment
- **fix**: the mask takes an optional segment, `/\.temp\/genTempDir\.symlink\/[\dT.-]+Z\.(?:r[a-f0-9]+\.)?([^.]+)\.[a-f0-9]+/`

### D6 — thinker boot runs over budget; `roleBootClamps` snapshot drifts

### D7 — the practice configs drop jest behaviors main owed
- **what**: absent after the upgrade: the `.log/`, `.behavior/`, `.scratch/` haste cuts · `.mjs` transform, node_modules not exempt · the 30s unit budget · the `.agent/repo=.this/` skill suites · the brain tier pick once per run · `jest.retryTimes(2)` and attempt-agnostic snapshots on the live suites · the 240s acceptance budget · the 7-worker acceptance pool

- **why**: the practice has no repo seam
- **fix**: each practice config exports `asJestConfigOfRepo({ config, suite })` (`jest.repo.ts`), which adds the cuts, the transform, the budgets, the worker pool, `jest.repo.env.ts` (retries, budget, snapshots), and `jest.repo.prepare.ts` (the practice prepare, then the brain pick; it replaces `jest.brain.globalSetup.ts`). package.json drops `--runInBand` from the two acceptance commands. evidence: the full integration run shows `🦉 brain tier pick: held` and the 7 skill suites pass
