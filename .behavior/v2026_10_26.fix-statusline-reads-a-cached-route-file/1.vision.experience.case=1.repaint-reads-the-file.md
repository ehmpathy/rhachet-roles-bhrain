# case 1 — a repaint reads the file

happy · critipath · cell bound-once · fresh · repaint · many · — · —

## .narrative

the human works in one of 44 sessions on a shared box. they glance at the bottom of the screen
and read `🗿 5.1.execution.from_vision, review.peer, l1@i002 🔍` — the same words, the same glyph,
in the same place as yesterday. they notice no change in the line.

what they do notice is the box. integration suites that turned red under load on 2026-10-23 now
pass; the fans are quiet; `top` shows no row of node processes, one per seat, that climbs with
every message. the line costs them a glance, and costs the box a short bash read.

behind the glance: each repaint is one bash that reads the branch from `.git/HEAD`, reads the
route's status file, confirms no `.route/` ledger is newer, and prints its `line` field.

## .timeline

