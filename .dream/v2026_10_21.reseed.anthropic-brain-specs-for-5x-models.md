# 🌙 dream: anthropic brain atom specs for the 5.x models

- kind = reseed
- owner = ehmpathy/rhachet-brains-anthropic
- caught 2026-10-21

## .the cue that fired

`reflect.on.token.spend` prices each call from the brain atom's `spec.cost.cash`. the transcripts
it reads name `claude-opus-5-5`. a grep of the installed spec for any 5.x model returned no match.

## .the gap, precisely

- `rhachet-brains-anthropic@0.4.3` is the latest on npm (modified 2026-07-28)
- `dist/domain.operations/atoms/BrainAtom.config.js` holds no opus 5.x or sonnet 5.x config
- its `cache.get` is the flat 0.1× of input; opus 5.5 and sonnet 5.5 price a cache read at 0.05×
- `cache.set` holds the 5-minute write only; the 1h write has no field
- ⇒ every opus 5.5 / sonnet 5.5 call renders `unpriced` in the tool
- `getBrainAtomsByAnthropic()` — what `rhachet/brains` discovery returns — lists only the
  version-less aliases (`claude/opus`, `claude/sonnet`, `claude/haiku`); the versioned slugs
  (`claude/opus/v4.5`) live only in `CONFIG_BY_ATOM_SLUG`, which the sdk root does not export
- a `BrainAtom` carries no model id, so a consumer cannot match a transcript's `message.model`
  to an atom; it must derive a slug and hope the package declared that exact one
- ⇒ the consumer reads the versioned specs via a deep import of
  `rhachet-brains-anthropic/dist/domain.operations/atoms/BrainAtom.config`

rates seen on the provider's price page (webfetch, 2026-10-21 — a pointer, re-verify at the source):

| model | input | 5m write | 1h write | cache read | output |
|---|---|---|---|---|---|
| opus 5.5 | $4 | $5 | $8 | $0.20 | $20 |
| opus 5 | $5 | $6.25 | $10 | $0.50 | $25 |
| sonnet 5.5 | $2 | $2.50 | $4 | $0.10 | $10 |
| sonnet 5 | $2 | $2.50 | $4 | $0.20 | $10 |

## .the shape of the fix

1. add atom configs for opus 5.5, opus 5, sonnet 5.5, sonnet 5 (and fable / mythos 5.x if served)
2. set each `cache.get` per model, never as a derived 0.1× — the multiplier now varies by model
3. add a 1h write field beside `cache.set` (e.g. `cache.set.5m` + `cache.set.1h`), so a transcript
   whose usage names `ephemeral_1h_input_tokens` can be priced
4. list the versioned atoms in `getBrainAtomsByAnthropic()` (or export `CONFIG_BY_ATOM_SLUG`
   from the sdk root), and carry each atom's `model` id on the atom so a consumer matches by id
5. release; bump the dep here, and drop the deep import in `getTokenRatesByModel.ts`

source of truth beside the brain atom specs, which the vision forbids.
