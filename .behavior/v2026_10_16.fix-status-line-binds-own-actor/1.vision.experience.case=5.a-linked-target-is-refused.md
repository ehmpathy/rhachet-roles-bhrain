# case=5 · a linked target is refused

coordinates: L=split · T=link · feel=sharp · care=critipath

## .narrative

someone pointed `settings.of.repo.json` at another file. a write through it would land wherever it
points — perhaps a peer's file, perhaps the human's home. the init refuses to write, the same way
rhachet's own layout findsert refuses (`must be a real file`), and names the fix. it warns rather
than fails, so `rhx init` and `rhx upgrade` carry on with every other init (S2).

## .bdd

```
given a split layout whose settings.of.repo.json is a symlink
  when [t0] the init runs
    then stderr holds a `status = not configured` tree that names the link and the fix
    then the link and its target are unchanged
    then exit 0
```
