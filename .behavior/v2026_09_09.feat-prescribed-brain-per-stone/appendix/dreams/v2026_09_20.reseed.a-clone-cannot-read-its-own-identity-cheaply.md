# 🌙 dream: a clone cannot read its own identity without an 11s subprocess

- kind = reseed
- owner = `ehmpathy/rhachet`
- caught = 2026-09-20

## .the cue that fired

the wisher asked the plain question: *"does the brain set work? i.e., do we reliably set the
brain from route?"*

⇒ the `5.4` dogfood had answered **yes** — the chain closed end to end, and the brain-cli replied
`Set model to claude-opus-4-8[1m]`. but that yield measured **2 timeouts then 1 success** and
concluded the cap was *"genuinely exceeded by this host"*. n=2 on the fail side, n=1 on the pass
side. **that cannot tell a hard floor from a noisy one**, and the two take opposite repairs.

## .the gap, precisely

`applyStoneBrainOnEntry` gates its dispatch on `getCloneAddress`, which spawns
`rhx clone whoami` under `WHOAMI_TIMEOUT_MS = 2_000` (`getCloneAddress.ts:27`).

measured, `.agent/.notes/tool.probe-rhx-latency.js`:

| invocation | trials | min | p50 | max | inside 2s |
|---|---|---|---|---|---|
| `rhx clone whoami --output json` | 12 | 3891ms | **11224ms** | 13962ms | **0/12** |
| `rhx clone list --output json` | 6 | 16537ms | **19904ms** | 20524ms | 0/6 |
| `rhx --version` (bails early) | 8 | 1006ms | 1520ms | 2176ms | 0/8 |

⇒ 🔴 **a HARD floor, never a noisy cap.** the dogfood's attempt 3 was a tail event. there is no
cache — `getCloneAddress` spawns fresh every tick — so the feature's gate clears 0 times in 12.

### the cost is not `whoami`'s own work

`invokeCloneWhoami.js:38` reads `process.env[CLONE_ENV_KEYS.serial]`, does one disk lookup, and
one socket probe capped at 1000ms (`isCloneLive.js:20`). **`clone list` is slower still**, so the
cost is general to an `rhx` command invocation, not a defect in this command.

### 🔴 the value is already in the caller's own environment

```
RHACHET_CLONE_SERIAL = 442f54ca-6258-4818-85af-771123cf1dc2
```

read from this session's `process.env`, instantly. **the 11s subprocess exists to fetch a string
already in memory** — because the key that names it is rhachet-internal (`utils/cloneEnvKeys.js`),
and no SDK export surfaces it. measured: `rhachet`, `rhachet/actors`, `rhachet/brains`,
`rhachet/keyrack` carry **no clone-self accessor**.

## .the family — and this is the third instance

🔴 **one pattern, three times: a clone has no surface to read ITSELF, only surfaces built to read
a PEER.**

| the read | the peer instrument, and its cost | the self-read task |
|---|---|---|
| another clone's live brain | `clone whoami` | `#528` |
| another clone's transcript | `clone get` — a cwd heuristic that refuses on a tie | `#544` |
| 🔴 **its own identity** | `clone whoami` — an 11s subprocess | **`#545`** |

⇒ each peer instrument carries a cost that solves a **discovery** problem. a self-read has no
discovery problem, so it pays that cost for nothing.

🟡 **the durable lesson: when a self-read is routed through a peer-read instrument, the tell is a
cost with no matching question.** a cwd heuristic answers *"which of these is yours?"*; a
subprocess answers *"what does another process know?"*. a caller that already holds the answer
needs neither, and the giveaway is that the instrument's expense buys it no information.

## .the shape of the fix

🔴 **upstream, and dispatched** — three bars, each with a test, on `#545`:

1. **no subprocess** — an SDK accessor returns `{ serial, slug, actorHash }`; assert no exec fires
2. **inside a hook budget** — 12 trials, p100 < 50ms (today: 0/12 under 2000ms)
3. **fails loud outside a clone** — `ConstraintError`, never a synthesized serial

the cheaper alternative, which clears bars 1 and 2 by construction: **publish `CLONE_ENV_KEYS`**
so a consumer may read `process.env` without reach into `dist/utils/`.

### the local half, once either lands

`getCloneAddress` reads the in-process surface first and keeps the spawn as its fallback. the 2s
cap then stops to matter on the common path.

⚠️ **a larger cap is NOT the local fix.** the tightest hook budget is 5s and p50 is 11.2s, so the
cap would have to exceed the budget it sits inside.

## .why it is not done in this round

- **not clean.** a read of `process.env.RHACHET_CLONE_SERIAL` today reaches into another repo's
  private convention. it would work, and it would couple this repo to an undeclared key that may
  be renamed with no notice
- **the honest local move is the fallback shape**, and that is worth one round of its own once
  `#545` names the surface to prefer

## .what this re-prices

🔴 **the `5.4` dogfood's verdict needs a caveat it does not carry.** it reports the chain closed
end to end, which is true, and it reads as *the feature works*. **the mechanism works; the gate
in front of it does not clear on this host.** the yield's own measurement — 2 fails, 1 pass — was
the signal, and n=3 was too few to read it.

⇒ **a success rate quoted from 3 samples is a story, not a measurement.**
