# case=4 · a human's own status line stays theirs

coordinates: L=split · T=foreign, or G=foreign-statusLine · feel=sharp · care=critipath

## .narrative

a human already set a status line — in the repo's file, or in their own `~/.claude/settings.json`.
`--settings` outranks the user layer, so a write here would hide theirs. the init reads both
layers, finds a command that names neither `routeStatusLine` nor `route.status.line`, and leaves
both files intact: `🦉 as leaves fall · status = skipped`, with the layer and the command it found.

## .the limit — the check is per machine

`settings.of.repo.json` is committed, and it outranks the grove layer. the init reads the grove of
the machine it runs on, so a teammate whose own grove holds a `statusLine` still receives ours from
the commit, and ours hides theirs for them. the guarantee reads "on this machine". the fix is a
per-role status line upstream (`.dream/v2026_10_16.reseed.rhachet-role-declared-frame-lines-per-brain-cli.md`).

## .bdd

```
given a split layout whose settings.of.repo.json holds a foreign statusLine
  when [t0] the init runs
    then the file is byte-for-byte unchanged, no backup written
    then stdout says status = skipped, names the file and the command found
    then stdout names the fix to opt in: remove yours from that file, then rerun the init
    then exit 0

given a split layout with no statusLine, and a grove that holds a foreign statusLine
  when [t0] the init runs
    then settings.of.repo.json is unchanged
    then stdout says status = skipped, names the grove and the command found
    then stdout names the fix to opt in: remove yours from ~/.claude/settings.json, then rerun the init
    then exit 0
```
