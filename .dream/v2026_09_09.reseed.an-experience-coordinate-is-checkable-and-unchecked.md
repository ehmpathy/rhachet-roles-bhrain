## .the gap, precisely

`rule.require.experience-coverage` asks a catalog to cite a demo per cell. **it does not ask that the
citation be verified against the demo's own `given`.**

a coordinate marker — `case=5 [t2]` in a cell whose row is `conceded` and whose column is
`exhausted` — is a **claim about a step's `given`**, and only a read of that step can falsify it:

- no glob checks it — the file exists, the step exists, the markup parses
- no count checks it — the census is a **sum over markers**, so a wrong marker sums identically to a right one
- no type checks it — it is prose

⇒ **the census gets harder to trust as it gets more complete**, which is the signature of the defect.
a catalog with 135 cells and 28 markers has 28 unverified claims, and the reader who would catch one
is the reader who opens all 28.

### the three shapes it takes, and they need different repairs

| shape | what it is | the repair | census effect |
|---|---|---|---|
| **over-claim** | the cited step demos no cell at all, or a cell nobody walked | **drop** the marker | falls |
| **re-file** | the step is a real demo of a **different** cell | **re-point** it | none |
| **transpose** | two markers cite each other's demo | **swap** them | none |
| 🔴 **dangle** | the cited step **does not exist** in the cited case | re-point, or name the branch | none |

⚠️ **the middle two move no count, so an arithmetic check cannot find them.** only a read of the step
can. that is what makes this mechanizable-but-unmechanized rather than merely unchecked.

🔴 **the fourth shape is the cheapest to catch and was found last**, which is a fact worth its ink: a
`[tn]` absent from its own timeline needs no semantic check at all — a string match settles it. it
survived four peer rounds and a hand sweep because every reader who met it was busy with whether the
coordinate was *right*, never with whether it was *there*.

### 🔴 and the surface matters as much as the shape

the hand sweep audited the **matrix** — cells, refusal classes, actor rows — and round 4 found three
instances outside it:

| surface | count |
|---|---|
| a `.see also` line in a peer case file | 1 |
| the route's yield | 2 |
| a narrative aside in a case file | 1 |

⇒ **a checker must walk every `case=N [tn]` in the behavior directory, never only the catalog's own
cells.** the catalog is where the markers are *counted*; it is not where they all *live*.

### 🔴 and a repair can CREATE an instance

`i004`'s first find was **residue of `i003`'s repair**: a step was retagged `enter × answered ×
exhausted` in round 2, and a class-table row 150 lines away still cited it as a demo of
`enter × conceded`. the retag was correct; the sweep was absent.

⇒ **a coordinate retag is a RENAME, and a rename owes a grep.** `rule.always.fix-forward-under-scouts-honor`
asks whether a fix is safe and clean; it does not ask *"what else cited the thing I just moved?"*

## .the shape of the fix

**a checker, and the inputs are both structured text already.**

for each `case=N [tn]` marker in `inventory.of=experience._.md` (or `case=_.md`):

1. **read the cell's coordinates** from its position — the slab header gives the move (axis A), the
   row gives the debt state (axis B), the column gives the budget state (axis C)
2. **open `case=N.$slug.md`** and read step `[tn]`'s `given` / `when`, plus the file's ambient
   `given` block, which supplies whatever the step does not restate
3. **assert the three agree.** the `when`'s verb is the move; the `given`'s stated state is B; the
   ambient budget/rounds is C

it need not be perfect to earn its place. **the transpose and re-file shapes are the ones a human
read misses and a string match catches**, because the wrong marker is a *valid* coordinate that
names a *different* cell — exactly the case a proofreader's eye slides over.

⚠️ **two lower rungs are cheaper and each is worth its own line** (`philosophy.entoolment-is-the-pinnacle`):

- 📚 **a brief-level rung** — add to `rule.require.experience-coverage`: *"a retag is a rename, and a
  rename owes a grep of every marker that cites the retagged step"*. costs one paragraph, and it
  would have caught the `i004` instance outright
- 💪🔩 **a half-checker** — assert only that each cited `[tn]` **exists** in the cited case file. it
  catches naught found on this route, and it is a guard against the shape where a step is deleted
  and its marker outlives it
