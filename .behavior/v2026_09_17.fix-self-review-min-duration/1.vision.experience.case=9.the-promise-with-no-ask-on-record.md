# case=9 — the promise with no ask on record

**cell** `D0 = absent` · **feel** sharp · **care** **critipath**

> 🔴 **the only cell in the walk where every other axis has NO defined operand.** `D3` reads an
> mtime **against the trigger's `.since`**; `D5` reads elapsed **since the ask**. strike the ask and
> both read a file that is not there — so this is a **discriminant**, never a seventh axis, and the
> demo is what keeps its one cell covered.

## .the narrative

a driver arrives, is asked for a self review, reads, writes their articulation at the owed path.
then the stone is rewound — a peer review came back, or the wisher moved the scope.

**the rewind archives the ask. the articulation survives it**, because a review file is not a stone
artifact and no cleanup reaches it.

the driver still holds the slug. the promise is advertised as a **firm checkpoint that does not
invalidate**, so no line of the design tells them an ask must be re-minted first. they do the
natural act: they re-promise.

```
🍃 no ask on record
   │
   ├─ this review was never asked for, or its ask was rewound
   │  ├─ stone = 1.vision
   │  └─ slug  = all-done
   │
   ├─ a promise answers an ask. with no ask, two gates cannot run —
   │  the freshness bar has no date to measure, and the haste cue has no start
   │
   ├─ ask for it, and the guard hands you the path
   │  └─ rhx route.stone.set --stone 1.vision --as passed
   │
   └─ then promise again 🍵
```

### 🔴 .the "aha" — the wrong answer is not a pass, it is a LAUNDER

> **a gate with no datum does not fail open quietly. it MINTS the datum, and the mint is what
> clears the review.**

the adjudication's last act is `setSelfReviewTriggeredReport`. with no verdict in front of it, a
promise that fell through to that line would mint a fresh `.since` dated **now** — and then a
pre-rewind articulation reads as **fresh** against a timestamp that postdates it.

⇒ so the failure is not *"a check was skipped"*. it is *"an ask was manufactured to satisfy the
promise in front of it"* — **the freshness bar's own defect, entered from the other side.** a review
nobody requested clears, and the record afterward is indistinguishable from one that was asked for.

🟡 **that is what makes this a critipath at a frequency that reads like an alterpath.** a rewind is
uncommon; a laundered review is unrecoverable, because the evidence it was laundered is the very
timestamp the launder wrote.

## 🔴 .the verdict outranks even the PATH check — and that is D5's mirror, not its exception

`D5`'s invariant ranks a verdict the driver can **act on** above one they cannot: a driver told to
slow down when their file sits at the wrong path learns the wrong lesson and pays a round trip for
the right one.

here the order runs the other way, for the same reason:

| if the guard reported… | the driver's next move | what it costs |
|---|---|---|
| the path mismatch first | fix the path, promise again → **`challenge:unasked`** | a round trip to learn a lesson the **next** command supersedes |
| 🔴 the absent ask first | re-ask → and the ask's own emit **hands them the owed path** | naught. one command, and the path question answers itself |

⇒ **the driver's one move is the same whatever the path says.** so `challenge:unasked` is checked
before the declared-path diff, and the order is the contract
(`getSelfReviewChallengeDecision.ts` — `.note = ORDER IS THE CONTRACT`).

## .the bdd sketch

```
given [case9] a self review was asked for on 1.vision, slug all-done
  and  the driver wrote their articulation at the owed path
  and  the stone was then rewound, which ARCHIVED the ask
  and  the articulation survived the rewind

  then the precondition holds — asks before > 0, asks after == 0
       # the case is worthless if the ask survived; this pins that the setup
       # reached the state under test, via a REAL --as rewound, never a hand-unlink

when [t0] the driver re-promises the articulation that survived
  then the promise is REFUSED
   and stdout names the absent ask and both operands (stone, slug)
   and stdout names the two gates that cannot run
   and stdout names the one command that recovers — and it is the ASK
   and stdout does NOT hand out the promise guide     # they must ask, not promise
   and stdout does NOT reproach haste or the file     # the file may be perfect
   and 🔴 NO ask was minted behind the driver's back   # the launder assertion

when [t1] the driver declares the WRONG path, still with no ask
  then the absent ask OUTRANKS the path mismatch
   and stdout names no path diff                      # D5's mirror, by if-order

when [t2] the driver re-asks, re-reads, re-saves, and promises
  then the verdict is gone                            # a precondition, never a wall
```

🔴 **`[t0]`'s last clause is the one that matters most, and it is the easiest to omit.** a clamp
that proves only the **refusal** would stay green through an edit that refuses *and still mints*.
the assertion is over the ask markers on disk after the refused promise: `asks == []`.

🟡 **and `[t2]` is the second-easiest to omit.** without it, a later *"refuse harder"* edit could
make the state **unrecoverable** and no test would notice. `[t2]` pins the way **out**.

🔴 **the acceptance case rewinds for real.** the reachability argument is a claim about
`archiveStoneSelfReviewTriggers`, and only a real `--as rewound` tests it. a fixture that unlinks
`.since` by hand would prove the verdict **renders** and prove the state **reachable** not at all.

## 🟡 .why this cell was found at VERIFICATION rather than at the walk

the six driver axes were walked as a product, and a product cannot surface a coordinate that
**deletes** one of its own operands. `D0 = absent` is exactly that: it does not pick a position on
`D3` or `D5`, it removes the thing they measure.

⇒ **the transferable form:** a latent axis whose positions strike an operand **cannot inherit a
verdict** from the space beside it. `D8` (`cause`, yield item 12) was found late and every cell of
its new slice inherited a verdict already argued, so the re-walk could be deferred with no loss.
`D0` inherited **naught** — every invariant in this walk is written over operands it deletes — so
its one cell was a real gap, and it owes this demo rather than a row.
