# seed S08 — use a slug instead of the level

## .said

> maybe we can simplify that and use a slug instead

## .settled

**drop the `rN` level from the self-review articulation path; key the path by its slug alone.**

```
before   $route/review/self/for.$stone._.r$index.$slug.md
after    $route/review/self/for.$stone._.$slug.md
```

⇒ this is the **same key the promise already uses** — `(stone, slug)`, hashless
(`getStonePromises.ts:12`). so the articulation path and the promise artifact come to agree, and
the one input a driver cannot compute leaves the path entirely.

🔴 **it retires a class, not an instance.** the off-by-one, the level pitfall, and the *"guess the
level"* cell all exist because a computed ordinal sits in a path a human writes by hand. with no
ordinal, none of them can occur.
