# case=2 — get reports the state

feel × care: happy × critipath · actor: clone · ⇒ inventory rows `get · off` and `get · on`

## .narrative

a clone boots into an unfamiliar repo and wonders whether its stops will be held for the glossary.
it asks, and the answer costs one read and no write:

```
$ rhx learn.terms.hook get
🦉 stillness

📜 learn.terms.hook get
   ├─ status = disabled
   ├─ settings = .claude/settings.of.repo.json
   └─ to turn it on: rhx learn.terms.hook enable
```

in kai's repo, after case=1, the same question answers:

```
📜 learn.terms.hook get
   ├─ status = enabled
   ├─ settings = .claude/settings.of.repo.json
   ├─ hook = Stop → learn.domain.terms --when hook.onStop, guarded on the learner link
   ├─ reaches = sessions that hold the learner
   └─ to turn it off: rhx learn.terms.hook disable
```

## .[tn] sketch

```
given('[case2] a repo whose settings hold no term hook')
  when('[t0] `rhx learn.terms.hook get` runs')
    then('exit 0; stdout reports status = disabled and names the enable command')
    then('the settings file is byte-identical after the run')
given('[case2b] a repo where the toggle was enabled')
  when('[t0] `rhx learn.terms.hook get` runs')
    then('exit 0; stdout reports status = enabled, the hook, and the disable command')
```
