# 🌙 dream: extract the ten `formatRouteDrive*` render operations into leaf transformers

- **kind** = `fix`
- **owner** = `ehmpathy/rhachet-roles-bhrain`
- **caught** = 2026-09-17

## .the cue that fired

`arch-opport-decomposition`, verbatim:

> *"Extract `formatRouteDrive*` into one-operation-per-file transformers in `route/drive/` and have
> `stepRouteDrive` import them, so the narrative is purely composition and the render bytes are
> testable where a transformer belongs."*

## .the gap, precisely

`stepRouteDrive.ts` declares ten pure render operations as private closures in its own body:

```
formatRouteDrive              formatRouteDriveBlocked
formatRouteDriveMalfunction   formatRouteDriveExhausted
formatRouteDriveMalfunctionEscalate
formatRouteDriveEscalate      formatRouteDriveBlockReason
formatRouteDriveNudge         formatRouteDriveComplete
formatRouteDriveUnbound
```

each is a transformer (`define.domain-operation-grains`) and owes its own file and test. the
convention already holds in `route/drive/`: `formatRouteDriveMixedHalt.ts` and
`formatRouteDriveWhere.ts` are named files with tests.

| cost | how it lands |
|---|---|
| untestable at leaf grain | a closure has no import path; its bytes are provable only via a full drive run |
| unrecomposable | no other surface can render a drive body without a re-derive |
| not narrative | a reader who follows the halt branch lands in 40 lines of string assembly |

## .the shape of the fix

- one file per operation under `route/drive/`, each with a `.test.ts`
- lift each closure's free variables into its `input:` before the move — the one place a move can
  change behavior
- **the check:** `__snapshots__/stepRouteDrive.integration.test.ts.snap` pins every byte, so a
  faithful move is a zero-diff snapshot run

## .why it is not done in this round

| | answer |
|---|---|
| **SAFE?** | 🟡 partly — each lifted variable is a risk, and the snapshots bound it |
| **CLEAN?** | 🔴 no — 20 new files, the orchestrator restructured, and all ten predate `brain:` |

⇒ a smuggled refactor under this feature's name. the reviewer graded it a nitpick, aimed at the
diff's neighbours.
