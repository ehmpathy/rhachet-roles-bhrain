## .the gap, precisely

**a review's target set is `--diffs since-main`, and the round's own record lands inside it.** so
the artifacts a driver is REQUIRED to write in order to discharge a review are artifacts the NEXT
review must read.

⚠️ **a first draft of this dream blamed `$route/.reviews/**` and was WRONG** — the token breakdown
the guard itself writes shows no `.reviews/` entry at all; that dir is already out of scope. **the
measured slices are these, from r008's i016 breakdown of a 796.4k target set:**

| the rule | where its artifact lands | measured |
|---|---|---|
| `rule.always.itemize-the-fulcrums-you-best-guess` | `$route/.fulcrums/` | **77.8k · 9.8%** |
| `rule.always.catch-dreams-for-followups` | `.dream/` **and** `$route/dreams/` (a symlink) | **63.2k + 33.8k · 12.1%** |
| `rule.always.archive-the-wishers-words-verbatim` | `$route/.seeds/` | inside `.behavior/` |
| the stone's own progress record | `$route/*.yield.md` | inside `.behavior/` |
| ✅ `rule.always.converge-with-reviewers.via-a-taken-per-point` | `$route/.reviews/` | **already excluded** |

```
.behavior/  312.1k  39.2%     .dream/  63.2k  7.9%     .fulcrums/  1.8k  0.2%
⇒ the round's own record = 377.1k = 47.4% of the target set
```

🔴 **the sharpest single line: `$route/dreams/**` is a SYMLINK to `.dream/**`, so 33.8k of it is
counted TWICE in one prompt.** that alone is 4.2% of the window, for zero information.

**every rule above is correct, every one is mandatory, and every one enlarges the corpus under
review.**

⇒ on a branch with commits the term is damped — `since-main` computes against the merge-base, so
committed work leaves the diff. **on a branch with zero commits it compounds without bound**, and a
driver cannot commit without a human grant (`rule.forbid.commits-the-route-did-not-ask-for`).

```sh
rhx grepsafe --pattern 'since-main' --path src/domain.operations
rhx route.mutate grant get
```

🔴 **the sharpest form: a review conversation is a WRITE to the thing under review.** the mechanism
is not exotic and it is invisible until measured, because each individual `.taken` is small — the
seven here cost ~28.7k tokens, which is 2.7% of the window, per round, forever.

## 🔴 .why this bites harder than an ordinary scope defect

**it inverts the incentive the whole review ladder runs on.** a driver who answers thoroughly — a
`.taken` per point, a dream per deferral, a fulcrum per judgment call — pays a larger context tax
next round than one who answers tersely. ⇒ the same shape as the defect **this very wish exists to
repair**: the self-review clock charged the driver who repaired the artifact.

⚠️ **and the terminus is a hard wall, not a slow degradation.** at 94.6% and +4.4 a round, two more
rounds of correct behavior make every unbound lane permanently unreadable. the lane does not
degrade — it stops.

## ✅ .the fix, APPLIED per-guard on this route

the grant arrived, and the seven dark lanes now carry:

```
--paths-wout '.behavior/**' --paths-wout '.dream/**' --paths-wout '.fulcrums/**'
```

**the deliverable is untouched** — every `src/`, `blackbox/`, and snapshot file stays in scope.
`behavior-intent-coverage` and `arch-smell-scopeleaks` keep the wish and yield as explicit `--refs`,
so each still grades the code against the intent; the intent is **supplied** rather than scanned.

⇒ that is the per-route mitigation, and it works today for any author who holds the grant.

## 🔴 .the fix that is NOT applied — the default

**a per-guard `--paths-wout` is a workaround every route must re-discover.** the cure belongs
upstream, in whatever mints a route's guards, so no future driver pays this at all. three seams,
cheapest first:

1. 🔴 **ship the exclusions in the guard TEMPLATE** — a route's generated peer lanes carry
   `--paths-wout` for the round-record dirs from birth. narrowest change, zero engine risk, and the
   drive believes it is the right one
2. **default it in the scope computation** — `$route/.fulcrums/**`, `$route/.seeds/**`,
   `$route/dreams/**` join `.reviews/**` as out-of-scope unless a lane opts back in. ⚠️ weigh this
   one: a reviewer may legitimately want to grade whether a fulcrum was itemized honestly
3. 🟡 **de-duplicate the symlink regardless of the above** — `$route/dreams/**` resolves to the same
   bytes as `.dream/**`, and a target set that counts both is wrong under **any** policy. this is a
   defect rather than a preference, and it is worth its own repair

## .why the default is not done in this round

the SAFE/CLEAN test (`rule.always.fix-forward-under-scouts-honor`):

- **SAFE — no.** the target-set computation is the input to **every** review on **every** route. a
  change there changes what every rubric in every repo reads, and the drive has one branch's
  measurement
- **CLEAN — no.** it touches the review scope operation, its acceptance snapshots, and the guard
  contract — a subsystem this wish never opened, in a diff already ~250 files wide

⇒ deferred, and because the SAFE test is what fails it owes a fulcrum as well as this dream. it is
recorded under **`F21`**, whose `D` branch this measurement decided.

🟡 **and seam 1 is owned elsewhere** — `ehmpathy/rhachet-roles-bhuild` mints the route templates, so
that half is dispatched there rather than adopted here (`rule.always.scope-onetime-lessons-to-the-behavior`).
