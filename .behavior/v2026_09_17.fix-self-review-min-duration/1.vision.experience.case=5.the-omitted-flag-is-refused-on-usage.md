## .the narrative

a driver types the promise command from memory and omits `--into`. the guard refuses **before it
touches the filesystem**, and the refusal is a usage error, not a review verdict:

```
🗿 --into is owed
   │
   ├─ a promise names the file it promises for
   │
   ├─ the owed path is
   │  └─ $route/review/self/for.3.3.blueprint._.has-questioned-assumptions.md
   │
   └─ run
      └─ rhx route.stone.set --stone 3.3.blueprint --as promised \
           --that has-questioned-assumptions \
           --into $route/review/self/for.3.3.blueprint._.has-questioned-assumptions.md
```

🟡 **the path carries no `r2` any more** — `S12` removed the level, so the owed path is computable
from `(stone, slug)`, which the driver already holds.

the refusal **hands them the answer**. the cost of the required flag is one copied line; the
purchase is that every later promise is a **checkable claim** rather than a bare assertion.

### .the "aha"

> **the flag is not a hoop. it is the only way the driver and the guard can disagree out loud.**

with `--into` absent, a driver who wrote to the wrong path and a driver who wrote to no path are
**indistinguishable to the guard** — both produce "absent", and the guard cannot part them because
it was never told what the driver believes. the flag makes the belief visible, and a visible belief
can be corrected.

## 🔴 .the tension this case must not hide — and the verdict that resolved it

`rule.prefer.defaults-match-common-case` says a required flag whose value the surface could infer
is friction with no payoff — and the guard **can** infer this path; it computes it already.

⇒ this cell's own counter was **detection**: *"an inferred path always matches itself, so it detects
no defect. but that argument buys the flag exactly one case — `case=3` — and it charges every promise
in the repo for it."*

🔴 **that counter was refuted mid-round and the flag was ruled in anyway.** `S12` removed the `rN`
level, so the path became computable and the one case the detection argument bought
(`case=3`'s level pitfall) went **unreachable** — the drive read that as fatal and revised its guess
to *optional*. `S15` ruled **required**, on a reason neither this cell nor `F03` held:

> **a check with ONE operand can report a failure. it takes TWO to report a difference.**

| the guard holds | the best it can report |
|---|---|
| the computed path alone | a **boolean** — *"the articulation is absent"*. true, and it names no cause |
| 🔴 the computed path **and** the declared one | a **diff** — which segment diverged, and the move that closes it |

⇒ so `rule.prefer.defaults-match-common-case`'s premise does not hold here: **the surface can infer
the path it wants, and cannot infer the path the driver used.** those are two quantities, and the
rule grades a flag that duplicates one.

⚠️ **and the friction is real, and stays on the record.** a required flag pulls against `S04`'s
*"eliminate friction"*, in a wish whose subject is friction removal. the residual is one copied line
per promise, and it is now a **stated** price rather than an unnoticed one.

## 🟡 .the assertion a reviewer should hold this to

**`and no trigger report is mutated`.** a usage error must not burn an attempt. if it did, a driver
could exhaust the liveness hatch on typos and reach a state only a human could clear — which would
re-create, in a new place, the exact defect this wish repairs.

### 🔴 `S11` inverted the direction of the harm; `S13` and `S15` each raised it again

under the clock, a burned attempt drove the driver **toward** the hatch — a leak in a gate. the
attempt count is now **half the gate condition**, so a burned attempt is a leak of the gate itself:

| | a usage error that mutates the report |
|---|---|
| **B** — the clock gates | the driver drifts toward the hatch. a slow leak |
| 🔴 **`S11`** — the count gates | 🔴 **the driver clears with no read at all.** two typos is a passed review |
| 🔴 **`S13`** — `attempts == 0 ∧ elapsed < 30s` | 🔴 **ONE typo is enough**, and only for the hasty driver. the count is half the condition, so a single leaked increment retires the challenge |
| 🔴 **`S15`** — `--into` required | 🔴 **the exposure is now on EVERY promise.** a mandatory flag is a mandatory usage-error surface |

⇒ **so this assertion stops to be a liveness nicety and becomes the gate's integrity condition —
twice over.** `S13` halved the number of leaks it takes; `S15` multiplied the occasions for one.

🟡 **and it generalizes past `--into`.** the clause a reviewer should actually hold the code to is
**only a promise the guard adjudicated increments the count** — a stronger statement than this cell's
own scope, and it is why `F08`'s entry carries the fork case as a bypass rather than a delay: M lanes
on one slug arrive in seconds.

🔴 **this is the round's sharpest interaction between two independent rulings**, and neither seed
names it: `S13` made the count load-bearing and `S15` added a way to burn it. ⇒ the invariant is
stated in full in `1.vision.yield.md` rather than in either seed, because it is a property of the
**pair**.
