# 🌙 dream: a daily spend budget for the instinct daemon

- kind: feat
- owner: ehmpathy/rhachet-roles-bhrain (role=subconscious, skill=instinct.of)
- caught 2026-11-27

## .the cue that fired

the wisher asked for a budget to stop a runaway token cost, then asked that it be caught for a follow-up.

## .the gap, precisely

the route bounds each ask (an output cap at the 500-token gate, and a timeout that fails open). it does not bound the sum: a tree with every instinct enabled and hard, over a long day of stops, has no cap on total cash.

## .the shape of the fix

- a cash cap per tree per day, held beside the toggle state
- set by `rhx instinct.of --role <role> set --budget <cash>/day`; `get` reads it back as spent of cap
- checked before the brain is called, from the sum in `.log/bhrain/instinct/` that `rhx instinct._.cost` already reads
- at the cap: the ask is skipped (zero cost), the stop passes, and the seat gets one `say` that names the cap and the command to raise it
- the default cap is set from the first metered week of the trail, never guessed

## .why it is not done in this round

the wisher deferred it. it also needs a metered trail to set its default, and the trail ships in this route.
