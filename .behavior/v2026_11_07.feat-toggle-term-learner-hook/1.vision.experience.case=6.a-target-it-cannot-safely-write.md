# case=6 — a target it cannot safely write

feel × care: sharp × critipath · actor: any · ⇒ inventory rows `enable · link` and `enable · malformed`

## .narrative

a clone runs `enable` in a repo where `.claude/settings.of.repo.json` is a symlink to somewhere
else. a write through it would land in a file the toggle does not own. it refuses, fast, before any
write, and teaches the fix:

```
$ rhx learn.terms.hook enable
✋ ConstraintError: the settings target is a link, so learn.terms.hook will not write through it
   ├─ settings = .claude/settings.of.repo.json
   ├─ points to = /elsewhere/settings.json
   └─ fix: replace the link with a real file, then rerun `rhx learn.terms.hook enable`
```

exit 2. in another repo the file holds a trail comma a human left, so it does not parse:

```
✋ ConstraintError: the settings target is not valid json, so learn.terms.hook will not rewrite it
   ├─ settings = .claude/settings.of.repo.json
   └─ fix: repair the json, then rerun `rhx learn.terms.hook enable`
```

exit 2, no write, no backup made. the same refusal guards `disable` and `get` — a read that cannot
parse the file cannot honestly answer `disabled`.

## .[tn] sketch

```
given('[case6] a split layout whose settings.of.repo.json is a symlink')
  when('[t0] `rhx learn.terms.hook enable` runs')
    then('exit 2; stderr opens with ✋ ConstraintError and names the link and the fix')
    then('the link and its target are byte-identical')
given('[case6b] a settings.of.repo.json that is not valid json')
  when('[t0] each of enable, disable, get runs')
    then('exit 2; stderr names the file and the fix; the file is byte-identical')
```
