### what `[t0]`'s ban covers, since the sweep found a legal case that looks identical

`case=6`'s example carries `2.7.tmux` — the same kind of stone id — and it is not a violation. the difference is not the term; it is **where the term sits relative to what the reader must act on:**

| where the reference sits | verdict |
|---|---|
| inside the **answer** or the **ask** — the part the reader acts on | **banned.** it makes the actionable line unreadable in one pass |
| inside an explicitly-skippable trailer — *"the detail, if you want it"* | **legal.** the reader was told they may skip it, and a reader who opts in has already accepted the lookup |

⇒ so `[t0]`'s ban is scoped to the lines that carry the load, never to every token in a message. `case=6`'s ask block is jargon-free and its optional trailer is not, which is the shape the rule wants rather than an exception to it.

🟡 stated here rather than left implicit, because `2.1.criteria` inherits `[t0]` verbatim — and an unscoped *"no internal jargon"* acceptance line would fail `case=6`'s own correct example.

🟡 the last line carries a real ask, so it carries the treatment — and that is the repair `i009` made. the example previously read `⭐ ask — none. this is an answer.` above an unstarred offer, which inverted `case=6`'s rule on both halves:

| `case=6` says | the old example did |
|---|---|
| `[t1]` a message with **no** ask carries **no** treatment | stamped `⭐` to announce an absence |
| `[t0]` a message **with** an ask carries the treatment | left the actual ask — *"say the word"* — unmarked |

⇒ **an offer IS an ask**, which is what made the old line wrong rather than merely redundant. the two demos now agree: **the marker tracks the ask, and an absence gets silence rather than a marker that says `none`.**
