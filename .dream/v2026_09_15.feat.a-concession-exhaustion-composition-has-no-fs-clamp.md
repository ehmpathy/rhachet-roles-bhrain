## .the gap, precisely

the divergence itself is unclampable at runtime, by construction:
- `getRouteDriveExhaustedMessage.ts:63-82` reads `concession` once, feeds it to both `stdout`
  (`:70-78`) and `blocksStop` (`:82`). the old two-read path is gone.
- with no persisted-reason read to disagree with the live one, no fixture can drive stdout and
  blocksStop apart. a runtime clamp on the divergence would be green-before — toothless, the
  acceptance-#5 case the vision §5 rules as "report verified, do not ship a fake clamp."

what IS clampable, and absent, is the end-to-end fs composition: for an exhausted lane with a live
`better` concession, `getRouteDriveExhaustedMessage` yields `blocksStop: true` + the concession-shaped
stdout; for a `none` lane, `blocksStop: false` + the human-wait stdout. that clamp has teeth against
a flipped comparison (`=== 'better'` → `!==`) or a mis-routed render branch.

**checkable:** no `getRouteDriveExhaustedMessage*.test.ts` exists (`Glob` returns none), and no
`.test.ts` under `src/domain.operations/route` references `getRouteDriveExhaustedMessage`.

## .why it costs more than the marginal lock it buys

every constituent of the composition is ALREADY clamped, exhaustively:
- `computeConcessionExhaustionKind` — 8-case unit clamp (`getStoneConcededLaneSlugs.test.ts`).
- `asRouteStoneDisposition` — the pure classifier (`asRouteStoneDisposition.test.ts`).
- the render — `formatRouteDriveHalts.test.ts` case1b / case1c / case2.

so the composition clamp locks one link: that the SAME `concession` feeds stdout and blocksStop —
a 3-line link the shared `const` already guarantees structurally. the marginal regression it
catches is narrow; the fixture it demands is wide.

## .the shape of the fix

an integration test on the `genRouteScene` harness (`getRouteDriveBlockerMessage.integration.test.ts`),
extended to write:
1. a stone guard with peer-review levels + budgets (so `getCurrentPeerMeters` yields an exhausted lane).
2. an exhausted meter jsonl (`.route/reviewPeerMeters.jsonl`) at rounds ≥ budget.
3. a `passage.jsonl` stance row — `{ status: 'conceded', reviewer, about, given, severity }` — keyed
   to the live given hash (mirror the hash-first order the harness already uses).
4. the given files, keyed to the same hash.

two cases: `[better]` → assert `blocksStop === true` + concession-shaped stdout; `[none]` (no stance
row) → assert `blocksStop === false` + human-wait stdout. verify teeth: flip `:82` to `!== 'better'`
→ `[better]` goes red.

## .why it is not done in this round

**safe? yes. clean? no.**

- the divergence defect is structurally impossible now, and every constituent classification is
  exhaustively clamped — so the composition clamp guards a residual, not the reported defect.
- the fixture is heavy and fragile: it ripples into guard-config construction, meter jsonl format,
  and passage jsonl stance-row format — three fixture surfaces this change does not otherwise open.
  under the SAFE/CLEAN test (`rule.always.fix-forward-under-scouts-honor`) that is "not clean," so
  it is caught rather than smuggled into an unrelated round.
