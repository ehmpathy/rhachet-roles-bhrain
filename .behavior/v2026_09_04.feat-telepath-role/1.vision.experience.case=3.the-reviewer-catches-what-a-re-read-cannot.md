# case=3 · the reviewer catches what a re-read cannot

**cell** = `driver · reviewer · sharp · complete · file`
**feel** = sharp · **care** = critipath (`freq` = every stone that emits a yield · `cost` = an unread reviewer that grades clean)
**issues** = #394 · #386

## .the narrative

a driver finishes `1.vision.yield.md` and signals `--as arrived`. the guard fires its peer reviewers. one of them is new:

```sh
rhx review.by --role telepath --for prose-density
```

the driver believes the yield is terse. it re-read the file twice.

the reviewer returns:

```
🦉 not even a vole

🔍 review.by --role telepath --for prose-density
   ├─ rules: 4
   ├─ targets: 3 files
   └─ summary
      ├─ 2 blockers
      └─ 1 nitpick
```

the two blockers:

1. `§.why the reviewer` restates a claim `§.what` already made — one claim, two paragraphs
2. `§.evaluation` carries a dated measurement in place; rehome to a `case=N` and cite it

the driver's first reaction to blocker 1 is that it is wrong. those are two different points — one names the mechanism, the other names its cost. it can feel the distinction as it reads them.

⇒ and that feel is the defect, not a defense against it. the driver wrote both paragraphs, so on re-read its *intent* fills the seam between them; the reviewer has no intent to consult, so the seam is all it sees.

🟡 so the choice is whether to argue or to re-read as a stranger, and it is a real fork — a `[REFUTE]` is legitimate and costs one round. the driver takes the second: it reads the two paragraphs against the question *"what does a reader who did not write this take from them?"* and the distinction it felt is absent from the page.

it fixes both, writes a `.taken.by_self` per point, and re-arrives. the reviewer returns `0 blockers / 0 nitpicks`, and the stone passes.

⇒ **what it keeps is not the fix — it is that its own confidence on a re-read counts for naught**, and that is the one lesson only a second reader can teach.

## .why a hook cannot serve this

| the rule | the defect lives in | a hook sees it? |
|---|---|---|
| lowercase, shouts, gerunds | one **token**, in the edit itself | yes — the edit carries the violation |
| chronological accretion | the **relation between paragraphs**, across the whole doc | no — the edit is locally correct |

**every append that accretes passes a per-edit check.** each new section is true, answers a real correction, and reads clean alone. the violation is that a later paragraph restates a claim an earlier one already made.

⇒ the mechanism must **hold the whole document at once** and ask *"does this state one claim?"* that is a reviewer, never a hook.

## .why the author cannot serve it either

> a re-read re-reads the author's **intent**, and the intent fills the seam. a reviewer has no intent to consult, so the seam is all it sees.

measured 2026-08-30 on this repo, branch `beav/feat-adopt-seeded-briefs` — seven passes against `rule.require.timeless-lessons` over ~60 briefs:

| surface | passes | blockers |
|---|---|---|
| role briefs | v2 → v5 | 3 → 1 → 1 → **0** |
| `role=any` | v5 → v7 | 3 → 1 → **0** |

each pass ran 50–120s at ~$0.003–0.016. total under five cents.

against that: six prior rounds in which the author re-read their own briefs caught none of it. the human caught three by hand before they mandated the sweep.

🟡 **one result is decisive: v6 flagged text the author was certain they had already fixed.** the fix had been applied through a `.agent/` symlink into `dist/` and silently reverted by the next build. only a reader with no memory of the edit could surface it.

## .the bdd timeline

```
given [case3] a route whose guard declares a telepath peer reviewer
  and  a driver that has emitted a yield
  and  telepath's canon resolves in this repo

when  [t0] the driver signals `--as arrived`
then       the guard runs `rhx review.by --role telepath --for <rubric>`
 and       one rubric runs per invocation
 and       stdout carries a numeric count for blockers AND nitpicks

when  [t1] the reviewer finds a restated claim across two paragraphs
then       it reports a blocker that names both paragraphs
 and       the guard tallies it and holds the stone

when  [t2] the driver revises and writes a `.taken.by_self` per point
then       the reviewer re-reads with the articulation and the diff in context

when  [t3] the reviewer returns 0 blockers and 0 nitpicks
then       the guard caches the clean reviewer on the artifact hash
 and       the stone passes

when  [t4] the driver re-arrives with an unchanged artifact
then       the guard reuses the cached clean reviewer
 and       no brain cost is paid twice
```

## .the cue this earns

> **after any round where a correction was answered by an APPEND rather than a revision, run the rubric.** a re-read will pass it.

per `research.selfreview-effectiveness`, a when-then cue scores `d ≈ 0.65` where a principle alone scores `d ≈ 0.05`. **the cue is the deliverable; the reviewer is what gives it teeth.**

## 🟡 .the one flag that must never appear

```sh
--optional rules    # 🔴 forbidden for a telepath rubric
```

it turns a zero-match rules glob into a `🌙 skipped` that renders `0 blockers / 0 nitpicks`, exit 0 — which a guard tallies as **approved**. that is INV-1/2/6 in the inventory, and `case=5` demonstrates the correct behavior instead.
