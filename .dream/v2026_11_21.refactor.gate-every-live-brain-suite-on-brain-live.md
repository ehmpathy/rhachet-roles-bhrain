# 🌙 dream: gate every live-brain suite on BRAIN_LIVE

kind: refactor · owner: rhachet-roles-bhrain · caught 2026-11-21

## .the cue that fired

the reminder suites failed at setup on a keyless host: `jest.integration.env.ts` sourced every `ehmpathy.test.*` key in strict mode, for suites that call no brain. that is an ungated test.

## .the gap, precisely

- the setup is now strict only under `RUN_BRAIN_TEST` (`BRAIN_LIVE=true`), and lenient else
- a suite that DOES call a live brain is not yet gated per test. on a keyless host it fails at the brain call, not at setup. it should skip unless the named flag targets it

## .the shape of the fix

- census every integration and acceptance suite that reaches a live brain (`genContextBrain`, `rhx review`, reflect)
- wrap each live-brain `given`/`when` in `given.runIf(RUN_BRAIN_TEST)`, or inject a fake brain where the brain is incidental
- CI sets `BRAIN_LIVE=true` on the tier that owns live-brain proof

## .why it is not done in this round

it spans every review and reflect suite repo-wide, well outside the one-daemon-per-clone wish. the suites this wish touches already run green keyless.
