# experience dimensions: memory.guard

## .the axes — each closed, each orthogonal

| axis | positions (closed) | orthogonal because |
|---|---|---|
| **actor** | clone · human | the clone meets the hook per call; the human meets only its notice. either can occur with any other cell |
| **payload** | command (Bash) · path (Write, Edit) | the hidden axis under `verb` and `token`: only a command string carries them. named, so the two below are conditioned on it explicitly rather than by footnote |
| **verb** (payload=command) | none · redirect (`>`, `>>`, `>|`, with an optional `N` or `&` before) · copy (`cp`, `mv`) · tee (`tee`, `teesafe`) | which write mechanism the command holds, and so how it is graded: cp and mv blunt, by any memory path beside them; redirect and tee by where their target lands |
| **memory role** | write-target (the verb lands in memory) · read-only (memory named, the write lands elsewhere or no write) · absent (no memory path) | where memory sits relative to the write; any verb can pair with any role, save `none × write-target` (no write, no target — impossible) |
| **token** (payload=command) | absent · fd-dup (`N>&M`, `>&N`) · fd close (`>&-`) · quoted arrow (`=>`, `->` inside a quoted pattern) · quoted bare `>` (a comparator inside a quoted pattern, e.g. `awk '$1 > 5'`) | the tokens that hold a `>` yet are NOT file redirects; the closed set the redirect grammar must refuse. independent of verb and role |
| **redirect place** (verb=redirect or tee, memory named) | absolute or home path · relative path · `$var` path · operands unreadable (tee fed by `xargs` or `find -exec`) | whether the guard can say where the write lands from the command string alone. a tee operand is placed exactly as a redirect target is. only `relative` reads the next axis |
| **bash cwd** (redirect place=relative) | known outside memory · known inside memory (the harness `cwd`, or a `cd` into memory) · moved outside memory by a `cd` · unknown (no `cwd` field · a `cd` the fold cannot pin · past the tracked cap) | the base a relative path resolves against. set by the harness, then moved by `cd` across segments; independent of the anchor axis, which places the skill, not the write |
| **act** (derived, blocked verdicts only) | write · copy · unplaced | what the blocked verdict says happened; it decides the nudge text. never chosen by the caller, so it holds no cells of its own: each act is walked through the rows that produce it |
| **payload size** | within the env cap · past the env cap (~128KB) | whether the payload can ride the environment; independent of what it says. the guard hands it to node on stdin, so size must not vary a verdict |
| **guard health** | runs · not linked · link dangles · skill file unrunnable (syntax fault · empty · cut short) · node absent · setup step exits 2 · cli absent · module fails to load · throws as it loads · throws as it runs · exits an unknown code · exits a stray 2 · timed out · timed out on a host that lacks `timeout` · host `readlink` lacks `-f` | whether the guard could execute at all; independent of what it was handed. the last position is a host quirk the guard absorbs: it still judges, so it is walked as a health position, not as a fault |
| **input** | well-formed · empty · malformed · valid json that is no tool call · unreadable | the hook's stdin; a healthy guard can get bad input and a broken guard good input |
| **anchor** | env=root + cwd=root · env=root + cwd=subdir · env=elsewhere · env unset + cwd=root · env unset + cwd=subdir | where the hook looks for the skill. `CLAUDE_PROJECT_DIR` and cwd cross, since `${CLAUDE_PROJECT_DIR:-.}` falls back to cwd; the second position is the drifted cwd after a `cd` |

## .the walk, and where it collapses

the full product is large; seven collapses keep it exact, each stated:

1. **guard health ≠ runs** → the guard never reads the payload, so payload, verb, role, token, place and size do not vary the outcome. one cell per fault, plus one cell that pins the forbidden outcome, plus the one host quirk that still judges. the outcome of every fault is the same: exit 1, one stderr line `📜 memory.guard: could not run (<cause>); call allowed. fix: <fix>`, never exit 2. the cell names what varies: the cause and the fix.
2. **input ≠ well-formed** → no tool to judge. one cell per bad input (4). empty stays silent (exit 0); every other bad input is a blind spot the guard names (exit 1).
3. **anchor** only decides whether the skill is found. anchors that find it behave as the baseline (`env=root + cwd=root`); anchors that miss it behave as `not linked`. one cell per non-baseline anchor (4), each verdicted on that basis; the drift cell is walked with a memory write, since that is the act a miss would let through.
4. **token** never changes a verdict — that is the invariant under test. so token is walked against the cells it could corrupt: `verb=none` × role ∈ {read-only, absent} (a read must stay a read: 2 tokens × 2 = 4), and `redirect × write-target` (a real write must stay a write: 2 tokens × 1 = 2). 6 cells. the two rarer look-alikes take one cell each, on the read side they could corrupt: a quoted bare `>` beside a memory read, and an fd close with no memory path. 8 cells.
5. **redirect place × bash cwd** → an absolute or home path is placed by its text, so the cwd does not vary it (rows 4, 5). `$var` is unplaceable whatever the cwd: one set-under-`.claude/` cell, one with no such var. `relative` is the only place the cwd decides: it crosses the cwd positions, each way a position arises, with memory named beside it. a relative redirect with no memory path in the command passes whatever the cwd (row 6). 9 cells with the `$var` pair.
6. **payload size** only decides whether the payload reaches node. it is walked against the two verdict extremes only: a true write (must still halt) and a plain read (must still pass). 2 cells.
7. **tee** writes its operands and naught else, so it is walked as a redirect is: by role, then, for a read-only tee, by where its operand lands. a relative operand reads the cwd exactly as row 50 and row 54 do, so it takes the three cwd poles that decide a tee (known outside, moved into memory by a `cd`, unknown) and not the full cwd axis. `$var` takes both roles: read-only (an unset var) and write-target (a var set under `.claude/`). a tee × absent passes as row 9 does. 9 cells: write-target, an operand past a redirect, absolute outside, relative with cwd known (the durable-brief route), relative with cwd unknown, `$var` read-only, operands unreadable, relative with a `cd` into memory, `$var` set under `.claude/`.
