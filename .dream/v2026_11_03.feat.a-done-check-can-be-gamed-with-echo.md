# 🌙 dream: a done check can be gamed with `echo ok`

kind: feat · owner: rhachet-roles-bhrain, role=achiever · caught 2026-11-03

## .the cue that fired

the vision for `feat-achiever-no-excuses` makes a goal's done check a shell command (exit 0 = done).
its self review on requirements cut the anti-game refusal from a nano round.

## .the gap, precisely

a check of `echo ok`, `true`, or `:` exits 0 with no read of the world. it closes any goal, so it is
"looks done" with extra steps.

## .the shape of the fix

`goal.memory.set` refuses a `--how.gate` whose first command word is `echo`, `true`, `:`, or `exit 0`,
with the same message as a prose check (name a world check, or state `--how.gate.self-attested-why`).
clamp: a set with `--how.gate 'echo ok'` exits 2.

## .why it is not done in this round

the route is nano, and the wish's two clamps do not need it. the record shows every check in plain
text, so a commander can catch a gamed one at review in the meantime.
