# case=2 · the stance you must declare

- **coordinates** = `enter × answered × live`
- **feel** = sharp · **care** = critipath · **verdict** = forbidden → demoed

**acceptance #1's cell.** *"neither, or both, is refused."* this is **neither** — the driver answered
every point and tried to walk through without a word about whether it agrees.

## .the narrative

*driver, on `5.1.execution`, round 3*

I answered the architect. I answered the mechanic. every `.given` has its `.taken`. I run
`--as passed` expectantly.

**today** the stone holds and the halt tells me the counts — *"architect: 1 blocker, 3 rounds, 4
budget"* — and offers me two remedies, both of which read as somebody else's problem: increase the
budget, or ask a human to approve. so I add budget, re-arrive, and the architect raises the same
blocker. round 4. round 5.

🔴 **the halt never asked me the one question I could answer**: *do you think this is a defect?*

**now it does.** the same halt, with a new block at the bottom:

```
🗿 route.drive
   └─ held — one lane answered, and undeclared
      ├─ architect (l1)  : 3 rounds, 4 budget  ███░ answered, undeclared
      ├─ mechanic  (l1)  : 2 rounds, 4 budget  ██░░ approved
      │
      └─ declare a stance on architect's blocker.1 — exactly one
         ├─ concede — "fix the flagged concern, then re-arrive"
         │  └─ rhx route.stone.set --stone 5.1.execution --as conceded --with architect \
         │       --about blocker.1
         └─ dispute — "this is fine to continue"; the drive proceeds, the council rules at the close
            ├─ write the argument into a fulcrum entry first
            │  └─ .fulcrums/inventory.of=fulcrums.case=F00N-<slug>.md
            └─ rhx route.stone.set --stone 5.1.execution --as disputed --with architect \
                 --about blocker.1 --why <that path>
```

🔴 **the block teaches `S11`'s norm by its SHAPE: concede first, one line; dispute second, two.** a
driver reads top-down, so the first branch reads as the expected move — and the escalation costs an
extra step to reach. ⇒ **the surface's own friction sorts the two**
(`rule.prefer.defaults-match-common-case`).

🔴 **the dispute branch's two steps are `F018` on the surface a driver reads.** the command validates
a reference it cannot create, so a halt that printed only the command would send a driver into a
refusal it could have prevented (`rule.require.errors-name-the-fix`). ⇒ **the halt names the file to
write before the command that points at it** — and that asymmetry, bought for free, is what makes the
escalation the heavier branch.

⚠️ **the concede label must name WORK, never a budget request.** *"I need another round"* reads as
unavailable to a driver with none left, so they reach for the dispute instead. under `S11` a concede
is *"fix and run again"* — the fix comes first, and the budget ask follows only where a round is
owed. 🟡 **the stance itself has no default**, argued at § *what is awkward* § 6.

🟡 **the two meter rows are a SKETCH; the live render is multi-line** and comes from
`formatReviewsMeterLines`, which this halt (`formatRouteDriveMixedHalt`) and the guard tree
(`formatGuardTree:502`) both call. ⇒ **the block beneath them is what this case actually claims**, and
it is new prose on an extant halt. the meter rows above it are unchanged by this design — except for
`case=4`'s `disputed` word, which is a change to the **shared** row contract and is priced at `F04`.

**the aha:** *the silence was never neutral. a driver who re-arrived without a word had already made
the call — it just made it invisibly, and the record showed a budget that shrank for no stated
reason.*

## .the bdd timeline

```gherkin
given a stone `5.1.execution` with peer reviewers `architect` (l1) and `mechanic` (l1)
  and the architect's latest .given raises 1 blocker
  and .taken.by_self.architect exists and --as contemplated --that architect has run
  and no stance is on record for the architect                    # B = answered

[t0] when the driver runs --as passed
     then the stone is HELD                                       # 🔴 R4 — the new refusal
      and the halt names architect as "answered, undeclared"
      and it prints exactly TWO commands, dispute and concede
      and it prints NEITHER "approve as-is" NOR "increase budget"  # 🔴 not a human's turn yet

[t1] given instead the architect is exhausted rather than live
     when the driver runs --as passed
     then the stone is HELD identically
      and the halt still prints dispute and concede               # 🔴 the stance precedes the budget
      and it does NOT print "peer reviewer budget exhausted"       # the old halt is superseded

[t2] given the mechanic is ALSO answered and undeclared
     when the driver runs --as passed
     then the halt names BOTH lanes
      and a stance is owed per CONCERN, never per stone           # F01 + S07

[t3] given the driver declares on architect only
     when it runs --as passed
     then the stone is STILL held, and the halt names the mechanic alone
      and the architect is absent from the halt                   # progress is visible

[t4] given the architect's .given raised 0 blockers
     when the driver runs --as passed
     then it is admitted with no stance owed                      # B = clean; R2's other face
```

🔴 **`[t1]` is the row that reorders the ladder.** today an exhausted lane with a live blocker
halts on *budget*, and the driver's own lever is a top-up. after this behavior the **stance** is
asked first, because a top-up on a disagreement buys a round that changes no mind.

⚠️ **`[t0]`'s last line is the ergonomic claim.** the extant halt offers *"approve as-is — a human
must grant"* at a moment when the driver has an unspent move. `rule.always.spend-own-levers-before-
escalation` names that exact trap: *"two remedies rendered side by side with no owner column read as
two human remedies."* ⇒ **the stance block replaces them, and both human remedies return only once
every lane carries a stance.**

## .why it fails safe

**fast** — refused at the gate, before any subprocess · **loud** — the halt names the lane, its
state, and both commands · **teaches the fix** — two copy-paste lines, and the words on them say
what each means rather than what it does.

⚠️ **the driver is never stuck here.** both exits are its own, need no human, and cost no budget.
this is a **prompt**, not a wall — which is why the feel is sharp and the care is critipath: it
fires on nearly every hard stone, and a bad copy costs the driver a re-read.
