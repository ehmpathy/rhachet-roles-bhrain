# rule.always.entool-the-skills-you-touch

## .what

when you use a skill and a brain still has to do part of the job, **that leftover brain work is a
defect in the tool, not a duty of the caller.** name it, and upsert the skill one rung closer to a
single deterministic call.

this is the WATCH half of externalization. `rule.always.externalize.tactics.into_skills` says
*write the skill*. this rule says *the written skill is 💧 fluid — rung 2 of 4* — and it is the
learner's permanent job to notice which rung each skill it touches actually sits on.

the rungs are rhachet's determinism spectrum: 0 🧠 tribal → 1 📚 brief → 2 💪💧 **fluid skill** →
 3 💪🔩 **rigid skill** → 4 💪🪨 **solid skill**. **all five are tools**;
they differ only in brain cost per use (`philosophy.entoolment-is-the-pinnacle`).

## .why

`philosophy.entoolment-is-the-pinnacle` carries the full argument. the short form:

- a **brief** amortizes the derivation; a brain still applies it every time
- a **tool** amortizes the execution too; **one call, no brain**
- imagine cost is time + tokens — tokens → money → resources → nature, time → latency → people
  wait longer. **and a probabilistic step can be wrong**, which is the third cost and often the
  largest

⇒ every rung climbed is paid once and saved without bound. and the leftover glue is the cheapest
possible place to find the next rung, because **you already hold the evidence** — you just did the
work by hand.

## .the cues — when → then

do not evaluate skills in the abstract. these fire on things that happen to you anyway:

| when… | then… |
|---|---|
| you call a skill, **then** run a command to finish what it started | the follow-up command belongs **inside** the skill — note it |
| you call a skill and **read its output to decide** the next call | that decision is a candidate branch **inside** the tool |
| you call the same two skills in the same order, twice | the pair wants **one** call that composes them |
| you must **read a skill's instructions** to know what to run | it is rung 2 (💧 fluid). ask what 🔩 rigid looks like |
| a skill's output must be **reshaped** before the next step consumes it | the contract mismatch is the defect — fix the seam, not the caller |
| you write a **new** skill | write it at the highest rung you can defend today, not the fastest one |
| a skill **fails** and you work around it by hand | 🔴 the workaround is the strongest entoolment signal there is — never leave it unnamed |

## .the test — name the leftover work

after any skill call, answer one question out loud:

> **"what did I still have to figure out myself, after that one call?"**

- **naught** — rung 4, 🪨 solid. leave it alone
- **one or more steps** — name each one. each is an unclimbed rung

⚠️ **name the WORK, not a count of turns.** a turn is an indirection: two of them can differ by
orders of magnitude in time, tokens, and risk, so a count tells you none of the three. the named
step is what you can actually entool; the count is not.

then answer the second, which is the one that stops over-reach:

> **"is that leftover step a JUDGMENT, or a STEP?"**

- a **judgment** — it weighs an ambiguous case, reads intent, decides a tradeoff → **leave it with
  the brain.** entoolment must never fake determinism over genuine judgment
- a **step** — it is the same every time, and you could write down exactly what you did →
  **that is entoolable.** it is owed a tool

⚠️ you must answer BOTH. the first alone drives toward a tool that lies; the second alone never
notices there was a gap.

## .what to do with what you found

| the case | the move |
|---|---|
| you can entool it now, and it is small | do it now — that is the whole rule |
| you can entool it, but it is real work | write it down where the next traveler finds it: a seed to the repo that owns the skill, or a catch in `.dream/` while the radio is read-only |
| it is a judgment, not a step | say so explicitly — a documented "this stays with the brain, because X" is a real artifact. it stops the next traveler from a fake-tool attempt |

**a skill that belongs to another repo is re-seeded, never entooled here** — the tree that owns
the path owns the upsert.

## .the anti-patterns

- **the silent glue** — you do the leftover step by hand every time and never once name it. the
  gap is invisible precisely because you are good at the close
- **the fake tool** — determinism asserted over a fluid process. it is confidently wrong at scale,
  and worse than the brain it replaced, because a brain hesitates and a bad tool does not
- **💧 fluid forever** — a skill whose file is a list of instructions for a brain, unchanged across
  a dozen uses, because it "works"
- **the workaround that outlives the defect** — a broken skill routed around by hand. the learner's
  own trait forbids this: *fix at source, no shortcuts*

## .the mantra

> if you finished the job by hand, the tool is not finished. 🦉🔧

## .enforcement

- leftover brain work observed after a skill call, and never named = **violation of learner purpose**
- a manual workaround for a broken skill, left unrecorded = **blocker**
- a tool that asserts determinism over a genuine judgment = **blocker** (fail loud at the seam)
