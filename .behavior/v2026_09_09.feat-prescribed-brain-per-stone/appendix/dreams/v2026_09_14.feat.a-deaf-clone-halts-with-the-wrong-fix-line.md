# 🌙 dream: give a DEAF clone its own halt cause and its own fix line

- kind  = feat
- owner = `ehmpathy/rhachet-roles-bhrain`
- caught 2026-09-14

## .the cue that fired

peer reviewer `ergo-friction-hazards` (r009 i002, nitpick.1), on `5.1.execution.from_vision`:

> *"a DEAF clone that is enrolled still reports serial+slug → address confirmed → dispatch spawns
> `clone say` → `child.pid` is set → outcome is `requested`. … In the build the deaf case renders
> the same `⟨requested — unconfirmed⟩` surface as a healthy clone, so a human who reads a deaf
> clone's drive sees no hint that the switch can never land and that the remedy differs from a
> normal miss."*

and the vision itemized the same cell before the build existed — `apply × other-known × deaf`,
graded **sharp · alter**, with its own note:

> *"halts with case=2's SHAPE but needs a DIFFERENT fix line — a deaf clone needs a re-enroll WITH A
> SOCKET … a real errors-name-the-fix gap the blueprint stone owes a distinct message for."*

## .the gap, precisely

`getCloneAddress` does not read `reachState`, deliberately — `setStoneBrain.ts:304-306`:

```
 * .note = `reachState` is NOT gated on. a gate on a vocabulary this repo does not own
 *         would refuse states it cannot enumerate, and the causes above already cover
 *         every condition this operation can honestly assert
```

so a deaf clone walks the happy path end to end:

| step | what happens on a DEAF clone |
|---|---|
| `clone whoami` | exits 0, payload carries a serial → **address confirmed** |
| `dispatchBrainSwitch` | the child forks, `child.pid` is set → **`submitted: true`** |
| the outcome | `requested` |
| the render | `⟨requested — unconfirmed⟩` — **byte-identical to a healthy clone's** |

⇒ **the report is honest and undifferentiated.** it asserts no false state, and it offers a human no
way to tell a switch that will confirm next turn from one that can never land.

the two conditions need opposite acts:

| condition | the remedy |
|---|---|
| healthy, unconfirmed | naught. read the next turn |
| deaf | **re-enroll with a socket.** a re-entry of the stone will never help |

## .the shape of the fix

a **fifth** `StoneBrainHaltCause` — `unreachable-clone` — plus its row in
`formatStoneBrainUndispatched.ts`'s `HALTS` table, whose `fix.cmd` names the socket:

```ts
  'unreachable-clone': {
    live: 'confirmed — but the clone holds no live socket',
    why: [ … ],
    fix: {
      says: ['re-enroll the driver WITH a socket, then re-enter the stone —'],
      cmd: 'rhx enroll claude --as @:driver --roles driver',
    },
  },
```

🔴 **and the hard half is the DETECTOR, not the render.** `DEAF` is rhachet's word:

- to gate on the literal is to hard-code a peer repo's state enum into a driver hook
- the enum grows, and this build then refuses a state it has no opinion about — which is exactly
  what the extant `.note` refuses, and correctly
- ⇒ the honest input is a surface that answers *"can a say reach this clone?"* rather than one that
  hands back an enum this repo must interpret

so the fix is two halves, and the first belongs to another repo:

1. **ask `ehmpathy/rhachet`** for a reach predicate a caller can act on without a vocabulary copy
2. **then** add the fifth cause and its halt row here

## .why it is not done in this round

**SAFE — no. CLEAN — no.**

- **safe** — the only detector available today is a text compare against `reachState`, which
  contradicts a stated design note and would refuse states it cannot enumerate. a gate that guesses
  is worse than an honest `⟨unconfirmed⟩`
- **clean** — the correct input does not exist. it is an ask on another repo, on another cadence,
  and it sits beside the `whoami --brain` ask already filed as `ehmpathy/rhachet#528`

⇒ **and the reviewer's own grade agrees**: a nitpick, and their own minimum ask was that *"the
deferred distinct surface should be recorded"* rather than built. that record is now in
`5.1.execution.from_vision.yield.md`, and this is its queue entry.

⚠️ the condition that would make it urgent: **a route that enrolls its driver over a socket that can
drop.** today the driver's clone is long-lived and its deafness is rare; a shorter-lived clone makes
this the common failure rather than the alterpath it is graded as.
