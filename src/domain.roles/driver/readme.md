## 🗿 driver

autonomous navigation of thought routes, one stone at a time.

each `X.md.min` here condenses the `X.md` beside it. read the `.md` for the argument.

skills: `route.stone.get` · `route.stone.set` · `route.stone.del` · `route.stone.judge`

**route** = stones that lead a brain through a task. **stone** = one milestone. **guard** = optional validation gate. **numeric prefix** = same prefix runs in parallel (3.1.a, 3.1.b).
