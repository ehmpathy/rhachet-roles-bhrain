# 🌙 dream: a scoped test gate renders identically to a full one

- **kind** = reseed
- **owner** = `ehmpathy/rhachet-roles-ehmpathy`
  (`.agent/repo=ehmpathy/role=mechanic/skills/git.repo.test/git.repo.test.sh`)
- **caught** = 2026-09-20

## .the cue that fired

fourteen review iterations reported a gate line of the shape:

```
unit 1515 / 0 (136 suites) · integration 1179 / 0 (64) · acceptance 3614 / 0 (130)
```

on the fifteenth the same command ran with `--thorough`:

| what | scoped | `--thorough` | delta |
|---|---|---|---|
| unit | 1515 / 0, 136 suites | **2258 / 0**, 235 suites | +743 tests, +99 suites |
| integration | 1179 / 0, 64 files | 1523 / **12**, 120 files | +344 tests, +56 files, 🔴 **+12 red** |
| acceptance | 3614 / 0, 130 files | 3614 / 0, 130 files | **naught** |

🟡 **the acceptance row is the control, and it is what makes the other two legible.** its two runs
are identical, so the deltas above are the scope and never a change in the suites.

⇒ **the 12 were red the whole time** — both files sit outside `--diffs since-main`, both are
byte-identical to HEAD, and the failures are environmental (11× `spawnSync /bin/sh ENOBUFS`, 1×
a 90s traversal timeout). the branch never touched them, and never checked them either.

## .the gap, precisely

🔴 **the two runs print the same shape, and the shape asserts more than the scoped run measured.**

| the line reads as | what the scoped run measured |
|---|---|
| *the integration suite passes* | *the 64 files `--diffs since-main` selected pass* |

the scope is right for speed and right for a feedback loop — `rule.prefer.scoped-tests-locally`
asks for exactly this. **the defect is that the output does not say which of the two sentences it
states.** a reader, human or robot, takes the stronger one by default, and the stronger one is the
one a yield then repeats.

⚠️ and the selection rule sharpens it: the scope is the **diff**, so *"a file this change cannot
break"* and *"a file this gate cannot check"* are the same set. that is a correct optimization and
a silent one.

🔴 **it is the same shape as `rule.require.clamp-edge-cases`'s blast-radius gap, one level out.** a
bite check proves the repair and cannot find its blast radius; **a scoped gate proves the changed
files and cannot report the unchanged ones.** in both, the instrument is right, the output is
green, and the green covers a strictly smaller claim than it appears to.

## .the shape of the fix

**the number is already computed — the runner knows how many suites it selected and how many exist.
the whole repair is to print the ratio rather than the numerator.**

```
🐚 git.repo.test --what integration
   ├─ scope: 64 of 120 files  (--diffs since-main)
   │  └─ 🌑 56 files unchecked — run --thorough to include them
   └─ tests: 1179 passed, 0 failed
```

three properties:

- 🔴 **`64 of 120` rather than `64`.** the denominator is the whole repair — it is what makes
  *unchecked* visible without a second command
- **name the selector** (`--diffs since-main`), so a reader knows *why* 56 were skipped rather than
  merely *that* they were
- 🟡 **and print it on success, not only on failure.** the green run is the one that gets quoted
  into a yield and a PR body, so it is the one whose claim must be exact

⚠️ **do not make `--thorough` the default.** the scoped run is the correct default for the loop it
serves; the defect is the report, never the scope.

## .why it is not done in this round

**SAFE: yes** — additive output on a skill, and it changes no selection and no exit code.

**CLEAN: no**, and this is the half that blocks. the skill lives in
`ehmpathy/rhachet-roles-ehmpathy`, a different repo — this round's diff cannot reach it, and a tree
adopts only what is scoped to itself (`rule.always.scope-onetime-lessons-to-the-behavior`). a local
copy would be a second home for one skill, which is the braid
`rule.always.reuse-pavement-before-improvise` names.
