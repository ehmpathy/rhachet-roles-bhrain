# 🌙 dream: the zero-selected tip recommends `--thorough`

- **kind** = `reseed`
- **owner** = `ehmpathy/rhachet-roles-ehmpathy` (role=mechanic owns `git.repo.test`)
- **caught** 2026-09-07

## .the cue that fired

while I wrote `rule.forbid.thorough-test-runs` — a rule that forbids the flag outright — I read
the skill and found **the skill itself recommends it**, in the one moment a driver is most
likely to reach for a remedy.

## .the gap, precisely

`git.repo.test.sh:1431-1435`, on a run that selected zero tests:

```
echo "   └─ tests: 0 (no tests to run)"
echo ""
echo "🥥 did you know?"
echo "   ├─ jest --changedSince may miss some file changes"
echo "   └─ use --scope and --thorough to target tests directly"
```

⇒ **half of that line is right and half inverts its own advice.** the header promises to
*"target tests directly"* — and `--thorough` is the one option on the line that targets no test
at all. it runs every suite in the repo (`:587-590` sets `THOROUGH`, `:304`/`:388` drop the
`--changedSince` bound).

**the diagnosis it should carry:** zero-selected means the change detection did not see the file
you edited. `--scope 'path://<that file>'` **names** it, so the next run reports which one was
missed. `--thorough` runs all of them, so it never reports it — the symptom is buried under a
green wall, and the driver learns no more than before.

⚠️ **the cost lands on the reader, not the author.** a tip printed by the tool at the moment of
confusion carries the tool's full authority. a driver who has read the forbid rule will still
meet this line at the exact moment the rule is hardest to recall.

## .the shape of the fix

drop `--thorough` from that line. the tip becomes:

```
🥥 did you know?
   ├─ jest --changedSince may miss some file changes
   └─ name the file to target it: --scope 'path://<your file>'
```

one line, one option, and the option is the one that answers the diagnosis.

⇒ **and the wider ask:** `rule.forbid.thorough-test-runs` is authored here in
`rhachet-roles-bhrain`, but `git.repo.test` is the mechanic's. the rule belongs in the tree that
owns the flag — re-seed it to `repo=ehmpathy/role=mechanic`, beside
`rule.prefer.scoped-tests-locally`. a forbid that lives away from the surface it governs is a
forbid its readers never boot.

## .why it is not done in this round

- **safe?** yes — a one-line stdout edit
- **clean?** 🔴 **no.** the file is `rhachet-roles-ehmpathy`'s, reachable here only through
  `node_modules`. an edit here would be overwritten by the next install, and this route is bound
  to `rhachet-roles-bhrain`

⇒ so it is a `reseed`, dispatched rather than done. a tree adopts only what is scoped to itself.
