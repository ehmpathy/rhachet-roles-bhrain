# razor: box

shaves: a claim at the wrong level (a model stated as the world) · settled by: rivals (the model against a simpler and a richer rival, for the same use)

## .the question

> **for what use is this model held, and is its error small enough for that use?**

`razor=anti-razor` asks for fit to every observation; this asks for fit to the one use. `razor=misplaced-concreteness` asks if the model is taken as the world; this asks if it fits its job.

## .the source

- George Box and Norman Draper, 1987, p. 424: "Essentially, all models are wrong, but some are useful."
- tied to Box, "Science and Statistics", *JASA*, 1976 (exact words `guess:` not read)
- read via https://en.wikipedia.org/wiki/All_models_are_wrong

## .fails when

- "all models are wrong" shields a sloppy model. the half "some are useful" owes a test of use; that test is the razor
