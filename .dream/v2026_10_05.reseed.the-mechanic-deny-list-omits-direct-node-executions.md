# 🌙 dream: the mechanic's deny list forbids direct node executions

- kind: reseed
- owner: ehmpathy/rhachet-roles-ehmpathy (role=mechanic — the `.claude/settings.json` permission template)
- caught: 2026-10-05

## .the cue that fired

a driver ran `node -e` one-liners to poll a background task and parse json. no allow rule named
`node`, so each call reached the auto-approval path and ran. the wisher saw it and asked that it be
forbidden.

## .the gap, precisely

- the deny list carries `bash`, `cd`, `find`, `grep`, `ln`, `ls`, `mkdir`, `mv`, `sed`, `tee`, and
  `npx jest` — every raw tool the paved skills replace — and omits `node`
- `node -e` is the most general escape of all of them: it reads, writes, and spawns with no repo
  bound, so it reaches every act those other denies exist to route through a safe skill
- the leak path, measured: `pretooluse.check-permissions.sh` blocks an unlisted command once, records
  it in `.claude/permission.nudges.local.json`, and passes an identical retry. the nudge file holds
  several `node -e …` entries — each one a call that went through on its second attempt. a deny
  rule is the only layer that a retry cannot pass
- the hook's own allowlist also prints `[p]: node`, from a settings layer outside this repo, so an
  allow exists somewhere above the project too. a deny outranks it at every layer
- the repair here is `Bash(node:*)` on the deny list of `.claude/settings.json`, which is an actor
  symlink and not tracked. it holds for this actor only, and the next `rhachet init` may restamp it

## .the shape of the fix

- add `"Bash(node:*)"` to the mechanic's deny template, beside `Bash(sed:*)`
- the `statusLine` entry runs `node -e …` through the harness, never through the Bash tool, so the
  deny does not touch it
- optional: a PreToolUse hook that names the paved alternatives (`rhx` skills, the Read tool,
  `head` / `tail`) in its refusal, so the block teaches rather than merely stops

## .why it is not done in this round

the template is owned by another repo. a tree adopts only what is scoped to itself, so the local
deny is the in-scope repair and the template is a reseed.
