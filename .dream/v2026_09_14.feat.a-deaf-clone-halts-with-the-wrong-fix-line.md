# 🌙 dream: give a DEAF clone its own halt cause and its own fix line

- kind  = feat
- owner = `ehmpathy/rhachet-roles-bhrain`, after an ask on `ehmpathy/rhachet`
- caught 2026-09-14

## .the cue that fired

peer reviewer `ergo-friction-hazards`, on `5.1.execution.from_vision`:

> *"a DEAF clone that is enrolled still reports serial+slug → address confirmed → dispatch spawns
> `clone say` → `child.pid` is set → outcome is `requested`. … a human who reads a deaf clone's drive
> sees no hint that the switch can never land and that the remedy differs from a normal miss."*

the vision itemized the same cell first — `apply × other-known × deaf`, graded **sharp · alter**.

## .the gap, precisely

`getCloneAddress` ignores `reachState`, by a stated design note (*"this repo does not own that
vocabulary"*). so a deaf clone walks the happy path:

| step | on a DEAF clone |
|---|---|
| `clone whoami` | exits 0 with a serial → address confirmed |
| `dispatchBrainSwitch` | `child.pid` set → `submitted: true` |
| the render | `requested` — identical to a healthy clone |

the two need opposite acts: a healthy clone needs naught; a deaf one needs **a re-enroll with a
socket**, and a re-entry of the stone never helps.

## .the shape of the fix

1. **ask `ehmpathy/rhachet`** for a reach predicate — *"can a say reach this clone?"* — that a caller
   acts on with no copy of rhachet's state enum
2. then add an eighth `StoneBrainHaltCause`, `unreachable-clone`, and its row in
   `formatStoneBrainUndispatched.ts`'s `HALTS`, whose fix names
   `rhx enroll claude --as @:driver --roles driver`

🔴 the hard half is the detector. a text compare on `reachState` hard-codes a peer repo's enum, and
refuses states it cannot enumerate once that enum grows.

## .why it is not done in this round

- **SAFE — no.** the only detector today is that text compare, against a stated design note
- **CLEAN — no.** the correct input lives in another repo, beside the `whoami --brain` ask
  (`ehmpathy/rhachet#528`)

the reviewer graded it a nitpick and asked only that the deferral be recorded.

🟡 **the trigger:** a route whose driver holds a socket that can drop. deafness is rare on a
long-lived clone; a short-lived one makes it the common failure.
