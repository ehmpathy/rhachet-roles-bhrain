# case 3 — done without proof stays open

feel: sharp · care: critipath · actor: achiever · seams: store, stop hook

## .narrative

the achiever believes the flaky test is fixed after one green run. it tries to mark the goal fulfilled.
the store runs the done check (ten runs); run seven fails. the close is refused: the goal stays
inflight, and the refusal shows the check's tail. the achiever keeps at it.

the other shape: the done check is prose ("looks good"). the set refuses it at once, since a check
that names no command can never prove aught. the achiever writes a real check, or, where the world
has no check (a taste call a commander makes), states why with a self-attested reason the commander
can read.

## .[tn] — a sketch

```
given  goal fix-auth-test with how.gate 'for i in $(seq 10); do npx jest auth.test.ts || exit 1; done'
when   [t0] rhx goal.memory.set --slug fix-auth-test --status.choice fulfilled
then     the check exits 1
     and the set exits 2: ✋ ConstraintError: done check failed; the goal stays inflight
     and the check's tail is shown
when   [t1] rhx goal.memory.set --slug x --how.gate 'looks good'
then     the set exits 2: the done check names no command (exit 127 shape), so it can prove naught
     and the fix is shown: a shell check, or --how.gate.self-attested-why '<why no world check exists>'
when   [t2] rhx goal.memory.set --slug pick-the-glyph --how.gate.self-attested-why 'a taste call; the commander picks'
     and rhx goal.memory.set --slug pick-the-glyph --status.choice fulfilled --status.reason 'the commander chose 💎'
then     the close is accepted, and the goal is marked self-attested in the record
     and goal.triage.infer lists every self-attested close, with its why, beside the goals
         (the commander can read and reopen each one; a self-attested close is never silent)
when   [t3] the self-attested why is empty, or the slug's ask names a world outcome a command could read
         (a test, a file, a pr state)
then     the set exits 2: a world check exists, so a self-attested close is refused for it
```
