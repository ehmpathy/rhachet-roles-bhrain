# rule.always.run-the-razors-before-a-claim

> **before a claim leaves you, put to it the razor its shape invites. the catalog holds each razor's question, and what settles it: `catalog.of=razor._.md`.**

**how it applies the basis:** a claim about to leave is the claim you trust most, since you just wrote it. each razor is one fixed question aimed at a known way a mind fools itself; the catalog lets the question you would not have recalled still run.

## .the move

| the claim's shape | the razors it invites |
|---|---|
| a cause | occam, anti-razor, hickam; hume-proportion; instrument |
| a blame, or a credit of intent | hanlon; morgan |
| a rival dismissed | rapoport |
| a verdict of fact | hitchens; russell |
| a superlative ("always", "never", "100%") | sagan |
| a refutation | duhem-quine |
| two options offered as the only two | false-dilemma |
| an "ought" | hume-is-ought |
| a claim no test is named for | popper; alder |
| a removal | chesterton |
| a count offered as an outcome | goodhart |
| a sample offered as the whole | survivorship |
| "all", "always", "every" over a few cases | hasty-generalization; overfit |
| a lesson from one place used in another | external-validity |
| a trait of the parts said of the whole, or the reverse | composition-division; simpson |
| a label given a cause or a will ("the system wants") | misplaced-concreteness |
| a claim made from the top of a layer | leaky-abstraction |
| a model offered as right | box |
| all forest and no trees, or the reverse | ladder |
| "this case is surely different" | base-rate |
| one source, no second | segal |
| a word of certainty | feynman; cromwell |
| a lesson | foundation vs application (`rule.always.razor-the-foundation-from-the-application`) |

then do the work its question owes: logic → inspect the claim; observation → name the read and run it; rivals → name them at full strength first.

a claim that survives a razor is "not yet refuted", never "proved".

## .the test

> **which razor does this claim's shape invite, and what is left after it?**

## .enforcement

nitpick: a claim of a shape in the table that left with its razor unrun · a razor copied into a second brief instead of cited from its catalog file

peer: `rule.always.trust-no-one-especially-not-yourself` (the first thought is its move)

forbid twins, one per shape of claim: `rule.forbid.claims-stuck-high` · `cases-with-no-point` · `circular-definitions` · `part-whole-transfers-unchecked` · `labels-given-a-will` · `unfalsifiable-claims` · `oughts-from-an-is` · `claims-with-no-evidence` · `single-causes-unweighed` · `motives-before-slips` · `false-dichotomies` · `counts-offered-as-outcomes` · `numbers-with-no-class` (each `rule.forbid.$slug.md`)
