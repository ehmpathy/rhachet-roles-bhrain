# case=5 — a budget set at what it reaches

**feel** sharp · **care** critipath — the fail-safe for case=4 when no cut fits. it is walked
on the librarian's first budget in this pr, and again on any later edit that adds a cue.

## narrative

the author has moved every argument out of the librarian and sets `budget: tokens: 5000`, as
the wish proposed. the boot halts: about 7–8k, over by a third. they read the halt's four fixes
and run the census to see what is left. every line that remains is a cue: 53% of the rules,
70% of the `kno*` articles. the next cut they could make would drop a when-row from
`rule.forbid.itemization-without-coordinates`.

they stop there. a cue is not theirs to trade for a number. they set the budget a little above
what the boot reached and write a comment above it that names the proposal, the reach, and the
floor. in the pr table they put the gap in plain view, so the wisher sees a budget that fell short
of its target on purpose, rather than a cue that quietly vanished.

the librarian keeps every article and every rule at say. no core usecase is lost: the budget
moves, never the boot's content.

## [tn] sketch — what makes this safe, not merely honest

the narrative says "declare what it reached". the risk is a declared figure with no headroom,
which turns the next ordinary edit into a halt. the sketch asserts the figure and the headroom.

```
given librarian/boot.yml with every argument moved out
  and `rhx census.cues --glob 'src/domain.roles/librarian/briefs/**/*.md*' --emit` equal to its
    pre-change capture (no cue cut)

  when [t0] the author runs `npx rhachet roles cost --what src/domain.roles/librarian/boot.yml`
    then it reads payload P (expected ~7–8k), above the 5,000 proposal

  when [t1] the author sets `budget.tokens` to the least multiple of 250 strictly above P
    and writes above it `# proposed 5,000, reached P. the floor is the cue text; a cut would drop a row`
    then `npx rhachet roles boot --what src/domain.roles/librarian/boot.yml` exits 0
    then the headroom (budget − P) is between 1 and 250 tokens
      (strictly above: a P that is itself a multiple of 250 still gets headroom. zero headroom
       passes too, per case=4 [t0], but it turns the next edit into a halt, so it is not chosen)

  when [t2] the pr body is drafted
    then the librarian row reads `14,116 → P · budget <n> · proposed 5,000 · why: cue floor`
```
