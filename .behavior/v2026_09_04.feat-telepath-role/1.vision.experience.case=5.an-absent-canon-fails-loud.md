# case=5 · an absent canon fails loud

**cell** = `adopter · reviewer · sharp · canon-absent · file`
**feel** = sharp · **care** = critipath (`freq` = every first wire-in on a repo that lacks the canon · `cost` = a reviewer that grades clean because it graded no file)
**issues** = #386 · #394

## .the design decision this cell forces

telepath is a **generic** role in `rhachet-roles-bhrain`. its output-half canon lives today in `rhachet-roles-ehmpathy` under `mechanic` and `architect` `lang.prose/`.

`rhachet-roles-ehmpathy` is a **devDependency** of this repo — never a dependency. so a consumer that enrolls telepath does **not** thereby get ehmpathy's briefs.

⇒ if telepath's rubric cites `.agent/repo=ehmpathy/role=mechanic/briefs/practices/lang.prose/*.md`, the glob resolves to zero files on every consumer that never enrolled ehmpathy's mechanic.

**the canon must come to telepath. a generic role cannot cite a specific repo's briefs for its own rubric.** that settles the migration the readme calls *"owed and not yet done"* — it is not merely owed for tidiness; the reviewer cannot run at all without it.

## .the narrative

an adopter on a fresh repo enrolls telepath and wires the reviewer in. they run it against the yields:

```sh
rhx review.by --role telepath --for prose-density
```

the repo enrolled `bhrain` but never **`telepath`** — the role that owns the canon once F01's move lands. the rubric's rules glob matches zero files. the reviewer does **not** report clean:

```
🦉 woah there

✋ rules glob is ineffective — it matched 0 files
   ├─ rubric: prose-density
   ├─ glob:   .agent/repo=bhrain/role=telepath/briefs/rule.forbid.narratives.md
   └─ fix
      ├─ enroll the role that owns these rules:
      │  └─ rhachet init --roles telepath
      └─ then rebuild so .agent/ repopulates
```

exit non-zero. the guard grades it a **malfunction**, and the stone blocks.

the adopter enrolls telepath, rebuilds, re-runs. the reviewer finds its four rules and renders a verdict.

## .the invariant — INV-1 · INV-2 · INV-6

> **a telepath reviewer must fail loud when its rules glob matches zero files. it must never render `0 blockers / 0 nitpicks`.**

### the attemptable route that breaks it

one flag:

```sh
--optional rules
```

per `contract.reviewer-output`, it turns a zero-match into:

```
🌙 skipped — no rules found (--optional rules)
   └─ summary
      ├─ 0 blockers
      └─ 0 nitpicks
```

exit 0. **the guard tallies `0/0` as approved.**

⇒ that reproduces the very failure the wish names — *"an unreviewed reviewer is indistinguishable from a clean one"* — **inside the cure**. the flag is one word, it reads as a convenience, and it is exactly wrong for a rubric whose whole value is that it ran.

### the pit of success, verified

the default is **strict**. `stepReview` throws `BadRequestError` on an ineffective rules glob:

- `src/domain.operations/review/stepReview.integration.test.ts:116-136` — *"[case2] rules glob matches zero files → throws BadRequestError about ineffective glob"*
- `src/contract/cli/review.ts:52-54` — `--optional` skips *"instead of a fail-loud error"*

⇒ the invariant holds **by default** and breaks only on an explicit opt-in. so the deliverable is not a code change — it is a **documented forbid** so no future adopter reaches for the flag to quiet a red reviewer.

## .the three ways to settle the canon, and why one wins

| option | consequence |
|---|---|
| **cite ehmpathy in place** | breaks on every consumer that never enrolled ehmpathy. the reviewer blocks or, with `--optional`, lies |
| **copy into telepath, leave ehmpathy's** | two homes for one rule. they drift on the structural half — the exact failure `generic-governs-structure-never-voice` names |
| **move `lang.prose/` to telepath; ehmpathy adopts by reference** | one home. `lang.tones/` stays with ehmpathy. this is what the seam brief already declares |

🟡 the move makes `rhachet-roles-bhrain` a **dependency** of `rhachet-roles-ehmpathy`, never the reverse. that direction is correct — a generic is depended upon; it depends on none.
