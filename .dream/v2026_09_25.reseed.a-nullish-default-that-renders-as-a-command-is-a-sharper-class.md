# 🌙 dream: `rule.forbid.unexpected-defaults` owes a cue for the default that renders as a COMMAND

- kind  = `reseed`
- owner = `ehmpathy/rhachet-roles-ehmpathy` (the rule's home — **not this repo**)
- caught = 2026-09-25

## .the cue that fired

the eleventh warmer audit pass found a `?? 0` on a pid, and the value reached a stdout line that
reads:

```
   └─ stop: kill 0  ·  never spawn: rhx review … --warmer off
```

`kill 0` sends SIGTERM to the **caller's entire process group**. so a driver who copy-pastes the one
documented stop command would terminate their own shell, their editor, and the guard run that
spawned the warmer — on a surface whose own comment says it exists to be acted on.

🔴 **the rule that forbids this is already extant, and it is exact.**
`rule.forbid.unexpected-defaults` carries `customer.discount ?? 0.1` as its second blocker example.
the defect was an absence of TRANSFER, never of knowledge — the same diagnosis the eighth pass
reached about `asGradeCensus`. ⇒ **so this dream is NOT for a new rule.** it is for one cue row the
extant rule does not carry.

## .the gap, precisely

the rule's harm model is stated once, and it is about EPISTEMICS:

> *"callers must know when data is absent vs when operation failed"* · *"hide failures from callers"*
> · *"make debug impossible"* · *"corrupt data silently"*

every one of those is a harm to a reader's BELIEF. the pid case is a strictly worse class, and the
rule has no words for it:

| the default | the harm | who suffers |
|---|---|---|
| `customer.discount ?? 0.1` (the rule's own example) | a caller cannot tell a real 10% from a guess | a reader's belief, recoverable |
| 🔴 `pid ?? 0`, rendered as `kill ${pid}` | the reader RUNS it and SIGTERMs their own process group | the reader's machine, **not recoverable** |

⇒ the difference is not degree. the first default is read; the second is **executed**, and the
surface was purpose-built to be copy-pasted (`rule.require.errors-name-the-fix` asks for a concrete
next move, so the more that rule is honored the more dangerous a bad default becomes).

🟡 **and that inversion is the part worth the reseed.** two rules this repo holds pull in opposite
directions on one line of stdout: *"name the fix"* says print a runnable command, and *"forbid
unexpected defaults"* says never print a guess. a surface that honors the first and forgets the
second hands over a runnable guess.

## .the shape of the fix

one cue row on `rule.forbid.unexpected-defaults`, in its `.how` list, plus a third blocker example:

```md
- 🔴 does the defaulted value get RENDERED as something the reader will RUN?
      a `??` default in a path, a url, a pid, an id, or a shell command is worse than one
      in a figure: the reader does not merely believe it, they execute it. the canonical
      case is `pid ?? 0` → `kill 0`, which signals the caller's whole process group.
```

and a line in its `.note`, beside the extant failhide pointer:

```md
🔴 the severity is set by what the default REACHES, never by the default itself. a guessed
   figure misleads; a guessed pid, path, or command ACTS. where the value flows to a
   copy-pasteable surface, the absence renders ABSENT and no command is offered
   (rule.require.safe-by-default).
```

## .why it is not done in this round

**SAFE — yes.** it adds a cue to a rule; it changes no shipped behavior, and
`rule.require.a-cue-is-not-a-claim` says a costly defect earns as many cues as it takes, from as
many angles as can be found. two cues on one defect cannot disagree.

🔴 **CLEAN — no, and the reason is ownership rather than size.** the rule lives in
`ehmpathy/rhachet-roles-ehmpathy`, which is a different tree.
`rule.always.scope-onetime-lessons-to-the-behavior` is explicit: *"a lesson whose home is another
repo is re-seeded there, never adopted here."* a copy of the cue in this repo's briefs would be a
second home for one rule — the braided-trail shape `philosophy.pavement-saves-nature` names — and
the peer's copy would stay unimproved.

⇒ the local half was already done: the defect is fixed in `genReviewWarmer` and
`emitReviewWarmerSpawn`, clamped by `emitReviewWarmerSpawn.test [case6]` whose discriminator is the
negative `not.toContain('kill 0')` plus `not.toMatch(/kill \d/)`, and **proven red by neuter — 2 of
21 fail when the `?? 0` is restored.** the worked example the reseed would cite is therefore already
written and already green.
