# domain.term.choice.reason: prose.elucidation

## .etymology
declared by `src/domain.roles/telepath/briefs/define.elucidation.md` — the latin roots and what
they claim about the act. amend it there.

🟡 **the direction is one-way, and it is forced.** a published brief cannot cite this glossary
(`hazard.published-brief-cannot-cite-the-repo-glossary`), so it must stand alone — which makes the
glossary the copy that cites, every time. what remains here is the half no published brief carries:
**why each rejected synonym was rejected.**

## .why not each forbidden synonym

| rejected | why |
|---|---|
| clarification | *clarify* names a direction of change — make it clearer. a passage can be clearer and still unusable. elucidation names the outcome: the peer can act |
| explanation | one-directional. an explanation is given; it has no form that covers the ask. elucidation's second direction has no word under `explain` |
| communication | the genus, not the differentia. it covers the channel, the medium, and the act of emit — none of which is the success condition |
| illumination | the same latin root, and it fits — but it names the light rather than the transfer, so it reads as a property of the passage. the test is a property of the peer |
| transfer | too wide. a transfer of bytes is a transfer. elucidation is a transfer until the peer can use it, and the bound is the whole word |

## .disputes

### dispute: obfuscation — raised 2026-09-04 — status: OPEN
- raised.by  = the wisher
- claim      = *"maybe the peer to elucidate is to forbid.obfuscation"* — the classic antonym, one
               word, and a clone recognizes it at once
- counter    =
  - 1 · it collides with a declared concept — two words, one concept
    - `rule.forbid.subversive-prose`'s own fundamental reads *"it is subterfuge … it masks the true intent and the true message"*, which is obfuscation
  - 2 · it claims intent, where most failed elucidation is not deliberate
    - the author elucidated themselves
  - 3 · it covers only the give direction, and elucidation has two
- alternative = `assumed-context`, which reaches the shared root of both directions: *you cannot
               un-know what you know, so you cannot see what the peer lacks* — give → I omit it;
               ask → I guess instead
- resolution = **unresolved — the wisher's call.** the honest repair, if `obfuscation` is taken, is
               to fold `subversive-prose` into it rather than boot both

`rule.forbid.subversive-prose` shipped with *"subversive prose aims to tire the reader into

itself had no cluster and no brief.

🟡 **that is the arrears this cluster closes**, and it is the shape `rule.forbid.domain-term-synonyms`
exists to prevent: a word that performs contract work with no declaration behind it.

## .invariants
- a passage that is clear and unusable to its peer has not elucidated — clarity is not the bar
- a question is an act of elucidation, never an admission that one failed
- ⇒ so every rule that grades an answer also grades a question, and no second rule set is owed
