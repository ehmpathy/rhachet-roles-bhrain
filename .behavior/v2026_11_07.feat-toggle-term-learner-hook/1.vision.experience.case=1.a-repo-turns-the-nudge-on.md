# case=1 — a repo turns the nudge on

feel × care: happy × critipath · actor: human · ⇒ inventory row `enable · off · present · split`

## .narrative

kai keeps a repo whose vocabulary drifts: three clones this week named one concept three ways. he
wants the learner's glossary nudge back, but only here. he runs one command:

```
$ rhx learn.terms.hook enable
🦉 so it is

📜 learn.terms.hook enable
   ├─ status = enabled (added)
   ├─ settings = .claude/settings.of.repo.json
   ├─ hook = Stop → learn.domain.terms --when hook.onStop, guarded on the learner link
   ├─ reaches = sessions that hold the learner
   ├─ takes effect = at each session's next start; a live session keeps its old settings
   └─ share it = commit .agent/.actors/actor.via.repo=ambient/brain/.claude/settings.of.repo.json
```

the output names the one file it touched, what it put there, when it bites, and how it spreads.
the share leaf names the tracked path, not the `.claude` link, since `git add` refuses a path
beyond a symlink. he commits the file. naught else in the repo changed.

## .[tn] sketch

```
given('[case1] a split-layout repo with the learner linked and no term hook')
  when('[t0] the human runs `rhx learn.terms.hook enable`')
    then('exit 0')
    then('settings.of.repo.json holds one Stop entry whose command runs learn.domain.terms --when hook.onStop behind a learner-link guard')
    then('the entry carries the toggle author, outside the repo=…/role=… namespace')
    then('every other key of settings.of.repo.json is unchanged')
    then('stdout names status = enabled (added), the file, the hook, and when it takes effect')
    then('the share leaf names the git-tracked path, through the .claude link, that `git add` accepts')
  when('[t1] `rhx learn.terms.hook get` runs')
    then('it reports enabled')
  when('[t2] a session that was already live reaches a stop')
    then('it does not run the hook — the output said so at t0')
```
