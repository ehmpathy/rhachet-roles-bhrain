## .how to read the states

| state | means |
|---|---|
| closed | a cluster exists |
| open | the word is owed and absent |
| homed | a cluster exists, and a dispute inside it is unsettled |
| watched | attested, and composes no dobj or dop name yet — one instance too thin to name, or a position held inside its genus's cluster. no cluster is owed until the word enters a name; the row says which trigger it waits on |

a row that grows an argument earns its own file and the row cites it by path
(`rule.require.catalog-is-an-index`). extant: `gap=flake.md` · `gap=sentinel.md`.
