# case=1 · the closed escape hatch

- **coordinates** = `enter-review × carried-unanswered × live`
- **feel** = sharp · **care** = critipath · **verdict** = forbidden → demoed

the core case. the driver edited its way past an unanswered blocker; the door is now shut.

## .the narrative

*driver, mid-drive on `5.1.execution`*

the architect came back with two blockers. one says a name I chose is overloaded. I disagree, and
the answer would take a paragraph.

so I do the cheaper act: tighten an unrelated comment, save, `--as passed`. the hash moves, every
reviewer re-rolls, and this time the architect happens not to raise it.

**that is the loop I can no longer enter.** the door now answers before the reviewers spin up, and
the paths it quotes carry hash `9f2a1c` — **the hash the critique was raised at**, not the one my
edit just produced. my edit did not erase the question; it changed only the code the question was
asked about.

so I read the two blockers. one is real — I fix it and quote the fixed lines. the other I dispute,
so I cite the rule that says my choice holds. `[REFUTE]`, with evidence. eleven minutes; the loop I
was in cost nine days.

**the aha:** I never disputed the *work* of an answer. a cheaper door sat beside it and looked
equally legitimate. shut that door and the honest path is the only path — and it is not even hard.

## .why it fails safe

| property | how |
|---|---|
| **fast** | `[t1]` halts before a subprocess spawns — token-free, second-scale |
| **loud** | a rendered reply-prompt with the reviewer, its verdict, and both paths; plus a persisted `passage.jsonl` blocker the stophook re-reads |
| **teaches the fix** | cites the file to read, the file to write, and the command to run |

⚠️ **`[t1]` holds only because the debt is keyed by reviewer, never `(reviewer, hash)`.** an
entrance gate over hash-keyed debt reads `carried-unanswered` as `none` and admits — right place,
no debt to see.

### 🔴 .this sketch was right where the test's first draft was wrong

`[t3]` above says *"the entrance gate admits it, **and the peer reviewers run**."* it does **not**
say passage is allowed — and that distinction turned out to carry the weight.

the first draft of the test asserted exit 0 at that step. it got exit 2, because the reviewers ran
**at the moved hash** and raised a **fresh** critique there, which is itself unanswered and must
gate. ⇒ **the answer buys entry, never passage.**

the test now carries a fourth step the sketch did not model — answer the fresh critique, *then* pass —
so the journey walks the **entrance** gate and the **exit** gate as each bites in turn.

⚠️ **the sketch is left as written.** it is accurate for the scope it claims; the fourth step is an
extension past its terminus, not a correction of it. what is recorded here is that a prose sketch
outperformed a hurried test draft — the demo was the cheaper place to be right.
