# 🌙 dream: the forbid-test-background hook guards a door the harness walks around

- **kind** = `reseed`
- **owner** = `ehmpathy/rhachet-roles-ehmpathy` (`role=mechanic`)
- **caught** 2026-09-07, on `ehmpathy/rhachet-roles-bhrain` @ `beav/fix-contemplation-gate-on-entrance`

## .the cue that fired

a full `--what acceptance` run sat `inflight` for **2595s** and never reported. it was not slow —
it was **clobbered**, by me, six times over.

## .the gap, precisely

`claude.hooks/pretooluse.forbid-test-background` refuses a `git.repo.test` call that carries
`run_in_background: true`:

```
🛑 BLOCKED: git.repo.test must run in foreground
fix: remove run_in_background from your Bash tool call
```

⇒ **the flag is refused, and the state it names is not prevented.** the harness auto-backgrounds
any command that exceeds its foreground budget, so a caller who obeys the hook — passes no flag at
all — still ends up with a backgrounded run. an acceptance lane takes tens of minutes, so it is
backgrounded **every time**, by construction.

🔴 **and the hook's refusal reads as a guarantee.** once told the run is foreground, the caller
believes naught can disturb it, and then runs the next check.

## .why that is harmful rather than merely untidy

`package.json` `test:acceptance:locally` opens with `npm run build`, and `build:clean:tsc` is
`rm -rf dist/`. so **every** `git.repo.test` invocation destroys and rebuilds the tree that any
concurrent invocation is mid-execution against.

**measured, this session:** one backgrounded acceptance lane, then six further invocations while it
ran — `--what integration` ×2 (one scoped), `--what acceptance --scope` ×1, `--what unit`,
`--what types`, `--what lint`, `--what format`. the acceptance lane never terminated.

⇒ 🔴 **the failure mode is a HANG, not an error.** a suite whose `dist/` is deleted underneath it
does not fail loudly; it stalls. so the contaminated run is indistinguishable from a slow honest
one, and the caller reads a stall as a long lane. **the measurement it eventually reports, if it
reports one, is untrustworthy and does not say so** — which is the `rule.forbid.failhide` shape at
the harness scale.

⚠️ **the trap compounds with the wait.** a long lane is exactly the window in which a caller reaches
for *"some useful work while I wait"*, and every useful item on that list is another
`git.repo.test`.

## .the shape of the fix

three rungs, and the third is the durable one:

| rung | the fix | what it buys |
|---|---|---|
| 📚 **1** | say it in `howto.run-tests.[lesson].md` — *"never run a second `git.repo.test` while one is live; the build is destructive and the victim HANGS rather than fails"* | a caution the reader may recall |
| 💪🔩 **2** | widen the hook: refuse a `git.repo.test` call when a **lockfile** says one is already live | catches the case the flag-check misses |
| 💪🪨 **3** | 🔴 **a build lock in the skill itself** — `build:clean` takes an exclusive lock; a second invocation waits, or fails loud with *"a run is already live since T"* | the caller cannot cause it, whatever the harness does |

⇒ **rung 3 is the entoolment answer**, and rung 1 alone is the weakest: the caution is met precisely
when a caller is idle and impatient, which is when a brief loses.
`philosophy.entoolment-is-the-pinnacle` — the hook mechanized the *flag*, and the flag was never
the hazard.

⚠️ **and the hook should stop its over-promise meanwhile.** if it cannot hold the guarantee, its
copy must not assert it: *"must run in foreground"* → *"do not launch a second run; this one may be
backgrounded by the harness regardless."*

## .why it is not done in this round

**not safe, and not clean.** it edits a skill and a hook owned by another repo
(`rule.always.scope-onetime-lessons-to-the-behavior`: a lesson whose home is another repo is
re-seeded there, never adopted here), and a build lock changes the concurrency contract of every
repo that enrolls the mechanic. its own safety check is the full test matrix of those repos.

⇒ this route's scope is the contemplation gate. what was found is real, it is measured, and it
belongs upstream.
