hook or role link drops into each temp repo (enroll artifacts, settings), which CI lacks.

2. exclude that class at its source: the temp-repo factory, or a review-scope polluter
   (`rule.require.exclude-review-scope-polluters`) if a real driver would hit it too
3. keep the count in the snapshot — it is a true fact of a hermetic fixture — once the fixture is
   hermetic
