# razor: hickam

shaves: a cause among rivals · settled by: rivals

## .the question

> **could two or more causes hold at once, each behind part of the effect?**

the rivals are cause SETS, not single causes. a fault in code often has two roots.

## .the source

- attributed to a Hickam, possibly John Bamber Hickam, MD; date uncertain: "a man can have as many diseases as he damn well pleases"
- read via https://en.wikipedia.org/wiki/Hickam%27s_dictum

## .fails when

- it invites a pile of needless causes. each extra cause still owes its own read: run `razor=occam` on the set

## .run by

`rule.always.skepticize-the-layer-of-a-cure`
