## .what the 2 failures are

both sit in LLM-dependent `review.*` files and both came back **green** in the after run
(`after8`: 3252/3252). they are brain nondeterminism, not defects — recorded rather than
waved off, because a baseline with unexplained red is a baseline nobody can lean on.

⇒ this is also why `compare` keys on the **passed-before** set rather than on totals: a
case that was red before is excluded from the no-loss claim, so a flaky baseline cannot
manufacture a false pass.

## 🔴 .this stone took three attempts. the two failures are the lesson

| attempt | what destroyed it |
|---|---|
| 1 | **I edited the test harness mid-run.** jest lazy-loads each test file as it reaches it, so the run became a blend of old and new code. killed at ~25 min |
| 2 | **an external `npm run build` mid-run.** `build:clean:tsc` does `rm -rf dist/`, and every fixture resolves its skills through a symlink into `dist/`. 401 cases died with `symlink target not found` |
| 3 | tree frozen by agreement. **43m19s, clean.** |

⇒ **the shared mechanism: this suite resolves through `dist/`, and `dist/` is deleted by
any build.** that makes a long measurement fragile in a way no amount of personal
restraint fixes — attempt 2 was destroyed by a hand that was not mine.

**the rule this yields:** a measurement of this suite needs the tree frozen **by
agreement**, announced out loud, for its whole duration. say so before you launch it.

## 🟡 .the cost of the order I actually walked

the stone says *"a baseline taken after a change is not a baseline"* — and I violated the
spirit of it. this number arrived **last**, after every change was already built and
measured. it is still a valid before/after, because the original path stayed reachable
behind `ACCEPTANCE_LINK_CACHE=off` + `--runInBand`, and that switch is what made the late
capture possible.

⇒ **the switch is what saved the claim.** had I instead stashed the changes to measure
the original, the late baseline would have been unreachable and the whole comparison
would rest on a start point nobody measured.
