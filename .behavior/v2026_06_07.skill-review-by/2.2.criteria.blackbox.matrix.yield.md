## gaps

1. **nitpicks-only case** — matrix.5 row 4: shipped adhoc emits a "heads up..." vibe and exit 0 for nitpicks-only (blockers gate exit, nitpicks do not). **resolved:** exit 0, show nitpick counts.

2. **empty rubrics.yml** — what if `rubrics:` list is empty? **proposal:** fail fast with "no rubrics found in rubrics.yml" (exit 1).

3. **no files match scope** — what if forwarded paths match zero files? **proposal:** forward to `review`, let it degrade gracefully.

4. **rubric has no rules** — shipped adhoc warns on stderr and continues if a rubric has no rules behind it. bhrain reads rules inline from rubrics.yml, so this reduces to "no files match scope" (gap 3) once the rules expand.

---

## decomposition: acceptable

core matrix has 3 independent dimensions (rubrics.yml, --for, result) — acceptable.
no matrix exceeds 4 dimensions. scope+brain and vibe are orthogonal concerns with clean small matrices.
