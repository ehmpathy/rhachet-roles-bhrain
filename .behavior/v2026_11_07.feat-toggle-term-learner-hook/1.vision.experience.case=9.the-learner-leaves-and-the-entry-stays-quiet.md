# case=9 — the learner leaves, and the entry stays quiet

feel × care: sharp × critipath · actor: a developer, then a clone · ⇒ inventory row
`enable · on · present · split · learner unlinked`

## .narrative

kai's repo enabled the toggle in march. in june a teammate trims the roles: `rhx init --roles
-learner`. rhachet unlinks `.agent/repo=bhrain/role=learner`, and its prune removes every
`repo=…/role=learner` hook. the toggle's entry is not one of them — its author does not start with
`repo=` — so it stays in the settings file.

an unguarded entry would now run `rhx learn.domain.terms` on every stop, against a skill that is
gone: an error on every stop at best, a held stop on every stop at worst, and `rhx learn.terms.hook
disable` is gone too, so the tool could not undo it. that is the per-stop charge the hook was
withdrawn for, with no switch to turn it off.

so the entry the toggle writes is guarded on the learner's own link:

```
[ ! -e .agent/repo=bhrain/role=learner ] || ./node_modules/.bin/rhx learn.domain.terms --when hook.onStop
```

with the learner gone, each stop runs one shell test and exits 0. no node process, no error, no
hold. the teammate's sessions stop as if the toggle had never been set. the leftover line is the
only trace, and it costs naught.

to clean it up, two paths:

- relink the learner, then `rhx learn.terms.hook disable`
- or delete the one Stop entry by hand; `git diff` shows exactly one block gone

once the learner is gone, so is `rhx learn.terms.hook --help`; no learner-gated channel can teach
this. what survives the unlink is the entry itself: its author, `toggle=learn.terms.hook/role=learner`,
names the skill that wrote it and the role it needs, to anyone who greps the settings for the
command or reads the diff. the toggle's `--help` names both cleanups too, but that reaches only a
human who reads it before the unlink. since the leftover costs naught (above), the cleanup is a
tidy, never an urgency.

## .[tn] sketch

```
given('[case9] a repo where the toggle is enabled, then the learner role link is removed')
  when('[t0] a session reaches a stop')
    then('the term hook exits 0 and the stop is not held')
    then('stderr holds no error from the term hook')
    then('no node process is spawned by the term hook')
given('[case9b] the same repo, with the learner relinked')
  when('[t0] `rhx learn.terms.hook disable` runs')
    then('the leftover entry is removed')
```
