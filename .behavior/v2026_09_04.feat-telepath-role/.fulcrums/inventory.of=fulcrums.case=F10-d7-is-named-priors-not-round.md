# F10 · D7 is named `priors` — not `round`, and not a third `attempt` value

**rework** = clean · **status** = open · **confidence** = 85%
**taken** 2026-09-04, at `i003`, mid-drive
**where** = `1.vision.experience.dimensions.md` §D7 · `1.vision.experience.case=_.md` (the `taken` slice)

## .the fork

the `dimensional-decomposition` peer reviewer blocked on a latent axis and **named two shapes for it**:

> *"The walk needs a `round` axis (first · converged) **or** a third `attempt` value (`fresh-converged`)."*

⇒ so the fork is not *whether* the axis is owed — that is settled, and the reviewer is right. it is **which of three shapes it takes**, and I declined both of the reviewer's.

## .the options

| option | shape | verdict |
|---|---|---|
| **A** | a third `attempt` value — `fresh` \| `fresh-converged` \| `cached` | **rejected** — it flattens a 2×2 |
| **B** | a `round` axis — `first` \| `converged` | **rejected** — it names a counter, not a state |
| **C** | a `priors` axis — `none` \| `taken` | **taken** |

## .why A is rejected — it repeats a defect this same file already carries a section about

the four states are real:

|  | `none` | `taken` |
|---|---|---|
| **`fresh`** | the cold first arrival | the warm convergence re-read |
| **`cached`** | ∅ — a cache needs a prior run | a third arrival, unchanged, hash hit |

⇒ a three-value `attempt` axis collapses that 2×2 into a line. **that is precisely D4's defect**, which `dimensions.md` carries a whole subsection about — *"D4·supply is a flattened 2×2 whose fourth state has no coordinate"* — and which a reviewer made me justify at `i001`.

**to take option A would be to commit, one axis later, the defect I had just defended against.**

## .why B is rejected — `round` names a counter, and the counter is not what varies

a 2nd arrival and a 5th arrival are **the same experience**: the subject carries answers, and the reviewer must honor them. what changes between round 2 and round 5 is a number nobody experiences.

⇒ this is the identical ground on which `retried` was rejected as a third `attempt` value at `i001`. **the same test, applied consistently**, rejects `round` too.

## .why C — `priors` names the state, and it reuses this repo's own word

`taken` is not a coinage. `.taken.by_self` is the extant artifact name in `rule.always.converge-with-reviewers.via-a-taken-per-point`, so the axis value **is** what the subject carries.

⇒ `rule.always.reuse-pavement-before-improvise`: the word was already paved.

## .the enumeration that backed it

per `rule.require.enumerate-before-you-name` — the instances listed **before** the word:

| instance | value |
|---|---|
| a driver's first arrival at a stone | `none` |
| a driver re-arrives after a `.taken` per open point | `taken` |
| an author runs the reviewer by hand on a draft | `none` |
| an adopter's first wire-in run | `none` |
| a reader | ∅ — a reader runs no reviewer |

⇒ covers every row, and excludes its neighbours: it is not `attempt` (computed vs reused) and not `supply` (what reached the reviewer).

## .what the option cost, and what it bought

- **cost** — the product grows `288 → 576`, and two exclusion triggers had to be re-costed (`768` for the hook axis, `1,152` for the read axis)
- **bought** — a cell no artifact had: `driver · reviewer · sharp · oversized · file · fresh · taken`, **the convergence ratchet**. the `.taken` files are in the subject, so each round grows it toward the gate. **measured on this route: 79,789 → 117,470 tokens, +47% across two rounds**, unchanged rubric and file list

## .why 85% and not higher

two open edges:

1. **the reviewer offered two shapes and I took neither.** that is defensible on stated grounds, and it is still a driver who overrules a reviewer's own proposal — the kind of call that should be visible rather than buried in a `.taken`
2. **`priors` is a new word in this route's vocabulary.** `taken` is paved; `priors` as an axis name is not. a reviewer may prefer `answers` or `articulations`, and either would serve

⇒ **the rework is clean either way** — a rename of one axis label across two artifacts, with no rubric, guard, or brief that depends on it.
