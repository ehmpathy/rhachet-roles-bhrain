# 🌙 dream: let a reviewer expand its own target files over a few rounds of tooluse

- kind: feat
- owner: rhachet-roles-bhrain
- caught: 2026-09-30

## .the cue that fired

`targetFiles` is **87.6%** of a review prompt — 878.4k of 1.0M chars on a measured run, 113
files, every one shipped in full whether the reviewer needed it or not. the grove pays
**626.9M chars** on that one input, and `targetFiles` is classed `cacheable: false`, so most
of it is re-paid at full input rate every round.

the whole mass is pushed because the composer cannot know which files matter. **the reviewer
can** — after it reads the diffs and the paths.

## .the gap, precisely

review is one-shot push today: the composer decides the whole scope, renders every target in
full, and the brain gets one turn. so the prompt must carry every file that *might* matter.

⇒ that is the wrong party in possession of the decision. the composer guesses; the reviewer
knows.

measured consequence, one run: 113 targets at 881.3k, of which the reviewer's report cited a
small fraction. the rest was bought and unread.

## .the shape of the fix

give the reviewer **a few bounded rounds of tooluse** so it self-discloses progressively:

1. **round 1 — the map, not the territory.** ship `targetPaths` (already a declared input,
   currently 0 chars) plus `targetDiffs`. the reviewer sees every path and every delta, and
   no full file bodies.
2. **rounds 2..N — expansion on request.** expose one tool, `expandTarget({ path })`, which
   returns that file's body. bound it: a max expansion count and a max total chars, both
   declared per lane, both metered.
3. **the budget is the contract.** an exhausted expansion budget is a normal terminus, never
   an error — the reviewer reports on what it chose to read, and the meter records what it
   asked for.

🟡 **and the cache interaction is the reason this is not obviously a win.** each tooluse turn
appends to the conversation, so a multi-turn run caches its *own* turns (the census already
grades this `⊘ self`) and may share *less* across rounds. so the measurement owed is a NET:
input chars saved by unexpanded files, minus cross-round prefix lost to a longer conversation.

⇒ so this dream ships against a **measurement**, never an argument. `rhx review._.cost` is the
instrument, and `rule.require.report-both-cost-levers-with-trend-and-locus` is the report that
would make the net legible.

## .why it is not done in this round

it is a contract change to the review prompt and to the brain-call shape, and it inverts which
party decides the scope — not safe or clean inside a cost-meter route. it also depends on the
section reorder settled this round (`targetFiles` → `targetDiffs` → `conversation`), whose own
effect must be measured first so the two levers are not confounded.

⇒ and the honest risk: a reviewer that under-expands reviews less than it should. the
expansion budget is the guard, and its floor is a behavior question, not an implementation one.

## .amended 2026-10-04 — two facts the overflowed `5.3.verification` round added

surfaced when 8 of 9 peer reviewers refused for overflow, and the wisher named this option again
(always push the diffs; let the reviewer fetch full files over turns):

- 🔴 **the default brain has no tooluse.** `openrouter/deepseek/flash` is an atom, so `--focus pull`
  is refused on it (`BRAIN_DEFAULT_OF_REVIEW.ts`). so the loop must be run by the **harness**, not
  the model: the reviewer answers with a structured `need: <path>[, <path>]`, the harness appends
  those bodies and calls again. no tool grammar is needed, and every turn is append-only, so each
  prior turn is a byte-identical prefix of the next
- 🔴 **a new file's diff IS its whole body.** on that branch 831 of 1098 targets were new, so "push
  the diffs" alone still sent the whole branch. round 1 must send an **outline** of each new file
  (exports, signatures, test names) in place of its body, or this option saves naught on a
  greenfield-heavy branch
- log every disclosure — which files were pushed at which grain, which were fetched — so a file
  the rubric grades that stayed unread is visible in the given, never silent
