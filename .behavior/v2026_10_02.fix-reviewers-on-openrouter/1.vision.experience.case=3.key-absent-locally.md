# case 3 — the key is absent locally

sharp × criti

## .narrative

a maintainer, or a clone on a fresh machine, runs `rhx review` the day after the cutover. their
keyrack holds FIREWORKS from before but no OPENROUTER key. the review must not spend, must not
hang, and must not fall back to fireworks. it fails at once and names the fill command.

## .fail-safe owed
- **fast**: before any brain call
- **loud**: a non-zero exit, with the error on stderr
- **teaches**: names the command that sets the key

✅ verified and pinned: `blackbox/review.key-absent.acceptance.test.ts`. with the key out of env and
keyrack, `rhx review` exits 2 before any brain call, renders one `✋ ConstraintError` block with no
stack trace, and names `rhx keyrack set --owner ehmpath --key OPENROUTER_API_KEY --env prep`. the
refusal block is snapped.

the "no stack trace" half needed a fix here: keyrack throws from rhachet's own helpful-errors copy,
so `instanceof` missed it and node printed the stack. `isCallerConstraintError` reads the shared
`code.exit = 2` instead.

## .timeline

```
given('[case3] OPENROUTER_API_KEY not in the keyrack')
  when('[t0] the maintainer runs rhx review with the default brain')
    then('the maintainer sees a non-zero exit at once, with no spinner wait on a brain call')
    then('the maintainer reads OPENROUTER_API_KEY and the keyrack set command on stderr')
  when('[t1] the maintainer pastes the set command, then runs rhx review again')
    then('the maintainer sees the review run on openrouter/deepseek/flash')
```
