# 🌙 dream: stepReview's formatted review owes a masked snapshot

kind: fix · owner: rhachet-roles-bhrain · caught 2026-10-23

## .the cue that fired

a 5.3 peer reviewer (ergo-contract-snapshots, i002) pointed out that no suite snaps
`review.formatted`. the driver's first answer had claimed the default-brain suite did, and that
claim was false.

## .the gap, precisely

- `stepReview` is a public sdk export. its return value (`review.formatted` plus the `metrics`
  block) is output a caller reads
- `stepReview.integration.test.ts` snaps only the two refusal renders (case2c, case3 t1). the
  clean and dirty review bodies (case9) are graded by partial matchers
- `stepReview.caseBrain.claude-sonnet.integration.test.ts` grades by `toContain`,
  `not.toContain`, `toBeGreaterThan(0)`, and `expect.any(Number)` alone
- ⇒ a regression that drops the review header, reorders the metrics block, or rewords the
  severity lines stays green in every suite

🟡 **the premium suite is closed.** `stepReview.caseBrain.claude-sonnet` now pins a masked
skeleton (`asSkeletonOfReview`) and the masked `metrics` key tree (`asShapeOfValue`), inline. what
stays owed is the default-brain suite: lift those two transformers to a shared test util and snap
its case9 clean and dirty variants the same way.

## .the shape of the fix

- add one transformer that masks a review's volatile bytes: the brain's prose per concern, the
  counts, the costs, the times. it keeps the header, the section order, the severity line
  shapes, and the `metrics` keys
- snap `asStable(result.review.formatted)` and the masked `metrics` shape for the clean and dirty
  variants, first in the default-brain suite (cheap), then in the premium suite
- run each twice to prove the mask holds against a brain's variance before it gates ci

## .why it is not done in this round

safe, but not clean: the gap is extant on main and spans two suites this budget pr did not
author. a mask that holds against a brain's variance needs its own runs to prove, and a mask
that does not hold turns ci red on a pr whose subject is boot budgets.
