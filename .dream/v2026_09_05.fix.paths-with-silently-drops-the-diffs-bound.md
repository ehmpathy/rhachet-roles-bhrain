## .the cue that fired

a driver re-ran an overflowed reviewer lane scoped, per
`rule.always.diagnose-reviewer-malfunctions`. the scoped run returned **3 blockers**, each one that
named a true file and a true line.

none of them were in the branch's delta.

the check that caught it was one command — each cited path against
`git diff origin/main --stat`. **zero matches.** every finding named code that predates the branch.

## .the gap, precisely

`rhx review --help` documents both flags as defaults:

```
--diffs   which diff range to scope to   (default: since-main)
--join    how to combine diffs + paths   (default: intersect)
```

**neither default applies when `--paths-with` is supplied without an explicit `--diffs`.** the
paths argument does not intersect with the diff — it **replaces** it.

measured in this tree, same rubric, same subsystem glob:

| the invocation | targets |
|---|---|
| `--paths-with 'src/…/guard/**/*.ts'` alone | **112** |
| the same, plus `--diffs since-main --join intersect` | **34** |

`git diff origin/main --name-only` held **21** files. so the unbounded form graded roughly **five
times** the delta.

## 🔴 .why it is worse than a wrong count

**the tell is an ABSENCE, never an error.** the run exits 0, prints a well-formed report, and
returns plausible observations about real code. the only difference in stdout is a row that does
not appear:

```
   └─ scope
      ├─ diffs: since-main          ← present only when the bound applied
      ├─ paths: src/…/guard/**/*.ts
      └─ join: intersect
```

so a reader who does not already know to look for that row has no signal at all. the report reads
as a report.

⇒ the cost is not wasted tokens. it is a **driver who repairs, or argues with, another branch's
work** — and files a taken that claims a fix for a defect that was never theirs.

## .the shape of the fix

the resolver must apply its own documented defaults. concretely, at the scope-resolution site:

- when `--paths-with` is supplied and `--diffs` is **not**, the `--diffs` default (`since-main`)
  and the `--join` default (`intersect`) still apply — as documented
- a caller who genuinely wants the whole subtree asks for it: `--diffs none`, or an explicit
  `--join union`

the safer half, if the default change is judged too broad a behavior shift: **print the scope
block unconditionally**, with an explicit `diffs: (none)` row when no bound applied. that turns a
silent absence into a visible statement, and costs no behavior change at all.

⚠️ **both halves are worth it.** the default fix removes the trap; the unconditional scope block
removes the *silence*, which is what made the trap expensive.
