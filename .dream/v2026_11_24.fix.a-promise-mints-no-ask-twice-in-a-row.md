## .the gap, precisely

the brief frames the cause as a race (a generation that moves between the round's start and the mint). two misses in two promises on one stone, in one session with no concurrent `route.stone.set`, reads less like a race and more like a step the promise itself takes that moves the generation before its own mint. unread: which write that is.

## .the shape of the fix

- a clamp first: a `stepRouteStoneSet` test that promises review N and asserts the `.since` marker of review N+1 exists after the call, with no other actor. red now, if the cause is the promise's own write

- the render must not print an ask it did not record: if the mint is dropped, say so and print the re-ask command
