# 🌙 dream: an overflowed lane does not print its own scoped re-run

- **kind** = fix
- **owner** = `ehmpathy/rhachet-roles-bhrain` (this repo)
- **caught** 2026-09-06, at stone `5.3.verification` of
  `.behavior/v2026_09_03.fix-contemplation-gate-on-entrance`

## .the cue that fired

five lanes overflowed the context window for **five consecutive rounds** (i021–i025). every round I
classified the malfunction correctly, cited the cause down to the line
(`parseReviewArgs`, `src/contract/cli/review.ts:147`), and filed it upward as a human-only bind
repair.

`rule.always.diagnose-reviewer-malfunctions` prescribes a **driver-owned** act for exactly this row
— re-run the same rubric narrowed, via `rhx review`, which is not bound to the guard's hardcoded
`--diffs since-main`. it grades the omission as a blocker:

> **an overflowed lane reported upward with no scoped re-run.**

I did not perform it, five times. the rule was in context every one of those rounds.

## .the gap, precisely

**the overflow emit is a diagnosis with no remedy attached.** it prints everything needed to
*understand* the failure and no part of what helps *act* on it:

```
✋ prompt exceeds 75% of context window
   ├─ 137.1% of 1000000 tokens
   └─ reduce scope or use --focus pull

🔍 lets see why...
   ├─ rules: .agent/repo=bhuild/…/rule.require.contract-snapshot-exhaustiveness.md
   ├─ targets
   │  ├─ diffs: since-main  →  files: 324
   │  ├─ paths: (none)      →  files: null
   │  └─ joined via intersect  →  files: 299, tokens: 1022.7k
```

⚠️ `reduce scope or use --focus pull` is generic copy. it names **no flag**, **no glob**, and — the
load-bearing omission — **it does not say the rubric can be re-run outside the guard at all.**

⇒ so a driver reads the emit, agrees with it, and files it. the emit and the rule together describe
a lever, and neither one hands it over.

🔴 **and this malfunction is uniquely disguised.** the rule states it plainly: *"an overflowed lane
returns terminal and unlocks the next level, so it reads much like a lane that ran."* exit 2, level
advances, report filed. every incentive says the diagnosis is complete.

## .the shape of the fix

the emit already holds **every value the remedy needs**. the rubric path is on the `rules:` line; the
join is on the `joined via` line. only the narrowed glob is a judgment, and a repo-shaped default is
serviceable.

so the fix is one added branch in the overflow emit — a **remedy block** beside the diagnosis block:

```
🔧 run it narrowed, yourself
   └─ rhx review --rules '<the rules: value, verbatim>' \
                 --diffs since-main --join intersect \
                 --paths-with '{src,blackbox}/**' \
                 --output '.review/<stone>.<lane>.scoped.md' --goal exhaustive
```

three properties it must hold, each learned the expensive way on this branch:

1. 🔴 **both `--diffs` and `--paths-with` printed explicitly**, though both are documented defaults.
   `--paths-with` alone **silently drops the diff bound** — measured 112 targets vs 34, ~5× the
   delta, every extra item code the branch never touched
   (`.dream/v2026_09_05.fix.paths-with-silently-drops-the-diffs-bound.md`). a prefilled command that
   omits `--diffs` teaches the defect
2. **the rubric path verbatim from the `rules:` line** — a driver who retypes it can mistype it, and
   a rubric glob that matches zero files makes `rhx review` *skip* with a clean `0/0`, which reads
   as an approval
3. **the narrowed glob as a repo-level default, overridable** — `{src,blackbox}/**` is right for
   this repo. it belongs in config, never hardcoded in the emit

**measured, this branch, 2026-09-06** — the scoped form on the identical rubric and delta:

| | the guard bind | the scoped form |
|---|---|---|
| targets | 299 files | **158 files** |
| tokens | 1022.7k | **618.2k** |
| context | 137.1% — over the failfast | **61.8%** — under it |
| verdict | 💥 malfunction | ✅ runs |

⇒ **the lens was recoverable the whole time, at the cost of one command.**

## .why it is not done in this round

**safe: yes. clean: no.**

the overflow emit is engine surface. a change to it moves guard-emit snapshots across the acceptance
corpus, and this branch's whole subject is the contemplation key — an emit-copy change would land a
second, unrelated behavior inside a diff already under five-round review. that is the ripple
`rule.always.fix-forward-under-scouts-honor` calls dirty.

⚠️ **and it is out of the wish's bounded scope.** `0.wish.md` fences four items explicitly and tells
the driver not to expand past them; a reviewer-emit ergonomics repair is a fifth.

⇒ so it is caught rather than done, and the **deferral itself is itemized as a fulcrum**, because a
dream alone would report the work and hide the call.

## .the durable kernel, for whoever picks this up

this is an instance of a general shape, and it is worth stated in its own words:

> **a diagnosis that names a remedy the reader owns, without handing over the command, will be read
> as a diagnosis that names someone else's remedy.**

the driver-facing rule already carries the general claim; a rule looked past is not repaired by a
louder rule (`rule.require.specialize-a-rule-its-readers-look-past`). the cue has to move to **where
the reader already is** — and for an overflowed lane, that is the emit.
