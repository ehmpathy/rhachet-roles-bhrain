# review/partition — a declared shared exposure

`review/partition/` owns the partition contract: how a set of `--partition '<slug>=<globs>'`
declarations parses, how it splits a review's targets, and what it refuses.

two contexts read it, and both are sanctioned consumers:

| consumer | why it reads the partition contract |
|---|---|
| `review/` | a `rhx review` run splits its own targets, and refuses a set that cannot hold them |
| `route/guard/partition/` | `route.guard.partition` declares the set a guard's lanes will run, and must refuse exactly what `rhx review` refuses — else a set declared clean faults at review time |

## .the contract

only these exports are read across the context line. all else under `review/partition/` stays
private to `review/`.

| export | grain | what it guarantees |
|---|---|---|
| `asReviewPartitionsFromFlags` | transformer | the parse of the `--partition` flag values into declared partitions |
| `getAllTargetsByPartition` | transformer | the split of a target list across those partitions — each partition's own and common targets, the targets none claims, and which partitions lack the bound route |
| `ReviewPartitionSplit` | type | the shape of that split, which every consumer reads |
| `asReviewPartitionRefusal` | transformer | the refusal a split earns, or null — one text both commands print |
| `asReviewPartitionRepair` | transformer | a declared set, repaired to claim each unclaimed file and hold the route — one placement every refusal proposes |
| `asReviewPartitionRepairLines` | transformer | the tree lines of that repair — one render the stone entrance and a review run both print |
| `getOneReviewPartitionsFault` | transformer | the first defect in a set of declarations, with the corrected declaration to paste — one fault both commands print before any other check |
| `asReviewPartitionFlagsMerged` | transformer | a set with one value per slug — a slug declared over several flags merged, every lone value kept byte for byte — the form a route stores |
| `asReviewPartitionDeclarationParts` | transformer | one `--partition` value split into its slug and its glob text — the one read of a value's slug, so a claim names the slugs a set holds the way the parser does |
| `asReviewPartitionDeclarationText` | transformer | the paste-ready text that declares a whole set, one comma-list `--partition` per slug — one render the repair and a refusal's proposal both print |
| `asReviewPartitionCountsLabel` | transformer | one partition's `<slug>: N narrow targets + M common targets` label — one render the overflow split and both route partition trees print |
| `asReviewPartitionUnclaimedLabel` | transformer | a split's `unclaimed: N` label — one render the review plan and both route partition trees print |
| `getAllGlobsUnmatchedOfSplit` | transformer | each declared glob that claims none of the split's targets — the silent typo |
| `asReviewPartitionUnmatchedLines` | transformer | the tree branch that flags those globs — one render both plans print |
| `isPathOfRouteSpec` (at `review/isPathOfRouteSpec`) | transformer | whether a path is a file of the bound route — the one rule the split, the overflow lever, and the coverage read all share |

⇒ a partition is review's own concept (`term=review.scope.partition`), so the contract stays in
the context that minted it, and the route reads it as a consumer — the direction the guard is
built on (route runs review lanes). a reshape here is a contract change for BOTH consumers; read
every call site before you make one.
