# domain.term.choice.reason: split

## .etymology

to split is to divide a whole into parts, with no part lost. both instances in the code keep that
promise: a partition split names its `unclaimed` targets and refuses the run rather than drop
them; a run split names its `targetsGone` rather than count them as zero.

## .enumeration — two instances, checked before the word was settled

per `rule.require.enumerate-before-you-name`, the instances the word must cover:

| instance | covered? | excludes its neighbours? |
|---|---|---|
| `ReviewPartitionSplit` — targets across declared partitions | ✅ | ✅ — a `partition` is one part, never the whole |
| `TargetSplitOfRun` — target mass across named prompt inputs | ✅ | ✅ — the `locus` places mass by directory, which is a third axis this word does not claim |

⇒ one concept at two axes, never an overload. the axis is the qualifier beside the word, so no
second word is owed.

rejected:
- **breakdown** — already a forbidden synonym under `locus`, and it names no parts
- **division** — a synonym with no gain, and it reads as an arithmetic operator
