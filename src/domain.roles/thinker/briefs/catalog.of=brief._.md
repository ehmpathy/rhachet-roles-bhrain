# catalog.of=brief — every thinker brief and skill, by shelf

one row per member. each member is one read away; its path is computable from its shelf and name:

```
src/domain.roles/thinker/briefs/$shelf/$name.md      # a brief
src/domain.roles/thinker/skills/$skill/              # a skill
```

e.g. shelf `cognition`, name `cog101.concept.definition` → `briefs/cognition/cog101.concept.definition.md`

🟡 **a shelf whose subject you meet at the keyboard is a cue: read its root (`._`) or catalog member first.**

the root briefs (`distilisys.grammar.compressed`, `style.words.lowercase`, `term=brain.atomic_vs_replic`,
`terms.motive.intent.goal`, `trait.chillnature`, `trait.ocd`) boot whole beside this catalog.
