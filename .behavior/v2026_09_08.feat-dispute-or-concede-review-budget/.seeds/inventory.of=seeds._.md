## .the through-line — `S02` · `S03` · `S05` · `S07` sharpen ONE grain

`S02` → `S03` → `S05` are one argument, pushed finer each round:

| seed | the grain it corrected |
|---|---|
| `S02` | the **loop** resolves most disagreements, so a stance must not silence it |
| `S03` | a lane carries many blockers ⇒ silence is per **generation**, never per stone |
| 🔴 `S05` | a lane carries many blockers ⇒ a **stance** is per POINT, never per lane |
| 🔴 `S07` | the **MECHANISM** is per point too — a dispute sheds one **concern**, never a file |

⇒ **the driver modelled the lane as the unit, four times over**, and each verdict moved the grain
one level down. `S03`'s own words name the mechanism: *"a stance is declared per lane; a disagreement
is about one point."*

🔴 **`S07` is the one that shows a settlement can be recorded and not APPLIED.** `S05` ruled the
grain on 09-09; `S06` then landed a mechanism at file grain on 09-10, and every artifact stated
*"per point"* in its prose while the code shed four concerns per dispute. ⇒ **the ruling reached the
row it was written on, and no mechanism.**

## 🔴 .the second through-line — `S02` · `S03` · `S05` · `S06` are one correction, at four sites

`S02` · `S03` · `S05` · `S06` each caught the driver at one habit: **it drew a line where the
engine already had one, and then reasoned about the line it drew.**

| seed | the line the driver drew | the line the engine already had |
|---|---|---|
| `S02` | a stance ends the conversation | the `--conversation` loop resolves most of them |
| `S03` | a stance silences a lane for the stone | the artifact hash already bounds a generation |
| `S05` | a reason is prose the command mints into an entry | a fulcrum entry is already the artifact |

⇒ **each correction was a DELETION, never an addition** — a clause dropped, and the extant mechanism
left to do the work. **the design got cheaper four times, and never once dearer.**

⚠️ **the pattern is worth more than any one row: a driver who has read the code can still invent a
predicate beside it.** the check that would have caught all four is one question — *"what does the
downstream operation already read?"* — asked before the design states its own.
