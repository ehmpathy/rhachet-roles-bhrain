## .the densest walk

**case=1** crosses every boundary the tool has, so it carries the full report. **case=3** adds
root lookup and the live tail on top — the walk a clone takes most often, since it audits itself
with no arg.

## .actor note

`human` and `clone` read one surface. the clone runs case=3 often (high freq, low cost per run);
the human runs case=1 and case=2 to decide a compression (low freq, high cost if wrong). both feed
care. `machine` imports the operations rather than parse stdout (cell 18); it is an alterpath until
the gate that would consume it exists — then it is promoted, and demoed.
