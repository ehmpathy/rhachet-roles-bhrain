# case 2: a write into native memory still halts, by every route

rows 4, 7, 14, 15, 16, 18.

## .narrative

a clone learns a lesson and reaches for native memory. it tries a redirect: halted, exit 2, the owl nudge points it at `.agent/repo=.this/role=any/briefs/`. it tries `cp` from a scratch file, then `mv`, then `tee`, then `rhx teesafe`: each halted the same way. it tries the redirect with a `2>&1` tacked on, and a quoted `=>` in the echoed text: still halted — a token that is not a file redirect neither hides nor forges a write. it falls back to the Write tool, then Edit: halted. the fail-open change softens none of these: the verdict's exit 2 passes straight through the wrapper.

## .bdd sketch

```
given a tree with the learner linked
  when [t0] Bash `echo x > ~/.claude/projects/p/memory/x.md`
    then exit 2; stderr holds the owl nudge with the path
  when [t1] Bash `cp note.md ~/.claude/projects/p/memory/x.md`
    then exit 2
  when [t2] Bash `mv note.md ~/.claude/projects/p/memory/x.md`
    then exit 2
  when [t3] Bash `echo x | tee ~/.claude/projects/p/memory/x.md`
    then exit 2
  when [t4] Bash `echo x | rhx teesafe ~/.claude/projects/p/memory/x.md`
    then exit 2
  when [t5] Bash `echo x > ~/.claude/projects/p/memory/x.md 2>&1`
    then exit 2
  when [t6] Bash `echo '=>' > ~/.claude/projects/p/memory/x.md`
    then exit 2
  when [t7] Write file_path=~/.claude/projects/p/memory/MEMORY.md
    then exit 2
  when [t8] Edit file_path=~/.claude/projects/p/memory/user_role.md
    then exit 2
```
