# test fixture: concurrent peer reviews, with a bound at one level

- **l1** — `l1-a`, `l1-b`, `l1-c`, `l1-d`, in no group, so no bound binds them
- **l3** — `l3-a`, `l3-b`, `l3-c`, all in group `serial`, whose `concurrency` is 1

every reviewer records its own in-flight window into `.test/windows.log`, so a test
computes max-in-flight from OBSERVED overlap rather than from the wall clock.
