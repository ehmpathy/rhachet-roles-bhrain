# razor: hume, is and ought

shaves: a claim that cannot be tested · settled by: logic

## .the question

> **which value joins this "is" to this "ought"?**

no ought follows from an is alone. an absent premise is the gap; the value it needs has an owner, often the human.

## .the source

- Hume, *Treatise*, 3.1.1, 1739-40
- read via https://en.wikipedia.org/wiki/Is%E2%80%93ought_problem

## .fails when

- the ought is relative to a stated goal: "to reach B, do C" is a fact, checkable. in software most oughts are goal-relative; name the goal and the gap closes
