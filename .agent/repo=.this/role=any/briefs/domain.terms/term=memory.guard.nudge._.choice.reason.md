# domain.term.choice.reason: memory.guard.nudge

## .etymology

**nudge** — a push toward the right path, not a scold. the text exists to route the bot to a
durable home for what it wanted to remember; the halt is the means, the route is the point.

| word | why rejected |
|---|---|
| `error` | the call was not a fault; the bot chose a forbidden home |
| `warning` | a warning lets the call proceed; a nudge halts it |
| `notice` | reserved for the fault line a guard that cannot run prints |

## .evidence

- the hook stdout of other ehmpathy roles already uses "nudge" for a halt that names the paved path
  (`permissions.nudges`)
- each nudge ends in the routes, never in the rule alone (`asMemoryGuardNudge.test.ts.snap`)

## .disputes

none.
