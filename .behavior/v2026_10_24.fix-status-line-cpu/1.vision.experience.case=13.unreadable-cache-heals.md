# case=13 — an unreadable cache file is a miss that heals (sharp · critipath)

## .narrative

a second uid ran the seat once, or an odd umask left the cache file mode 000. the next repaint
cannot read it. the line must not blank: the read fault is a miss, so the line renders afresh and
one stderr row names the code, the path, and the fix. the miss then writes the cache by rename,
which replaces the unreadable file, so the repaint after it hits with no row.

## .bdd sketch

```
given('[case13] a seat whose cache file it cannot read')
  when('[t0] the seat repaints')
    then('the line renders, and one stderr row names the read fault and its fix')
  when('[t1] the seat repaints again')
    then('it hits, and prints no row')
```
