## .the gap, precisely

`rule.require.get-set-gen-verbs` gives `get` one guarantee and it is the whole reason the verb exists:

> *"get guarantees no side effects (the one pure axis)"*

this operation breaks it three ways, and **every one of the three is a write to disk**:

| the write | what it does |
|---|---|
| `findsertReviewSelfGitignore({ route })` | creates `review/self/.gitignore` if absent |
| `setSelfReviewTriggeredReport(input)` → `.since` | mints or updates the ask marker, and increments the attempt count |
| `setSelfReviewTriggeredReport(input)` → `.uptil` | claims first-adjudication with an atomic `wx` create |

🔴 **and the third one carries the gate**, which raises the stakes past cosmetics: the `.uptil` claim
is what decides whether the haste cue fires. a caller who reads the name as a query and calls it
twice burns the claim and silently retires a driver's confrontation.

**checkable evidence:**

```
git show HEAD:src/domain.operations/route/guard/review/self/getSelfReviewChallengeDecision.ts
  ⇒ both `findsertReviewSelfGitignore` and `setSelfReviewTriggeredReport` are already imported
```

⇒ so the shape is **extant**, and predates the round that found it. `c27ff1b` is the commit that
introduced the file.

## .the shape of the fix

the sanctioned verb is **`gen`** — findsert. the operation is precisely a findsert: it finds the
trigger report or mints one, then returns the verdict that follows.

```
getSelfReviewChallengeDecision  →  genSelfReviewChallengeVerdict
```

`decision` → `verdict` rides along because the return field is already `decision`, and
`genSelfReviewChallengeDecision` would read as *"generate a decision"* where `verdict` names what was
adjudicated. either name satisfies the rule; the verb is the part that must change.

**the code call sites are four**, and each is a one-line import + call rename:

- `src/domain.operations/route/stepRouteStoneSet.ts`
- `src/domain.operations/route/guard/review/self/getSelfReviewChallengeDecision.ts` (+ its test)
- `src/domain.operations/route/formatRouteStoneEmit.ts` (a docblock cite)
- `src/domain.operations/route/guard/review/self/getSelfReviewTriggeredReport.ts` (a docblock cite)

⚠️ **the file rename is the part to plan**, not the call sites: `git mv` plus the test, plus a sweep
of the two docblock cites.

🔴 **the split option, which is strictly better and strictly larger.** the reviewer offers it as an
alternative — separate the read of the verdict from the writes, *"so a caller can choose the pure
form"*. that yields

```
getSelfReviewChallengeVerdict   — pure. reads the report, returns the verdict
setSelfReviewPromiseAdjudicated — writes. the gitignore, the .since, the .uptil claim
```

⚠️ and it is **not** a free win: the current shape's write-then-decide order exists on purpose —
`firstAdjudication` is won by the atomic `wx` create and then read, so a pure verdict computed
*before* the write would be back to the racy count this round removed. **a split must hand the claim
from the writer to the reader, or it reintroduces the defect.** state that constraint in the fix.

## .why it is not done in this round

**SAFE ✅ · CLEAN 🔴.**

- **safe** — a rename moves no behavior, and four call sites plus a test is a mechanical change
- 🔴 **not clean** — `grep getSelfReviewChallengeDecision` returns **88 files**. four are code; the
  other **84 are behavior-route prose** across a dozen historical routes, each an immutable record of
  what a past round found. a rename either leaves 84 stale cites or rewrites 84 archaeological
  documents, and the second is forbidden outright

⇒ and this round already carries four independent deliverables to one gate, which its own yield flags
as a scope question for the council. a fifth, on a **nitpick**, against an **extant** name, is the
smuggled refactor `rule.always.fix-forward-under-scouts-honor` names by that word.

🟡 **the call is recorded as a fulcrum** —
`$route/.fulcrums/inventory.of=fulcrums.case=F16-the-get-that-writes-keeps-its-name.md` — because the
deferral is a judgment about ripple cost, and a judgment made alone is what a fulcrum list exists to
surface.
