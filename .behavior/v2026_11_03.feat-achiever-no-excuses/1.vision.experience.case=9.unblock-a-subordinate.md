# case 9 — unblock a subordinate (the densest walk)

feel: happy · care: critipath · actor: achiever, subordinate · seams: radio, store, cure tool, stop hook, clock

## .narrative

the achiever dispatched a task to a subordinate clone. the subordinate reports back through the radio:
"blocked: the test needs a prep key i don't hold." a passive supervisor would relay that up. this
achiever treats the subordinate's blocker as its own.

the talk hook never sees the report: it fires on a commander's prompt only. the radio seam has two
guards, and this case is the first: when the achiever dispatched the task, it set a goal for it, and
that goal's done check reads the task's state (DELIVERED). the report cannot be lost, because the goal
it bears on stays open until the check passes. (the second guard, for a report no goal holds, is the
stop's read of inbound radio tasks: case 13.) the achiever logs the report as progress on
that goal, then runs the same three questions.

it can cure it: it holds the prep key grant, so it unlocks, tells the subordinate, and the work moves.
where it cannot (the fix is in a third repo), it dispatches to that owner with an hour, and tells the
subordinate when to expect it. where only the commander can act, it names that one act. in no branch
does the subordinate's "blocked" end the achiever's turn.

## .[tn] — a sketch

```
given  a dispatched task to a subordinate, and a goal for it whose done check reads the task as DELIVERED
when   [t0] rhx radio.task.pull --via os.fileops --from @this --list shows a blocker report
then     the talk hook does not fire (it reads the commander's prompt only); the open dispatch goal holds the record
     and the achiever logs the report as progress on that goal
when   [t1] the cure is in reach → it runs it, replies via radio.task.push, the goal closes by its check
when   [t1'] the cure is another owner's → --cure.via dispatch --cure.await 60m (case 5)
when   [t1''] only the commander can act → --cure.via charter (case 7)
then     each branch leaves the goal closed, or blocked with a cure; the stop hook holds otherwise
```
