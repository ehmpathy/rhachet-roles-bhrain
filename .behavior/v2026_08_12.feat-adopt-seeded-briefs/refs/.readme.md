# refs/ — what was given to this route 📥

## .what

input the route received from outside itself — material it did **not** author. all else in a route
dir is output: stones, guards, yields, reviews.

| file | holds |
|---|---|
| `template.[feedback].v*.[given].by_human.md` | a feedback template handed to the route |

⚠️ **the template carries the org's bracket form.** it is extant input this route did not author,
so it stays until disturbed. every file **this** route names takes the coordinate form instead —
brackets are glob metacharacters, and a bracketed filename is hard to reference
(`rule.forbid.brackets-in-filenames`, librarian).

## ⚠️ .the wisher's seeds are NOT here — they are in `.seeds/`

a seed set is an **occurrence set**, so it is itemized as an inventory with its own summary:

```
.seeds/inventory.of=seeds._.md            # the axis, the counts, the gaps
.seeds/inventory.of=seeds.case=$id.md     # one entry per utterance
```

⇒ **`refs/` cannot hold them, and the reason is the summary.** `refs/` holds mixed input — the
feedback template above sits here too — so the set declares no axis and reports no gaps, which is
what `rule.forbid.itemization-without-coordinates` forbids. `.seeds/` gives the axis a home, and
sits beside `.fulcrums/` on the same convention.

see `rule.always.archive-the-wishers-words-verbatim` (driver) for when a seed is owed and what it
holds, and `.seeds/inventory.of=seeds._.md` for what this route settled.
