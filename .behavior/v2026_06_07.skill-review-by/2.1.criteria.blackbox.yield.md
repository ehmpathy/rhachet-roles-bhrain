# blackbox criteria: review.by skill

## usecase.1 = run all rubrics

```
given(role mechanic with 2 rubrics declared in rubrics.yml)
  when(rhx review.by --role mechanic --paths 'src/**/*.ts')
    then(stdout shows all rubrics with pass/fail marks)
      sothat(user sees the full review set outcome)
    then(each rubric shows ✓ or ✗)
      sothat(user knows which passed)
    then(files written to .reviews/by=mechanic/rubric=$slug.md)
      sothat(user can read full review details)
    then(exit 0 if no blockers, exit 2 if any blockers)
      sothat(ci/cd can gate on review results)
```

## usecase.2 = run single rubric

```
given(role mechanic with 2 rubrics)
  when(rhx review.by --role mechanic --for mech-failhides --paths 'src/**/*.ts')
    then(only mech-failhides rubric runs)
      sothat(user can iterate on one concern)
    then(stdout shows only that rubric)
    then(only .reviews/by=mechanic/rubric=mech-failhides.md written)
```

## usecase.3 = forward scope to review

```
given(role mechanic rubrics)
  when(rhx review.by --role mechanic --paths 'src/domain/**/*.ts')
    then(each review runs against the forwarded paths)
      sothat(user controls scope from one command)

given(role mechanic rubrics)
  when(rhx review.by --role mechanic --diffs since-main)
    then(each review runs against the diff scope)
      sothat(user can review only changed files)
```

## usecase.4 = brain override for evals

```
given(default brain fireworks/deepseek/v4-flash)
  when(rhx review.by --role mechanic --for mech-failhides --brain $other)
    then(review runs with the overridden brain)
      sothat(eval harness compares brains on identical inputs)
```

## usecase.5 = vibe override via rubrics.yml

```
given(rubrics.yml declares vibe.mascot=turtle, vibe.artifact=shell)
  when(rhx review.by --role mechanic)
    then(stdout shows turtle mascot and shell artifact)
      sothat(roles brand their reviews without cli flags)

given(rubrics.yml declares no vibe block)
  when(rhx review.by --role mechanic)
    then(stdout shows default owl mascot and magnifier artifact)
```

## usecase.6 = guard integration (single rubric, the guard-invocation shape)

```
given(review.by run with blockers)
  when(guard parses stdout)
    then(stdout summary contains parseable "N blockers" line)
      sothat(route guards can judge review results)
    then(stdout summary contains parseable "N nitpicks" line)

given(a guard dispatches one rubric via rhx review.by --role mechanic --for mech-failhides)
  when(that single rubric has findings)
    then(stdout still emits a summary block with parseable "N blockers" / "N nitpicks")
      sothat(a guard can invoke one rubric per peer review and tally straight off stdout)
    then(exit 2 when the single rubric has blockers)
      sothat(the guard-invocation shape mirrors how guard peer reviews run today)
```

## usecase.7 = error cases

```
given(role slug with no role directory that fits)
  when(rhx review.by --role nonexistent)
    then(fail fast with "role not found at .agent/repo=*/role=$role")
    then(exit 1)

given(role directory with no rubrics.yml)
  when(rhx review.by --role mechanic)
    then(fail fast with "rubrics.yml not found for role $role")
    then(exit 1)

given(rubrics.yml exists but --for slug not present)
  when(rhx review.by --role mechanic --for nonexistent)
    then(fail fast with "rubric not found: $slug")
    then(exit 1)

given(rubrics.yml has duplicate rubric slugs)
  when(rubrics.yml is parsed)
    then(fail fast with "duplicate rubric slug: $slug")
    then(exit 1)

given(rubrics.yml has an empty rubrics list)
  when(rubrics.yml is parsed)
    then(fail fast with "no rubrics found in rubrics.yml")
    then(exit 1)

given(rubrics.yml is malformed yaml)
  when(rubrics.yml is parsed)
    then(fail fast with "failed to parse rubrics.yml: $detail")
    then(exit 1)

given(no --role arg supplied)
  when(rhx review.by)
    then(fail fast with usage error)
    then(exit 1)
```

## usecase.8 = serial execution

```
given(role with 4 rubrics)
  when(rhx review.by --role mechanic)
    then(the 4 rubrics execute one at a time, in order)
      sothat(behavior mirrors the route guard's serial runner; parallelism deferred)
    then(stdout waits for all to complete before display)
      sothat(output is not interleaved)
```

## usecase.9 = partial failure

```
given(role with 3 rubrics, 2 pass and 1 has blockers)
  when(rhx review.by --role mechanic)
    then(all 3 rubrics shown in stdout)
      sothat(user sees complete picture)
    then(summary shows total blockers/nitpicks)
    then(exit 2)
      sothat(ci/cd gates on any failure)
```

## usecase.10 = stdout format

```
given(all rubrics pass)
  when(rhx review.by --role mechanic)
    then(stdout header shows success vibe: "righteous!")
    then(each rubric shows: r{N} {slug} ✓)

given(some rubrics fail)
  when(rhx review.by --role mechanic)
    then(stdout header shows concern vibe: "hmm, let's see...")
    then(failed rubrics show: r{N} {slug} ✗ with blocker/nitpick counts)
    then(summary section shows total counts)
```
