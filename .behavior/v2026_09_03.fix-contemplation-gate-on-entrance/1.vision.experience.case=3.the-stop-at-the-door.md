# case=3 · the stop at the door

- **coordinates** = `enter-review × fresh-unanswered × live`
- **feel** = sharp · **care** = critipath · **verdict** = forbidden → demoed

today this is caught — but only after a full review round and a judge pass have burned. **this case
is about *when*, never whether.**

## .the narrative

*driver, one minute after a critique landed*

three reviewers came back, one with blockers. I have not written a `.taken`, but I am impatient, so
I run `--as passed` to see what happens.

**today** all three spin up again. two are clean and cached, so they are cheap. the third is not.
twenty minutes and a few hundred thousand tokens later the judges run, pass, and *then* the gate
tells me what it could have told me at second zero.

**now** the door answers at once, with the same reply-prompt tree — no reviewer ran, no round was
spent. **the answer arrived before the cost did.**

**the aha:** the gate was never wrong about *what* to require — it was wrong about *when*. moved to
the entrance, the same rule no longer costs a review round to enforce.

## .why it fails safe

**fast** — zero subprocesses; the refusal costs a directory read · **loud** — the same reply-prompt
renderer the exit gate uses, so one format is learned once · **teaches the fix** — cites the file to
read, the file to write, the command to run.

🔴 **`[t0]` asserts no meter advances, and that matters beyond cost:** a round spent to be told *"you
owe an answer"* is a round the reviewer cannot spend later to **confirm the fix**. the exit-gate
position quietly drained the budget that convergence depends on.
