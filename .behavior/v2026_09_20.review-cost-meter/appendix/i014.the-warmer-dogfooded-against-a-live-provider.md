# i014 — the warmer, dogfooded against a live provider

dated 2026-09-24, on `beav/feat-review-cost-meter`, brain `fireworks/deepseek/v4-flash`.

every prior clamp on the warmer ran against a stub. the yield said so outright — "what is
proven is what the warmer RECORDS, never that a poke moves a real provider's cache." this is
the first run where a poke met a real replica.

## .the setup

```bash
rhx review --rules '…rule.forbid.stdout-on-exit-errors.md.min' \
           --paths-with 'src/domain.operations/review/warmer/asReviewWarmerPlan.ts' \
           --warmer 2x,1m --brain fireworks/deepseek/v4-flash \
           --output '.behavior/…/.reviews/peer/5.1.execution.from_vision._.review.i999.dogfood.r1._.given.by_peer.dogfood-warmer.report.md'
```

the `--output` path decides this, and that is itself the first defect found.

## .defect 1 — a hand `rhx review` spawns no warmer, and says naught about it

the default output path produced a review that succeeded with no warmer line at all — no
spawn, no refusal, no mention.

the gate is `review.ts:470`:

```ts
const laneOfReview = asReviewRunIdentity({ output: outputPath });
if (warmerPlan && reviewed.outcome === 'reviewed' && laneOfReview) …
```

a hand review writes to `.review/$branch/$isotime.output.md`, which does not match
`GRAMMAR_OF_GUARD_REVIEW_OUTPUT`, so `laneOfReview` is null and the whole block skips.

the behavior is correct (a hand review has no next round, so it must not spend — `0.wish`
bar 11); the silence is not. `emitReviewWarmerSpawn` has a `refused` branch whose own test
reads "it is not silent — a refusal is the loudest outcome," and that branch is unreachable
from the one case a driver hits most: `--warmer on` is the default, so a driver who leaves it
and runs a review by hand gets a warmer they asked for and no word that it never came.

the defect is invisible to every extant test, since the suites call `genReviewWarmer`
directly and never traverse the `laneOfReview` gate above it.

### repaired the same day

first caught as a dream on the ground that the acceptance clamp collides with a peer's
in-flight `--polluters` work — a ground that did not survive one `git status`:
`reviewWarmerFlag.acceptance.test.ts` is untracked, this branch's own file; the yield's
4-of-5 note was about a different file it merely resembled. an objection whose weight rests
on a dependency is worth one re-read before it earns a deferral.

| | |
|---|---|
| the fix | the emit hoists above the lane gate; the gate gets its own `refused` reason. the spawn stays inside, so bar 11 is untouched |
| the clamp | `reviewWarmerSilence.acceptance.test.ts` — a real review, a laneless `--output`, asserted on stdout |
| proven red | reverted the one-line gate → 9 of 15 failed, and the "the review itself succeeded" row stayed passing, so the red was the silence and never a broken fixture |

the clamp's first draft was itself a false red: it spawned from a temp-dir cwd, which reports
"available brains: (none)" — the brain registry looks up against `.agent/` relative to cwd
(`rule.forbid.cwd-outside-gitroot`). the review died before the emit, stdout was empty, and
every silence assertion went red for the wrong reason. a clamp that goes red is not yet a
clamp that bites; the "the review itself succeeded" row parts the two reds.

## .result 2 — the poke works, and the two-poke arc shows the whole mechanism

| | poke 1 | poke 2 |
|---|---|---|
| at (from review 2) | `+68s` | `+129s` |
| why | `1m since the last touch` | `1m since the last touch` |
| promptTokens | 3,225 | 3,225 |
| cacheGetTokens | 0 | 3,224 |
| hit | false | true |
| cost | `$0.001383360` | `$0.000036648` |

37.7× cheaper on the hit. poke 1 met a cold replica, missed, and populated it; poke 2 landed
on the same replica and was served 3,224 of 3,225 tokens — 99.97%.

that is the affinity pin proven at the poke layer: the two pokes, one minute apart, land on
the same replica — the property `x-session-affinity` exists to buy, built by the 2026-09-18
repair. a run with no pin would have dispatched poke 2 arbitrarily and read `cacheGetTokens: 0`
again.

the miss is a fact, not noise: poke 1's `hit: false` rides in the row and never joins a rate
(`0.wish` bar 10, observed rather than asserted). it also confirms the code's own claim that a
miss bills in full — a miss cost 37.7× a hit for the identical prompt.

## .what this does NOT prove

- it is not `case=6 [t3]`. that sketch needs two review rounds with a repair between, and
  asserts the second round's cache share exceeds the first's. this proves a poke hits; it does
  not prove a poke makes the next review hit
- the gap was 1 minute, not 20–120. the cadence was compressed to fit one session, so this
  says naught about whether a 15m cadence holds a prefix across a real driver gap. the
  eviction probe already measured that separately
- one lane, 3.2k tokens. a real lane's prefix is ~58k, and the census that motivated this work
  ran over 11 lanes

## .result 5 — the cost meter read these rows back, and the answer was uncomfortable

added 2026-09-24, once `F27`'s join shipped. the same run dir, through `review._.cost --of run`:

```
│  ├─ cost: $0.000109706
│  └─ warmer: $0.001420008  over 2 pokes, 1 of which HIT
```

the warmer cost 12.9× the review it is attributed to — and the timestamps make it worse than a
ratio. the pokes landed 68s and 129s after the review they sit beside. so this spend protected a round that never came, because the dogfood ended.

that is `0.wish`'s own named weakness, recorded there as a bounded residual: a guard whose
budget is already exhausted still spawns, and the warmer then pokes for a round that will not
come — observed rather than predicted, and observable only because a surface finally opened
the file. the bar's name and test were met for a full day while this was true and unreadable.

the figure does not generalize, and the reasons go on the record so nobody cites it as one
that does:

| why it is not a general result | |
|---|---|
| the scope is a toy | one lane, 3.2k tokens. a real lane's prefix is ~58k, and the review side of the ratio grows ~18× |
| the warmer cost is one miss | poke 1's `$0.001383360` is 97.4% of the total. a warmer that hit twice would have cost `$0.00007` — 19× less than the review |
| the review was already warm | it cost `$0.000109706` because review 1 had warmed it 53s earlier. against a cold `$0.000865700` the ratio is 1.6×, not 12.9× |

what does generalize: a warmer that outlives its last round is pure loss, and the coarse spawn
gate permits exactly that. the magnitude is bounded by `k` pokes; the waste is bounded by
naught the guard knows.
