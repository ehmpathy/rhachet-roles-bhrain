the case below: a guard refused a quick reply because the name of a slow verb sat inside its text.

## .what happened

a foreground `director.reply` carried a done line whose proof named the test verb by its command. the pretool guard refused the call: the test verb runs past 60 seconds, so it must run in the background.

## .the two claims

- the reply guard: a foreground call is cut at 60 seconds, and this command runs the slow verb
- the reply verb: it only files a message; it runs no test

## .the run

the same reply, sent in the background, exited 0 in under two seconds. the slow verb never ran: its name sat inside the `--what` text.

## .the verdict

the guard matched the verb name anywhere in the command line, quoted text included. its claim failed the run. the reply was not slow; the match was wide.

## .the cost

one refused reply, and a re-send in the background.

## .the cure

the guard matches the verb only at a command position, never inside a quoted flag value. until that lands, a reply that must name a slow verb runs in the background, or names the proof in words.
