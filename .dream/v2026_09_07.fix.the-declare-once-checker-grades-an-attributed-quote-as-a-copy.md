# 🌙 dream: the `declare-once` checker grades an attributed quote as a copy

- **kind** = fix
- **owner** = `ehmpathy/rhachet-roles-bhrain` — `src/domain.roles/telepath/skills/review.for/review.for.declare-once.claims.js`
- **caught** = 2026-09-07

## .the cue that fired

a conformance pass repaired nine glossary clusters that had restated a published brief. the repair
`declare-once` prescribes is **quote with attribution**, and the role's own readme already models it:

> **elucidation is the transfer of a concept until the peer can USE it.**
> — quoted from `define.elucidation`, which declares it; amend it there

the checker reports every one of those repairs as a fresh violation. so the artifact that obeys the
rule and the artifact that breaks it render identically.

## .the gap, precisely

`review.for.declare-once.claims.js` normalizes each file to a word bag and reports any span of ≥12
words that appears in two or more files. **it reads no markdown structure**, so it cannot part:

| the shape | what it is |
|---|---|
| the same claim typed twice, in two files | the defect the rule names |
| a `>` blockquote plus an attribution line that cites the file which declares it | **the rule's prescribed repair** |

measured 2026-09-07 on `term=prose.emphasis`:

- `_.choice._.md:33` and `_.choice.reason.md:51` each quote `rule.forbid.emphasis-noise`'s question
- each quote sits in a `>` block, directly under a line that cites the rule by path
- the checker reports all three files as one violation

⇒ the count is not merely inflated. **a repaired file stays flagged, so the flag stops to signal
work** — and a reader who conforms to the report will delete a citation the rule requires.

## .the shape of the fix

1. **skip a `>` blockquote whose adjacent line carries an attribution** — a path plus one of
   `quoted from` · `declared by` · `states` · `amend it there`. the adjacency window is one line
   above the block's open or one line below its close
2. **report it, do not silently drop it** — an `attributed: N` line beside the count, so a reader
   can see the checker saw them. a silent skip is the failure class the audit dreams already name
3. **clamp it** — a two-file fixture: one bare copy, one attributed quote. the bare copy must go
   red and the attributed quote must not (`rule.require.clamp-edge-cases`)

🟡 **do not skip every blockquote.** a copied claim inside an unattributed quote is still a copy,
and that is the common shape in a route artifact that restates a brief.

## .why it is not done in this round

**safe? yes. clean? no.**

the attribution heuristic is a design question rather than a one-line predicate — the vocabulary is
open (`quoted from`, `declared by`, `per`, `amend it there`), and a loose match would swallow real
copies that merely sit near a path. that wants its own round, its own fixture, and its own clamp.

and the checker is a candidate for promotion to a 🪨 solid skill
(`.dream/v2026_09_07.enskill.the-canons-mechanical-checkers-are-solid-skills-not-a-scratch-pad.md`),
so its predicate becomes published behavior. a heuristic shipped in haste is harder to withdraw
than to get right.

## .the fulcrum

> **an instrument that grades a rule's own prescribed repair as a violation of that rule is not
> merely noisy — it inverts the incentive.** the cheapest way to clear its report is to delete the
> citation, which is the one edit the rule forbids.
>
> rework: **clean** — the predicate is local to one checker. the deferral is on DESIGN, never on
> ripple.
