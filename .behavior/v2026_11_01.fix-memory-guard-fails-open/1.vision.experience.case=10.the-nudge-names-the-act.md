# case 10: the halt names what the guard saw: a write, a copy, or a write it could not place

row 8 (rows 4, 7, 54, 57 produce the other acts; their demos are `case=2` and `case=9`).

proof: `src/contract/cli/asMemoryGuardNudge.test.ts` and its snapshot; `src/domain.roles/learner/getLearnerRoleHookCommand.integration.test.ts` `[caseA]` `[t1]`; `src/domain.operations/memory/getMemoryGuardVerdict.test.ts` ("blocked verdict of a copy verb names the copy, not a write").

## .narrative

a halt is one verdict with three acts, and the nudge reads differently for each, so the clone is told the one step that fits.

- a **write** (`echo x > …/memory/x.md`, `tee`, `teesafe`, `cp` or `mv` whose destination is memory) halts with `blocked: write to claude native memory` and no read hint: the clone meant to write, and the route is the durable brief.
- a **copy** (`cp ~/.claude/projects/p/memory/a.md ./a.md`, a copy out of memory) halts with `blocked: a copy beside claude native memory`. the clone may have meant only a read, so the nudge adds `only a read?`: a `cp` or `mv` beside memory blocks in either direction; read it with `cat`, or redirect to an absolute path outside memory. this is the extant over-match, kept, and the nudge is what makes it a one-call detour, not a dead end.
- an **unplaced** write (a redirect through a `$var`, or a relative path with no cwd known) halts with `blocked: an unplaced write beside claude native memory`, and the hint says why it blocks and the route: redirect to an absolute path outside memory.

all three keep the same tail: why memory fades, the durable homes (`briefs/`, `skills/`), the secrets line, and the instinct line.

## .bdd sketch

```
given the nudge for a memory path
  when [t0] the act is write
    then it names `blocked: write to claude native memory`
    then it holds no `only a read?`
  when [t1] the act is copy
    then it names `blocked: a copy beside claude native memory`
    then it holds `only a read?` and `read it with cat`
  when [t2] the act is unplaced
    then it names `blocked: an unplaced write beside claude native memory`
    then it holds `$var` and `redirect to an absolute path outside memory`

given [caseA] a linked learner
  when [t1] `cp ~/.claude/projects/p/memory/x.md /tmp/x.md` fires the hook
    then exit 2
    then stderr holds `✋ blocked: a copy beside claude native memory` and `read it with cat`
```
