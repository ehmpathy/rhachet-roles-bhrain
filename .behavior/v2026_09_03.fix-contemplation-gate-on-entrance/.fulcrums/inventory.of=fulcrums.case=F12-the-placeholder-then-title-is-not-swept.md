## .taken, and why at the time

**deferred to a dream**, with r005's premise refuted and its observation kept.

the premise — *"the same branch treats that title as a defect elsewhere"* — is false, and
the evidence is one line in the file r005 cited. `[t10.5]` snaps **both** streams inside one
`when`, so its two titles must differ or the jest keys collide; they name the stream because
they had to. **`[t10]` in that same file still reads `then: stdout has good vibes`.** the
retitle was a key-collision repair, never a convention.

⇒ so this is **not** an inconsistency this branch introduced, which is what parts it from
the two blockers it resembles.

### 🔴 why not the middle option, which is the one that looks reasonable

to retitle only the four r005 named would **manufacture** the very defect the other two
findings punished: four authoritative frames beside 371 stale ones, where the stale ones now
read as deliberate exceptions rather than as a uniform habit.

⚠️ **that is the sharp asymmetry here.** for the emphasis markers, the partial sweep was
worse than no sweep. so is this one — and unlike the markers, the full sweep is genuinely
out of reach, not merely large.

## 🔴 .the call above was REVERSED at i022, and the entry says so rather than quietly rewritten

**the 5% doubt named below was the right read, and this entry took the wrong side of it.**

### what the reversal rests on

the ground is the one the 5% doubt already identified: **new code owes the current standard.**
what makes it decisive rather than merely arguable is that the boundary is **mechanically
checkable** — `git diff origin/main` decides which bytes this behavior authored, with no
judgment per site:

| the bytes | the rule | why |
|---|---|---|
| **added by this branch** | 🔴 **retitle, now** | a deferral about other people's code cannot excuse my own new code |
| **pre-extant on `origin/main`** | ✅ deferred to the dream | 369 sites, mostly outside the contact set |

⇒ the sweep set was measured rather than trusted to either reviewer's count:

```
git diff origin/main -- blackbox/__snapshots__ | grep '^+exports.*stdout has good vibes'
```

**seven**, not four. r005 named four, r007 named two, and one — `peer-budget-isolation [t2]` —
**was named by neither.** all seven are now closed, verified by that same command, which now
matches **0**, and by a symmetry check: 7 keys in the `.snap` files, 7 titles in the `.ts` files,
one matched pair per frame.

### 🔴 the verification ground below was OVERSTATED, and that matters more than the count

this entry argued that *"an unverified 375-key hand edit is the fabrication this drive refused
twice."* **that conflates two rungs of the ladder this drive itself established.**

a title-and-key retitle touches **no snapshot value**. it is the **stale** rung — bytes exist, the
delta is a string, and the pair is checkable by grep symmetry. the technique is independently
proven on runnable twins, where `jest --ci` refuses to write keys, so `1586 passed` is positive
proof a moved key still matches its title. ⇒ **the credential gate was never what blocked this.**

**scope is the only ground that survives**, and it is sufficient on its own for the 369.

### ⚠️ the consequence, stated rather than hidden

three files now read **mixed** — `peer-budget-isolation` carries two named `then` titles at `[t0]`
and `[t2]` beside two placeholders at `[t3]` and `[t4]`, because those two keys predate this
branch.

that is the ragged edge this entry originally argued against, and it is **accepted on purpose**:
any other line — sweep-the-file, sweep-the-directory — moves the ragged edge somewhere less
principled and adds a judgment call per site. **a boundary a command can compute beats a
boundary a reader must adjudicate**, and the dream carries the rest.
