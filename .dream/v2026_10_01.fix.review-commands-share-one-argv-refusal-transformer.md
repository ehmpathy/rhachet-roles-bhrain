## .the shape of the fix

one pure transformer, e.g. `src/contract/cli/asArgvRefusals.ts`:

```ts
asArgvRefusals({ argv, known, valued, repeatable }): { unknown: string[]; stray: string[]; repeated: string[] }
```

it folds in `FLAGS_OF_DISPATCHER` (known, valued, repeatable) so no command restates it. each
command then declares only its own sets and help text, and renders the three lists. a
data-driven unit test pins the walk once; each command's acceptance snapshots stay as-is.
