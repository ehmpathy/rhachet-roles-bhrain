# case=5 · the preemptive pad

- **coordinates** = `driver × none × live`
- **feel** = sharp · **care** = critipath · **verdict** = demoed
- **requirements** = `0.wish.md` req 1 (refused by default)

🔴 **the loophole cell.** a gate that fires only at exhaustion is a gate a driver walks around by
arrival early. this is why the `live` column is in the grid at all.

## .the narrative

*driver, on `5.1.execution`, round 1, every lane at 1/3*

i have read the halt copy. i know that when `mech-rules` runs dry it will refuse my top-up. so i top
up **now**, while the meter is healthy and no refusal has ever been printed.

```
$ rhx route.guard.budget --for review --add 10 --stone 5.1.execution
```

```

🗿 route.guard.budget
   ├─ route = .behavior/v2026_09_17.fix-budget-grant-needs-urgent-concession

   ├─ scope = the latest level (l1) — 3 reviewers, each 1/3
   │
   └─ ✋ refused — a round is earned, never taken
      ├─ the last round carried no urgent concession
      │  └─ live absorptions on this stone: none
      │
      ├─ 🟡 the meter is not dry. a grant is refused whether or not it is.
      │     the gate reads the EVIDENCE, never the counter.
      │
      └─ what to do — yours to run
         └─ drive the rounds you have. if a concern ships nameable harm,
            concede it `--severity urgent` and this grant is yours.
```

🔴 **the gate reads B, and B alone — never C.** a gate conditioned on exhaustion would be a bound a
driver defeats by anticipation: top up at round 1, and the refusal never fires for the life of the
stone. ⇒ **the `live` column must be refused for the `exhausted` column's refusal to carry weight.**

⚠️ **and the copy must say why**, or a driver reads the refusal as a bug: the meter is visibly
healthy, so *"budget exhausted"* would be a lie and *"refused"* with no reason reads as a
malfunction. the 🟡 line is what makes the refusal legible at a live meter.

**the aha:** *i thought the bound was on the counter. it is on the argument — and i had not made one
yet.*

## .the bdd timeline

```gherkin
given a stone `5.1.execution` with three l1 lanes, each budget 3, rounds 1
  and NO live absorption on the stone                                 # B = none
  and every lane has budget left                                      # C = live

[t0] when the driver runs route.guard.budget --add 10 (bare form)
     then the command exits 2
      and every lane's `budget: 3` is UNCHANGED
      and stderr states the meter is NOT dry, and that this changes naught

[t1] when the driver runs the same add with --peer mech-rules
     then it is refused identically                                    # 🔴 F09 — the gate precedes the scope parse

[t2] when the driver runs the same add with --level 1
     then it is refused identically                                    # 🔴 F09 — all three scopes, one gate

[t3] when the driver drives three real rounds and the lane exhausts
     then the refusal it meets is case=1's                             # the same gate, different copy branch

[t4] given a live urgent concession stands from round 1
     when the driver runs the bare --add 10 at a LIVE meter
     then it is GRANTED                                                # ⚠️ the residual hole, walked
      and 10 rounds land on a lane that had 2 left
```

🔴 **`[t1]` and `[t2]` are the bypass check, and they are the reason `grant-scope` is not a grid axis
but IS an invariant** (`dimensions §5`). a gate that sits after the `--peer` / `--level` parse would
refuse the bare form and permit the scoped one — a bypass exactly one flag wide.

⇒ **the invariant: the gate precedes every scope parse and every guard read.** in the extant
`routeGuardBudget`, that means the check lands before line 2252's guard enumeration, never beside the
write at 2312.

🔴 **`[t4]` is the honest residual and it is walked rather than buried.** with the gate on B alone,
one urgent concession permits an arbitrary pad on a healthy lane. two bounds are absent by design:

| absent bound | where it is recorded |
|---|---|
| the target lane must be exhausted | `F10` — best-guessed **no**, to keep one predicate |
| `--add N` has a cap | `dimensions §6` — unmechanized residual; `ROUNDS_OFFERED_ON_TOPUP` is where a cap would live |

⚠️ **`[t4]` is the strongest argument against the one-predicate best guess.** if a reviewer or the
wisher rules that the pad matters more than the simplicity, `F10` flips and the gate reads `B ∧ C`.

## .why it fails safe

**loud** — the refusal explains the healthy meter rather than let it read as a malfunction
(`rule.forbid.surprises`) · **uniform** — the same verdict at every scope, so no flag is a bypass ·
**early** — the check precedes the guard read, so a refused pad touches no file.
