# case=6 — review progress with no passage write (sharp · alterpath)

## .narrative

a driver waits on a peer review. the seat's line reads `l1@i001`. the reviewer finishes its
second round, and a second later the driver glances at the line and sees it tick to `l1@i002` —
progress, though no stone moved. why it ticks: the guard appended a row to
`.route/reviewPeerMeters.jsonl` (the file `getAllRouteStoneGuardReviewPeerMeters` reads), and
that file is on the fingerprint's allowlist, so the repaint missed and recomputed. a stop hook
that rewrites `.drive.blockers.latest.json` beside it moves naught the render reads, so the
driver's seat stays on the cheap path there.

later the driver steps away for a minute. the line still reads right when they return: if some
future render input ever lives where the fingerprint does not look, the 30s max age is the
backstop, so a line is at most 30s stale, never stale forever.

## .bdd sketch

```
given('[case6] a bound route in peer review at l1@i001, cache warm')
  when('[t0] a meter row for round 2 is appended to .route/reviewPeerMeters.jsonl, no passage write')
    then('the next repaint prints l1@i002')
given('[case6b] a warm cache whose fingerprint still matches, aged past 30s')
  when('[t0] the line repaints')
    then('the render runs once and the cache is rewritten')
```
