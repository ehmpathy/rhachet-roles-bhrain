# case 11: a tee is graded by where it lands

rows 62, 63, 66 and 67 (rows 59–61, 64, 65 are the rest of the tee walk).

proof: `src/domain.operations/memory/getMemoryGuardVerdict.test.ts` ("allows a memory read piped to tee into a durable brief"; "blocks a tee whose operands may land in memory: cat … | tee out.md"; "allows a memory read piped to tee outside memory"; "blocks a copy verb through an anchor: cd … && tee a.md" and "…: D=…; echo x | tee $D/a.md"; "blocks a write through a folded cwd: cd …; cd memory; tee a.md").

## .narrative

a clone finds a note in claude native memory that belongs in the repo. it does what the nudge advises: read it, and put it in a durable brief. it runs `cat ~/.claude/projects/p/memory/a.md | tee .agent/repo=.this/role=any/briefs/b.md` from the repo root.

the guard sees a memory path and a tee. it does not halt on the memory path alone, as it does for `cp` and `mv`: a tee writes its operands and naught else. it places the one operand against the harness `cwd`, finds it lands in the repo, and lets the call through, silent. the note is now in a brief.

the same pipe with no `cwd` known cannot be placed: `tee out.md` might land in memory. the guard does not guess. it halts with the unplaced nudge, whose route is an absolute path outside memory. a tee to `/tmp/out.md` needs no cwd, and passes.

the same grade cuts the other way. a clone that runs `cd` into the memory dir and then `tee a.md` writes into memory: the guard folds the `cd` into the cwd, places the operand there, and halts. so does `tee $D/a.md` when `D` was set under `.claude/` earlier in the command: the guard cannot let a var it saw point at memory slip past.

## .bdd sketch

```
given a memory note and a harness cwd at the repo root
  when [t0] the clone pipes the note to tee into a durable brief
    then the verdict is allowed
    then the call proceeds silent
  when [t1] the clone pipes the note to tee at an absolute path outside memory
    then the verdict is allowed

given a memory note and no harness cwd
  when [t2] the clone pipes the note to tee at a relative path
    then the verdict is blocked, act unplaced
    then the nudge names `an unplaced write beside claude native memory` and the absolute-path route

given the same note
  when [t3] the clone runs `cp` of the note out of memory
    then the verdict is blocked, act copy: cp and mv are graded blunt (row 8), tee is not

given a memory dir
  when [t4] the clone runs `cd` into it, then `tee a.md`
    then the verdict is blocked: the folded cwd places the operand in memory
  when [t5] the clone sets `D` to it, then pipes to `tee $D/a.md`
    then the verdict is blocked: a var set under `.claude/` is never let through
```
