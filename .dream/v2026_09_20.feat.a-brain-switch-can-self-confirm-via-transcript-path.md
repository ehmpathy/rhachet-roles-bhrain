# 🌙 dream: confirm a brain switch via the hook's own `transcript_path`

**kind** = feat · **owner** = `ehmpathy/rhachet-roles-bhrain` · **caught** 2026-09-20 ·
**status** = built and withdrawn 2026-09-20; the ask moved upstream as `ehmpathy/rhachet#544`

## .the cue that fired

the `5.4` dogfood dispatched `/model claude-opus-4-8[1m]`, the brain-cli accepted it, and the drive
could not record that acceptance. the wisher asked: *"shouldn't it find the exact session via
`rhx clone whoami` and target JUST that clone's transcript?"*

## .the gap, precisely

`clone get` cannot map a clone to its own transcript:

| id | owned by | where it lives |
|---|---|---|
| the clone serial | rhachet | `RHACHET_CLONE_SERIAL` |
| the transcript exid | the brain-cli | the transcript's filename |

rhachet infers the link from `(cwd, spawnedAt)` (`genCloneHistoryLink.js:19-21`). with two clones in
one cwd it ties, refuses, and quarantines each candidate (`:61-68`) — measured: `exidsAmbiguous`
over 11 ids, empty history.

the discriminator exists on the hook side: the platform names the transcript in `transcript_path`,
and `src/contract/cli/telepath.ts:95-102` already parses it. ⇒ `clone get` reads a **peer**; a
brain-switch verify is a self-read.

## .the shape of the fix

1. record the prescribed value and the request time when `dispatchBrainSwitch` fires
2. on a later hook turn, read `transcript_path` and scan its tail for the brain-cli's reply
3. a match confirms; a refusal halts loud and names the rejected value

no vocabulary bridge is owed: the guard value is the brain-cli's own `/model` argument (`F10`), and
so is the reply.

the wisher, verbatim: *"this looks gross. shouldnt we just be able to get it from `rhx clone
whoami`?"* — and *"for now, just do it without the double confirmation."*

⇒ **the mechanism was sound and its place was wrong.** a consumer repo had to add a shell stdin
capture to every hook wrapper and scrape another tool's prose — a dependency nobody declared.

the reply shapes, measured, for whoever builds it upstream:

```
accept:  {"type":"system","content":"<local-command-stdout>Set model to \u001b[1m<brain>\u001b[22m</local-command-stdout>"}
refuse:  {"type":"system","content":"<local-command-stdout>Model '<brain>' not found</local-command-stdout>"}
```

two traps:

1. **the ANSI anchor carries the load.** a brain value can contain `[1m]` (the million-token
   marker); a `/\[[0-9;]*m/g` strip turns `claude-opus-4-8[1m]` into `claude-opus-4-8`, and the
   compare fails on a switch that landed
2. **bind on `type === 'system'` and the `<local-command-stdout>` wrapper, both.** of 57 records that
   named one brain value, 55 were the conversation's own prose about it

## .why it is not done in this round

the self-read belongs in rhachet's contract. the wisher ruled single-confirmation for now.
