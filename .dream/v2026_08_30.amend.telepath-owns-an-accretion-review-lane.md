# dream: telepath needs a REVIEW LANE for accretion, not a hook

**kind**: amend · **target**: this repo's seed [#386](https://github.com/ehmpathy/rhachet-roles-bhrain/issues/386)
(`feat(telepath): generic communication role for bhrains`) · **caught** 2026-08-30

## .why this is an amendment and not a new seed

#386 already lists `rule.forbid.chronological-accretion` among the generic communication rules
that move to telepath. **a seed that asks telepath to own that rule would be a duplicate.**

what #386 does **not** carry is the rule's **enforcement path** — and #386 raises exactly that gap
for a peer rule, in its own words:

> *"lowercase … is a good rule with NO enforcement path — it is a `prefer` nitpick with no hook, so
> base-model gravity overrides it under load … same class of problem: a good rule that leans on
> memory instead of enforcement."*

⇒ accretion is in that class. this dream answers the enforcement question for it, with a measured
result — and the answer is **not** the mechanism #386 reaches for.

## 🔴 .a preToolUse hook CANNOT catch accretion

#386's peer dream proposes a preToolUse hook. that mechanism fits lowercase and **structurally
cannot fit accretion**:

| the rule | the defect lives in | so a hook can see it? |
|---|---|---|
| lowercase, shouts, gerunds | one **token**, in the edit itself | ✅ yes — the edit carries the violation |
| chronological accretion | the **relation between paragraphs**, across the whole document | 🔴 no — the edit is locally correct |

**every append that accretes passes a per-edit check.** each new section is true, answers a real
correction, and reads clean on its own. the violation is that a later paragraph restates a claim an
earlier one already made — which is invisible to any actor that holds only the diff.

⇒ so the mechanism must be one that **holds the whole document at once and asks "does this say one
thing?"** that is a review lane, not a hook.

## .the ask

telepath publishes a **review rubric + lane** for its own generic prose rules, so any role runs:

```sh
rhx review --rules '<telepath accretion rubric>' \
           --paths '<the tree under revision>' \
           --goal exhaustive
```

⚠️ **one `--rules` flag only.** repeated flags take the LAST one silently, and a comma-joined list
errors outright. the header prints `rules: N` — verify it, or the pass grades against the wrong
rubric and reports inflated results.

the same lane serves every rule in #386's migration list; accretion is simply the one with measured
evidence behind it.

## .the evidence — measured 2026-08-30, this repo, `beav/feat-adopt-seeded-briefs`

seven passes against `rule.require.timeless-lessons` over ~60 briefs:

| surface | passes | blockers |
|---|---|---|
| role briefs | v2 → v5 | 3 → 1 → 1 → **0** |
| `role=any` | v5 → v7 | 3 → 1 → **0** |

each pass ran 50–120s at ~$0.003–0.016. total under five cents.

against that: **six prior rounds in which the author re-read their own briefs caught none of it.**
the human caught three by hand before they mandated the sweep.

⚠️ **one result is decisive**: v6 flagged text the author was certain they had already fixed. the
fix had been applied through a `.agent/` symlink into `dist/` and silently reverted by the next
build. only a reader with no memory of the edit could surface it.

## .the mechanism — why a re-read fails and a review does not

> a re-read re-reads the author's **intent**, and the intent fills the seam. a reviewer has no
> intent to consult, so the seam is all it sees.

this is the premise `rule.always.get-a-second-opinion-before-foreman` (driver) rests on. that brief
argues *"it sees what one brain misses"* and does not state **why** one brain misses — that line is
owed to it, and is tracked separately.

## .the cue this earns

> **after any round where a correction was answered by an APPEND rather than a revision, run the
> rubric.** a re-read will pass it.

per `research.selfreview-effectiveness`, a when-then cue scores d ≈ 0.65 where a principle alone
scores d ≈ 0.05 — so the cue is the deliverable, and the lane is what gives it teeth.
