# case 4 — an absent file reads as absent

sharp · critipath · cell bound-once · absent · repaint · one · — · —

## .narrative

the human upgrades, opens a session on a bound branch, and glances down. where the stone used to
be, the line reads `🗿 status unknown, rhx route.drive`. it is not blank, so they know the line is
alive; it names the one command that fills it. they need not run it: at the end of their first
turn the stop hook runs `route.drive`, and by the next glance the line reads
`🗿 1.vision, yield 🌾`. the gap lasted one turn, and it told them what it was.

behind the glance: the release that ships this changes the command to a bash reader, but no
render input has been written since, so no status file exists. the reader will not boot node to
render one, so it says so instead. a torn or unparseable file (inventory case 7) reads the same way.
