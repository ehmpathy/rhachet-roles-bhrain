# 5.1.execution.from_vision.yield

the vision, executed: one optional guard key, one inline parse branch, one entry hook.

⇒ the road to each decision — measurements, dogfood reverts, review rounds — is in
`appendix/5.1.execution.the-road.md`. this file states what holds.

## .what shipped

### the core

- **the field** — `brain?: string` on `RouteStoneGuard`
- **the parser** — an inline `key: value` branch
  - `model:` is matched as an alias and warned, its value dropped (`F2` · `F18`)
  - a value that is not a literal slug is refused (`isGuardValueLiteral`), so no fabricated slug
    reaches `/model`
- **the hook** — `applyStoneBrainOnEntry`
  - an absent key returns before any I/O, so `case=10` pays zero
  - a declared key dispatches unconditionally, with no compare and no live-brain read (`F14`)
- **the term** — the `term=route.guard.brain` cluster and its children

### the halt

- **seven causes**, derived from `HALTS` so the compiler is the index: `unenrolled` (exit 2) ·
  `killed` · `unreadable-clone` · `unreadable-payload` · `unreadable-address` · `timed-out` ·
  `spawn-failed`
- each renders the fix its own cause needs; `rhx enroll` leads only for `unenrolled`
- `timed-out` adds an `also` line that names `rhx enroll`, since a 2s race can land either cause
- the acceptance halt is snapped, with its host-dependent cause block scrubbed

### the outcome

- `formatStoneBrainOutcome` renders `requested` · `undispatched` · `inherited` · `none`
- `requested` is a declared brain, never an observed one — `clone say` proves submit, not accept (`F5`)
- `inherited` (case=7) renders `brain = <slug>` in the drive's `where do we go?` bucket
  - fed by a `DriveBrainInheritance { slug, stone }` record, written only on `requested`
  - it survives a stone passage: `delDriveBlockerState` keeps the record and resets the count
  - gated per ROUTE, so a route with no `brain:` key does no state read

### the concurrency

- **the drive-state lock** — `withDriveStateLock`, `O_EXCL` on POSIX
  - an abandoned lock is reaped only on proof: a `.reap` claim, a re-read under it, and
    `kill(pid, 0)` → `ESRCH`. every uncertain answer reads ALIVE
  - PID reuse defeats the proof and fails loud, in the safe direction
  - it is not reentrant, so in-lock writes go through `setDriveBlockerStateUnlocked`
- **the dispatch claim** — one `/model` write per stone per 15s window
  - a lock cannot bound it: the `clone say` child is detached and outlives any parent lock
  - the claim holds `{ stone }` alone; its age is the file mtime (`rule.forbid.timestamps-in-route-artifacts`)
  - written before the dispatch, released on any non-`requested` outcome, keyed on the stone
  - `BRAIN_DISPATCH_CLAIM_WINDOW_MS` copies rhachet's `CLONE_SUBMIT_VERIFY_TIMEOUT_MS`; a clamp reads
    rhachet's value off disk and asserts `>=`, since only a shrink is harmful
  - the corrupt-claim breadcrumb is written after the lock is released

### the fail-loud repairs

- a wrong-typed state field throws with `field`, `was`, `typeWas`; an absent field stays benign
- `delDriveBlockerState` has no catch and returns `void`, and runs its whole decide-and-act under one lock
- the reviewer-brain read (`asReviewPeerBrain`) gates on an allowlist, `LITERAL_SLUG`; any other form
  returns `cause: 'unreadable'`, never a fabricated slug
- the fd handoff to the dispatch child is closed on every arm, once, after `spawn()`
- one ENOENT-degrade idiom, two leaves: `getOneFileText` and `delOneFile`

### ⚠️ built and unwired

- `getGuardParseWarnings` + `formatGuardParseWarnings` render the `key-empty` · `key-alias` ·
  `key-near-miss` · `key-unreadable` advisories, and no production surface calls them
- ⇒ case=4's fail-safe is unreachable. caught as
  `dreams/v2026_09_27.fix.wire-the-guard-parse-warnings-to-a-surface.md`

## 🔴 .what the tests do not cover

the **enrolled dispatch** — a `/model` that lands in a live clone — is not hermetic and must not be:
it needs an ambient enrolled clone (`rule.forbid.bare-host-deps`), and a mocked `clone say` proves
only the mock (`rule.forbid.integration.mocks`). ⇒ it is proven by the dogfood at `5.3.verification`,
whose guard declares `brain: claude-sonnet-5[1m]`.

## 🔴 .two deferrals, recorded

### the rejection arm — the brain accepts the keystroke and refuses the slug

- the outcome reads `requested`; the refusal is undetected
- not buildable here, measured 2026-09-16: `clone get` reads a transcript keyed by `exid`, and all 29
  clones on this host report `exid: null`. a detector would match a guess at the refusal text
- accepted by the vision (`F5`, seed `S6`): it degrades to the pre-feature behavior, never below it
- the ask: `ehmpathy/rhachet#528`, and
  `.dream/v2026_09_09.reseed.clone-whoami-cannot-report-the-live-brain.md`

### the deaf clone — enrolled, addressed, and its pty hears no keystroke

- the outcome reads `requested`, identical to a healthy switch; the remedy differs (re-enroll with a socket)
- not built: `DEAF` is rhachet's `reachState` vocabulary, and a gate on a peer's enum refuses states
  this repo cannot enumerate
- clamped as a deferral: `getCloneAddress [case11]` asserts `LIVE` and `DEAF` read byte-identical,
  so a build that parts them must edit the row
- `.dream/v2026_09_14.feat.a-deaf-clone-halts-with-the-wrong-fix-line.md`

## .the whoami shape

`rhx clone whoami` reports `slug: null` for a live, enrolled clone. the applier reads `slug ?? serial`,
since `clone say` addresses `@:<slug|serial>` — both halves are first-class in its contract.

## .the parse constraint

every other top-level guard key matches a bare `key:` header by exact equality
(`parseStoneGuard.ts`). `brain: opus` needs a prefix match plus a value extract; a fifth bare literal
would parse `brain:` and drop its value — case=4's failhide from the other side.

## .the decisions this stone inherits

| ruled | what it binds here |
|---|---|
| `F4` | the parser stays permissive — an unknown key is dropped, never thrown |
| `F10` | the value is the brain-cli's own `/model` argument, passed verbatim |
| `F12` | `brain:` bounds the driver alone; peer `--brain` flags untouched |
| `F14` | the applier converges — no compare, no live-brain read |
| `F5` | the silent-refusal corner is accepted; `ehmpathy/rhachet#528` is a todo, not a gate |
