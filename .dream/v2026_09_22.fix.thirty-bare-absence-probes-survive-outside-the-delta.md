## .the cue that fired

`arch-hazards-maintenance` blocker.1 at i018 named fifteen bare probes in one acceptance suite:

```ts
const yieldExists = await fs
  .access(path.join(tempDir, '1.vision.yield.md'))
  .then(() => true)
  .catch(() => false);   // an EACCES / EIO / ENOTDIR reads as "not there"
```

⇒ all fifteen are repaired, routed through the shared `isPathFound`, which allowlists **only**
`ENOENT` and rethrows the rest. the lane's scope was `blackbox/driver.route.set.yield.acceptance.test.ts`,
because that file is in the diff.

## 🟡 .why this is worth a record rather than a sweep in the round that found it

the SAFE/CLEAN test (`rule.always.fix-forward-under-scouts-honor`):

- **SAFE — yes.** the repair is `fs.access(p).then(…).catch(() => false)` → `isPathFound(p)`, and
  `isPathFound` is already the shared operation with its own integration corpus
- **CLEAN — no.** thirty edits across nine acceptance suites, none of which this round otherwise
  touches, inside a diff already ~255 files wide. each of those nine files would then join the
  review corpus of the **next** round and pull its whole contents into every lane's token budget —
  and token overflow is this route's live, twice-measured failure mode

⇒ so the bound is not the risk of the change; it is the **review cost a file pays when it joins
the delta**, which is a cost no rule currently prices.

## .the shape of the fix

1. **the sweep itself** — 30 sites, mechanical, one import per file
2. 🔴 **a lint rule, so the thirty-first never lands.** the shape is syntactically recognizable:
   a `.catch` whose body is a bare literal, on a promise from `fs.access`. that is the only
   durable half — a sweep repairs a census, a rule repairs the class
3. ⚠️ **do it in a diff of its own.** a test-only sweep PR has no production surface, so it
   reviews cheaply — and bundled into a feature diff it does the opposite, since it drags nine
   unrelated files into every lane's corpus

## 🔴 .the one property that makes it worth the trip

**a reviewer's reach is defined by the diff, and a defect's reach is not.**

the fifteen and the thirty are the same defect by the same rule with the same repair. the fifteen
were found because an unrelated rename touched their file; the thirty stay invisible for exactly as
long as nobody edits theirs.

⇒ that is the transferable half: *a diff-scoped review finds defects in proportion to how much a
file was edited, never in proportion to how much harm it carries* — so a stable file is not a
reviewed file, it is an **unreviewed** one, and its silence has been mistaken for health on this
route twice already (the seven dark lanes at i015/i016, and now this).
