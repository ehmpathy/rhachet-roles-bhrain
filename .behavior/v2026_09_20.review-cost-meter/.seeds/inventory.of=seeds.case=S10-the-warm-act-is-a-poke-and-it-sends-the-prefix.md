## .what it did

**coined `poke`** — the act a keep-alive performs. the driver had no word for it; the probe
had a phase named `poke` and the wisher promoted the phase name to the domain term.

**settled the object of a poke as the `prefix`, never the `head`** — after the driver
surfaced that `head` is claimed in shipped code for a narrower slice (102.7k static top,
cut at literal markers by `getOneHeadMarkerOffsets`).

## 🔴 .what the settlement surfaced, that neither party held

the wisher proposed `cache head poke`, then asked whether `head = prefix`. the driver
answered from `metrics.compiled.json` alone — head 102.7k vs a prefix that runs past it —
and offered a **rename of `head`** as the more honest of two options.

that offer was wrong, and `term=prompt.cache.shared-prefix._.choice._.md` already said so:

| term | what it is | property of |
|---|---|---|
| `promptHeadStatic` | the block a compiler **emits** to serve as one | ONE prompt — declarative |
| **shared prefix** | the run two requests **actually had** in common | a PAIR — measured |

⇒ they are two concepts, never two names for one. and **`static head` was already on that
term's forbidden-synonym list** — so the collision the driver "discovered" was settled
before the exchange began.

🔴 **the driver proposed a shipped-field rename against a term file it had not read.** the
evidence was one directory away, and the branch's own git status listed it as added.

## 🟡 .the consequence for the keep-alive

a poke is ONE prompt. a shared prefix takes TWO. so:

> **a poke sends a head. whether it becomes a prefix is decided by the next real round.**

in the probe that gap is closed by construction — the poke replays the arm's exact bytes, so
the pair is guaranteed and the shared prefix is the full 240k. in a real keep-alive it is not:
the warmer replays a **predicted** head, and a wrong prediction warms bytes the next round
never shares — it spends and protects none.

⇒ that is the prediction clamp already caught in
`.dream/v2026_09_24.feat.a-prefix-keep-alive-…`, now with a name:
**a poke that never becomes a shared prefix is a head sent to no one.**
