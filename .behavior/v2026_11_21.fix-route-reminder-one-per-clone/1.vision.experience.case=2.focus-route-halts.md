# case=2 — the focus route halts

inventory rows: r4 `[t0]`, r4b `[t1]`, r5 + r4b on completion `[t2]`. feel: sharp (r4, r4b), happy (r5). care: critipath.

## .narrative

the clone drives B. B hits a guard that needs a human: its passage reads `blocked`. the drive hook sees B not live and reaps the clone's daemon. A is still live from earlier, but the clone does not drive A; a poke about A would pull the clone off the halt the human must answer. so the clone gets silence, which is correct: a blocked route waits on a human, not on a poke.

variant: B completes — every stone passed. the drive hook reads the frontier empty and reaps the daemon the same way.

the sharp part is the human's read. today a reap through `delRouteReminder` wipes the log, so `route.reminder.get` would then claim *"no daemon was ever registered"* — false. the reap keeps the focus file, so `get` reads the focus route and says why the reminder is down, and what brings it back.

when the human unblocks B (or the clone rebinds to A) the next drive spawns a fresh daemon with the right focus.

## .[tn] sketch

```ts
given('[case2] one clone, focus = B, A still live', () => {
  when('[t0] B turns blocked and the clone drives', () => {
    then('synced = deregistered');
    then('the clone pid handle is gone; the focus file stays, still = B');
    then('no daemon nudges about A');
  });
  when('[t1] the human runs route.reminder.get', () => {
    then('it names the focus route and its halt, never "never registered"');
    // reminder is not live — focus .behavior/B is not a live drive (blocked);
    //   it returns on the next route.drive of a live route
  });
  when('[t2] B completes instead', () => {
    then('synced = deregistered; get names route-complete');
  });
  when('[t3] the clone rebinds to A and drives', () => {
    then('a fresh daemon spawns with focus = A');
  });
});
```
