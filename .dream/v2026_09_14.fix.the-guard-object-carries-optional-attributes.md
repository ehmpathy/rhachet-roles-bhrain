**kind** = fix · **owner** = `ehmpathy/rhachet-roles-bhrain` · **caught** 2026-09-14

## .the cue that fired

a `brain?` field joined `RouteStoneGuard`. `rule.forbid.undefined-attributes` grades an optional
domain-object attribute a **blocker**:

> *"never allow undefined attributes for domain objects unless database-generated metadata …
> if null: set as null and explain why; forbid if no good reason; otherwise: define exact type."*

the self-review graded the field against its neighbours on doc style, never on optionality — so it
shipped conformant to the file and divergent from the rule.
