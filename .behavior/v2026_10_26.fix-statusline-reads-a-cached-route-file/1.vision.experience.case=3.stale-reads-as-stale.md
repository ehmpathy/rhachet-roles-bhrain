# case 3 — a stale file reads as stale

sharp · critipath · cell bound-once · stale · repaint · one · — · —

## .narrative

the human glances down and reads
`🗿 5.1.execution.from_vision, review.peer, l1@i002 🔍 · stale, rhx route.drive`. the suffix tells
them two things at once: the round count may be behind, and the one command that catches it up.
they run it, or simply wait — the next turn's stop hook runs `route.drive` for them — and the
suffix is gone. they were never shown a blank, and never shown a confident lie.

how it came to lag: a guard process appended round i003 to `reviewPeerMeters.jsonl`, then died
before its status write (the box ran out of memory under 44 seats). or a human, under a
`route.mutate` grant, fixed a line of `passage.jsonl` by hand. either way a `.route/` ledger is newer
than the status file; the reader sees that with a bash `-nt` test, which spawns no process.

a yield file the driver writes is not such a case: yields are no render input, so the line stays
fresh while the driver works.
