# 🌙 dream: a verification table records COUNTS, so an untracked test removal leaves no record

- kind: `fix` — the durable half is a `reseed` to `ehmpathy/rhachet-roles-bhuild`
- owner: `ehmpathy/rhachet-roles-bhrain`
- caught: 2026-09-19

## .the cue that fired

a re-run of the `5.3.verification` evidence table: five rows grew, and two fell by the same amount.

| row | prior | now | delta |
|---|---|---|---|
| unit (scoped) | 136 files, 1423 | 135 files, 1414 | 🔴 −1 file, −9 |
| unit (full) | 60 files, 850 | 59 files, 841 | 🔴 −1 file, −9 |

⇒ one 9-test unit file left the tree, and no instrument can say which.

## .the gap, precisely

- no tracked deletion: `git diff --diff-filter=D` is empty against `origin/main` and against `HEAD`
- 🔴 **git is silent by construction** — an untracked file written and then removed leaves no
  object, no index entry, no reflog line
- the one witness would have been a prior list, and the table recorded a count

**the obvious cause, refuted.** a −9 unit / +64 integration shape reads as a migration. the new
`mutateDriveBlockerState.integration.test.ts` tests lock contention (`[case2]`–`[case7]`) — new
coverage, not a re-home. that refutation is the valuable half: the migration story fits the
arithmetic and is wrong.

## .the shape of the fix

> **record the LIST, not only the COUNT.**

- local: a `5.3.verification.tests.txt` beside the table — the sorted `npx jest --listTests` per
  suite, so the next delta names itself in a `diff`
- durable: bhuild's `5.3.verification.guard` self-review `has-all-tests-passed` demands *"the final
  summary line (counts)"*; it could demand the list

## .why it is not done in this round

- **SAFE** — the local half is; an artifact changes no behavior
- **CLEAN — no.** the template half lives in another repo, and the local half reshapes a yield that
  twelve reviewers approved — a full re-review round for a delta already stated
- *"counts, or a manifest?"* is a contract call for the bhuild template

🟡 this dream does not settle which file left; it makes the next delta settleable. the net is
unambiguous: +60 across the three suites, all green, zero skipped.
