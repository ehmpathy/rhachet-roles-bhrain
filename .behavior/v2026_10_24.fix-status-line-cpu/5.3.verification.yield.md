### found at this stone — scope counts that measured the host

`review.join-intersect` and `review.rules-only-default` link the reviewer role into a temp repo,
then count the review scope. the link's output is host-dependent: brain config per detected brain,
and a root `.gitignore` negation that lands in some runs and not others. left uncommitted, it rode
into `since-main` and `since-staged`. so ci at `ca73ce6` rendered 7 / 9 / 8 while this box rendered
9–12, and one local run flipped between attempts. a snapshot edit to this box's figures would have
broken ci.

calls it, so each count states the case's own change. join-intersect case2's file-list snapshot,
which pinned the host's artifacts, is replaced by `since-main is empty, as the repo is unchanged`.

### found at this stone — the "clean" fixture was not clean

`review.representative-clean` asserts the reviewer finds no blocker in
`blackbox/.test/assets/codebase-mechanic/src/clean.ts`. one attempt in the full run returned
`blocker.1: redundant paragraph comments` at `clean.ts:9,24,39` — `// return the computed total`
