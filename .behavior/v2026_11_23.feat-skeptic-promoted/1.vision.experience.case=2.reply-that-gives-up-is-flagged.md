# case=2 — a reply that gives up is flagged

feel: sharp · care: critipath · co-tenant: +subconscious

## .narrative

a seat ends its turn with *"the deploy target is unknown yet — which stage should i use?"* the turn ends at once: the skeptic's onStop hook (`rhx instinct.of --role skeptic --to question-assumptions`) spawns the instinct in the background and returns, so no turn is held.

the instinct reads only the reply's output tokens, with the skeptic's briefs as its cached prefix, and asks *what here should have been skepticized?* it flags one claim:

- "the deploy target is unknown": no basis stated, no record cited, and a read could settle it

the flag reaches the seat as an `rhx clone say` message, as a route nudge does. it names the claim and the basis it owes: the file that sets the stage. the seat reads `serverless.yml` and finds `stage: prep`. it writes a record to `.skepticism/` (the claim, the read, the path and its content hash) and replies *"deploys to prep (record: stage-is-prep)"*. the record is `.skepticism/inventory.of=skepticism.case=stage-is-prep.md` (research 7).

the next instinct run reads the citation. the record exists and its hash matches the file, so it flags naught.

## .bdd sketch

```

    then [t4] the record check finds it, hash matched; the instinct flags naught
  when the flag rate on the labeled replay is below the bar
    then [t5] the flag goes to the log only; the seat meets no message
```
