## .settled

**three surfaces that answer one question family must share one name axis.** the shipped
set named three different axes — `meter` the instrument, `fleet` the scope, `corpus` the
source — so a reader who learns one cannot infer the other two.

and the container pair is **`tree` | `grove`**, not `tree` | `fleet`. a fleet is ships; a
grove is what trees come in. the repo already speaks `tree` (the grove-wide roll-up is
`by tree`), so `grove` completes a pair a reader infers without a lookup.

🟡 two things the driver pushed back on, and the reasons stand independent of the verdict:

- **a verb, not a preposition.** `review.budget.of tree` has no verb, so it can only ever
  read. the extant CLI shape is `noun.noun.verb --flag value`, which gives
  `review.budget.get --of tree` and leaves the `set` slot open
- **`budget` names an allowance.** `route.guard.budget` is one — you `--add` to it and it
  constrains. what these commands report is realized spend, which nothing allowances. so
  `budget` is right only on the aspirational reading, where a `set` half is intended

⇒ and the reshape exposed a cell nobody had noticed: *"what will THIS tree's lanes cost?"*
has no surface at all. `corpus` was never a scope — it was a **source** — so once `--of`
names the scope and `--from` names the source, the gap gets a home and a command collapses
into a flag.
