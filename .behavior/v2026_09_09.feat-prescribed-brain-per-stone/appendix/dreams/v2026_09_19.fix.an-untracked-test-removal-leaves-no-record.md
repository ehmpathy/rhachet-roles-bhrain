# 🌙 dream: a verification table records COUNTS, so an untracked test removal leaves no record

- kind: `fix`
- owner: `ehmpathy/rhachet-roles-bhrain`
- caught: 2026-09-19

## .the cue that fired

the `5.3.verification` yield's evidence table was re-run in full after the i008/i009 repairs landed.
five rows grew and **two went down by exactly the same amount**:

| row | prior | now | delta |
|---|---|---|---|
| unit (scoped) | 136 files, 1423 | 135 files, 1414 | 🔴 **−1 file, −9** |
| unit (full) | 60 files, 850 | 59 files, 841 | 🔴 **−1 file, −9** |

⇒ one unit test file with 9 tests left the tree, and **no instrument on disk or in git can say which
one.**

## .the gap, precisely

a removal is invisible exactly when the file was never committed:

| the check | result |
|---|---|
| `git diff --stat origin/main...HEAD --diff-filter=D` | ✅ empty — no tracked deletion since main |
| `git diff --name-status --diff-filter=D HEAD` | ✅ empty — no tracked deletion in the worktree |
| `globsafe 'src/domain.operations/route/guard/*.test.ts'` | ✅ all 16 present |
| `git ls-tree -r HEAD -- …/route/drive/` | ✅ no unit test existed there to lose |

⇒ 🔴 **git is silent by construction.** an untracked file that is written and later removed leaves no
object, no index entry, and no reflog line. the only witness would have been a prior *list*, and the
table recorded a **count**.

### the obvious explanation was checked and REFUTED

a −9 unit / +64 integration shape reads as a unit→integration migration. the two new integration
files were read rather than assumed:

```
$ grepsafe --pattern 'given\(|when\(|then\(' --path …/mutateDriveBlockerState.integration.test.ts
  [case2] twenty increments contend for one file
  [case3] a critical section throws mid-hold
  [case4] a lock already held by another writer
  [case6] a lock whose holder is PROVABLY gone
  [case7] a lock whose holder is THIS live process
```

⇒ that file tests **lock contention** — a new capability, never a re-home of a state-mutation unit
test. so the `+64` is new coverage and does not account for the `−9`.

🟡 **the refutation is the valuable half of this dream.** the migration story is plausible, fits the
arithmetic, and is wrong — so a future traveler who re-derives it would stop there and record a
cause that was never checked (`rule.forbid.obfuscation`: a plausible frame that changes what a
reader concludes).

## .the shape of the fix

> **record the LIST, not only the COUNT.**

a count can only report *that* something moved. a list reports *what*, which is the one fact a delta
investigation needs and the one this table cannot supply.

```sh
# the instrument already exists and is already permitted
npx jest --listTests
```

⇒ the verification table gains one artifact beside it — `5.3.verification.tests.txt`, the sorted
output of `--listTests` per suite — and the next delta names itself in a `diff` rather than in a
four-call hunt that ends unsettled.

**where it belongs:** the template that stamps the verification stone, so every route inherits it —
`ehmpathy/rhachet-roles-bhuild`, `…/templates/5.3.verification.guard`'s `has-all-tests-passed`
self-review, which today demands *"the final summary line (counts)"* and could demand the list.

🟡 **so this is a `reseed` in substance even though it is filed `fix` here** — the durable repair is
bhuild's template, and the local half is one artifact this repo can add unilaterally. the local half
is worth doing either way: it costs one command and it is what makes the next count auditable.

## .why it is not done in this round

- **SAFE?** 🟡 **the local half is.** an added artifact changes no behavior and no test
- **CLEAN?** 🔴 **no.** the template half lives in another repo, on another cadence; and the local
  half changes the shape of a verification yield that **twelve reviewers just approved**, which
  would cost a full re-review round to buy a record of a delta that is already stated in prose
- ⇒ and the question *"what does a verification table owe — counts, or a manifest?"* is a **contract
  decision** for the bhuild template rather than a repair this route may make alone

⚠️ **the bound is stated rather than smoothed:** this dream does not settle which file left. it makes
the next such delta settleable, and it records that this one is not.

🟡 **the net on this branch is unambiguous even though the cause is not** — coverage across the three
suites moved **+60**, every suite is green, and **zero** tests are skipped on any of them.
