# review — its declared shared exposures

`review/` owns the review run: its subprocess runner, its target enumerator, and the identity a
guard stamps on each run. most of the tree is private to `review/`. the exports below are read
across a context line, and each read is sanctioned.

## .the contract

| export | grain | sanctioned consumers | why they read it |
|---|---|---|---|
| `runOneReview` · `ReviewRun` | communicator · type | `route/guard/review/`, `review.by/` | the one review runner the guard and `review.by` share — a second runner would drift on capture, timeout, and exit class |
| `asErrorMessage` | transformer | `review.by/` | a runner fault renders through the same message reader the runner uses |
| `enumFilesFromGlob` | communicator | `reflect/` | reflect reads review's RELATIVE-path enumerator; `@src/utils/enumFilesFromGlob` returns absolute paths, a different contract |
| `asReviewRunIdentity` · `asReviewRouteOfOutput` | transformer | `route/guard/partition/` | the route keys a run to the reviewer and route the guard stamped on its `--output` path |
| `asErrorHeadline` | transformer | `route/guard/` (`getAllReviewerLevels`) | a malformed guard's parser fault renders under one class label — the same headline cut review applies, so the meter row never shows one failure under two class names |
| `getAllTargetsAskedForByName` | transformer | the domain.operations root (`getAllTargetsByPolluterVerdict`) | the shared polluter verdict sits at the root beside `isTargetPolluter`, so `rhx review` and an enroll lane read one verdict; the by-name exemption reads review's own glob grammar (`isPathMatchedByGlob`), so it stays here (rule.require.exclude-review-scope-polluters) |
| `partition/` | — | `route/guard/partition/` | declared on its own, in `partition/.readme.md` |

⇒ a reshape of any export above is a contract change for every consumer it names; read each
call site before you make one. an import of any OTHER `review/` module from outside `review/` is
an undeclared reach-in — declare it here with its reason, or lift it to a neutral home.
