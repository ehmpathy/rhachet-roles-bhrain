## 🔴 .the shape of the fix — a DATA migration, never a rename

1. **the reader accepts both, first.** `passage.jsonl` holds `"status":"contemplated"` on disk in
   every route in every repo on this engine. so the status parser takes `conversed | contemplated`
   and normalizes, **before** any writer changes. a rename without this makes every extant route's
   history unparseable — the disposition (`asStoneDisposition`) is derived from the latest passage
   entry, so an unrecognized status silently changes what `route.drive` reports
2. **the writer moves next**, once every reader in the tree accepts both
3. **the cli flag takes an alias** — `--as conversed` canonical, `--as contemplated` accepted and
   undocumented, so extant scripts and route templates do not break at the boundary
4. **operations and the blocker key rename** — internal, safe once 1–3 land
5. **snapshots re-mint** in one pass; `blackbox/__snapshots__` and `src/**/__snapshots__` both carry
   the word in guard emits
6. **the briefs follow** — `rule.always.converge-with-reviewers._`, `…via-a-taken-per-point`,
   `rule.forbid.unanswered-exits-from-a-blocker`, `howto.drive-routes`, and every `.md.min` beside
   them

⚠️ **a bulk find-and-replace cannot do this safely.** it cannot part a **citation** of the old word
from an **instance** of it — the dispute entry, `F14`, seed `S08`, and this dream must all keep
`contemplate` intact, and each is a `.md` a sweep would rewrite. the identical hazard
`rule.forbid.brackets-in-filenames` names: **the repair is file-first and by hand.**

## .why it is not done in this round

**dirty, and the SAFE/CLEAN test fails on both counts** (`rule.always.fix-forward-under-scouts-honor`):

- **not clean** — a data migration with back-compat across a published cli, five operations, and
  persisted records in every consumer repo
- 🔴 **not safe, and this is measured on this very branch.** stone `5.3.verification` sits blocked
  with **five of eleven reviewer lanes overflowed** because `--diffs since-main` sweeps a corpus that
  grows every round, at **~144% of a 1M-token window across 310 files**, with **zero commit quota**
  to collapse it. a repo-wide rename would add several hundred changed files to that diff and darken
  the lanes that still read

⇒ `rule.forbid.domain-term-synonyms` sanctions the wait in its own words — *"left in place until
disturbed — no forced mass-rewrite"* — so the glossary is settled now and the contracts migrate as
their own behavior, on a branch whose diff can carry it.
