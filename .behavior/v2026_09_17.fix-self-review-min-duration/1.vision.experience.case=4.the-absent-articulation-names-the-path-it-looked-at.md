# case=4 — the absent articulation names the path the guard looked at

**cell** `c2` · **feel** sharp · **care** critipath

> the extant failure mode, made legible. `S01` clause 4: *"explicitly say if the file was not found
> at the path."*

## .the narrative

a driver promises before they write. the claimed path is the owed path — they copied the command
the guard printed — and no file is there.

today they are told the articulation is absent, and the fix is a guess: absent from **where**?
the driver must go read `getSelfReviewArticulationPath` to find out.

🟡 **this line also sent them to count `rN` levels, and `S12` deleted the level.** what survives is
the harder half: the guard knows the path and does not print it.

after: the guard states the one fact that makes the verdict actionable — **the path it looked at** —
and hands back the two commands that close it.

```
🗿 not there, friend
   │
   ├─ i looked here
   │  └─ $route/review/self/for.3.3.blueprint._.has-questioned-assumptions.md
   │     └─ ✘ no file
   │
   ├─ write your findings there — a repair you made, or a hold you reasoned
   │
   └─ then promise again
      └─ rhx route.stone.set --stone 3.3.blueprint --as promised \
           --that has-questioned-assumptions --into <that path>
```

### .the "aha"

> **the guard always knew the path. it just never said it — and where it does say it, it says it
> wrong.**

the path is computed by one operation, from four inputs the guard holds
(`getSelfReviewArticulationPath.ts`). the absence of the path from the **verdict** was never a limit
of the design — it was a line of output nobody wrote.

⇒ the cheapest repair in this whole wish, and the one that removes the most driver confusion per
character changed.

### 🔴 .why this cell is a critipath rather than a polish item

**measured on this route, this round.** `--as passed` on `1.vision` printed:

```
│  ├─ articulate into
│  │  ├─ /review/self/for.1.vision._.r1.has-grounded-in-reality.md    ← no route segment
```

`setStoneAsPassed.ts:248-259` builds the self-review emit with **no `route` field**, and
`formatRouteStoneEmit.ts:265` falls back to `route: input.route ?? ''` — so the segment collapses to
the empty string and the driver is handed an absolute path at the filesystem root.

🔴 **on `--as passed` only.** the next command, `--as promised --that <slug>`, prints the same path
correctly — `formatWalkTheWay`, `formatPatienceFriend`, and `formatLetsReflect` each pass `route`
through intact. **the misdirection lands on the command that hands out the ask**, and the correction
arrives on the command a driver reaches only after they have already written the file.

**a driver who obeys the printed instruction lands in `c8`** — misplaced, through no fault of their
own — and is then told their articulation is absent.

### 🔴 .and the SAME defect fires a second time, on the `rN` level

measured on this route, this round, at `r2`: the drive wrote `has-experience-coverage` to
`for.1.vision._.r1.…` and the guard owed `for.1.vision._.r2.…`.

| call site | what it passes as `index` |
|---|---|
| `findNextUnpromisedReview.ts:25` | `selfReviews.indexOf(nextUnpromised)` — **zero-based** |
| `setStoneAsPassed.ts:256` | `nextIndex + 1` — **one-based** |

one field, two conventions ⇒ the two emits print `rN` and `r(N−1)` for one owed review.

🔴 **so the printed path is wrong in TWO of its fields**, at two different call sites, for two
unrelated reasons. that is what makes `c8′` a class rather than a slip — and the wisher confirms it
is not confined to this drive: *"that index jump everyone seems to have a problem with too"*
(`S07`).

✅ 🔴 **and the repair is RULED** (`F09`, `S12`): not a third reconciliation — **remove the derived
component from the path entirely.** `for.$stone._.$slug.md`, keyed `(stone, slug)` exactly as the
promise already is. `S09`'s narrower *"just fix it if there's a diff"* was the recorded bound and was
not taken.

⇒ **so this member of `c8′` is unreachable rather than repaired.** a quantity the path does not carry
cannot be derived three ways. 🟡 **the route-segment member survives** — that is a different field, at
a different call site, and it is still live.

⇒ so `c2`'s repair is not *"add a helpful line"*. it is *"make the path the guard prints the path
the guard reads"*, and only then say whether a file is there. the second half is worthless while the
first half lies.

⚠️ **the code fix is out of the vision's scope** and is caught as a dream. what belongs to this cell
is the grade: **correctness, not ergonomics.**

## .the sketch caveat

the tree shape above is illustrative. `formatPatienceFriend` renders a path already (via
`formatWalkTheWay`), so two separate gaps sit behind this cell and they must not be conflated:

| the gap | severity | status |
|---|---|---|
| the path drops its route segment **on `--as passed`**, and prints correctly on `--as promised` | 🔴 correctness — a driver who obeys the first is refused, and the two commands disagree | **live** |
| the path's `rN` level is derived **zero-based** at one call site and **one-based** at the other | 🔴 correctness — the two emits name two different files for one owed review | 🌙 **unreachable** — `S12` removed the level |
| there is **no verdict line** that says no file was found there | ergonomics — the driver must infer the absence | **live** |
| 🔴 the guard **has** the declared path and renders no diff against the computed one | 🔴 correctness — a mismatch reads as an absence | **live, and newly owed** — `S15` made `--into` required, so the operand exists |

⇒ the third is the line nobody wrote. **the first and the fourth are defects and are why this cell is
a critipath**; the second is retired by a verdict rather than by a repair.

🔴 **and the fourth row is new to this cell.** it was not a gap while `--into` was optional — the
guard could not count on a declared path. `S15` guarantees one on **every** promise, so *"the
articulation is absent"* where a declared path differs from the computed one is now a message the
guard has the evidence to improve and does not.
