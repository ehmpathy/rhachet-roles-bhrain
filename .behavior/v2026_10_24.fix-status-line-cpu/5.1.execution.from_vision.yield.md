## .how the fix reaches a live box

1. **release** — this pr merges and ships a version that carries the subpath
2. **upgrade** — each repo runs `rhx upgrade`, which installs that version
3. **init** — the driver init re-runs (`npx rhachet roles init --repo bhrain --role driver`), which
   rewrites the repo actor's settings command to `cli/route.status.line`
4. **re-enroll** — an active seat holds its own settings copy, so it keeps the old command until it
   re-enrolls or restarts. meanwhile it runs `legacy warm`, the barrel plus a cache hit, ~1.4× cheaper
   than today, never dearer

until the release lands, a consumer applies `appendix/rhachet-roles-bhrain@0.42.1.patch` and runs
steps 3 and 4. the pr body names this sequence. a seat whose settings still name `cli/route`
gets ~1.4× (the render skipped, the barrel load kept) until its driver init re-runs, which
rewrites the command; the consumer patch's output names that step.

the split of the warm repaint (`--runs 20`): `import()` floor 0.044s (the command shape's own cost)
· subpath import only 0.063s (+~0.017s, the leaf modules) · subpath warm 0.078s (+~0.015s, the
HEAD read, the stats, one cache read). a `git` spawn costs +~0.010s over bare node, which the HEAD
read saves on every hit (the vision's `[research]` row). the vision's literal "no `@src` module"
clause is not met; the departure costs ~0.017s and is fulcrum `F5`.
