# F09 · `forbid.subversive-prose` is STRUCTURE, and the seam already admits it

- **rework** = clean · **status** = open · **confidence** = 90%

## .the fork, stated fairly

`S05` and `S06` ask telepath to carry `rule.forbid.subversive-prose`. telepath's `rule.require.generic-governs-structure-never-voice` is a **blocker** rule that assigns register to the adopter.

an aphorism, an invented metaphor, a hedge stack, and a self-issued checkmark are all **register**. so on a fast read of the seam they fall to the adopter, and telepath may not rule on them.

| option | what it means |
|---|---|
| **A · it is voice** | the rule ships per mascot repo, forked per adopter |
| **B · it is a third axis** | the seam gains an **assertion** grain beside structure and voice |
| **C · it is structural, and the seam already says so** | no amendment. telepath carries it today |

## .taken, and why at the time

**C**, and it was reached by a read rather than an argument. the brief answers this on three independent grounds.

### 1 · the seam's own test returns "structure"

`:37`:

> **"would this rule read the same if the reader's mascot were a seaturtle instead of an owl?"**
> yes → **structure.** it is telepath's · no → **voice.**

⇒ *"a claim must be disputable"* reads identically for a seaturtle and an owl. **an unfalsifiable sentence is unfalsifiable in every register**, and an aphorism is an aphorism in lowercase with a 🐢 or a 🦉.

### 2 · the brief's definition of structure ALREADY names it

`:7` defines the structure axis as:

> *"**what the message says**, in what order, in how many words, where each passage sits"*

⇒ **"what the message says" is the first item on the list.** whether a passage asserts a disputable claim is precisely *what it says*. the axis was never merely order and placement.

### 3 · the voice blocker enumerates a CLOSED list, and no shape on it matches

`:63-64`:

> blocker: a telepath rule that prescribes **an emoji, a capitalization, a persona, or a mascot line**

⇒ four items, and `forbid.subversive-prose` prescribes none of them:

- no glyph, no case, no persona, no mascot line
- ⇒ what it forbids is a sentence that commits to no position

## .so option B was WRONG, and it would have cost a wisher round on a blocker rule

the first draft of this fulcrum took B and filed it at 70%, with a note that the brief was *"unread for this question"*. **the read was one file and it reversed the call.**

⇒ B would have asked the wisher to amend a `blocker` rule that other repos cite — the same class of risk F06 carries — **to obtain a permission the rule already grants.**

🟡 this is the third time on this route that a citation stood in for a read, and the second time it changed an answer.

## 🟡 .what the rule must still avoid, so it stays on the right side of the seam

C holds only if the rule is written structurally. two shapes would break it:

| a shape that would cross the seam | why |
|---|---|
| *"do not write aphorisms in the owl's voice"* | names a mascot — voice |
| a rule whose **examples** are the only content, in this repo's register | `:66` grants the example a voice; it does not grant the rule one |

⇒ so the rule states the property — **a claim must be disputable; prose must inform rather than work the reader** — and lets each adopter's register supply the words. the `S06` fix list is already in that form: *strip the metaphor*, *delete the self-issued verdict*, *state the limitation flat*.

## .and assertion is NOT a sub-grain of density

the cheaper call is to fold this into the density rules and skip the seam question entirely. `S06` refutes that, and the refutation is the sharpest fact in either seed:

> **rhetoric and density are indistinguishable on the page. both are short. both are punchy.**

⇒ a terseness pass **concentrates** rhetoric rather than reduces it. every density rule in the set makes this defect worse, and no density rubric line detects it.

🟡 so C says the rule is **telepath's**, never that it is **redundant**. it is a distinct rule under the structure axis, beside the density set.

## .rework, and why

**clean.** it is a placement decision at vision stage; reversal costs an edit to a plan.

⇒ and C is the cheapest of the three to reverse: it adds one brief under an extant axis. A forks the rule per repo, and B amends a blocker other repos cite — both are dearer to undo.
