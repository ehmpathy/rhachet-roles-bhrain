## .step 3 — confirmation

### the switch WAS accepted — observed in this session's own input

the `/model` line the hook submitted landed in this clone's pty, and the brain-cli answered:

```
/model claude-opus-4-8[1m]
Set model to claude-opus-4-8[1m]
```

that is the brain-cli's own acknowledgment of the switch the guard prescribed. the chain is
closed end to end: **the guard declared it, the hook detected it, the hook dispatched it, and
the brain-cli accepted it.**

### `clone get` came back empty — and the root cause is NOT the cwd

```
$ rhx clone get @:e9f8f134-770a-4b1a-bab9-b3ff3c64f62e --tail 20
⚠ history is empty because this clone shared a cwd with another at spawn — enroll each in
  its own worktree to separate their transcripts
😶🎧 talk of @:e9f8f134  ·  tail 20
   └─ (no messages yet)
```

🔴 **the address was EXACT.** the serial `whoami` returned was passed verbatim, and `clone get`
resolved that clone without ambiguity. **what it could not resolve is which FILE is that clone's
transcript** — one level below where the warn line points.

#### the two ids, and the absent map

| id | owned by | where it lives |
|---|---|---|
| the clone **serial** — `e9f8f134-…` | rhachet | `RHACHET_CLONE_SERIAL`, what `whoami` returns |
| the transcript **exid** | the brain-cli | the transcript's own filename |

rhachet states the gap in its own source — `genCloneHistoryLink.js:19-21`:

> *"the exid lives in the transcript's filename (an interactive TUI never prints a parseable
> session id), so we DISCOVER the file rather than parse the stream"*

⇒ so the link is **inferred**, never looked up: newest transcript under this cwd's dir, written
at-or-after spawn (`getAllEligibleTranscriptCandidates`). with two clones in one cwd the
heuristic has two equally plausible candidates, so it **refuses and quarantines each**
(`:61-68`) rather than link the wrong one — a privacy guarantee, never a defect. the
`--output json` form reported `exidsAmbiguous` over 11 ids.

#### 🔴 the discriminator EXISTS, and this repo already reads it

a hook fires **inside** the clone, and the platform hands it the transcript by name:

```ts
// src/contract/cli/telepath.ts:99-102
transcriptPath:
  typeof payload.transcript_path === 'string'
    ? payload.transcript_path
    : null,
```

**exact, platform-named, no discovery, and immune to a shared cwd.**

⇒ **`clone get` is the wrong instrument for a SELF-read.** it is built to read *another* clone
from outside, where a cwd heuristic is the only handle available. a hook that verifies its own
`/model` switch holds a better one already.

| the read | the instrument | its ambiguity |
|---|---|---|
| **this** clone's own reply | `transcript_path`, off the hook payload | ✅ none |
| **another** clone's reply | `clone get` | 🔴 cwd heuristic; refuses on a tie |
| another clone's live **brain** | `F5`'s `whoami --brain` | a cross-repo ask |

🟡 **that re-prices `F5` downward.** self-confirmation needs no ask at all — it needs the payload
field this repo already parses. `F5` buys a read of a **peer** clone's brain, which this feature
does not perform.
