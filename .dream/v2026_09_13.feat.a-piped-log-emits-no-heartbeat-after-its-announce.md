# 🌙 dream: a piped log emits no heartbeat after its announce

- **kind** = feat
- **owner** = `rhachet-roles-bhrain`
- **caught** = 2026-09-13

## .the cue that fired

a peer reviewer (i009/r10, point 1) named a harm the non-tty render carries:

> a CI runner that reaps a job with no output for N minutes

the repair that landed — one `🦉 l1 pours N lanes` line per level, on genuine stderr, before any
lane launches — closes the **silence** and does not close that **kill**. every lane announces at
t≈0, so the log is quiet thereafter for up to the full `PT21M` review bound.

⇒ the cue is the gap between the harm cited and the harm repaired, and it fired while the repair's
own docblock was written.

## .the gap, precisely

**checkable, in three reads:**

1. `src/domain.operations/route/guard/review/asReviewLevelPourAnnounce.ts` — composes exactly one
   line per level. its `🟡 .bound` states the limit outright
2. `src/domain.operations/route/guard/genContextCliEmit.ts` — `drawStatus` returns at `:117` under a
   pipe, so no per-tick status reaches a piped stream. that suppression is deliberate and clamped
   (`genContextCliEmit.test.ts [case10]`)
3. ⇒ therefore, between a level's last launch and its first settled block, a piped log receives
   **zero bytes**

**the arithmetic that bounds any repair:**

| cadence | lines over `PT21M` |
|---|---|
| `SPIN_MS` = 80ms — the tty spinner, un-gated | ~15,750 |
| 30s | 42 |
| once — what shipped | 1 |

🟡 **and the harm does not land on this repo's CI today.** walked 2026-09-13: this repo runs
**GitHub Actions** (`.github/workflows/`: provision, publish, release, review, test), which has no
log-inactivity timeout. the reap behavior is a CircleCI-class property, so the gap is real for a
runner this repo does not currently use.

## .the shape of the fix

a heartbeat at the site the announce already occupies, so it inherits a stream no oracle reads:

- `runStoneGuardReviews` holds both the level roster and the pour boundary, and already writes to
  genuine stderr there via `console.error`
- start an interval at the pour, clear it in the same place the pour is awaited, and emit one line
  per tick that carries the level, the elapsed, and the inflight count
- ⛔ **do NOT reach for the emit path.** `route.ts:980` hands the emit `process.stdout`, so any byte
  written there is captured by the 36 frozen peer snapshots — and 7 extant fixtures have a
  multi-member level
- compose it as a leaf transformer beside `asReviewLevelPourAnnounce`, so the line has a clamp of
  its own — and add a **wire** clamp in `blackbox/driver.route.peer-concurrency.acceptance.test.ts`,
  because 6 unit clamps stayed green under a cut wire when the announce landed

**the clamp with teeth:** run a level whose lanes are slower than two cadences; assert ≥2 heartbeat
lines on stderr and zero on stdout. cut the interval → red.

## .why it is not done in this round

**SAFE = yes. CLEAN = no**, and the dirt is a **contract** rather than an implementation or a blast
radius:

- the code is trivial and additive
- the **cadence is a number nobody has chosen.** 30s, 60s, and *"only while a lane is inflight"* are
  each defensible, and each is a new promise about what a piped log emits
- ⇒ a contract picked mid-execution to close a nitpick is the shape this round spent four fulcrums
  to learn to refuse

⚠️ **and unlike an implementation deferral, this one must not be re-priced each round.** a re-read
would find the diff still trivial and land a cadence the wisher never ruled.

⇒ the decision is recorded as **fulcrum F15**, per `rule.always.catch-dreams-for-followups` — a
dirt deferral owes both, because a dream reports the work and hides the call.
