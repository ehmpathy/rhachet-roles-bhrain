# 🌙 dream: `rhx` runs `dist/` with no staleness signal, so a driver tests the OLD engine

- **kind** = fix
- **owner** = `ehmpathy/rhachet-roles-bhrain`
- **caught** 2026-09-04, from `.behavior/v2026_09_03.fix-contemplation-gate-on-entrance`

## .the cue that fired

four `rhx route.stone.set --as contemplated` calls in a row answered *"this reviewer raised no
blockers"* — and one of the four named a reviewer whose `.given` tallies **1 blocker**.

⚠️ **the ack was not merely wrong; it was wrong in the precise shape of the defect the behavior was
mid-flight to fix.** that is what made it legible at all. a driver without that specific context
reads *"raised no blockers"* as good news and moves on.

## .the gap, precisely

`rhx` resolves skills through the built package, so a route-guard command executes
`dist/**/*.js` — never `src/`. no step warns when the two disagree.

**measured, this repo, 2026-09-04:**

```
$ rhx globsafe --pattern 'dist/domain.operations/route/guard/review/peer/*.js' --long
  2K  2026-09-03 <time>  …/getAllRouteGuardReviewPeerGivensAtHash.js     ← DELETED from src
      (no getLatestPeerGivensPerSlug.js)                                    ← ADDED to src
```

⇒ `dist` carried a file `src` had deleted, and lacked one `src` had added. built the previous
evening, before a day of work on exactly those files.

**the consequence:** every live exercise of the guard during i001–i003 ran the **pre-fix** engine.
the change was validated by `npm run test:unit` (which compiles `src`) and by no live run at all,
while the driver believed the live runs were confirmation.

⚠️ **the failure is silent and it is confirmatory-biased.** the stale engine does not error — it
answers, plausibly, in the shape the driver expects. and the four gates (`types`, `unit`, `format`,
`lint`) all read `src`, so a fully green board says naught about what `rhx` will do.

### why it is worse than an ordinary stale build

| | an ordinary stale build | this |
|---|---|---|
| what runs | old app code | **the guard that grades the work** |
| who notices | a user, on a wrong result | no one — the guard's verdict IS the result |
| the check that would catch it | run the app | 🔴 **none exists.** the tests do not use `dist` |

⇒ in a repo whose product is a **guard**, a stale `dist` means the reviewer, the gate, and the halt
are all the previous version — including on a branch whose whole purpose is to change them.

## .the shape of the fix

three rungs; the first is cheap and probably sufficient.

1. **a staleness warn at skill resolution** — compare the newest `src/**/*.ts` mtime against the
   newest `dist/**/*.js`. if `src` is newer, emit to **stderr** and continue:
   ```
   ⚠️ dist is older than src — this ran the PREVIOUS build.
      fix: npm run build
   ```
   ⇒ warn, never halt: a stale `dist` is legitimate mid-edit, and a hard stop would break every
   skill call during ordinary work.

2. **name it in the driver briefs** — a `rebuild before you re-arrive` line, since the driver is the
   role whose whole loop is mediated by these skills.

3. **a build step in the arrive path** — the strongest and the most invasive; it makes `--as arrived`
   slow and couples the guard to the build. **probably wrong**; recorded so it is not re-proposed
   without the objection attached.

⚠️ **an mtime compare is a heuristic** — a touched-but-unchanged file yields a false warn. acceptable
for a stderr warn; **not** acceptable for rung 3, which is a second reason to prefer rung 1.

## .why it is not done in this round

**safe: yes. clean: no.** the fix belongs in skill resolution — `findUniqueSkillExecutable` or the
`rhx` entrypoint — which is a surface no part of this behavior touches. it would put a
cross-cutting change to every skill invocation inside a diff about the contemplation gate, and it
ripples to the acceptance suite, the hook path, and every consumer repo that installs this package.

⇒ per `rule.always.fix-forward-under-scouts-honor`, dirt defers. the local repair — `npm run build`
before a live check — was done, and this records the general fix.
