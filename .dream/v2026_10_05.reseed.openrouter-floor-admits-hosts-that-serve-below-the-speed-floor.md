# 🌙 dream: the openrouter floor admits hosts that serve below its own speed floor

kind: reseed · owner: ehmpathy/rhachet-brains-openrouter · caught 2026-10-05

## .the cue that fired

the integration gate of `rhachet-roles-bhrain` went red with timeouts and zero cache reads on
inputs that ran in seconds a week earlier. the cause was the host the default slug was routed to.

## .the gap, precisely

the default supply `floor&speed=min50tps&privacy=full` (unchanged in 0.1.3):

- ranks admitted endpoints by INPUT price alone, though a review is output-heavy (2–5k tokens)
- gates speed on openrouter's `throughput_last_30m` median, cached 30 min on the machine
- sends the ask to ONE endpoint (`allow_fallbacks: false`), and steps past it only on 429 / 404

measured 2026-10-05 (deepseek/deepseek-v4.1-flash), nine identical ~900-token json asks:

| slug | served by | live speed | cache reads on a repeated 58k prefix |
|---|---|---|---|
| bare `openrouter/deepseek/flash` | morph/fp8, every ask | 19–64 tps (median read 12 at 13:29) | 0 |
| `…/floor&speed=min100tps&privacy=full` | coreweave/fp8, every ask | 132–227 tps | ~58k |

so a host whose median straddles 50 tps wins every ask while it is admitted, and serves about
half of them below the floor the slug names.

## .the shape of the fix

1. list `openrouter/deepseek/flash/floor&speed=min100tps&privacy=full` in `SLUGS_FILTERED_LISTED`,
   so a CLI consumer can choose it by name (rhachet selects by exact `atom.slug`). this alone
   lets `rhachet-roles-bhrain` fold `DEFAULT_TEST_BRAIN_VIA_CLI` into `DEFAULT_TEST_BRAIN`
2. rank a floor by estimated TOTAL cost (input + expected output), never input alone
3. demand a margin over the median (or the slow tail, if openrouter publishes one), so a host that
   straddles the floor is not admitted at it
4. consider a stall bound: no first token within N seconds steps to the next endpoint
5. 🔴 **pin the replica.** the package sends no session or affinity header at all, so two asks
   that share a long system prompt reach the same HOST (one admitted endpoint) but an arbitrary
   REPLICA. measured 2026-10-05 on coreweave: 8 of 9 round-2 asks warm at 99.7%, one at 0% on an
   identical prefix. derive a key from the system prompt (never a per-request id) and send it as
   whatever affinity hint openrouter forwards. ⇒ until then, every consumer's cache lever is
   best-effort — `rhachet-roles-bhrain`'s default reviewer included (its fulcrum `F100`)

## .why it is not done in this round

it belongs to another repo; a tree adopts only what is scoped to itself. this repo's tests were
pointed at the min100tps slug instead (`src/.test/genTestBrainContext.ts`), and the product
default stays the bare tier.
