# seed S20 — an absent credential is a halt, and it was owed rounds ago

## .said — verbatim, 2026-09-07

> if you need absent crednetials, shouldn't have you raised a blocker already?

## .settled

**yes. a point whose close needs a grant the driver cannot make is a `--as blocked`, at the round it
is recognized — never a re-arrival.**

`rule.always.raise-a-blocker-a-taken-cannot-close` states the test outright:

> *"is there a change I am PERMITTED to make that would close this point?"* — no → `--as blocked`,
> with the ask as a command the human can run.

⇒ the four absent test credentials fail that test at every round. **no answer converges an absence.**

## 🔴 .the sharp part — the rule was cited on the page it was broken on

the halt was not missed for want of the rule. the rule sat **quoted** in this route's own prose, in
the same rounds that re-arrived instead. ⇒ **a rule a driver can recite is not a rule a driver
obeys**, and the gap between the two is invisible from the inside precisely because the recitation
feels like compliance.

⚠️ **and the budget is what hid it.** the ladder read healthy every round — spend remained, lanes
re-ran, verdicts moved. so each re-arrival looked like progress on the very measure the rule warns is
uninformative: *"budget left is not evidence of a remedy."*

## ⚠️ .the honest bound — the halt does not excuse the answers

a blocker artifact owes the reviewers' points **verbatim with the driver's answer beside each one**.
so the halt is no shortcut past the `.taken` work; it is what to do **after** that work is done and
the residual is a grant.

⇒ the two rules divide by state, never by convenience: a critique **unanswered** is
`rule.forbid.unanswered-exits-from-a-blocker` and the halt is forbidden; a critique **answered and
unclosable** is this rule and the halt is correct.
