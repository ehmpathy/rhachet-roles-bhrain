# 1.instrument — yield

## .what was built

`bench.acceptance` — the measurement instrument, at
`.agent/repo=.this/role=any/skills/bench.acceptance.{sh,js}`.

| command | answers |
|---|---|
| `run --label X` | where does the wall clock go? — build/jest phases, per-file cost, per-case verdicts |
| `gate --label X` | the BAR — times the paved `npm run test:acceptance` end to end |
| `report --label X` | print a recorded run |
| `compare --before A --after B` | did every case that passed before pass now? |
| `failures --label X` | group a red run's failures by root-cause head |
| `env` | machine facts (cpus, memory, load) |

## .the guard, and the proof it bites

> the tool prints a MEASURED wall clock and a per-case verdict set, and its compare mode
> exits non-zero on a lost case.

**a guard that cannot fail is not a guard** — so it was made to fail on purpose:

```
$ bench.acceptance compare --before after8 --after smoke
   ⛈️  REGRESSION
   ├─ 3229 case(s) PASSED before and are now ABSENT:
   │  · blackbox/review.rules-only-default.acceptance.test.ts :: … then: cli completes successfully
   …
$ echo $?
2
```

⇒ exit **2**, with every lost case named. it also returns exit 0 on a real clean pair
(`smoke-off` → `smoke`, 21/21 held), so it discriminates rather than merely refuses.

## .why it answers TWO questions and not one

a stopwatch alone licenses a test deletion to win the bar. a case count alone hides
where the time sits. worse, a COUNT cannot clear a no-loss bar at all — a swap of one
case for another holds the count steady and loses the coverage. so the verdict set is
keyed on **full case name**, and the comparison is a set difference, never a subtraction.

## .provenance recorded per run

each run records `config.jestArgs`, `config.env`, and `config.cpus` beside the wall
clock. a duration with no config beside it is unfalsifiable — and this route needed
exactly that discrimination twice, when a polluted run had to be told apart from a clean
one.

## .artifacts

- `.log/bench.acceptance/<label>.json` — wall clock, phases, per-file cost, case map
- `.log/bench.acceptance/<label>.jest.json` — the raw jest payload
