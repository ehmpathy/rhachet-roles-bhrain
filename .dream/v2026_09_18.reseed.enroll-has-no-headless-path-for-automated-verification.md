# 🌙 dream: `rhx enroll` infers interactive from the caller's tty, so no test can verify a real `/model` lands

- kind  = `reseed` — the fix belongs to `ehmpathy/rhachet`
- owner = `ehmpathy/rhachet`
- caught 2026-09-18

## .the cue that fired

a peer reviewer (`ergo-acceptance-journey-coverage`) asked for an acceptance test with *"a live (or
hermetically-enrolled) clone and a snapshot"* that proves a `/model` dispatch lands. a feasibility
probe found a hard wall.

## .the gap, precisely

`invokeEnroll.js` picks interactive (a live pty) or headless (`--print`, one-shot) from the ENROLLING
process's own tty:

```js
// node_modules/rhachet/dist/contract/cli/invokeEnroll.js:231
interactive: !!process.stdout.isTTY,
```

a jest process has no tty, nor does a driver's sandboxed shell. probed (verbatim output):

```
$ rhx enroll claude --as @:dogfood-r4-probe --roles driver --no-socket --output json
{"outcome":"baked","serial":"41c95973-...","slug":"dogfood-r4-probe","socketEligible":false}
Error: Input must be provided either through stdin or as a prompt argument when using --print
```

`rhx clone list` then reads `"reachState": "DEAD"`. ⇒ **not a credential gap** — the branch fires on
`isTTY` before any brain call.

| ruled out | why |
|---|---|
| call an enroll sdk function with `interactive: true` | `package.json#exports` ships `.`, `./brains`, `./actors`, `./keyrack` — no enroll |
| wrap the child in a pty utility | not on this environment's command allowlist |
| `node-pty` as a test dependency | a native addon to reimplement enroll's pty logic — a fulcrum, never a driver call |

## .the shape of the fix

in `ehmpathy/rhachet`, cheaper first:

1. **an explicit override** — `enroll --interactive` or `RHACHET_ENROLL_INTERACTIVE=1`, for a caller
   that allocates a real pty itself
2. **a public `./enroll` export** that takes the pty-vs-print branch as a parameter

## .why it is not done in this round

- **SAFE — no.** the fix lives in another repo
- **CLEAN — no.** the one local workaround is new native-dependency infrastructure — a braided trail
