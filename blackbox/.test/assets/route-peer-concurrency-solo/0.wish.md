# test fixture: single-reviewer level, no group

- **l1** — `solo`, one reviewer, no group, no declared bound

the reviewer records its own in-flight window into `.test/windows.log`, so a test
can confirm the lane ran (window count = 1) without a wall-clock read.

.why = the announce was built for the 1-member case: `genContextCliEmit` seals no
header at inflight for the slotted path (`wave.launch(…); drawStatus(); return`),
and under a pipe `drawStatus` is a no-op, so without the announce a single-member
level is byte-silent from launch to settle. this fixture is the one acceptance
witness for that gap.
