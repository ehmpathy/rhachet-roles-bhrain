# domain.term.choice.reason: get

## .etymology
`get` is the one verb this repo uses to return a value with no side effect. it names one concept —
the side-effect-free return — so a caller knows from the name alone that the call changes naught.
`fetch`, `find`, `lookup`, and `calculate` each name that same act, so each is forbidden.

## .disputes
none.

## .evidence
- precedent: the get / set / gen / del verb set, where `get` is the sole pure axis
