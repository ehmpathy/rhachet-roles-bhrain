🟡 **the skeleton is the emitter's own.** `route.ts:2326-2344` renders success as an owl status line,
a blank, then a `🗿 route.guard.budget` tree whose rows are `route =`, `add =`, `peer =`, `level =`.
the refusal keeps that head and swaps the tail, so a driver reads one shape either way. ⇒ the vision
yield's § *before and after* renders this same cell and **must agree with this file byte for byte**;
where they drift, this file is the authority.

🔴 **the refusal teaches the two exits and prices them both.** it does not merely say *no* — it names
the converge path as the default (`rule.require.errors-name-the-fix`) and states the one condition
under which the refused command becomes the right one.

⚠️ **it must NOT lead with "ask your human".** `rule.always.spend-own-levers-before-escalation`
measures the cost of that adjacency: *"two remedies rendered side by side with no owner column read
as two human remedies."* the driver's own lever here is **convergence**, and it is listed first and
alone under *"yours to run."*

🟡 **the human path is deliberately absent from this block.** it exists (`case=4`), and to print it
here would hand a driver an escalation for a round the design already priced as unnecessary — the
exact cost `0.wish.md` §gain.rank names.

**the aha:** *the meter was never a display with a counter attached. the bound is the answer — the
round i wanted was a round the route already decided this work is not worth.*

## .the bdd timeline

```gherkin
given a stone `5.1.execution` with peer reviewer `mech-rules`, budget 3, rounds 3
  and mech-rules' latest .given raises 1 nitpick, 0 blockers
  and passage.jsonl carries NO live conceded row for any slug        # B = none
  and the lane is skipped for budget                                  # C = exhausted

[t0] when the driver runs route.guard.budget --for review --add 2 --peer mech-rules
     then the command exits 2                                         # constraint, not malfunction
      and the guard file's `budget: 3` is UNCHANGED                    # 🔴 the write never happens
      and stderr names the absent urgent concession
      and stderr names the converge commands, in order
      and stderr does NOT name a human command                         # the driver's lever is convergence

[t1] when the driver absorbs the nitpick --severity better
     then a passage row lands: status = conceded, severity = better
      and the concern is shed from the residual tally                  # getStoneConcededBetterConcernCounts

[t2] when the driver runs --as passed
     then the stone PASSES with the nitpick unconfirmed by mech-rules  # good enough inside the budget
      and no human was summoned                                        # 🔴 the whole point

[t3] given instead the driver retries the top-up verbatim at [t0]
     then it is refused identically                                    # idempotent refusal, no drift
      and no ledger row is written by the attempt                      # a refusal records naught
```

🔴 **`[t0]`'s second clause is the one a test must pin.** a gate that prints a refusal *after* it
mutates the guard file is not a gate. the check precedes every write, and `routeGuardBudget`'s extant
order already reads state before it writes (`route.ts:2271-2288` — *"read first and a malformed route
fails fast with the budget untouched"*), so the gate lands in a place the code already reserves.

⚠️ **`[t3]` matters more than it reads.** a refusal that logged an attempt would let a driver's churn
accumulate as evidence of effort. **a refusal is not an event** — it writes naught, so the ledger
records only what the driver actually decided.

## .why it fails safe

**fast** — the refusal precedes the guard write; a refused grant leaves the meter byte-identical ·
**loud** — exit 2, stderr, the absent predicate named explicitly (`rule.forbid.stdout-on-exit-errors`)
· **teaches the fix** — both exits printed complete, with the stone bound, in the order they should be
attempted.

🔴 **the pit of success is that the cheap path is now the correct one.** before the gate, the cheapest
move (`--add N`) was the one that fed the loop. after it, the cheapest move is to absorb the concern —
which is the move `rule.always.absorb-every-concern` already owes.
