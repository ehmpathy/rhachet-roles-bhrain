# seed S15 — `--into` is required, so the guard can show the diff

**status** live · **rules** `F03` → **required** · **utterance** 1 · **on** 2026-09-18

## .said

> yeah require --into; forces them to say where it is, so we can show them the diff too

## .settled

**`--into` is a required input on `--as promised`.** the driver states the path they wrote to, and
the guard compares it against the path it will read.

⇒ the reason is **not** the one the drive argued. the drive's case was **detection** — *"an inferred
path always matches itself, so an optional flag catches a mismatch only from the driver careful
enough to pass it."* the wisher's case is **diagnosis**: a declared path is a second operand, and a
second operand turns a verdict into a **difference**.

| the guard holds | the best it can report |
|---|---|
| the computed path alone | a **boolean** — *"the articulation is absent"*. true, and it names no cause |
| 🔴 the computed path **and** the declared one | a **diff** — which segment diverged, and the exact move that closes it |

## 🔴 .the concept, stripped of this round

> **a check with ONE operand can report a failure. it takes TWO to report a difference.**

so a forced declaration is not merely a stricter gate — it is the **only** way a gate can explain
itself. the party under the check holds half the evidence, and a check that never asks for it is
condemned to say *"no"* with no *"because"* attached.

⇒ the cost of the flag is one copied line per promise. what it buys is that **every** failure of this
check becomes actionable, rather than only the failures whose cause the guard could already guess.

## 🔴 .why this reason SURVIVES `S12` where the drive's reason did not

`S12` dropped the `rN` level from the articulation path, so the path keys on `(stone, slug)` — both
of which the driver already holds. the drive read that as fatal to `--into`:

- the flag existed so a driver could surface a **belief** about a component they could not compute
- no such component remains
- ⇒ so the drive revised its own 65% guess **against** the flag, and was wrong

**the diff argument is untouched by `S12`.** it does not rest on a path that is hard to compute; it
rests on the guard's inability to explain a mismatch it cannot see. an easier path makes a mismatch
**rarer** — it does not make the rare one any easier to diagnose.

🟡 **and the residual cases are real**: a stale path from a prior round, a copied line from the wrong
slug, a route segment dropped by an emit (`c8′`, measured twice this round). each is a case where the
driver's path and the guard's path differ for a reason **only the pair of them shows**.

## 🔴 .this is the round's FOURTH verdict the drive's fork mispriced — and it is a different shape

| # | fulcrum | what the fork lacked |
|---|---|---|
| `F01` | the **option** — E was absent from the comparison |

| `F11` | the **option** — E1 ∧ a target condition was neither E1 nor E2 |

⇒ the first three taught *"a fork is a hypothesis about the answer's shape."* this one teaches a
sharper lesson: **an option can be listed, chosen, and still mis-argued** — and a mis-argued option is
the more dangerous, because a later utterance that falsifies the argument reads as though it
falsifies the option.

🔴 **the drive did exactly that.** `S12` gutted the detection argument, and the drive concluded the
verdict should follow it to *optional*. ⇒ **check whether a new fact killed the CLAIM or merely the
REASON you gave for it** before you move a verdict.
