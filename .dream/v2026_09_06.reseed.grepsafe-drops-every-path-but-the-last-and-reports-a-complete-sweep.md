# 🌙 dream: `grepsafe` drops every `--path` but the last, and reports a complete sweep

- kind    = reseed
- owner   = `ehmpathy/rhachet-roles-ehmpathy` — `role=mechanic/skills/claude.tools/grepsafe.sh`
- caught  = 2026-09-06

## .the cue that fired

a term census over two trees returned one tree's hits and read as complete. the claim it produced
would have been three-quarters short.

## .the gap, precisely

`--path` is **last-wins**, silently. every earlier one is discarded, and the header advertises only
the survivor — so the output is internally consistent and externally false.

measured, on a value declared in the dropped path:

```
$ rhx grepsafe --pattern 'READER_MEMORY_WARM_MS' --path src/domain.operations --path src/contract
   ├─ path: src/contract
   ├─ lines: 1
   │  src/contract/cli/telepath.ts:16: *    READER_MEMORY_WARM_MS. the throttle models …
```

⇒ `READER_MEMORY_WARM_MS` is **declared** in `src/domain.operations/telepath/isReaderMemoryWarm.ts`.
its declaration is absent from the result, and the run exits `0` with a `🐢 sweet`.

## 🟡 .why it is worse than a wrong answer

the result is **not** malformed. it is a correct search over a smaller set than the caller asked for,
and the header names that smaller set — so a reader who checks the header sees agreement.

| what a caller can catch | what they cannot |
|---|---|
| an error, a non-zero exit, an empty result | a complete-shaped result over a truncated scope |

⇒ that is `rule.forbid.failhide` in an instrument, and it is the **second** measured instance in this
skill. the first is `.dream/v2026_09_06.reseed.grepsafe-skips-every-dot-prefixed-file-and-reports-a-clean-sweep.md`
— a different mechanism, the identical failure shape: the scope quietly shrank, and the report said sweep.

## .the shape of the fix

1. **accept repeats.** collect every `--path` into an array and search each, as `mkdirsafe` already
   does (`rhx mkdirsafe --path 'src' --path 'test' --path 'docs'` is a documented usage line) — so
   the repeat form is already the house convention this skill breaks.
2. **or fail loud.** if one path is the real contract, a second `--path` must exit non-zero and name
   the single-path form. an ignored flag is the defect; a rejected one is a message.

🟡 move 1 is the better one on evidence, because a peer skill in the same directory already reads the
flag that way — so a caller's expectation is set by the tree, not guessed.

⇒ and either move wants the clamp `rule.require.clamp-edge-cases` asks for: a case that passes two
paths where the hit lives in the FIRST, and goes red under the un-fixed skill.

## .why it is not done in this round

**it belongs to another repo.** `grepsafe` is `ehmpathy/role=mechanic`, and a tree adopts only what
is scoped to itself (`rule.always.scope-onetime-lessons-to-the-behavior`).

⇒ the local workaround is one call per path, and every census in this route now runs that way.
