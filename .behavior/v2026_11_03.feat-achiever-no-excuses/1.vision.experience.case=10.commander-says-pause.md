# case 10 — the commander says "pause"; the clone pauses

feel: sharp (the hold must not trap the commander) · care: critipath · actor: commander, achiever · seams: talk hook, store, stop hook

## .narrative

the commander has to leave: "pause here, pick this up tomorrow." two goals are inflight. a stop hook
that refuses every open goal would now trap the clone: it cannot stop, and the commander's own order
says stop. that is the worst feel this role can produce.

the pause is itself an ask, so the talk hook records it. the achiever marks each open goal `deferred`
with a when ("tomorrow, at the commander's return"), and covers the pause ask with that. the stop hook
reads deferred-with-a-when as terminal, and the stop passes. tomorrow, the boot hook lists the two
deferred goals first. no order was dropped, and the clone obeyed.

the sharp half: if the achiever tries `deferred` with no when, the set refuses: a defer with no when
is a drop under a marker. the refusal names the flag to add.

## .[tn] — a sketch

```
given  two inflight goals
when   [t0] the commander submits "pause here, pick this up tomorrow"
then     the talk hook records it as an ask
when   [t1] rhx goal.memory.set --slug x --status.choice deferred --status.when 'commander return, 2026-11-04'  (x2)
     and the pause ask is covered
then     the stop hooks read both goals as terminal; exit 0
when   [t2] rhx goal.memory.set --slug x --status.choice deferred   (no when)
then     the set exits 2: ✋ ConstraintError: a defer owes a when
              └─ add --status.when '<when you will return to it>'
when   [t3] the next session boots
then     goal.triage.next --when hook.onBoot lists the deferred goals first
```
