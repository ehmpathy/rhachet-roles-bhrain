# im an obsessive learner — for domain glyphs 📜

## .what

a **zoom-in** of `im_an.obsessive_learner.md` onto one more capture kind: the **glyph lesson**.

a glyph is a term on a surface with no room for a word. so it obeys the term law — one concept,
one symbol — and it lands in the repo's own catalog:

```
.agent/repo=.this/role=any/briefs/domain.glyphs/catalog.of=glyph._.md
.agent/repo=.this/role=any/briefs/domain.glyphs/catalog.of=glyph.axis=$axis.md
```

peer of `im_an.obsessive_learner.for.domain.terms` and `.for.domain.invariants`. same obsession,
one layer down.

## .why capture is urgent here

the term failures, verbatim: two glyphs for one concept · one glyph for two concepts · a glyph
claimed with no record.

🟡 **but the repair cost is worse than a term's.** a term appears in the contracts that use it. a
glyph prefixes **every surface it marks** — a readme header, a stdout line, a status line, a
declared config field, and every snapshot of all four.

⇒ so a claimed glyph spreads at once, and **each surface makes the repair dearer**. catalog it in
the round that claims it, or the next claimant greps, finds no match, and takes it.

## 🔴 .a grep proves a glyph is UNUSED — never that it is UNCLAIMED

a glyph may be **reserved** for a role that does not exist yet. it greps clean the whole time and
is never free.

⇒ **only the catalog settles it.** the grep is necessary and never sufficient — which is why the
catalog must be a written artifact rather than a search you trust the next claimant to run.

## .the cues — when → then

| when… | then… |
|---|---|
| you **claim** a glyph, on any axis | 🔴 catalog it. the row is the claim |
| the glyph is **not in the repo's palette** | add it to the palette first, with its one-line sense. then claim it |
| a grep returns **no match** | that proves unused, never unclaimed. **read the catalog** |
| a grep returns matches on **several surfaces** | three cases: one concept seen twice · a decoration that sorts no reader · two concepts. **only the third blocks** |
| you find a glyph in use with **no catalog row** | 🔴 the arrears. add the row now |
| two copies of the record **disagree** | reconcile to the catalog; make the others its dependents |
| you coin a **third** glyph for a concept a marker already covers | glyph-synonym drift. reuse the settled one |

🟡 **check the code before you swap.** a type that names its own slots — a `mascot` field beside
an `artifact` field — has already drawn the seam. a swap drafted against a misread of that seam
moves hundreds of occurrences and repairs no defect.

## .the test — answer both, on the page, before the claim

> **1. does this glyph name what its subject DOES?**
>
> **2. what CONCEPT does it hold — and does another glyph already hold it?**

a glyph picked for looks fails 1. a concept already held fails 2, and the repair is **reuse**,
never a coinage.

⇒ then update every published face that restates the catalog, so none drifts from the index.

## .mantra

> a grep finds what is used. only the catalog finds what is spoken for. 📜
