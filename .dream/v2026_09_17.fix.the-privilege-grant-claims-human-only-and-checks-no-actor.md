## .the gap, precisely

`route.ts:1845` — the command's own usage block:

```
rhx route.mutate grant allow   # grant privilege (human only)
```

`route.ts:1838-1889` — the implementation, in full:

1. `:1838-1855` — validate the action string is one of `allow` | `block` | `get`
2. `:1858-1867` — auto-detect the route from the branch bind
3. `:1875-1889` — `action === 'allow'` ⇒ `fs.mkdir` + `fs.writeFile(.privilege.mutate.flag, '')`

🔴 **there is no actor check at any step.** no meter, no TTY probe, no quota file, no `uses`
precedence — the three-level pattern `git.commit.uses` and `radio.uses` both carry is absent here.
*"human only"* is a string addressed to the party it binds.

and `rhx` is prefix-approved on the driver's own permission list
(`init.claude.permissions.route.jsonc`), so the call raises no prompt either.

### what the flag lifts — and it is wholesale

`route.mutate.guard.sh:94-98`, the pretooluse hook wired on `Read|Write|Edit|Bash`:

```sh
PRIVILEGE_FLAG="$ROUTE_DIR/.route/.privilege.mutate.flag"
if [[ -f "$PRIVILEGE_FLAG" ]]; then
  # privilege granted, allow all operations on this route
  exit 0
fi
```

one flag, and **every** `*.stone`, **every** `*.guard`, and all of `$route/.route/**` is writable by
the driver — the three path classes the hook's own header (`:5-8`) says it exists to protect, whose
stated reasons are a peek ahead at future stones, a read of the review criteria, and a direct mutate
of `passage.jsonl`.

## .the shape of the fix

🔴 **one predicate, at one call site, before the flag is written** — `route.ts`, between `:1867` and
`:1875`. both doors share that root, so one check closes both.

⚠️ **it must be an ACTOR check, never a seal.** the privilege grant is the human's legitimate lever,
and a route wish is likely to lean on it as the human path
(`0.wish.md` req 7: *"a human may still grant, with the route in view"*). to remove the door would
delete an answer somebody else relies on.

three candidate shapes, unranked:

| shape | reads as |
|---|---|
| a **`uses` meter** — `route.mutate.uses allow\|block`, three-level precedence | the paved pattern. `git.commit.uses` and `radio.uses` both ship it, and their operations are already factored (`radio.uses.operations.sh` holds the shared path/state/TTY logic) |
| a **TTY probe** — refuse unless stdin is a terminal | cheapest, and it is what `radio.uses.operations.sh` already calls a *"TTY guard"*. ⚠️ weaker: a driver can hold a TTY |
| a **confirm prompt** | rung 2 of `rule.prefer.prevent-over-correct`, and it composes with either above |

🟡 **and the `allow` branch should probably narrow**, separately and second: a flag that lifts
`*.stone`, `*.guard`, and `.route/**` at once is coarser than any single need for it. a scoped grant
(`--for guard` | `--for stone` | `--for route`) would let a human open the one door they meant.
⇒ that half is a **larger** change and should not block the actor check.

### what else moves with it

- `rule.always.spend-own-levers-before-escalation` — the `budget` field must leave the driver-owned
  guard row, and the row should name what a driver **may** still edit (`--paths-with`,
  `--conversation`, `level`)
- `route.ts:1845` help text — it already states the bound; once enforced, it should also name **how**
  a human grants it (`rule.require.errors-name-the-fix`)
- an acceptance case per door, plus one for the human path

## .why it is not done in this round

the SAFE/CLEAN test (`rule.always.fix-forward-under-scouts-honor`):

- **safe?** 🔴 **no.** it changes who may run a shipped command, on every route in every repo that
  boots the driver role. a wrong shape locks a human out of their own lever
- **clean?** 🔴 **no.** the fix touches `route.ts`, a booted brief in another role's tree, the help
  text, and an acceptance suite — and the scoped-grant half touches the hook as well. it ripples well
  past the diff the budget-gate wish opened

⇒ **defer, and the deferral is a judgment**, so it owes a fulcrum as well as this dream
(`rule.always.catch-dreams-for-followups`). the fulcrum is
`.behavior/v2026_09_17.fix-budget-grant-needs-urgent-concession/.fulcrums/inventory.of=fulcrums.case=F13-the-requirements-name-a-command-not-the-quantity.md`,
which states the A/B/C fork and takes C.

⚠️ **and the cost of the deferral is on the record too:** until this lands, a budget gate on
`route.guard.budget` bounds the **sanctioned path** and does not bound the **quantity**.
