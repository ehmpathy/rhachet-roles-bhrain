# case=5: graduation without a pedigree entry is held

inventory row: s6. feel: sharp. care: critipath — a pursuit that ends with no record is invisible to every later session and to the director.

## .narrative

every course has exited and `3.courses.review` chose to graduate. the student signals `--as passed` on `4.graduate`, but never ran `pedigree set`. the guard's judge holds:

```
$ rhx route.stone.set --stone 4.graduate --as passed

judge: rhx education.pursuit judge --criterion pedigree-stamped --route $route
   ├─ passed: false
   └─ reason: the pedigree entry is absent; run: rhx education.pedigree set
```

the student runs the fix; the second `--as passed` clears.
