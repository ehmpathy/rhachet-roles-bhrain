# case=5 — a broken cache fails safe (sharp · critipath)

## .narrative

a driver works on stone `3.plan` while the box's disk runs full. one repaint's cache write is
cut off half way — the file on disk holds half a json object. the driver glances at the seat's
status line on the next repaint and sees `🗿 3.plan`, the right stone, exactly as before. no
blank line, no garbage, no error in the harness. the seat read the broken cache, found it
unparseable, treated it as a miss, rendered the true line, and wrote a fresh cache over the
broken one (temp file + rename, so no reader ever opens a half write). the driver never knew;
the defect cost the seat one recompute and healed itself.

the unwritable dir is sharper for the operator. a seat runs in a worktree whose
`.agent/.cache/` is read-only. the driver still sees the right stone on every repaint — the line
looks perfect — but every repaint pays the full render, the very cost this fix removes. a
silent regression would hide on the box until `top` lit up again, so the seat makes it loud:
each failed write emits one stderr row,
`[route.status.line] fault: cache write failed (EACCES) at <path>, the line renders uncached`,
with the same `[route.status.line] fault:` prefix the renderer's other faults use. the operator
who reads the harness log finds the path to repair; the driver's line is never wrong and the
exit stays 0.

## .bdd sketch

```
given('[case5] a seat on a bound route, and a cache file that holds invalid json')
  when('[t0] the seat repaints its line')
    then('the seat sees the correct stone for the route')
    then('it exits 0')
    then('the cache file is replaced with a valid record')
given('[case5b] a seat whose cache dir it cannot write')
  when('[t0] the seat repaints its line')
    then('the seat sees the correct stone and it exits 0')
    then('stderr names the cache write fault and its path')
```
