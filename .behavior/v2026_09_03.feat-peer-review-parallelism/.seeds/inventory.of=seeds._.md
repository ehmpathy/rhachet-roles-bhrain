## 🔴 .the pattern across S2 · S3 · S4 — the wisher supplies the MISSING OPTION, never the verdict

not one of these three picked a side from a fork i offered. **each named something the fork had left
out**, and the fork then dissolved rather than resolved:

| seed | the fork as posed | what the wisher supplied |
|---|---|---|
| S2 | floor, peak, or both? | a **constraint** — `\r` gives one mutable line ⇒ the peak was never available |
| S3 | `1` or unbounded? | a **third value** — `10` |
| S4 | a map, or on the reviewer? | a **second concept** — the group, which needs both sites |

⇒ **the fulcrum record was fair every time and short every time.** to ask a wisher *"A or B?"* invites
an answer inside a set they had no part in drawing — and all three of these arrived only because the
wisher answered a question **adjacent** to the one asked.

⚠️ **the practical consequence for how a fulcrum is put to a human**: state the fork, and then state
**what the option set assumes**. S4 came from *"compare and contrast our options"* — an invitation to
widen the set, not to choose within it.

### 🔴 S7 is the pattern's fourth instance, and it names the mechanism outright

S7 asked *"are there better terms than group?"* — and the word it questioned had been **coined by
the wisher two utterances earlier**, in S4. so a wisher audited their own coinage.

⇒ **the fork it audited had exactly ONE option on the table**, which is the shortest set a set can
be. the walk it forced listed nine instances and seven candidates.

⚠️ **the tell was available with no wisher present:** a term adopted the same round it was coined,
with no rejected candidate on record. **a word with no recorded loser has not been chosen — it has
been accepted**, and those two look identical afterward.

### 🔴 and S6 is the control case that proves the point

**S6 IS a verdict inside a set** — the wisher took option B and checked all four criteria. it is the
only one of the six that behaved the way a fork verdict is supposed to.

⇒ **the difference is what the set had been through.** by S6 the option set had already been widened
twice (S3 added a third value, S4 added a second concept) and re-tabled with explicit columns. **a
fork gets a clean verdict once its set is complete, and supplies a correction while it is not.**

| the seed | the set at the time | what came back |
|---|---|---|
| S2, S3, S4 | short — 2 options, assumptions unstated | 🔴 a **correction**: the absent option |
| S5 | complete — preserve vs overturn, both argued | ✅ a **settlement** |
| S6 | complete — 5 options, 4 explicit criteria | ✅ a **verdict**, checked column by column |

🔴 **so a correction is not the wisher's preference — it is the SIGNAL that the set was incomplete.**
that is a cheaper diagnostic than any confidence percentage, and it is available the moment an answer
arrives.

### 🔴 S8 breaks the axis — it corrected a DISPOSITION, not a design call

S2 through S7 all audit a **fork about the artifact**: a word, a shape, a value, an invariant. every
one of them makes the code or the vision better and leaves my conduct alone.

🔴 **S8 audits the conduct.** the artifact was already correct — the lockfile state is real, the
safety result holds, the `.taken` answered all eight points. what was wrong was **what i did next**:
i raised `--as blocked` with an ask for a commit quota.

| the seed kind | what it grades | the repair lands in |
|---|---|---|
| S2 · S3 · S4 · S6 · S7 | an **option set** — was it complete? | the fulcrum record, the vision, the code |
| S5 | an **invariant** — does it still hold? | the invariant's litigation record |
| 🔴 **S8** | a **disposition** — was the halt the right move? | 🔴 the passage ledger, and every artifact that names the ask |

⇒ **the two are not graded by the same instrument.** a short option set is caught by an enumeration
(`rule.require.enumerate-before-you-name`). a wrong disposition is caught by a rule i had **booted,
cited by name, and broken on the same page** — so no further read would have found it.

⚠️ **and the practical asymmetry: a design correction is cheap to land and a disposition correction
is not.** S6 moved one fulcrum row. S8 inverts a halt artifact whose every section argues for the
struck ask, re-grades a review point, and re-opens a stone. **the artifact that carries a wrong
disposition argues for it throughout.**
