# case 4 — a blocker cured at once

feel: happy · care: critipath · actor: achiever · seams: store, the cure tool

## .narrative

an integration test fails: "credential is locked." the old achiever would write "blocked: keyrack
locked" and stop. this achiever reads the error, sees the fix it names, runs
`rhx keyrack unlock --owner ehmpath --env test`, and re-runs the test. no blocker record was ever
written; the cure took one turn.

the same move covers a stale build, an absent dependency, a wrong glob in its own guard, a tool it
builds that misbehaves (it cures the tool). a blocker whose cure is in reach is not a blocker; it is
the next step.
