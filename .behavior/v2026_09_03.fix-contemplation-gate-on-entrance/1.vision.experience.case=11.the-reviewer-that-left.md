# case=11 · the reviewer that left

- **coordinates** = `enter-review × {fresh,carried}-unanswered × retired`
- **feel** = sharp · **care** = critipath
- **verdict** = forbidden → demoed

🔴 **found at 5.3, never at the vision.** the C axis carried three values and this experience sits
on a fourth. a peer read of the execution's own snapshot surfaced it — the render already printed
`status = retired from the guard config`, so the experience was live in the product while the
contract that governs the product had no cell for it
(`rule.require.experience-catalog-evolution`).

## .the narrative

a driver arrives at a stone. the guard names a reviewer that owes an answer — and the driver opens
the guard config and cannot find it. the slug is nowhere. it was removed a week ago, by someone
else, in an unrelated change.

every instinct the driver has is wrong here:

| the instinct | why it fails |
|---|---|
| *"wait for it to speak again"* | it will not run. it is not in the config |
| *"top up its budget"* | `--add N` extends reviewers the config names. this one it does not |
| *"ask a human to overrule it"* | 🔴 an overrule forgives a **level**, and a slug absent from the config carries no level (F8) |
| *"edit the artifact and re-roll"* | the debt is keyed to the reviewer. no edit reaches it |

⇒ **the halt is real, the reviewer is gone, and exactly one lever remains: write the `.taken`.**
that is why the render carries a why-block naming the fix as the only one — absent that copy, the
halt reads as a defect and the driver hunts a reviewer that no longer exists.

## .why it is a critipath

it fails the care test in the direction that matters. **frequency is low** — a config edit that
retires a reviewer mid-conversation is rare. **cost is the whole stone**: a driver who reads the
halt as a defect has no next move that works, and every remedy they would reach for is shut. the
stall is not bounded by their patience; it is bounded by whether someone tells them the answer.

⇒ that is the same shape as case=1 — low frequency, unbounded cost — and it earns criti the same way.

## .the bdd

### `[t0]` a reviewer raises a blocker, then leaves the config

```
given  a stone whose guard names reviewers { architect, mechanic }
  and  mechanic has raised 2 blockers, unanswered
when   mechanic is removed from the guard config
then   the given remains on disk, and the debt is still owed
```

### `[t1]` 🔴 the driver enters a review round

```
when   the driver runs --as passed
then   the gate refuses at the door
  and  the halt names `mechanic`, a slug absent from the config
  and  the render marks it `status = retired from the guard config`
  and  a why-block explains that no edit and no wait can clear it
```

⇒ clamped at `formatRouteGuardReviewPeerContemplatePrompt.test.ts` `[case4]`, which asserts the
retired one is marked **and the live one is not** — so the marker discriminates rather than decorates.

### `[t2]` the driver reaches for the levers, and finds them shut

```
when   the driver tops up the budget
then   the state is unchanged — the config names no such reviewer to extend
when   a human overrules the level
then   the state is unchanged — the slug carries no level to forgive (F8)
```

### `[t3]` the answer discharges it

```
when   the driver writes the .taken and runs --as contemplated --that mechanic
then   it is ACCEPTED rather than rejected for an unknown slug
  and  the debt is discharged
  and  the next --as passed enters the round
```

🔴 **`[t3]` is the load-bearing step.** `setStoneAsContemplated.ts` rejects a slug that names
no peer reviewer — and a retired slug names no peer reviewer. so the naive read of that guard would
**refuse the one command that can clear the debt**, and the stone would be unpassable by any route.

⇒ clamped at `setStoneAsContemplated.test.ts` `[case5]`, which drives `genScene({ retired: true })`
and asserts the command *"is ACCEPTED, and guides rather than throws"*.
