# howto: razor a thought

> **a razor is ONE question whose answer decides. it is what a rule ships so an author does not have to hold the rule.**

every say-tier rule in this canon carries one, under `.the test`. **this file is how you forge a new
one** — the tactic under `rule.require.elucidation` and `rule.require.reflexive-condensation`, since
both ask you to judge, and neither can be judged by a principle held in the head.

## .why a razor and not a principle

a principle states what is good. a razor states which of two cases you have in front of you, and
it does so from the artifact alone.

⇒ the gap between them is measured, not asserted. this repo's own `research.selfreview-effectiveness`
scores a when-then cue at `d = 0.65` and a bare principle at `d = 0.05` — an order of magnitude,
on the same reader, on the same defect.

| a principle | a razor |
|---|---|
| *"prose should be findable"* | *"can you point at the line that carries its purpose?"* |
| answerable only by an author who already agrees | answerable by anyone with the page in front of them |
| fires when recalled | fires when asked |
| its failure is invisible | its failure is a verdict you can check |

🟡 **an author who agrees with a principle still ships the defect.** that is the whole reason the
canon carries razors rather than statements of intent.

## .the four moves

- **1 · name the OUTCOMES first, before the question**
  - a razor cuts into a small closed set — two, sometimes three, rarely four
  - if you cannot list them, you are not ready to write the question
  - ⇒ **this is the move that gets dropped**, and to drop it is what produces a razor with no edge
- **2 · find the property that DIFFERS and is OBSERVABLE**
  - not the property you care about — the one a reader can see on the page
  - *"is this obfuscation?"* asks about a concealed motive; *"did the omission change what the reader would DO?"* asks about an outcome
- **3 · phrase it as a question the artifact answers**
  - the author must be able to answer it without a second opinion, a run, or a memory of their own intent
- **4 · run it against your hardest FALSE POSITIVE**
  - the case that looks like the defect and is correct
  - a razor that condemns it is too wide; widen the question until it acquits, or the rule ships a rule its own examples break

## .the canon's own razors, as the demo set

each is a live instrument, and each shows a different cut:

| the razor | its cut |
|---|---|
| *"could a reader disagree, and know what would settle it?"* | two properties, both required — the shape most rules want |
| *"can the peer USE the concept now?"* | grades the reader's state, never the passage |
| *"does this mark RANK a line against its neighbours, or CLASSIFY it?"* | a fork between two legitimate acts — neither answer is a defect |
| *"who needs this, and WHEN?"* | three outcomes: keep, cut, move. **move** is the one the rule exists for |
| *"would this read the same if the reader's mascot were a seaturtle?"* | a swap test — change one variable, see if the claim survives |
| *"does the repair cost more than the boot?"* | a comparison, so it yields a call rather than a verdict |

⇒ **the swap test is the most reusable shape and the least reached for.** substitute one variable
and ask whether the claim holds: swap the mascot, swap the subject, swap the actor. a truism survives
every swap, which is exactly how you catch one.

## .the four failure modes

| the razor | why it fails |
|---|---|
| *"is this diffuse?"* | it restates the rule. an author who could answer it did not need the rule |
| *"did you intend to conceal this?"* | it asks about intent. unanswerable by a reader, and it invites a self-serving answer from the author |
| *"is this good prose?"* | the set is open. a razor with unbounded outcomes is a taste, not a cut |
| *"is this the strongest available settler?"* | it needs the answer first. if you knew, you would have used it |

🟡 **the first is the common one**, and it feels like a razor because it is short and it ends in a
question mark. **the test for a razor is not its length — it is whether an author who has not
grasped the rule can still answer it.**

## .the test for a razor

> **could an author who does NOT yet hold the rule answer this question correctly?**

yes → a razor · no, they would need the rule first → a restatement · they would need to consult
their own intent → **not a razor at all**; it grades the author rather than the artifact.

## .where a razor belongs

| the artifact | its razor |
|---|---|
| a rule | under `.the test`, above the when-then table |
| a when-then row | the row IS a razor, at a narrower grain — a cue plus its verdict |
| a tier call, a name call, a scope call | state it inline, at the point of the call, so the next author re-runs it rather than re-derives it |

⇒ **a call made with an unstated razor gets re-litigated.** the question costs one line and it is the
line that makes a decision auditable.

## 🟡 .the bound — a razor decides, it does not think

a razor is worth its place because it compresses a judgment you already made. **it does not make a
judgment you have not made.**

⇒ so a razor over a genuinely open question is a **fake tool** in question form: it renders a
confident answer where the honest artifact is *"this is unsettled, and here is the fork"*. the canon
has a home for that — a fulcrum, itemized, with its confidence stated.
