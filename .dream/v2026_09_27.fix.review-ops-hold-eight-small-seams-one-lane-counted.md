## .the shape of the fix

- **n2** — one `WARMER_FLAGS` const (`{ reviewer: '--reviewer', … }`) in `warmer/`; the argv
  builder, both validators, and the cli reader all read it. a unit test asserts the argv the
  builder emits parses back through the validators clean
- **n3** — one communicator `getOneFileTextOrNull({ path, of })` that owns the absence allowlist
  and the `UnexpectedCodePathError` wrap; the three callers compose it
- **n4** — rename to `get*` communicators that return a boolean (`getOneWarmerAliveVerdict`), or
  split each into a `get*` read plus a pure `is*` over its result. the second keeps the `is*`
  test cases pure
- **n6** — thread `metricsExpected` into both later sites; the stdout emitter and the return read
  the one value
- **n7** — eject to `review/withSpinner.ts` beside `genReviewDir.ts`, one op per file
- **n8** — pass a context object on each `BadRequestError` (`{ figures }` for overflow,
  `{ ruleGlobs }` for the empty glob), so an sdk caller branches without a stderr scrape
- **n9** — upgrade `helpful-errors` to a release that exports `MalfunctionError`, then rebase
  `ReviewTimeoutError` on it. the message already carries the `💥 MalfunctionError:` header
- **n12** — lift `WORD_OF_ABSENT` to `review/WORD_OF_ABSENT.ts`, the common ancestor of both
  readers (`rule.prefer.most-common-denominator`)

## .why it is not done in this round

safe, not clean. each is a refactor across files the round did not open, and n4 and n12 rename
or relocate exported names the grove, meter, and warmer suites import. n9 is gated on a
dependency upgrade. none ships a harm today: every site is consistent now, and the reviewer
graded all eight `better`.
