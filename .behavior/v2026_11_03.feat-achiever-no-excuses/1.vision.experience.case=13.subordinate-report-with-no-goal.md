# case 13 — a subordinate's report with no goal to hold it

feel: sharp · care: critipath (the radio seam is the one the talk hook never sees; the stop's read is its guard) · actor: subordinate, achiever · seams: radio, store, stop hook

## .narrative

a subordinate clone was never dispatched by this achiever; it found a defect on its own and pushed a
blocker report into this repo via the radio. no goal bears on it. no hook fires on a radio push
(the talk hook reads the commander's prompt only). so the report would sit unread, and the
subordinate would stay blocked while the achiever believes all is clear.

with this role, the stop hook reads the inbound radio tasks on the local channel as part of the
inventory. a QUEUED inbound task that no goal covers is an uncovered ask, and the stop exits 2. the
refusal names the task and the move: claim it onto a goal, then cure it by the same three routes.
the report was loud at the first stop after it landed.

## .[tn] — a sketch

```
given  an inbound radio task, QUEUED, on the local channel (os.fileops), covered by no goal
when   [t0] the achiever tries to stop
then     goal.triage.infer --when hook.onStop exits 2:
           💎 goal.triage.infer --when hook.onStop
              ├─ uncovered inbound radio tasks = 1
              │  └─ "blocked: the test needs a prep key" (exid 42, from <subordinate>)
              └─ claim it: rhx goal.memory.set --slug <s> --covers radio:42 ...
when   [t1] the achiever claims it, then runs a cure (case 4, 5, or 7)
then     the stop passes once the goal is closed or carries a cure
```
