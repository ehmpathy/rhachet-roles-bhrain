## .why the confidence is low — the axes are entirely my decomposition

**no seed named them, and no wisher verdict settled them.** the prior state was three partial,
disagreed registers (the root `readme.md#mascots`, `define.bhrain-repo-mascot`, and the owl's
palette), and the five axes are the shape i imposed to reconcile them.

`rule.require.enumerate-before-you-name` — written by me, this same round — demands the instance
list **before** the name. **the axes were named against the glyphs already in use**, which is the
right direction, and the set was never tested against a repo that uses glyphs differently.

## 🔴 .and the application went wrong once, under the wisher's eye

i classified 🌴🤙 with the `rung` ladder and the `halt` set as *"off-palette and correctly
claimed — a state or a tone, never a speaker."* the wisher rejected it:

> *"these are imported vibes; that differ from this repos vibes; why is that not clear?"*

they were right. 🌴 and 🤙 are both in the **seaturtle's** palette; a vibe IS voice, so an
off-palette vibe is an off-voice one by definition, where an off-palette **state** marker is
legitimate. **that distinction was absent from the axis file until the correction.**

⇒ so the five axes survived the correction and the **verdict rule inside one of them did not.**
that is evidence the decomposition is roughly right and under-specified, rather than wrong.

## .what would overturn the axis set

- a claimed glyph that fits **none** of the five → the set is incomplete
- two axes that never disagree on any glyph → they are one axis, and should merge
- the `vibe` walk above, if it settles on two senses → the axis wants a boundary-qualified name
