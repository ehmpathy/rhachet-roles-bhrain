# 🌙 dream: `getGitRepoRoot` must let a caller detect "not in a git repo" without a message match

- kind  = `reseed` — the fix belongs to `ehmpathy/rhachet-artifact-git`
- owner = `ehmpathy/rhachet-artifact-git`
- caught 2026-09-16

## .the cue that fired

`enroll-impl-arch-defects` flagged `getRepoRootWithFallback`'s not-in-git detection as a fragile
string match, and noted this feature grew its callers from two to eight.

## .the gap, precisely

```js
// node_modules/rhachet-artifact-git/dist/domain.operations/repo/getGitRepoRoot.js:21
if (!gitPath)
  throw new helpful_errors_1.BadRequestError('Not inside a Git repository', { input });
```

so a caller that must part *"not in a repo"* from *"the lookup broke"* matches the message:

```ts
// src/domain.operations/route/guard/getRepoRootWithFallback.ts
error instanceof Error && error.message.includes('Not inside a Git');
```

**`instanceof BadRequestError` is no remedy** — it is `helpful-errors`' generic 400 with no `code`,
so it would swallow every future 400 on this call. ⇒ the caller has no correct check; the message
match is the least wrong.

## .what is NOT the gap — measured

| the drift | what happens |
|---|---|
| upstream rewords its message | the predicate goes false and the error **rethrows**; `getRepoRootWithFallback.integration.test.ts [case2]` runs the real lookup from a non-git temp dir and goes red |
| a real fault swallowed as "not in git" | needs another error whose message carries `Not inside a Git`; line 21 is its only producer |

⇒ a maintenance hazard with a build-time clamp, never a live failhide.

## .the shape of the fix

in `ehmpathy/rhachet-artifact-git`, any one of:

1. a class — `NotInsideGitRepoError extends BadRequestError`, exported
2. a `code` on the metadata — `{ code: 'NOT_INSIDE_GIT_REPO', input }`
3. 🔴 **a non-throw read** — `getGitRepoRootOrNull({ from })`. an absent repo is not exceptional for a
   caller with a fallback, and all eight sites have one

⇒ prefer 3, with 2 as the compatible half-step. then replace the match here; keep `[case2]`.

## .why it is not done in this round

- **SAFE — no.** the throw lives in another repo
- **CLEAN — no.** a local `.git` probe is a second path beside a serviceable one
