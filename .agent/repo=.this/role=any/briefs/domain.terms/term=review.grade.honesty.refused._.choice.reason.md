# domain.term.choice.reason: refused

## .etymology

`rhx review` refuses a run it cannot send — `ConstraintError: prompt exceeds 75% of context
window` is the commonest — and the grade names what the run suffered. the word states the
cause of the nil, which is what makes the nil a fact: a refused call was never billed.

rejected:

| rejected | why |
|---|---|
| `skipped` | names a different, successful outcome: the `--optional rules` skip prints `0 blockers` / `0 nitpicks` and is a review that ran |
| `rejected` | already the verdict of a peer review that raised blockers (`route.guard.review`); one word over two concepts |
| `free` | names the price, never why. an `unknown` run may also have cost naught, and free would claim it |

## .the evidence

`getOneReviewRunGrade` parts `refused` from `unknown` on three witnesses: the prompt, the compiled
metrics, and the brain's answer. any one on disk means the call may have gone out, so the run is
`unknown`. only a run that left none of the three is `refused`.

## .the boundary

"refused, of WHAT?" — of a run's spend, by the honesty family. the review cli prints
`blocked by constraints` for the same event; that is stdout prose, not a grade.

## .disputes

none.
