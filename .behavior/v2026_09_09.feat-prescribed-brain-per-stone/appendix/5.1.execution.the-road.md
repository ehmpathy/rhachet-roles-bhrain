## 🔴 .the defect the dogfood caught, before a line of it was written

`getCloneWhoami` read `parsed.slug` alone. measured against this very clone, 2026-09-13:

```
$ rhx clone whoami --output json
{ "serial": "88412066-5baa-47e3-b321-ea1b09ab3bf4", "slug": null, "reachState": "LIVE" }
```

⇒ a **live, enrolled, reachable** clone reports `slug: null`. the slug-only read refused it, and the
switch would have silently never fired — the exact shape `F5` says is accepted for a *refused*
brain, arrived at here for a clone that was never even addressed.

the fix reads `slug ?? serial`, which is not a defensive fallback: `clone say` declares its address
as `@:<slug|serial>`, so **both halves were first-class in the contract all along** and the reader
had used only one.

🟡 the lesson is not *"add a fallback"*. it is that the applier was written against a **guess** at
the whoami shape, and one real invocation settled it. `rule.require.trust-but-verify`.

## 🔴 .the constraint the vision measured, and it shapes todo 2

every extant top-level guard key matches by **exact equality on a bare header**

```ts
if (trimmed === 'artifacts:') { currentKey = 'artifacts'; … continue; }
```

⇒ so `brain: opus` matches none of them — `trimmed` is `'brain: opus'`, never `'brain:'`.

⚠️ **a fifth literal in that list would parse `brain:` bare and silently drop its value** — the same
failhide shape `case=4` is about, arrived at from the other side.

| the extant shape | what `brain:` needs |
|---|---|
| a bare `key:` header, then `- ` items beneath it | 🔴 an **inline `key: value`** on one line |
| exact-equality match | a **prefix** match plus a value extract |

🟡 no top-level key carries an inline value today. inline `key: value` parses exist **only** nested
inside a `- ` peer-review item (`:258+`), so the shape is borrowed rather than invented.
