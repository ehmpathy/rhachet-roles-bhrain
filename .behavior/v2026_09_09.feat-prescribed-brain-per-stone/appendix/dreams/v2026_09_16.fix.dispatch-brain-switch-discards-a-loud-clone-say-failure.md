## .the gap, precisely

`dispatchBrainSwitch.ts`:

```ts
const child = spawn(
  input.rhx,
  ['clone', 'say', `@:${input.address}`, '--what', `/model ${input.brain}`],
  { cwd: input.repoRoot, detached: true, stdio: 'ignore' },   // ← the error goes to /dev/null
);
child.on('error', (error) => { … });                          // ← fires on SPAWN failure only
child.unref();
return { submitted: child.pid !== undefined };                // ← true the moment a pid exists
```

three facts compose into the defect:

- **`stdio: 'ignore'`** discards the child's stderr, where the `MalfunctionError` above is printed
- **`child.on('error')`** fires when the binary cannot be *launched*, never when it launches and exits 1
- **`submitted`** is `child.pid !== undefined`, so it is `true` for a say that failed a moment later

⇒ `setStoneBrain` then returns `{ outcome: 'requested' }` and the record prints
`⟨requested — unconfirmed⟩`. **the word `unconfirmed` is honest and it is not the same as `failed`,**
and a human reads the two identically.

🔴 **this is NOT the deferred brain-REJECTION arm.** that one needs a read of the brain's reply and has
no source (`clone get` returns `{ total: 0 }` on this host). this is a **transport** failure, reported
loudly by the very process we spawned, and thrown away.

## .the shape of the fix

do **not** await the child — that is `case=5`'s deadlock, and the fire-and-forget hand-off is what
carries the whole fix (`hazard.a-hook-cannot-say-into-its-own-clone`). two moves that keep it:

1. **capture rather than discard** — swap `stdio: 'ignore'` for an append-only fd on a per-route log
   (`$route/.log/brain.dispatch.log`), so a human who asks *"why did my switch never land?"* has the
   transport's own words plus its hint. one `fs.openSync`, one stdio array, no wait, no new await
2. **read the exit on the NEXT tick** — the child is long gone by the next `onStop`, so pair the entry
   marker with the captured tail: a marker whose log tail holds a `MalfunctionError` upgrades the
   render from `⟨requested — unconfirmed⟩` to a named halt cause with the transport's hint

⇒ **move 1 is small, safe, and clean** — it touches one file plus its integration test, changes no
contract, and cannot fire on a brainless stone (the dispatch is unreachable there, so `case=10`'s
*"pays naught"* is untouched). **move 2 is dirty** — it needs a timestamped, entry-keyed marker, so it
ripples into `DriveBlockerState`, its snapshot, and three suites, and it shares that ripple with
`.dream/v2026_09_15.fix.stone-brain-undispatched-overload-and-retry-backoff.md`.
