# 🌙 dream: a symlinked brief loses its `.md.min`, so `role=any` pays full price twice over

**kind**: fix · **owner**: this repo (`rhachet-roles-bhrain`) — `.agent/repo=.this/role=any/briefs/`
· **caught** 2026-08-31

## .the cue that fired

a density sweep asked *"which say-level briefs still lack a `.md.min`?"* — and `role=any` showed
five. two of those five **already have a min**, in the tree they are symlinked from.

## .the gap, precisely

boot prefers `$brief.md.min` over `$brief.md` when the sidecar sits beside the brief. a symlink
carries the `.md` and **not its sidecar**, so the preference silently falls back to full text:

| `role=any` brief | mode | points at | has a `.md.min` at the source? | what `role=any` boots |
|---|---|---|---|---|
| `im_an.obsessive_learner.md` | `120000` | `src/domain.roles/learner/briefs/` | ✅ yes | 🔴 **the full text** |
| `im_a.bhrain_owl.md` | `120000` | `src/domain.roles/driver/briefs/` | ❌ no | full text (correct) |
| `domain.terms/.readme.md` | `120000` | `repo=bhrain/role=learner/briefs/readme.domain-terms.md` | ❌ no | full text (correct) |
| `define.bhrain-repo-mascot.md` | `100644` | — real file | ❌ no | full text |
| `rule.forbid.cwd-outside-gitroot.md` | `100644` | — real file | ❌ no | full text |

⇒ **exactly one row is a live regression today** — and the mechanism behind it will fire again on
every future condense of a brief that is cross-listed.

## 🔴 .why it is worth more than one brief's tokens

`role=any` boots for **every role in this repo**. so a token there is charged once per role, per
boot — the highest multiplier in the tree.

🟡 **and the failure is silent in the worst way: the work was already done.** somebody condensed
`im_an.obsessive_learner.md`, and the tokens it saves reach the learner and no one else. a density
audit that counts `.md.min` files reports the brief as condensed — because it **is** — while the
boot that matters most still pays full price.

⇒ **a sidecar is part of the brief, and a symlink that carries only the `.md` is a partial copy.**

## .the shape of the fix

symlink the sidecar beside every symlinked brief that has one:

```sh
rhx symlink --at '.agent/repo=.this/role=any/briefs/im_an.obsessive_learner.md.min' \
            --to '../../../../src/domain.roles/learner/briefs/im_an.obsessive_learner.md.min' \
            --mode relative --idem findsert
```

**then guard it, or it recurs.** the invariant is mechanical: *for every symlinked `$brief.md` whose
target has a `$brief.md.min`, a symlinked sidecar must sit beside it.* that is a step, never a
judgment, so it is owed a tool rather than a habit
(`rule.always.entool-the-skills-you-touch`).

⇒ it belongs in the same parameterized boot-manifest case as
`v2026_08_13.entool.boot-manifest-guard.md`, which walks each role's `briefs/` already.

## 🟡 .why it is not fixed in this round

**a min does not merely shrink a brief — it REPLACES the text boot emits.**
`domainTermsBootReachability.integration.test.ts` asserts on `role=any` boot stdout. its assertions
are `toContain`, which makes *additive* briefs safe — and a **swap** is not additive. any assertion
that quotes a line present only in the full text would break.

so the repair needs an integration run, and it landed mid-release with the tree already verified
green. **a change that flips boot output is not a change to slip in beside a ship**
(`rule.always.fix-forward-under-scouts-honor`: safe **and** clean, or catch it).

## .the fulcrum

> **a sidecar is part of the brief. a symlink that carries only the `.md` is a partial copy, and it
> reads as a complete one.**
> rework: **clean** — two symlinks plus one guard case; no artifact hardens against its absence.
