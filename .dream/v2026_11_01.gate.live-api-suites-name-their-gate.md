## .the cue that fired

on PR #742, `stepReview.caseBrain.claude-sonnet.integration.test.ts` went red in CI with `400 "Your credit balance is too low to access the Anthropic API"`. no funded key exists for tests, so the shard reads as a defect on every PR, whatever the PR touched.

## .the gap, precisely

the suite calls the live Anthropic api and has no gate: no declared condition under which it runs, and no named place a reader learns why it is red.

## .the shape of the fix

- each live-api suite declares its provider and the key it needs in one place the CI matrix reads
- the matrix runs a provider's suites only where that provider is funded, and reports the unfunded ones as `unfunded`, not as a failure
- never a silent skip inside the test (`rule.forbid.failhide`): the gate lives in the matrix, named in the job title

## .what landed
