# reason: with-bottleneck@0.1.2

## package
- name: with-bottleneck
- version: 0.1.2
- type: prod

## reason
the grouped concurrent walk for peer reviews needs a per-group concurrency bound. with-bottleneck is the org's paved primitive for exactly this: genBottleneck({concurrency}).schedule(fn) releases its slot even on error (which acceptance case 5 requires — a failed co-member must not strand a slot), and its semaphore.active/.queued counters are what the aggregate tail status line reads for 'N inflight, M left'. hand-rolling would mean writing both the semaphore and the counters.
