# S14 · teach via demos — and the 👍 half must itself be dense

## .said

verbatim, 2026-09-04, mid-drive at `1.vision`:

> ok, so can we add some demonstrations of good vs bad ? that way we can teach via demos ?

then, on the first pair I wrote:

> these can be improved; […] that good example should be DENSER. there is still way too much noise.

## .settled

**a rule teaches by demonstration, never by assertion alone.** each rule carries a paired 👎 bad /
👍 good render of the same content, so a reader sees the repair rather than reads about it.

⇒ the convention is **paved, not coined**: every ehmpathy `lang.prose/` rule already carries
`### 👎 bad` / `### 👍 good`, and `rules101.content` specifies the shape.

### the second utterance is the sharper half

**a 👍 example is held to the standard it demonstrates.** a "good" render that is merely *less bad*
teaches the wrong target — the reader calibrates on what they are shown, so a noisy 👍 sets a noisy
bar.

⇒ **the repair for the 👍 half was to bulletize it**, which is how S15 arrived: the demand for a
denser positive example surfaced that no rule governed passage shape.
