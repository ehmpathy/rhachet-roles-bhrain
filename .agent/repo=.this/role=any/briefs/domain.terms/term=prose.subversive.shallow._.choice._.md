# domain.term: shallow

term.chosen   = shallow
term.kind     = adj
term.boundary = prose.subversive
term.synonyms.forbidden:
- empty
- vacuous
- filler
- fluff

## .what
`shallow` is **subversive prose with no substance beneath it** — the sentence asserts no position at
all, so there is naught for an observation to settle.

> **the repair is a CUT.** there is no mechanism under it to promote, because the sentence never
> stood in front of one.

## .the demo

| 👎 shallow | 👍 the settleable form |
|---|---|
| *"the review flow has some issues worth a look"* | *"the guard tallies `0/0` on a skip, so a skip and a clean pass are indistinguishable to it"* |
| *"the right approach depends on context"* | *"prose-only scope, because `--diffs since-main` pulls `src/` in"* |
| *"this should probably mostly work in most cases"* | *"70%. one read of `getExitCodeClass.ts` settles it"* |

## .the shapes that sort here

hedge stack · truism · absolution · pre-emptive concession · self-issued verdict · read-order
directive — enumerated in `rule.forbid.subversive-prose`'s table, which owns the sort.

🟡 **three of them repair to a bare deletion**, never a rewrite: absolution, pre-emptive concession,
read-order directive. that is the tell the shape carried no information at all.

## .why each synonym is forbidden

| word | why not |
|---|---|
| `empty` · `vacuous` | each reads as *"few words"*, and a shallow passage is often long. depth is the axis, never volume |
| `filler` · `fluff` | each names a **role in a document** — a passage put there to occupy space. shallow prose is frequently written in earnest |

## 🟡 .shallow is the SAFER of the two shapes

a reviewer cuts it on sight, because it reads as filler and defends itself poorly. its peer
`squishy` reads as **insight**, so the author feels lucid and the reader nods.

⇒ so a canon that catches only this half catches the cheap instance and ships the expensive one.
