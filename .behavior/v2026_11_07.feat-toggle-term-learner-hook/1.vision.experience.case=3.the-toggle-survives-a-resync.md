# case=3 — the toggle survives a re-sync

feel × care: happy × critipath · actor: human, then a clone · density 5 (cli · settings file · git ·
rhachet hook sync + derive · Claude Code Stop) · ⇒ inventory rows `enable · off · present · split ·
init --hooks → stale stop` and the peer-actor rows

## .narrative

kai enabled the toggle on monday (case=1) and committed it. on tuesday a teammate bumps
rhachet-roles-bhrain and runs `rhx init --hooks`. rhachet re-syncs every role's hooks: for the
`repo=bhrain/role=learner` author it deletes every entry the role does not declare, and it prunes
`repo=…/role=…` authors no linked role holds. then it derives each enrolled clone's settings from
the repo actor's file, and keeps a hook only where the author's `role=` segment names a role that
clone holds.

an entry under the learner's own author would die at the first step. a bare toggle author would
survive the first two and die at the third, so no enrolled clone would see it. the toggle's entry,
`toggle=learn.terms.hook/role=learner`, passes all three: it is outside `repo=`, and its role is
the learner.

on wednesday kai enrolls a clone with `--roles learner,driver`. it works two hours, then reaches a
stop. its distillation is stale, so the hook holds the stop and prints the distill guide, the same
nudge the withdrawn hook printed, from the same `learn.domain.terms --when hook.onStop` face. a
second clone, enrolled with `--roles driver` alone, is not nudged: it does not hold the learner,
just as it would not have under the withdrawn hook.

## .[tn] sketch

```
given('[case3] a split-layout repo where `learn.terms.hook enable` ran')
  when('[t0] `rhx init --hooks` runs (rhachet re-syncs role hooks and prunes orphans)')
    then('the term hook entry is still in the repo actor settings, byte-identical')
    then('`rhx learn.terms.hook get` still reports enabled')
  when('[t1] a clone is enrolled with the learner among its roles')
    then('its derived settings.of.repo.json holds the term hook entry')
  when('[t2] a clone is enrolled without the learner')
    then('its derived settings.of.repo.json holds no term hook entry')
  when('[t3] a learner session reaches a stop with a progress file older than one hour')
    then('the hook exits 2 and the stop is held with the distill nudge on stderr')
  when('[t4] the clone articulates today\'s progress file and stops again')
    then('the hook exits 0 and the session rests')
```

🟡 the clamps that matter most: revert the author to `repo=bhrain/role=learner` and t0 turns red;
revert it to a bare `toggle=learn.terms.hook` and t1 turns red.
