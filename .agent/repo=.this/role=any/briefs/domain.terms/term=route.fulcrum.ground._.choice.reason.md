# domain.term.choice.reason: ground

## .etymology

a dispute is argued **on grounds**, as an appeal is. the word names the kind of argument, which is
the one fact that decides who may settle it.

| word | what it loses |
|---|---|
| `basis` | it names the evidence, not the kind of argument it supports |
| `reason-kind` | coined, and it collides with the `.reason` file in every term cluster |

the two values carry their own weight: `wrong` is a claim about the reviewer's read, so a sure one
can be reflected upstream as a reviewer defect; `dirty` is a claim about cost, so it can only be
weighed.

## .evidence

the wish's two dispute shapes (#747 `.what`): a reviewer misread, and a fix not worth its cost. the
vision named them `wrong` and `dirty` (D4), and the wisher ruled the dirty row (S01).
