## .the cue that fired
a peer reviewer (bhrain route `fix-status-line-binds-own-actor`, 5.1 i004 r11) read the split layout
rhachet 1.49.2 lays out: `.claude/settings.of.grove.json` is a link to `/home/camper/.claude/settings.json`,
and the brain dir's own `.gitignore` re-includes it.

## .the gap, precisely
`.agent/.actors/actor.via.repo=ambient/brain/.claude/.gitignore`, as rhachet writes it:

```
/*
!/settings.json
!/settings.of.repo.json
!/settings.of.grove.json
```

`settings.of.grove.json` is an absolute link into the committer's home. committed, it dangles on
every other box (ci included), and each developer's next layout pass rewrites it to their own
home, so the diff churns per machine. `settings.json` is a relative link to the grove arrow, so it
is harmless alone; the grove arrow is the host-local byte.

## .the shape of the fix
- drop `!/settings.of.grove.json` from the generated `.gitignore`, so the host arrow stays local;
  the layout findsert already recreates it on each box
- keep `settings.json` (relative) and `settings.of.repo.json` (the real file) whitelisted
- note it in the layout's own output, so a repo that already committed the arrow learns to `git rm --cached` it

## .why it is not done in this round
the file is rhachet's to write; an edit here is reverted at the next layout pass. and no commit
has yet been asked of this route, so naught has shipped the arrow.
