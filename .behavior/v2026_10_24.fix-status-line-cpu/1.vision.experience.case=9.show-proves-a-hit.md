# case=9 — the show instrument proves a hit (happy · critipath)

## .narrative

a verifier must prove that a repaint with no change did no fresh work. they run
`rhx route.status.line.show --drop`: one real repaint, the exact command a seat's settings name,
with the cache dropped first. its tree reads `cache = miss`, its cpu, and the line. they run
`rhx route.status.line.show` again: `cache = hit`, the same line, a fraction of the cpu. the
verdict comes from whether the cache file was rewritten, never from the cpu figure, so a slow box
cannot pass a miss off as a hit. `--via legacy` repeats the walk through the old `cli/route`
export, and `--unbound` through a seat with no route bound.

## .bdd sketch

```
given('[case9] a seat whose cache was dropped')
  when('[t0] the instrument repaints once')
    then('it reads as a miss, and prints the line the seat shows')
  when('[t1] the instrument repaints again, with no change')
    then('it reads as a hit, and prints the same line')
  when('[t2] an arg rides through to the status line itself')
    then('it reads as untouched, never as a hit')
```
