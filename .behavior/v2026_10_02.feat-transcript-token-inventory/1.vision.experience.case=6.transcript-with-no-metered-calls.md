# case=6 — a transcript with no metered calls (sharp)

cell: path · one · unmetered · feel = sharp · care = critipath · boundaries = 3

## .narrative

`~/.claude/projects` holds test-fixture transcripts — measured on this machine, some are 252 bytes
(`abc123-def456.jsonl` under a `-tmp-test-fns-…` slug). a session can also crash at boot before
its first call. either way, no assistant record carries `usage`.

a human points the tool at one. a report of all zeros would read as *"this session was free"* —
a lie. so the tool refuses, exit 2, and says what it found instead.

## .the fail-safe render

```
🦉 the pond is still; naught to reflect

🌕 reflect.tokens
   └─ ✋ ConstraintError: no metered calls in this transcript
      ├─ from = ~/.claude/projects/-tmp-test-fns-…/abc123-def456.jsonl
      ├─ records = 3 (0 assistant records with message.usage)
      ├─ hint: a test fixture, or a session that ended before its first call
      ├─ fix: point --from at a transcript that made at least one call
      │  └─ rhx reflect.tokens --from <path-to-another.jsonl>
      └─ or: audit the whole project dir — unmetered files are skipped and counted
         └─ rhx reflect.tokens --from '~/.claude/projects/<slug>/*.jsonl'
```

## .timeline

  when('[t0] the human runs `rhx reflect.tokens --from <glob>`', () => {

  });
