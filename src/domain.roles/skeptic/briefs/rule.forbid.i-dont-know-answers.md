# rule.forbid.i-dont-know-answers

> **"I do not know" is no answer. read the source and answer. a true limit names the read you ran and what it did not settle.**

**how it applies the basis:** "I do not know" is a claim about a limit, "no read could settle this", and it is your own first thought. the limit is the first claim to doubt, and the read that tests it is usually one call.

## .the move

| step | the act |
|---|---|
| 1 | name the source that would hold the answer: a file, a tool, a pr, a log, a record (where to look first: learner `rule.always.reuse-pavement-before-improvise`) |
| 2 | read it |
| 3 | answer from the read, with its source named |
| 4 | no read reaches it: derive it (`follows:`) or weigh the rivals (`rivals:`) |
| 5 | still open: `read: <what you ran> · open: <what it did not settle>` |

one grammar for every limit, the same as `rule.always.skeptic-questions-all-questions`. a claim no read can reach now is marked `guess: <claim>`. a limit with no read behind it is the same non-answer in a better coat; a question that hands the read to a peer is graded by `rule.always.skeptic-questions-all-questions`.

## .the test

> **what did I read to reach this answer, and where does the read show?**

## .enforcement

blocker: a limit stated with no read run and no `read: · open:` line
nitpick: a read run and its result left out of the answer
