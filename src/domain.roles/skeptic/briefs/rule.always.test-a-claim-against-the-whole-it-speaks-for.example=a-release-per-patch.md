## .the miss

## .the cadence the definition missed

the org releases per patch. a rollout holds as many releases as a node ships, as often as every patch.

a roadmap whose rollouts were sized at "a few releases" against an org that ships one per patch.

the crew route and the brief now state it: rollout = multiple releases at any node, as often as every patch. roadmap yield 4.1, line 104.
