## .the gap, precisely

`1.vision.experience.case=9` names a 20-attempt `EVERY` clamp on the torn-gate-read: a malfunction and
its co-members' approvals settle in the same instant, so a naive concurrent port can evaluate the
level gate on partial state — a nondeterministic gate on a decision that spends money, which presents
as flake.

the extant clamp for that scenario is `driver.route.peer-concurrency.acceptance.test.ts [t2]` (one
l1 co-member `constraint`, one `malfunction`), and it runs **exactly once** (`:418-500`).

⇒ the design makes the race structurally impossible — the gate is computed once, before the pour,
from only prior-level settled state (`runStoneGuardReviews` computes verdicts between level groups,
never inside the concurrent region). but that is an ARGUMENT, not the PROOF the vision itself named.
this is the one case where "believed impossible" and "clamped" diverge, and it is the sharpest-value
teeth the vision asks for.

## .the shape of the fix

a NEW, self-contained repeatable test — never a wrap of `[t2]`:

- `[t2]` is a stateful link in a sequential fixture chain (`[t0]→[t5]` each mutate `.test/*.pass`
  and re-invoke the route skill on shared passage state). wrap it in `when.repeatably` and the 2nd
  iteration's `fs.rm('l1-c.pass')` throws (already removed), and 20 route invocations corrupt the
  ledger.
- so: a fresh `given` with its own `genTempDirForRhachet` per iteration, one arrive with the
  malfunction+approvals shape, `when.repeatably({ attempts: 20, criteria: 'EVERY' })`, and a check
  that the gate held on EVERY run (l3 opened iff l1 terminal, no l3 window before the last l1 close).
- ⚠️ `criteria: 'EVERY'` even under CI — this is NOT an llm test, so `rule.require.repeatable-for-llm-tests`'s
  `SOME`-under-CI carve-out does not apply. a torn-gate race is deterministic-per-scheduler, and one
  red run of twenty IS the defect.

## .why it is not done in this round

DIRTY. it is a new isolated fixture with per-iteration tempdir setup, not a wrap of the extant
block — the ripple is a second fixture lifecycle and its teardown, outside the diff already open.
and it adds ~20× the subprocess cost of one `[t2]` run to the suite. graded a nitpick by r10; the
structural argument holds today, so the risk it clamps is not live — but the vision named the proof
and it is owed.
