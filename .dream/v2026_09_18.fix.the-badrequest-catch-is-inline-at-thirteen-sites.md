## .the gap, precisely — measured, not estimated

the reviewer said *"~17 sites"*. the true shape is **two shapes, 14 sites**, and the split matters
for the fix:

| the shape | count | lines |
|---|---|---|
| the full block — `console.error(\`error: ${error.message}\`)` then `process.exit(2)` | **13** | `651`, `781`, `813`, `843`, `873`, `940`, `1115`, `1161`, `1219`, `1271`, `1986`, `2682`, `2765` |
| a **bare** variant — `if (error instanceof BadRequestError) process.exit(2);`, no emit | **1** | `725` |

verified by two greps over `src/contract/cli/route.ts`:

```
instanceof BadRequestError                      → 14 hits
console.error(`error: ${error.message}`)        → 13 hits
```

🔴 **the bare variant at `:725` is the part a reader would miss, and it is the part that makes the
hoist a judgment rather than a sweep.** it exits `2` and prints naught, so a caller sees a non-zero
code with no diagnosis — which reads as a deliberate silence at a status-line call site, or as an
omission. **a hoist must decide which**, and the answer is not derivable from the line alone.

🟡 the two newest sites — `:2682` and `:2765` — are this stone's own orchestrators
(`routeGuardBudget`'s refusal path, and `routeMutateGrant`'s). ⇒ **the stone conforms to the pattern
rather than introduces it**, which is what put the item out of scope.

## .the shape of the fix

`rule.require.hook-wrapper-pattern` gives the form directly — the handler stays clean, and the
wrapper is one line at the export:

```ts
const _routeGuardBudget = async (): Promise<void> => {
  // … the body, with no catch at all
};

export const routeGuardBudget = withRouteCliBadRequestExit(_routeGuardBudget);
```

and the wrapper itself:

```ts
const withRouteCliBadRequestExit =
  <A extends unknown[]>(fn: (...args: A) => Promise<void>) =>
  async (...args: A): Promise<void> => {
    try {
      return await fn(...args);
    } catch (error) {
      if (error instanceof BadRequestError) {
        console.error(`error: ${error.message}`);
        process.exit(2);
      }
      throw error;
    }
  };
```

**three calls it must make, and none is mechanical:**

1. 🔴 **the `:725` variant.** either it gains the emit (a behavior change — a silent exit becomes a
   spoken one) or the wrapper takes a `{ quiet: true }` option. **prefer the first**, and clamp it:
   `rule.require.errors-name-the-fix` says a bare non-zero code with no diagnosis is the defect, so
   the silence is likelier a gap than a design
2. **the stderr contract holds either way** — `rule.forbid.stdout-on-exit-errors` is satisfied by
   `console.error`, and the hoist must not drift it to `console.log`
3. **the exit code stays `2`** — a `BadRequestError` is caller-must-fix
   (`rule.require.exit-code-semantics`), so the hoist may not flatten it toward `1`

🟡 **and the wrapper owes a name that is not a gerund.** the reviewer's proposed name carries an
`-ing` noun, which `rule.forbid.gerunds` forbids in this repo. `withRouteCliBadRequestExit` above is
one candidate; the point is that the name is a real choice, not a transcription.

## .why it is not done in this round

the two questions of `rule.always.fix-forward-under-scouts-honor`, answered plainly:

| | answer |
|---|---|
| **SAFE?** | 🔴 **no.** the `:725` variant's silence is undocumented, so a hoist either changes behavior at a site this diff never opened, or carries an option that exists only to preserve a silence nobody can defend |
| **CLEAN?** | 🔴 **no.** 11 of the 13 sites sit in orchestrators this behavior never touched. the diff would reach from `:651` to `:2765` — nearly the whole file — to repair a pattern this stone inherited |

⇒ **defer.** it fails both questions, so a dream is the correct outcome and no fulcrum is owed — the
deferral turns on size and blast radius, never on a judgment the drive reserved.

🟡 **the same CLEAN test already governed a peer call on this stone**: `getGuardStoneNames.ts`'s
neighbours were left alone for the identical reason, and that precedent is cited in its own file.
this dream is that argument applied a second time, to a wider pattern.

## .the honest bound

this is a **readability** repair, not a defect repair. all 14 sites behave correctly today; what they
cost is 52 lines of identical prose and one silent divergence at `:725` that only a careful reader
finds. ⇒ it is the kind of item that should ride along with the **next** change that already opens
`route.ts` broadly, rather than justify a diff of its own.
