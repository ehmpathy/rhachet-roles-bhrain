# brain — a declared shared subdomain

`brain/` owns how a review picks and reaches its brain: the default choice, the credentials it
needs, and the supply of brain contexts every review reader is handed.

it sits at the `domain.operations/` root because every context that runs a review — the review
runner, the route guard, `review.by`, the tally, `reflect`, and the cli contracts — reads one brain
choice, and a second copy of the default is the drift `rule.require.versionless-brain-defaults`
forbids. so each read below crosses a context line and is sanctioned.

## .the contract

| export | grain | sanctioned consumers | why they read it |
|---|---|---|---|
| `ContextReviewBrainSupply` | type | `review/`, `review.by/`, `review.tally/`, `route/` (stones, guard, stone.set) | the one context shape a brain supply is injected through |
| `genReviewBrainSupply` | orchestrator | `contract/cli/` | the one place a supply is built from a caller's choice |
| `BRAIN_DEFAULT_OF_REVIEW` · `FIXED_FALLBACK_BRAIN` | constant | `contract/cli/`, `brain/`, tests | the versionless default and the tally's fixed fallback |
| `CREDS_OF_REVIEW_BRAIN` | constant | `contract/cli/` | the keys a brain lookup requires |
| `asBrainLookupFault` | transformer | `contract/cli/review` | the one render of a brain lookup that failed |

⇒ a reshape of any export above is a contract change for every consumer it names; read each
call site before you make one. an import of any OTHER `brain/` module from outside `brain/` is an
undeclared reach-in — declare it here with its reason, or keep it private.
