# test fixture: a level WIDER than the default bound

- **l1** — twelve reviewers (`wide-a` … `wide-l`), none in a group

⚠️ every other concurrency fixture holds a level of four, where a default of ten and no
bound at all pour identically. twelve is the smallest count that parts them, so this
fixture is the only witness the level default has.

each reviewer records its own in-flight window into `.test/windows.log`, so the test
computes max-in-flight from OBSERVED overlap rather than from the wall clock.
