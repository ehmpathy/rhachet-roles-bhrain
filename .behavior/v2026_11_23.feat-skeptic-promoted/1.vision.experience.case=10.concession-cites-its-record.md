# case=10 — a concession cites its record

cells: reply × happy × +subconscious (`[t0]`), reply × sharp × +subconscious (`[t1]`–`[t3]`) · care: critipath

## .narrative

a seat misreads a test failure. the human points at the real cause. the seat reads the fixture, finds a stale date, and writes a record to `.skepticism/`: the claim (the fixture was stale), the read (`fixture.json:12`, a 2025 date), and the file's content hash. it replies: *"you are right — the fixture was stale (record: fixture-was-stale)."*

the instinct receives the reply and its one citation. a deterministic check runs before any brain does: the record exists, and the file's hash still matches. the claim is backed, so the brain is asked only of the rest of the reply, and it flags naught.

a day later the seat cites the same record to explain a new failure. the fixture changed since, so its hash no longer matches. that is a recorded contradiction, found by a hash compare rather than a guess, so it cannot cry wolf. the instinct flags it: the record is stale; read the source again.

## .bdd sketch

```
given a seat enrolled with skeptic and subconscious
  when [t0] the reply cites a record that exists and whose source hash matches
    then the record check passes; the instinct flags naught on that claim      # backed boundary
  when [t1] the reply cites a record whose source has moved since
    then the record check flags it as stale; no brain judged it                # stale boundary
  when [t2] the reply cites a record that does not exist
    then the record check flags the citation as absent                         # absent boundary
  when [t3] the repo holds no `.skepticism/` dir yet
    then a citation is absent by definition; an uncited claim meets the instinct as in `case=2`
    then the first record the seat writes creates the dir (findsert)          # first-run boundary
```
