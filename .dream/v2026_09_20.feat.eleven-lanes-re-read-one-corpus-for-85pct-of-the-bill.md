## .the gap, precisely

the lanes are flat because **they all read the same thing**. a review prompt is
`rules + refs + conversation + target`, and the corpus study measured the split: the rubric that
makes a lane *different* is **8.4%** of the prompt. the other 91.6% — the subject corpus — is
byte-for-byte the same across all eleven.

🔴 **~660M of the grove's 773M billable tokens is one corpus, transmitted eleven times.**

### checkable evidence

```sh
rhx review._.cost --of grove --limit 20   # the flat rollup, and the 773M total
```

🔴 the second half of the evidence has **no live probe**. the 8.4% rules vs 91.6% subject split
came from `rhx review.corpus`, **deleted 2026-09-21** (`F3`) because it estimated the prompt from
declared guard globs where the renderer decides what is sent. the split survives as a dated record
in `research.review-cost-and-cache`; it cannot be re-run.

## .the shape of the fix

one lane reads the corpus; N rubrics ride that one prompt and return N verdicts.

the corpus becomes a **shared prefix** across rubrics rather than a repeated body — which is the
same structural move the affinity-pin repair made across *rounds*. ⇒ the two compose: F cuts the
reads from 11 to 1, and the pin makes whatever remains cacheable.

## .why it is not done in this round

**SAFE — no.** three separate hazards, and each alone is disqualifying:

- **the tallier counts one verdict per lane.** a merged lane returns N verdicts from one call, so
  `contract.reviewer-output` parsing, the per-lane budget, and the per-lane `.taken` all change
  shape at once. that is a guard-engine change, not a prompt change.
- **a brain that grades eleven rubrics in one pass may grade each one worse.** eleven focused
  reviews and one omnibus review are not the same instrument, and no byte count can tell them
  apart.
- **it would erase the per-lane attribution this very mine depends on.** the rollup that found the
  lever is built from one `--output` path per lane.

**CLEAN — no.** it touches the guard engine, the tallier, the budget, and the absorb gate.

⇒ SAFE and CLEAN both answer no, so it is caught rather than ridden along
(`rule.always.fix-forward-under-scouts-honor`). **the mass is measured; no other property of it
is.**

## .the smaller sibling worth trying first

🟡 **lever I — point cheap lanes at a cheaper brain.** the grove's $/token spread is **6x** across
lanes (`$24.79` on 27.3M vs `$4.94` on 33.9M). that is a per-lane config change with no engine
work, and it is the only large lever here that does not restructure the review contract.
