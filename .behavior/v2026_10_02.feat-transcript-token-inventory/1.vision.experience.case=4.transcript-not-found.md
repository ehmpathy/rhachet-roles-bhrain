# case=4 — transcript not found (sharp)

cell: path or uuid · none · feel = sharp · care = critipath · boundaries = 1, loud

## .narrative

the foreman pastes a session uuid from a dispatch: `rhx reflect.tokens --from 8f278020-…`.
they only know about `~/.claude/projects`. the session ran under an actor brain, whose
transcripts live under `$CLAUDE_CONFIG_DIR` — but that var is unset in the foreman's shell.

the tool fails fast, exit 2, and names every root it searched, so the foreman sees at once that
the clone's root was not among them, and how to reach it.

## .the fail-safe render

```
🦉 the pond is still; naught to reflect

🌕 reflect.tokens
   └─ ✋ ConstraintError: no transcript matched
      ├─ from = 8f278020-ef87-4df2-a7c4-344d83f56cca
      ├─ searched
      │  ├─ $CLAUDE_CONFIG_DIR/projects  (unset)
      │  └─ ~/.claude/projects/*/8f278020-….jsonl  (0 matches)
      ├─ fix: pass the full path
      │  └─ rhx reflect.tokens --from <path/to/8f278020-….jsonl>
      └─ or: set CLAUDE_CONFIG_DIR to the clone's brain dir
```
