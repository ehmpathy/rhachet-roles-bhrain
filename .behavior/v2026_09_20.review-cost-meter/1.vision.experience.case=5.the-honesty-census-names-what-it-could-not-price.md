# case=5 — the honesty census names what it could not price

- cell = `grove` × `cost` × `defend`
- path = **critipath** · feel = sharp · care = criti

## .the narrative

`case=2` is this defect at one tree's scale, where a driver might notice. at **grove**
scale nobody can: 3,663 runs across 19 trees, and no human reads them one at a time.

so the grove report owes a **census of its own honesty** — stated up front, beside the
total, never in a footnote:

```
├─ runs: 3,663
│  ├─ metered:  3,401
│  ├─ refused:      6
│  └─ unknown:    256   ⚠️ excluded from every figure below
```

the census is a **ratio a reader can act on**. `256 / 3663` is 7% — the total is credible.
`1800 / 3663` would be 49%, and the right response is to fix the logger before any lever is
argued from the number.

## .why this cell is `defend` and not `observe`

the reader is not here to learn the bill. they are here to learn **whether the bill can be
believed**, before they spend a round on a lever chosen from it.

an instrument that answers only `observe` prints a confident figure over a corrupt
corpus. the census is what converts *"here is the number"* into *"here is the number, and
here is exactly how much of the corpus it covers."*

it is the same claim `rule.require.distinguish-every-review-input` makes one layer
down, at the prompt rather than the grove: **a measurement that cannot state its own
coverage is not a measurement.**

## .the bdd sketch

```
given [case5] a grove whose runs grade into all three honesty buckets
  when [t0] the grove report is built
    then every run is graded exactly once — the three buckets sum to the run count
    then only `metered` runs enter the token and cost sums
  when [t1] the report is rendered
    then the three counts are printed in the header, above the totals
    then a nonzero `unknown` count carries a warn that the totals under-report
  when [t2] `unknown` is zero
    then the bucket still renders (as 0) — a reader must not have to infer its absence
  when [t3] EVERY run is unknown
    then no cost figure is printed at all — an absent measurement renders absent
```

## .what it depends on

- `asAccountedCost` — the three-way grade, reused verbatim from the per-tree meter
- `genReviewGroveStdout` — the census block, snapshotted

## .why it is a critipath

it is the grove's version of the wish's core claim. the instrument's value is not the
number it prints; it is that **a reader can tell how much of the corpus the number covers.**
without the census, `review._.cost --of grove` is a confident guess with a treestruct around it.
