# domain.term.choice.reason: artifact.trait

## .etymology
old french `trait` — *a stroke, a line drawn* — from latin `tractus`, *drawn out*.

⇒ the physical sense carries the claim exactly: **a trait is a line that runs through every mark the
hand makes.** it is not one mark; it is the character every mark inherits. that generality is what
parts it from a rule, which fires on one case.

⇒ **it is adopted, never coined.** the word already names this in ordinary english and in this
repo's own prior art — `trait.ocd`, `trait.chillnature`, and the thinker's
`trait.vs_skill.[article]`. what the cluster settles is that it names an artifact kind, and
therefore an `en-` verb.

## .why not each forbidden synonym

| rejected | why |
|---|---|
| habit | names a behavior acquired by repetition, and says naught about whether it was declared. a trait here is a file a role boots on turn one, with no repetitions behind it |
| instinct | names what is innate — untaught by construction. every trait here is authored, which is the opposite claim |
| disposition | the closest, and it names a tendency rather than an artifact. you cannot boot a disposition; you boot the file that confers one |
| default | names the value, never the artifact that supplies it. `trait.bulletize-reflexively` is the file; *"reach for a `-` first"* is the default it sets |
| persona | a voice, and telepath's seam assigns voice to the adopter (`rule.require.generic-governs-structure-never-voice`). `im_a.bhrain_owl` is a persona; `trait.bulletize-reflexively` is not |

🟡 **`disposition` and `default` are the two a careful reader will still reach for**, and both fail
on the same test: they name what the reader ends up with, where `trait` names what was written down.
an artifact kind must name the artifact.

## .the boundary against `skill` — already settled, in another register

`trait.vs_skill.[article]` (thinker) draws it in the human-psychology register, and every row
carries over to artifacts unchanged:

| axis | a trait | a skill |
|---|---|---|
| scope | broad — colors many domains | narrow — tied to one |
| evaluation | patterns over time | performance on a task |
| relation | sets the **posture** | executes **within** it |

⇒ **so no argument was owed here.** the settlement is a reuse
(`rule.always.reuse-pavement-before-improvise`), and the one fact it adds is that the same boundary
holds when both sides are files rather than people.

## .the consequence — a third kind the entoolment ladder omits

`philosophy.entoolment-is-the-pinnacle.concepts-vs-capacity` states a two-way split: a brief confers
`concepts`, a skill confers `capacity`. that split is correct and it is incomplete — a trait confers
neither.

🟡 **the easy misread is that a trait is rung 5**, because its imagine cost per use is zero. that
read fails on direction — and the direction table is declared in `catalog.of=externalization._`
under `.entrait moves the OTHER WAY`, not restated here.

⇒ what this cluster adds: an artifact you never touch again cannot sit on a scale whose unit is
*cost per touch*, so the amendment owed to `concepts-vs-capacity` is a third row, never a sixth
rung.

## .the gap this settlement makes visible

`im_a.bhrain_owl` and `im_an.obsessive_learner` are traits by every test above — declared, general,
booted, obeyed without recall — and neither carries the `trait.` prefix.

| the filename | what it declares |
|---|---|
| `trait.ocd` · `trait.chillnature` · `trait.bulletize-reflexively` | the prefix declares the kind |
| `im_a.bhrain_owl` · `im_an.obsessive_learner` | a **first-person** form that declares no kind at all |

🟡 **a sweep is forbidden and is not proposed.** `im_a.*` is cited across roles, and
`rule.forbid.domain-term-synonyms` permits an extant form to be left in place until disturbed. the
gap is named so the next author does not coin a third shape.

## .invariants
- **declared** — an undeclared tendency is temperament, and no artifact
- **no recall** — one you must fetch is a rule under the wrong prefix
- **a default, never a verdict** — it does not grade, so it carries no enforcement line
- **not a persona** — one that prescribes voice is, and telepath's seam bars it from a generic role
