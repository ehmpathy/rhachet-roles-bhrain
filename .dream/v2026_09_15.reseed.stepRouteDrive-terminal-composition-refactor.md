# 🌙 dream: collapse stepRouteDrive's return sites into one terminal composition

**kind** = reseed · **owner** = `ehmpathy/rhachet-roles-bhrain` · **caught** 2026-09-15

## .the cue that fired

an L3 architecture review (`enroll-impl-arch-defects`) of
`.behavior/v2026_09_09.feat-prescribed-brain-per-stone`, which framed it as *"a decomposition
opportunity for a follow-on wish … the current form is correct, just structurally fragile to the
next contributor."*

## .the gap, precisely

`stepRouteDrive.ts` (847 lines) builds `emit: { stdout }` at 20 sites. most compose through
`asRendered` / `asBooted` / `asStopped` / `asDriven`; the hard-stop gate's `composeHaltStdout`
composes on its own, because it fires before `stone` is known.

**no type or control-flow shape stops a 21st site from a raw, uncomposed `stdout`.** the invariant
*"every stdout passed through the brain + advisory composition"* holds by convention. that is why the
bypass class recurred across review rounds, each fix one more patched return site.

evidence: grep `emit: {` in `stepRouteDrive.ts`.

## .the shape of the fix

- each branch computes a variant `{ body; kind: 'halt' | 'work'; stderr? }` and falls through
- one terminal `composeStoneBrainRender` + `return` builds the `emit`
- look up `stone` before the gate, so the gate joins the same path
- **the clamp:** branches return the variant type, and only the terminal site can build `emit`

⇒ the invariant moves from convention to construction.

## .why it is not done in this round

- **SAFE — no.** it restructures the orchestrator every route runs on every hook tick. the gate's
  early exit before the `stone` lookup is required: a malfunction must escalate at once, and
  snapshots plus exit-code semantics depend on that order
- **CLEAN — no.** 20 return sites and the gate, and a large share of the drive snapshots re-baselined

⇒ caught as a `reseed`: a refactor of a correct, shipped orchestrator, worth its own behavior.
