## .the cue that fired

a hand run of the dispatch from inside an enrolled drive:

```
$ rhx clone say @:afb89825-ece3-48e4-b4f4-db0bd174d90d --what '/model definitely-not-a-real-brain-zzz'
💥 MalfunctionError: message was written to the clone but did NOT leave its input buffer
   — the brain never submitted it
exit=1
```

⇒ the transport fails loud, with the fix named — exactly what the wish's first bound asks for. the
applier reports only the launch.

## .the gap, precisely

- `dispatchOneSay` returns `submitted: child.pid !== undefined` — true the moment exec succeeds, true
  for a say that exits 1 a moment later
- `setStoneBrain` then returns `{ outcome: 'requested' }`, and the drive renders `brain = <slug>`
- ⇒ a say that failed and a say that landed render the same

🔴 **this is not the brain-rejection arm** (`F5`), which needs a read of the brain's reply and has no
source. this is a transport failure the spawned process reported, now on disk, and never read.

## .the shape of the fix

never await the child — that is `case=5`'s deadlock (`hazard.a-hook-cannot-say-into-its-own-clone`).
- on the next tick, check the apply log: it holds failures only, so **a non-empty tail written
  since the entry marker IS the failure signal**
- a presence check, never a parse
- ⇒ upgrade the render from `requested` to a named halt cause, with the transport's hint

## .why it is not done in this round

**DIRTY.** it needs an entry-keyed timestamp to scope the tail, so it ripples into
`DriveBlockerState`, its snapshot, and three suites — the same ripple as
`.dream/v2026_09_15.fix.stone-brain-undispatched-overload-and-retry-backoff.md`. `withDriveStateLock`
already pays the lost-update part of that ripple.

🟡 **move 1's one-round deferral is the lesson worth keep.** it was deferred to preserve eleven cached
reviewer verdicts, on the ground that no lane had raised it; a lane raised it two rounds later and the
cache was spent anyway. ⇒ **a cache-preservation deferral bets no reviewer will find what you just
found.**
