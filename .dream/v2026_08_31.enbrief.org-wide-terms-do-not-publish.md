# 🌙 dream: the org-wide half of the glossary never reaches a consumer

**kind**: enbrief · **owner**: rhachet-roles-bhrain · **caught** 2026-08-31

## .the cue that fired

the wisher asked *"why only in .agent/"* — of the glossary and the new externalization catalog.

the answer this repo had on file was `hazard.published-brief-cannot-cite-the-repo-glossary`:
*"the glossary stays where it is… it is correctly unpublished."*

⇒ **that answer is right for half the glossary and wrong for the other half**, and the wrong half
is precisely the half a published brief teaches.

## .the gap, precisely

`philosophy.entoolment-is-the-pinnacle._.md` ships via `dist/`. it teaches **entool**, **enskill**,
the five-rung ladder, and the tool/skill split — a vocabulary, by name, to every consumer.

the clusters that declare that vocabulary do not ship:

```
rhx globsafe --pattern 'dist/**/term=*'
  → one unrelated thinker brief. ZERO term=*._.choice.* files
```

so the axis is not *"is this a term?"* — it is **who the word serves**:

| the cluster | serves | unpublished is |
|---|---|---|
| `term=route.stone` · `term=route.guard.*` · `term=glossary.sweep.*` | bhrain's own machinery | ✅ correct |
| `term=artifact.*` · `term=enbrief` / `enskill` / `entool` · `term=pave` · `term=learn` | org-wide practice, taught by a **published** brief | 🔴 wrong |
| `catalog.of=externalization._.md` | the index over that same published family | 🔴 wrong |

⚠️ **and the second row is invisible from inside.** every citation dereferences here, because the
files are on disk here. only a consumer sees the gap, and no one in this repo is a consumer.

## .the shape of the fix

**the mechanism already exists and is already in use for this exact directory.** four briefs live
in `src/` and are symlinked into `.agent/` — among them **both** domain-term RULES:

```
.agent/…/domain.terms/rule.forbid.domain-term-synonyms.md      → symlink
.agent/…/domain.terms/rule.require.domain-term-itemization.md  → symlink
```

⇒ **the rules were published and the clusters they govern were not.** so the split is half done
already, and the second half is the same move applied to the org-wide clusters:

1. move each org-wide cluster into `src/domain.roles/<role>/briefs/domain.terms/` — the learner is
   the likely home, since it already owns the two rules
2. symlink each back into `.agent/repo=.this/role=any/briefs/domain.terms/`, so this repo's boot
   is unchanged
3. widen the `term=*._.choice.*` globs, or add a second glob over the new home

## .the open question this must answer first

🔴 **what decides which side a cluster lands on?**

*"who does the word serve?"* is the axis, and it is a judgment per cluster. two are already hard:

- **`term=glossary.*`** — the glossary discipline is org-wide, and `glossary.sweep.progress` is
  bhrain's own hook mechanism. one family, both sides
- **`term=route.*`** — a route is bhrain's, and `philosophy.entoolment-is-the-pinnacle.via-routes`
  is published and teaches it

⇒ so the split is not a clean prefix cut, which is what makes it a judgment rather than a sweep.

## .why it is not done in this round

**safe, and not clean.** the move ripples past the diff:

- `role=any/boot.yml`'s three `term=*` globs — the only glob entries in any boot.yml in the repo
- `domainTermsBootReachability.integration.test.ts`, which asserts on that fact
- `genDomainTermsScaffold`, the operation that findserts a cluster's files and boot entries
- every extant `term=…` citation, and a find-and-replace cannot tell a citation from an instance
  (`rule.forbid.brackets-in-filenames`'s measured lesson)

and this round's bound is briefs the seeds asked for. the correction to the hazard brief is the
cheap half and it landed; this is the rest.
