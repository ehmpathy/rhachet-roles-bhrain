# case=9 — an instinct flag opens the next turn

cells: prompt × happy × +subconscious (`[t0]`–`[t2]`), prompt × sharp × +subconscious (`[t3]`–`[t5]`) · care: critipath

## .narrative

a seat ends a turn with *"ci is green on the last push."* it ran no check this turn; it recalled the state from an hour ago. the turn ends.

the instinct flags the claim: a state, relayed, with no read this turn. the owed basis: the live ci status. the flag lands in the seat's session as a `rhx clone say` message, the way the route reminder lands a nudge. `clone say` types into the session's input, so the idle seat meets it as a new turn, unbidden, before the human writes again. it is marked 🫧, so the seat reads it as its instinct, never as the human. the seat meets its own unbacked claim while the claim is still fresh.

the seat reads the ci status, finds one job red, and corrects itself in the same breath it answers the human.

a flag can be wrong. later the instinct flags *"the test passes"*, but the seat ran it this turn and cited the record. the seat replies to the flag with the record. that false flag is the one number that matters: the labeled replay counts it, and a flag rate below the bar sends every flag to the log only.

## .bdd sketch

```
given a seat enrolled with skeptic and subconscious, as a live clone
  when [t0] the prior turn ended with a state relayed unread
    then the instinct's flag is delivered via `rhx clone say <addr>`, exit 0
    then the idle seat meets it as a new turn, marked 🫧, never read as the human's words
  when [t1] the flag names the claim and the basis it owes
    then it names naught else: no verdict on whether the claim is true
  when [t2] the seat reads the source and corrects itself
    then the record it writes is cited in the reply; the next run flags naught
  when [t2b] the turn the flag opened ends with the claim still unbacked
    then the instinct asks only of the flagged claim, flags naught again, and logs the miss
    then no chain forms: one flag per claim per session                       # loop-guard boundary
given the same seat, with the instinct wrong
  when [t3] a flag lands on a claim the seat had backed with a cited record
    then the deterministic record check had already found the record; the flag is a false flag, logged as one
  when [t4] the seat is not a live clone (no `RHACHET_CLONE_SERIAL`, or `rhx clone say` exits 2)
    then the flag goes to the log only; the seat meets no message, and no error
  when [t5] the instinct's call faults (no key, a provider fault, a refusal)
    then the fault and its spend go to the log; the seat meets no message, and the turn already ended
```
