# 1.vision.experience.dimensions

the axes along which a run of a driver init varies. two inits ride one `rhx init --roles driver`
and vary along the same axes: `init.claude.status-line` (the subject) and
`init.claude.permissions.route` (the route heal, F14). each is closed; the product is walked in
`1.vision.experience.case=_.md`.

| axis | positions |
|---|---|
| **N · init** | `status-line` · `permissions-route` — which executable runs. the route heal differs in one verdict: it has no driver gate (it heals the permissions of whichever repo layer it finds), and no foreign-line skip |
| **C · config** — the `.jsonc` beside the executable | `present` · `absent` (a partial install) · `no-statusLine-object` (status-line only: the config holds no `statusLine`) |
| **L · layout** of `<repo>/.claude` | `split` (settings.json is a link, or settings.of.repo.json exists) · `old` (real settings.json, no settings.of.repo.json) · `none` (no `.claude` at all) |
| **I · invoker** | `human` (a shell with no clone — `rhx init --roles`) · `repo-actor` (a clone whose `CLAUDE_CONFIG_DIR` is `<repo>/.claude`) · `peer-actor` (a clone of `hash=…`, `CLAUDE_CONFIG_DIR` elsewhere) |
| **T · target state** — the file the layout picks | `absent-key` · `ours-current` · `ours-older` · `foreign` (a human's own statusLine) · `link` (the target itself is a symlink) · `malformed` (not valid json) · `not-object` (valid json, but an array or a scalar) |
| **G · grove state** — `~/.claude/settings.json` | `no-statusLine` · `foreign-statusLine` · `malformed` · `absent` (no grove file, or no `~/.claude` dir: the layout's arrows dangle) |
| **D · driver ambient** — `.agent/repo=bhrain/role=driver` | `linked` · `unlinked` |
| **R · repo actor record** — its `actor.json` | `absent` · `agrees` (lists driver iff D=linked) · `lags` (rhachet rewrites it only at a clone enroll) · `malformed` |
| **E · later event** | `layout-findsert` · `enroll` (derive one actor) · `init --hooks` (derive every actor) · `unlink` (`rhx init --roles -driver`: rhachet runs no init on it, so no teardown runs — F15) · `migrate` (rhachet moves an old real `.claude/settings.json` into the brain dir on its first layout) |

## .why the axes are orthogonal

each axis is set by a different party, so no position of one fixes a position of another:

| axis | who sets it |
|---|---|
| L | the rhachet version that last laid out `<repo>/.claude` |
| I | who typed the command — a human shell, or which clone |
| T | the history of that one file — this init, a human edit, a stray link |
| G | the human's own `~/.claude/settings.json`, outside the repo |
| D | `rhx init --roles` — the link that makes driver ambient |
| R | rhachet's last clone enroll — so it lags D between an init and the next enroll |
| E | what runs after — rhachet's enroll, its hook sweep, its layout findsert |

the bonds, and they are declared: `L=none` admits only `T=absent-key` (no file, no state); `D` and
`R` bear only on `L=split`. all other pairs are free — a peer actor may meet a foreign target; an
old layout may meet a foreign grove; a record may lag either way.

## .the hidden-dimension check

candidates weighed and refused as axes, each with the reason:

| candidate | verdict |
|---|---|
| role of the actor that renders (driver vs mechanic) | not an axis of the **init** — it does not change where or whether it writes; it lives in F3 as a render concern |
| concurrent runs | covered by the extant `mktemp` + per-pid backup; no new verdict per position |
| `CLAUDE_CONFIG_DIR` set by a human, not a clone | folded into `I` — the test is the dir, not the kind of invoker; the leaf says "session" |
| a stray real `settings.json` from the old init (the upgrade path) | a sub-position of `L=split`, not its own axis — the split test fires on `settings.of.repo.json` alone. demoed in `case=1` (2nd given) |
| rhachet version within the split era | no verdict changes between 1.49.x releases; `L` already captures the seam that matters |

## .the invariants the walk enforces

- `T=link`, `T=malformed`, `T=not-object`, or `C=absent`, or `C=no-statusLine-object` → a warn that names the fix, exit 0, no write, whatever the other axes hold (no write goes through a link, nor over a file it cannot parse as an object; and `rhx init` / `rhx upgrade` never fail on it). both inits hold it (`N` does not change it)
- `T=foreign` or `G=foreign-statusLine` → skipped, whatever the other axes hold (never clobber a human's own)
- `G=malformed` or `G=absent` → binds; the grove is the human's file to repair or to create, never a fault of the init, and the init never creates `~/.claude` (a dangled arrow once failed `rhx init` with exit 1)
- `L=split, D=unlinked` → on an explicit init, our line taken back, else skipped with the fix — whatever `R` says. `E=unlink` runs no init at all, so the line stays (`case=_`, the unlink row)
- `L=split, D=linked` → binds — whatever `R` says. the gate reads `D`, the source rhachet derives the repo actor from, never the cache `R`
- `L=split` → the write lands in the derivation source, so every `E` keeps it
- `I` never changes **where** the init writes — only whether the note renders
