# 🌙 dream: `--resnap` silently overwrites a flaked LLM verdict

- **kind** = fix
- **owner** = `ehmpathy/rhachet-roles-bhrain`
- **caught** = 2026-09-23

## .the cue that fired

a verification stone restructured **one** error message, so it re-ran the acceptance corpus with
`--resnap` to re-take that message's pins. the run came back green on a file the round had never
opened — and the diff was a **verdict**, not a format:

```
- │   ├─ approved [TIME]      - │   ├─ 0 blockers ✓
+ │   ├─ rejected [TIME]      + │   ├─ 1 blocker 🔴
```

`blackbox/review.by.guard-peer.acceptance.test.ts.snap`, case `[case-seam-pass-aggregation]`, whose
declared subject is *"code is clean → the guard approves"*.

🔴 **the suite reported no failure.** the flake was not tolerated, not retried, not logged — it was
**written down as the new expectation**.

## .the gap, precisely

with `-u`, jest **rewrites a mismatched snapshot rather than reports a red**. so for a case wrapped
in `when.repeatably({ attempts: 3, criteria: 'SOME' })`:

| without `--resnap` | with `--resnap` |
|---|---|
| attempt 1 mismatches → red → attempt 2 → attempt 3 | attempt 1 mismatches → **snapshot rewritten** → attempt 1 clears |
| `criteria: 'SOME'` gets its three draws | 🔴 the retry budget is **never reached** |

⇒ **the one mechanism the repo built to absorb LLM variance is disabled by the very flag used to
refresh snapshots**, and it is disabled silently, for every probabilistic case in the corpus at once.

**measured, both directions** (`rule.require.clamp-edge-cases` — the bite test, performed):

```
with --resnap, whole corpus   → 3700 passed, 2 failed   (guard-peer silently rewritten)
restored to HEAD, no --resnap →   54 passed, 0 failed   (231s, one suite)
```

⇒ the verdict is **variance**, the rewrite was **wrong**, and no gate in the run could say so.

## 🔴 .the rule it violates, and why the blast radius is the whole corpus

`rule.require.preserved-test-intentions` forbids *"change expected values to match broken output"*,
and `rule.forbid.overzealous-blockers` carries this exact shape as its worked **blocker**-grade
example — a snapshot that pins the opposite of its own case name.

the defect is not that a human mis-judged one snapshot. it is that **`--resnap` is scoped to the
run, while the intent behind it is scoped to one suite.** a driver who restructures one message and
reaches for the flag has, with no warn and no prompt, granted an authority to overwrite **every**
expectation the run touches — every LLM verdict among them.

## .the shape of the fix

three candidate directions, in the order they deserve a try:

1. **refuse the combination.** `git.repo.test` already knows `--resnap` and already knows the suite
   list. a case that declares `when.repeatably` is a case whose snapshot must not be auto-written;
   the runner could fail loud when `--resnap` would rewrite one, and name the suite
2. **make `--resnap` demand a `--scope`.** the flag's honest use is *"I changed this output on
   purpose"*, which is always suite-scoped. an unscoped `--resnap` is the un-bounded form, and it is
   the one that bought this defect
3. **report what was rewritten.** the run printed `8 snapshots written` and named none. a per-file
   list in the emit would have surfaced `review.by.guard-peer` at once, rather than after a
   `git status` a careful driver happened to run

⇒ **2 is the cheapest and 1 is the most correct.** 3 is worth it regardless — it is a pure
observability win and it costs one emit line (`rule.require.status-feedback`: *"a mutation that does
not report what changed"* is graded a blocker there).

🟡 **and it composes with an extant dream rather than replaces it.**
`.dream/v2026_09_20.fix.an-llm-verdict-snapshot-exhausts-its-three-retries.md` asks whether that
case should draw from an LLM at all. **that dream fixes the case; this one fixes the instrument** —
and until the case is fixed, the instrument will hide the flake from the next driver.

## .why it is not done in this round

**SAFE: no.** the change lands in `git.repo.test`, the skill every gate in every route runs through.
a refusal rule that mis-fires would block a legitimate resnap for every driver in the org, and this
round has no way to measure that surface.

**CLEAN: no.** the skill lives in `.agent/repo=ehmpathy/role=mechanic/skills/`, a tree
`v2026_09_17.fix-self-review-min-duration` never opened — and it is not this repo's to change in the
first place, which makes direction 1 and 2 a **reseed** rather than a fix.

⇒ the deferral is a **dirt** call rather than a size one — the ripple reaches every route in every
repo — so it owes a fulcrum beside this dream, and `F25` carries it.
