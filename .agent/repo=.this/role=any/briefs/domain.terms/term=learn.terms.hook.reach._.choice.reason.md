# domain.term.choice.reason: reach

## .etymology

an arm reaches what it can touch. the hook's entry sits in one file, and only the sessions that
read that file are touched by it; the leaf reads `reaches = …` for that reason.

rejected:
- **scope** — `review.scope` already names the files a review judges; a second sense would
  overload it
- **audience** — implies a reader who chooses to read; a reached session has no choice, its stop
  simply runs the hook

## .boundary

the boundary `learn.terms.hook` ties it to this hook's entry. the reach is a fact about which
sessions read the target, decided by layout and by rhachet's peer-actor derive (an actor keeps a
hook only where it holds the author's role).

## .evidence

- the session-role axis R of `1.vision.experience.dimensions.md` and case=3 of the vision, which
  walks each position
- the leaf transformer `asTermsHookReachLeaves`
- invariant: no session outside the reach runs the hook, so a repo that never enables it, and a
  plain session on the split layout, stop as before
