# case=4 — each verb is idempotent

feel × care: happy × critipath · actor: any · ⇒ inventory rows `enable · on` and `disable · off`

## .narrative

a clone is not sure whether a teammate already enabled the toggle, so it runs `enable` anyway.
naught changes, and the output says so plainly rather than claim a write:

```
📜 learn.terms.hook enable
   ├─ status = already enabled
   └─ settings = .claude/settings.of.repo.json
```

the same holds for `disable` on a repo where it was never on: `status = already disabled`, no
write, and a target that was absent is not created. neither run leaves a diff to commit.

## .[tn] sketch

```
given('[case4] a repo where the toggle is enabled')
  when('[t0] `rhx learn.terms.hook enable` runs again')
    then('exit 0; stdout reports already enabled')
    then('the settings file is byte-identical; exactly one term hook entry exists')
given('[case4b] a repo where the toggle is off')
  when('[t0] `rhx learn.terms.hook disable` runs')
    then('exit 0; stdout reports already disabled')
    then('the settings file is byte-identical, or still absent if it was absent')
```
