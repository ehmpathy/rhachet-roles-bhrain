## .narrative

a driver clone is 400 calls into a route and its context feels heavy. it runs
`rhx reflect.tokens` with no args.

the tool reads `$CLAUDE_CODE_SESSION_ID` (the harness exports it to child processes), then looks
for that uuid under `$CLAUDE_CONFIG_DIR/projects/<slug>/` first (where an actor-brain clone
writes), then `~/.claude/projects/<slug>/`. so it finds the clone's OWN transcript even when a
peer session in the same cwd wrote more recently. the header names the root and the file.

the harness appends to this transcript right now — it was mid-write. the last line does not
parse. the tool skips it and says `1 partial line skipped (live tail)`, and the report stands.

the clone sees `tool.result · Read` at 19% and a single 30K file read at call 41 that has been
re-paid 359 times. it reads by range from then on.

  });

    then('calls rises by the calls since, and no prior call is double counted');
  });
});
