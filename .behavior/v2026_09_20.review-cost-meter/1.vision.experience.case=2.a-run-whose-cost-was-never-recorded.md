# case=2 — a run whose cost was never recorded

- cell = `tree` × `cost` × `defend`
- path = **critipath** · feel = sharp · care = criti

## .the narrative

a driver runs `rhx review._.cost --of tree` and reads `$0.041`. they conclude the tree is cheap.

but three of the twelve runs crashed before they wrote `metrics.realized.json`. their cost
is not zero — it is **unrecorded**. the brain was called, tokens were spent, and the log
does not know how many.

a naive meter renders `$0.00` for those three and sums them in. the total is then wrong in
the one direction nobody checks: it **understates**, and an understated bill reads as good
news, so no one investigates it.

the world this wish builds refuses that:

```
├─ runs: 12 (9 metered, 3 unknown)
├─ cost: $0.041      ← the 9 metered runs only
└─ ⚠️ 3 runs could not be priced — this total UNDER-reports
```

when a driver sees the run count and the metered count disagree, the number in front of
them stops being *"the bill"* and becomes *"the bill we can prove"* — different claims.

## .the distinction that carries the cell

there are two nils, and they are not interchangeable:

| grade | the nil is | renders |
|---|---|---|
| `refused` | a **fact** — the brain charged zero (a fully-cached round) | `$0` |
| `unknown` | an **absence** — no one recorded what it charged | **omitted** |

a meter that maps both to `$0.00` erases the difference between *"free"* and
*"unmeasured"*, and no downstream reader can recover it.

## .the bdd sketch

```
given [case2] a tree whose log holds runs with and without recorded cost
  when [t0] the meter is built
    then a run with a measured cost is graded `metered`
    then a run whose brain charged a true zero is graded `refused` and renders `$0`
    then a run with no cost record is graded `unknown`
  when [t1] the report is rendered
    then the `unknown` runs are excluded from the cost sum
    then the header states how many runs are unknown
    then an `unknown` run's cost renders absent, never `$0.00`
  when [t2] every run is unknown
    then the cost line is absent entirely — not `$0.00`
```

## .what it depends on

- `asAccountedCost` — the three-grade decision, with its own unit test
- `genReviewMeterStdout` — renders absence as absence

## .why it is a critipath

low frequency, maximum cost. the failure is silent and self-flatters: a grove that
under-reports its bill never draws the attention a grove that over-reports would. every
lever chosen against that number is chosen against a lie.
