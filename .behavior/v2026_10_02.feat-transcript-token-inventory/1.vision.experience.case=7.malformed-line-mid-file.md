# case=7 — a malformed line mid-file (sharp)

cell 13: one transcript · malformed-mid-file (here via `path`, finished) · feel = sharp · care = alterpath · boundaries = 2 (lookup, parse)

## .narrative

a human copied a transcript off a crashed laptop. the copy truncated one record halfway through
the file and the harness wrote on past it, so line 3,412 of 5,900 is half a json object.

they run `rhx reflect.tokens --from <path>`. a tool that skipped the bad line would hand them a
report that silently lacks one call — and if that call held the delta that brought a 40K log in,
the log would land in `unattributed` and the ranks would lie with no sign.

so the tool refuses. only the FINAL line may be partial (that is a live tail, case=3); a bad line
with records after it is a corrupt file. exit 1, and the error names where.

```
🦉 a ripple where the pond should be still

🌕 reflect.tokens
   └─ 💥 MalfunctionError: transcript has a malformed line before its end
      ├─ from = ~/copies/8f278020-….jsonl
      ├─ line = 3,412 of 5,900
      ├─ head = {"parentUuid":"a91c…","type":"assistant","message":{"usage":{"input_tok
      ├─ fix: re-copy the file from its source, then run again
      └─ note: only a final line may be partial — a live tail. a mid-file break is never skipped
```

the human sees the line number, re-copies the file, and the second run reports in full.

## .timeline

```ts
given('[case7] a transcript whose line 3,412 of 5,900 does not parse', () => {
  when('[t0] the human runs `rhx reflect.tokens --from <path>`', () => {
    then('exit 1 — never a report with a silent gap');
    then('the error names the file, the line number, and the line count');
    then('the error shows the head of the bad line, so the human can see the cut');
    then('the error teaches the fix — re-copy from source');
  });
});
given('[case7b] the same break, but on the final line', () => {
  when('[t0] the human runs `rhx reflect.tokens --from <path>`', () => {
    then('exit 0, with `1 partial line skipped (live tail)` — the case=3 rule');
  });
});
```
