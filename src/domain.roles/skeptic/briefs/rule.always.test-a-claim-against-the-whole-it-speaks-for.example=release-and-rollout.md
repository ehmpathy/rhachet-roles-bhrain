# rule.always.test-a-claim-against-the-whole-it-speaks-for.example=release-and-rollout

> row: a new term. 2026-11-16, the salespages prerender crew of a consumer director (#49). source: inbox 2026-11-16-salespages-defects-skeptic.

## .the shape, in any life

a mover tags boxes "fragile", "delicate" and "breakable", and the crew reads them as three grades of care. does each word name one kind of box, and does each kind have one word?

the case below: one axis got two words and an adjective on each, so the terms for a single release and for many drifted.

## .the miss

the crew's text split one axis with adjectives: "linear release" and "iterative rollout", and used release and rollout as synonyms. the human refused the synonym outright: rollout is the word for the decomposed kind, and no synonyms.

## .the cost

two words for one axis, an adjective on each to tell the kinds apart, and one upstream radio record (fc8a03e8e45092b0) that carried the old terms toward the architect's briefs.

## .the cure in the tree

the crew route and the brief now define release = one release, rollout = multiple releases, each the other's forbidden synonym, with no adjectives.

## .the cure upstream

radio record 7f4df47b54fe398d: the release vs rollout example for `rule.forbid.term.addition.synonym` and `.ambiguous` (architect). radio record fc8a03e8e45092b0 still holds the old "linear release / iterative rollout" text and is owed a drop, so the old terms do not ship.

## .the law it proves

`rule.always.test-a-claim-against-the-whole-it-speaks-for` (the row for a new term): a second word for one axis, or an adjective that splits one word, is a defect.
