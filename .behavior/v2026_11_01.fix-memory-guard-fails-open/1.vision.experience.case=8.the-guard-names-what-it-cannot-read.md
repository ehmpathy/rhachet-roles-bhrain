# case 8: a payload the guard cannot read is named; a big one is still judged

rows 26, 46, 48, 49 (rows 25, 47 itemized).

proof: `src/domain.operations/memory/asToolInvocation.test.ts`, `src/contract/cli/memory.integration.test.ts` `[case6]`, and `src/domain.roles/learner/getLearnerRoleHookCommand.integration.test.ts` `[caseA]` `[t4]` and `[caseH]`.

## .narrative

the harness pipes one json payload per call. three things can go amiss with it, and the guard answers each by what it can say.

an empty or blank stdin is no call, so the guard has no tool to judge and passes in silence.

a payload that is present but unreadable is a blind spot, and the guard names it. text that is not json, valid json that holds no tool call (`{}`, `[]`, `null`), and a payload whose tool field is renamed (`toolName` for `tool_name`) each read as a call the guard cannot judge. the call proceeds, exit 1, and the human sees one line with the cause. a harness that changes the field names would blind the guard on every call; the line is how the human learns it.

a payload past the environment cap (about 128KB; a heredoc of a long brief) rides node's stdin, not the environment. a payload held in the environment would fail every exec after it. so a true write of that size is still judged and halts with the nudge, and a plain command of that size is still judged and passes in silence, with no fault line in either.

## .bdd sketch

```
given [case6] malformed json on stdin
  when [t0] the guard runs
    then exit 1, never 2
    then stderr is one line:
      📜 memory.guard: could not run (tool payload is not json); call allowed. fix: none needed for this call; if it recurs, report it at https://github.com/ehmpathy/rhachet-roles-bhrain/issues

given [caseA] a linked learner, fed a payload the guard cannot judge
  when [t4] stdin is `{}` · `{"toolName":"Bash","tool_input":{"command":"ls"}}`
    then exit 1
    then stderr is one line:
      📜 memory.guard: could not run (tool payload has no tool_name); call allowed. fix: none needed for this call; if it recurs, report it at https://github.com/ehmpathy/rhachet-roles-bhrain/issues
  (and `[]`, `null` by the same cast: asToolInvocation)

given [caseH] a linked learner, fed a payload past the env cap
  when [t0] a 160KB memory write fires the hook
    then exit 2, the nudge
    then stderr does not hold `could not run`
  when [t1] a 160KB read fires the hook
    then exit 0, silent
```
