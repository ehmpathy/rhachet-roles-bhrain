# 🌙 dream: route.drive's Stop hook has no exit for a seat that does not own the route

kind: fix · owner: bhrain/role=driver · caught 2026-11-27

## .the cue that fired

two sessions shared one tree and one bound route: one forked into a fresh actor and drove the
route on; the other, stale, was resumed to answer a human's questions. on every stop, the stale
seat was told *"to refuse is not an option"* and offered three acts (`arrived`, `passed`,
`blocked`), each of which would rewrite the stone state the owner seat was mid-way through.
it declined, and the hook re-fired every turn, with no cap.

## .the gap, precisely

- the route bind is per tree, so every seat in the tree is held to the route
- no command marks "this seat is not the driver of this route" without a write to the shared
  stone state
- the hook has no cap, so a seat that rightly declines loops until the human closes it

## .the shape of the fix

- a per-seat lever, e.g. `rhx route.bind.del --scope seat` or a session-keyed opt-out, that
  releases THIS session from the route's Stop hold and leaves the route's state untouched
- or: the hook detects another live seat on the same route (a recent passage or transcript write
  under another actor) and nudges once, then releases
- `rhx reflect.on.transcripts` already finds the seats of a tree and which one spoke last

## .why it is not done in this round

the fix is a driver-role contract change (bind scope, a seat identity) — real design work in
another role's surface, raised from a seat that does not own the route it would touch.
