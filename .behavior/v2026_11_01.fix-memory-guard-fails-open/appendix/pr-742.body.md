## what changed

- **R5: a read stays a read.** the verdict graded `/>\s*/` as a write, so `2>&1`, `=>` and `->` in a read of a memory path halted the call. each simple command is now graded by where it writes; a true write into `~/.claude/**/memory/` or `MEMORY.md` is still blocked, exit 2
- **R6: the payload rides node's stdin, never the env.** `memory.guard.sh` exported the whole payload as `RHACHET_STDIN`; past the kernel's ~128KB cap on one env string, the `exec` failed. it now hands the payload to node via a here-string
