# case=8 — a driver seat halts beside the instinct

cells: reply × sharp × +driver (`[t0]`) and reply × happy × +driver (`[t2]`), with subconscious also enrolled · care: critipath · density: highest

## .narrative

a seat enrolled with `driver`, `learner`, `skeptic`, and `subconscious` drives a route. at execution it needs source files no read can reach. its first reply ends: *"the files are not there because the land never happened — where are they?"*

two onStop hooks read that turn, and only one of them can hold it:

- `route.drive --when hook.onStop` sees the stone still open and holds the turn
- the subconscious spawns its instinct detached and returns at once; it never holds a turn

the instinct flags two claims: a cause stated as fact with no read ("the land never happened"), and a question a read could narrow. the flag reaches the seat as a `rhx clone say` message, the same channel the route reminder uses. the seat meets the driver's hold and the instinct's flag together, each from its own role, one marked 🗿, one marked 🫧.

the seat does not loop. it runs the reads it skipped and records them in `.skepticism/` and as a fulcrum. it marks the stone `--as blocked`. its final reply asks once: *"read: origin/main, 3 local trees, 5 branches · open: the dir is untracked on the host that pioneered it."* the driver hook reads a blocked stone and lets the turn end. the next instinct run finds each claim backed and flags naught. the human gets one question, already narrowed.

## .bdd sketch

```
given a seat enrolled with driver + learner + skeptic + subconscious, on a stone that needs absent source
  when [t0] the final reply holds an unread cause and a bare question
    then route.drive's onStop holds the turn for the open stone                    # co-tenant seam
    then the skeptic's `instinct.of` onStop returns at once; the instinct runs detached       # never-hold boundary
    then the instinct flags the cause and the question, via `rhx clone say`          # flag boundary
  when [t1] the seat runs the reads, records them, and sets the stone `--as blocked`
    then the driver hook reads a blocked stone and lets the turn end                 # halt boundary
  when [t2] the final reply asks once, with an adjacent `read: … · open: …` line
    then the instinct flags naught                                                   # read-line boundary
  when [t3] two flags and a driver nudge land in one session
    then each says which role sent it; no flag repeats one already met                # dedupe boundary
```

## .what execution must settle

- the order the two onStop entries run in, and that the skeptic's `instinct.of` entry adds no wall time to the driver's (it spawns and exits)
- where the instinct keeps the claims it flagged this session, so the loop guard (vision, `its loop guard`) can skip a repeat; best guess: its own log, keyed by session
