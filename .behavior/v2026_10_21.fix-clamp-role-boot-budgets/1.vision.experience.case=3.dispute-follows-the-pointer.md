# case=3 — a dispute follows the pointer

**feel** happy · **care** alterpath (rare: one Read per dispute, and a miss costs a Read, never a rule)

the "pointer" is the min's own boot header (`path="….md.min"`) together with the role's one
convention line (F7): each `X.md.min` condenses the `X.md` beside it.

## narrative

a learner reads *"a redundant cue carries no drift risk"* and doubts it. the boot header shows
`rule.require.a-cue-is-not-a-claim.md.min`, and the learner readme says the full `.md` sits beside
each min. it reads `rule.require.a-cue-is-not-a-claim.md` and finds the inverted failure-mode
table, the telepath worked case, and the settlement. the doubt is settled in one Read.

## [tn] sketch — the two places the pointer can break

the narrative walks src. a consumer walks `dist`, and a min with no `.md` beside it (cell 14) is
a pointer to naught. the sketch asserts both.

```
given a booted header `<brief.say path=".agent/repo=bhrain/role=learner/briefs/rule.require.a-cue-is-not-a-claim.md.min">`

  when [t0] the reader strips `.min` and reads `.agent/repo=bhrain/role=learner/briefs/rule.require.a-cue-is-not-a-claim.md`
    then the Read succeeds (the `.agent` link resolves into `dist`)
    then the file holds the line `## .the failure modes INVERT, and that is the whole rule`

  when [t1] the author runs, for each role, `rhx globsafe --pattern 'dist/domain.roles/<role>/briefs/**/*.md.min'`
    and checks each result has its `.md` peer on disk
    then the count of mins with no `.md` is 0
    (a nonzero count is cell 14: a pointer to naught, caught in 5.3 before publish)
```
