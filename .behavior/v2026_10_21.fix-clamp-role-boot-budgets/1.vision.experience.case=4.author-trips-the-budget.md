# case=4 — an author trips the budget

**feel** sharp · **care** critipath (every future edit can trip it; densest boundary)

## narrative

a month later, an author adds a measured case inline to a learner rule's min. it is a reasonable
edit. the seat links each role from `dist`, so its own boot only warns; the clamp test, which
boots the `src` form and a plain seat-form copy, halts: over budget by 400 tokens, red in the
author's test run and in ci before any merge. the halt lists four fixes, and *condense* and
*reference* are the first two. the author moves the paragraph to the `.md`, and the test passes.
the budget caught the drift at the next test run, not six months later in a cost audit.

some edits have no paragraph to move: the new line is itself a cue. then the halt's fixes all
point at a cut, and a cut is forbidden. that turn is case=5, and it is part of this fail-safe.

## [tn] sketch — the limit, both sides, and the fix the halt cannot print

the narrative shows the rejection. it does not show that the last valid payload passes, nor what
the author does when every printed fix would cut a cue. the probe below was run 2026-10-21 against
a spec with `budget: tokens: 100`.

```
given learner/boot.yml declares `budget.tokens: N`, and `npx rhachet roles cost --what <it>` reads payload P

  when [t0] an edit leaves P = N exactly
    then `npx rhachet roles boot --what src/domain.roles/learner/boot.yml` exits 0     # the limit holds
  when [t1] an edit pushes P to N + 400
    then the same command exits 2, at once, before any brief is emitted                # fast
    then stderr opens `✋ ConstraintError: over budget`                                  # loud
    then it prints budget N, payload P, over-by 400, and four fixes:                   # teaches
      catalogize · condense · reference · eliminate

  when [t2] the author moves the inline paragraph to the `.md` (condense)
    then the same command exits 0, and `rhx census.cues --emit` for that file is unchanged

  when [t3] the 400 tokens are a new cue row, with no argument to move
    then the author raises `budget.tokens` with a comment that names the new row       # case=5
    then the same command exits 0, and the census holds the new row
    (the four printed fixes do not name this move. case=5 is where it is taught)
```
