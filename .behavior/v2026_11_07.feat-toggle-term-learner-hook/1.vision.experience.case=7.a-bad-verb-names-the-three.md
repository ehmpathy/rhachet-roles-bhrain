# case=7 — a bad verb names the three

feel × care: sharp × critipath · actor: any caller in a repo that links the learner · ⇒ inventory row `(absent / unknown)`

## .narrative

a clone guesses `rhx learn.terms.hook on`. it is not silently read as `get`, and it does not write:

```
$ rhx learn.terms.hook on
✋ ConstraintError: unknown verb `on`
   ├─ verbs
   │  ├─ get      report whether the term hook is on in this repo
   │  ├─ enable   add the onStop term hook
   │  └─ disable  remove it
   └─ help: rhx learn.terms.hook --help
```

exit 2. a bare `rhx learn.terms.hook` with no verb gets the same refusal (`no verb given`), since a
bare call that defaults to `enable` would write on a guess. `--help` prints the usage, the three
verbs, the default (disabled), and the exit codes, to stdout, exit 0.

## .[tn] sketch

```
given('[case7] a repo that links the learner — elsewhere `rhx` itself refuses the unknown skill, before the toggle parses a verb')
  when('[t0] `rhx learn.terms.hook on` runs')
    then('exit 2; stderr names the unknown verb and lists get, enable, disable')
    then('no file is written')
  when('[t1] `rhx learn.terms.hook` runs with no verb')
    then('exit 2; stderr names that no verb was given and lists the three')
  when('[t2] `rhx learn.terms.hook --help` runs')
    then('exit 0; stdout holds usage, the three verbs, and the default')
```
