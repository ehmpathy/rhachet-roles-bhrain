# case=8 · the record lags the link

coordinates: L=split · D=linked · R=lags · I=human · T=absent-key · feel=happy · care=critipath

## .narrative

a repo has run for weeks with mechanic alone. its repo actor's `actor.json` lists `any`,
`mechanic` — rhachet wrote it at the last clone enroll. the human now runs
`rhx init --roles driver`. rhachet links `.agent/repo=bhrain/role=driver`, then runs the driver's
inits — before any clone enrolls, so `actor.json` still says no driver.

the init asks the question rhachet itself asks: is driver ambient? the ambient roles are the
linked roles, so it reads the link, and binds. a gate on the record would have skipped here, and
printed that the repo actor is not enrolled with driver, to a human who just linked it.

## .bdd

```
given a split layout with driver linked, whose actor.json lists [any, mechanic]
  when [t0] the init runs
    then status = configured
    then settings.of.repo.json holds the route statusLine
    then no line says "not enrolled with driver"
```
