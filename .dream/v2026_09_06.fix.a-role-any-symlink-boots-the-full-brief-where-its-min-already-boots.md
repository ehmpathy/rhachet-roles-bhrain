# 🌙 dream: a `role=any` symlink boots the full brief where its `.min` already boots

- kind    = fix
- owner   = this repo (`ehmpathy/rhachet-roles-bhrain`)
- caught  = 2026-09-06

## .the cue that fired

a density audit gave two verdicts on one file. scanned as
`src/domain.roles/learner/briefs/im_an.obsessive_learner.md` it graded exempt; scanned as
`.agent/repo=.this/role=any/briefs/im_an.obsessive_learner.md` it graded 7 sections over the bar.

**the two paths are the same inode** — the second is a symlink to the first.

## .the gap, precisely

`.agent/repo=.this/role=any/briefs/im_an.obsessive_learner.md` points at the **full** `.md`, and
the SessionStart boot inlines it as a `<brief.say>`. meanwhile `repo=bhrain/role=learner` boots
`im_an.obsessive_learner.md.min` at `say` too.

⇒ **one brief, two `say`-tier boots in every session** — one compressed, one not. the min exists to
hold the boot cost down and the full source is loaded beside it.

it also makes a tier-aware audit disagree with itself, and both verdicts are locally correct:

| the path scanned | the `.md.min` sibling | the tier it grades |
|---|---|---|
| `src/domain.roles/learner/briefs/…md` | present | `ref` — the min boots, so its density costs no consumer |
| `.agent/repo=.this/role=any/briefs/…md` | absent (only the `.md` is symlinked) | `say` — graded, correctly |

⇒ the second verdict is the one that describes what a session pays. so a tool that grades tier by a
sibling lookup reports a false clean on every brief reached this way.

## .the shape of the fix

three moves, and the first is the cheap one:

1. **repoint the symlink at the `.md.min`.** one `rhx symlink` call. it drops the duplicate to two
   copies of the compressed form, which is a smaller waste and a truthful tier.
2. **or drop the symlink.** `repo=bhrain/role=learner` already boots the brief. this one exists so
   `repo=.this/role=any` carries the identity too — which is a real want, and a wisher call.
3. **and teach the audit to follow a symlink for its tier check** — take the realpath, then look
   for `${realpath}.min`, so one file gets one verdict whichever path reaches it.

🟡 move 3 is owed whichever of 1 or 2 lands, because the same shape can recur on any
`.agent/repo=.this/` symlink. audit the whole `role=any/briefs/` set for it.

## .why it is not done in this round

**safe, and not clean.** move 1 or 2 changes what `repo=.this/role=any` teaches — a booted role's
content, decided by whoever put the full `.md` there on purpose. that is a wisher call, not a
sweep.

⇒ the density in the full `.md` was repaired in place this round, so the artifact reads clean at
both boot sites today. what stays open is the duplicate boot itself.
