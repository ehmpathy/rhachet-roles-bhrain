## .notes

- **care for rows 1, 6, 9, 17, 19:** every call of a work day walks them, and a break has no workable route around it — a blocked Edit is routed past only by a human who strips the hook. `freq × cost` is intolerable; that is the crews' incident exactly.
- **row 8** is an extant over-match, kept: `cp` and `mv` are graded blunt, by the presence of a memory path, not by their destination (fulcrum F10). it errs toward the guard's one job and is rare. **tee is not graded this way**: it writes its operands and naught else, so rows 59–67 grade it by where each operand lands, exactly as a redirect target is placed. that split is why `cp M ./a.md` halts while `cat M | tee /tmp/out.md` passes.
- **row 62 is the read route the nudge names.** a clone that reads a memory note and tees it into a durable brief, with the cwd known, passes silent: the guard's own advice, honored.
- **row 24, the one invariant.** a guard that could not judge has no authority to halt (nurture: the wish chose flow over a guard that cannot run). consequence: in such a tree a true memory write passes, and the notice on every call is what tells the human the guard is off. rows 35–37, 39, 43 pin the sharpest forms: a file or step that would otherwise exit 2 or a silent 0.
- **rows 22, 40, 41 split a throw by who fixes it.** a module that fails to load is an install fault: a reinstall cures it, one line, no stack. a throw as the cli loads, or as the guard runs, is a shipped defect: a reinstall reloads the same throw, so the fix asks for a report and the stack follows the first line.
- **row 25 is silent, and rows 26, 46, 47 are not.** empty stdin is no call to judge. a payload that is present but unreadable, or readable but no tool call, is a blind spot, so it is named (exit 1).
- **row 30** cannot occur under claude code, which exports `CLAUDE_PROJECT_DIR` to every hook; it is reachable only from a bare shell, where the human chose the cwd.
- **row 31 is why the notice rides on exit 1, not exit 0.** claude code never shows a hook's stderr on exit 0; a non-0, non-2 exit renders a `hook error` notice to the human and lets the call proceed. see fulcrum F1.
- **rows 50–58 grade at the verdict grain.** the hook suite sends payloads with no `cwd` field, so the cwd-known cells are proven at `getMemoryGuardVerdict` and `asToolInvocation`, which carries the field; the cwd-unknown and `$var` cells ride the hook suite too.
- **row 54 and 57 share an act.** both end in the unplaced nudge: a write the guard cannot place, beside memory, blocks rather than guesses.
