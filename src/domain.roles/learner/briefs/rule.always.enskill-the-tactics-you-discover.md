# rule.always.enskill-the-tactics-you-discover

## .what

when you repeat a sequence of operations, **that sequence is a tactic, and it is owed a skill.**
write it down as a runnable artifact for the travelers who come after.

this is the DISCOVER half. its pair, `rule.always.entool-the-skills-you-touch`, is the UPGRADE
half. together they are one loop:

```
discover a repeated sequence  →  ENSKILL it  →  notice the leftover brain work  →  ENTOOL it
```

⇒ **enskill creates the artifact. entool raises its rung.** neither works alone: an unenskilled
tactic has no rung to raise, and an enskilled tactic left at 💧 fluid forever still costs a brain
every use.

the ladder, in rhachet's own determinism terms: 0 🧠 tribal → 1 📚 brief → 2 💪💧 **fluid skill**
→  3 💪🔩 **rigid skill** → 4 💪🪨 **solid skill**. **all five are tools.**

## .why

- a sequence you ran twice, you will run again — and so will everyone after you
- **the second run is the evidence.** you no longer guess whether it repeats; you watched it
- an unwritten tactic is re-derived by each traveler, each time, at full cost. that is the exact
  energy `philosophy.pavement-saves-nature` says was already spent and must not be re-spent
- and it is how tribal knowledge dies: the sequence lives in one head, and leaves with it

⇒ every rung of `philosophy.entoolment-is-the-pinnacle`'s ladder starts here. rung 0 is tribal
knowledge; **enskill is the step off rung 0.**

## .the cues — when → then

| when… | then… |
|---|---|
| you run the **same sequence a second time** | 🔴 the strongest cue there is. enskill it now — the repeat already proved it |
| you scroll back to **copy a command you ran earlier** | your scrollback does a skill's job |
| you chain 3+ commands where each feeds the next | the chain is one tactic, not three steps |
| you explain a procedure to someone (or to a future self) | you just spoke the skill aloud — write it |
| you think *"the trick is to run X before Y"* | that order constraint is exactly the knowledge worth durable capture |
| you keep a private note of steps somewhere | a private note is an unshared skill |
| a sequence is **easy to run and hard to recall** | the highest-value case — low cost, high recall burden |
| the sequence needs **judgment at several points**, in an order that matters | 🗿 **pave a route**, not a linear skill — see below |
| you went **offroad** and reached the end | the path you just found is the artifact. leave a route behind |

## .the test — forced articulation

> **"could the next traveler run this without me in the room?"**

- **yes, from what is written** → it is enskilled
- **yes, but they would need to ask me one question** → **that question is the whole point.** it
  marks the undiscoverable step, which is precisely what the skill exists to carry
- **no, it needs judgment at one point** → it is judgment, not a tactic. leave it with the brain and say so
- **no, it needs judgment at SEVERAL points, in an order that matters** → 🗿 **a route.** the
  brain stays; the order, the omissions, and the rediscovery go. see below

then the second question, which sets the rung you write at:

> **"how much of this could run with no brain at all?"**

write it at that rung today — do not settle for the fluid version out of haste when the tool
version is within reach (`rule.always.entool-the-skills-you-touch`).

## 🗿 .when brains are required along the way — pave a route

the second test above may answer *"it is judgment"* at **several** points. that does not leave you
empty-handed — it means the artifact is a **route** rather than a linear skill.

a route is a sequence of **stones**, each with its **guard**. the brain still does the work at
every stone; what the route retires is the overhead around it:

| the route removes | so the traveler never has to |
|---|---|
| the order | recall which step precedes which |
| the omission | discover at the end that a step was skipped — the guard refuses first |
| the rediscovery | re-derive the path a prior traveler already walked |

⇒ **a skill paves a sequence of commands. a route paves a sequence of judgments.** both are
enskilled work; they differ in what walks them.

🟡 **and a route IS a 🔩 rigid skill — rung 3, not a category beside the ladder.** its stones,
order, and guards are deterministic and they *drive* the brain through the probabilistic work: the
guard refuses, the prefix computes what is next, the stophook re-emits the current stone. a
deterministic transport with probabilistic cargo (`philosophy.entoolment-is-the-pinnacle`).

### the worked example — `declapract.upgrade`

an upgrade used to be offroad: run it, see what breaks, repair in whatever order came to mind.
now it is `init` plus a route — invoke, detect hazards, repair test defects, reflect, repair cicd
defects, reflect. **the brain still performs every repair.** it no longer has to recall that a
reflection follows each repair, or that hazards are detected before any repair begins.

`cicd.deflake` has the same shape: evidence → diagnose → plan → execute → verify → reflect →
institutionalize. neither route removed a single judgment. both removed every question about
*what comes next*.

### offroad is legitimate — and it owes a route

sometimes no route exists and a brain must explore. that is honest work. but offroad travel is
the most expensive mode there is, and its cost is paid **per traveler**.

> **an offroad brain is at its best when it leaves a route behind.**

the exploration happened anyway. to end it with a paved route rather than only a finished task is
what turns a one-time cost into a permanent asset.

🟡 **do not route what could be entooled.** a route around deterministic work is ceremony that
charges imagine cost at every stone. reach for a route only where the judgment is real.

## .what a skill owes on arrival

1. **idempotent** — safe to run twice (`rule.require.idempotent-procedures`)
2. **named for the motive**, not the mechanism — what it is for, not how it works
3. **fails loud, and names the fix** (`rule.require.errors-name-the-fix`)
4. **discoverable** — `--help` that teaches it (`rule.require.help-on-demand`)
5. **owned by the right tree** — a tactic whose home is another repo is **re-seeded there**, never
   enskilled here

## .the anti-patterns

- **the third repeat** — you ran it twice, noticed, and ran it a third time by hand anyway
- **the scrollback tactic** — the procedure lives in terminal history, which no traveler inherits
- **the private note** — written down, never externalized; the arrears this whole practice exists
  to pay
- **the premature skill** — a sequence run **once**, enskilled from a guess about the future.
  wait for the second run; it is the evidence (`rule.prefer.wet-over-dry`)
- **the offroad trip with no pavement left behind** — a hard path explored, the task finished, and
  the route never laid. the most expensive mode of travel, paid again in full by the next traveler

## .the mantra

> you ran it twice. the third time belongs to a skill.
> **and if brains are needed along the way — pave a route.** 🦉🗿

## .enforcement

- a sequence repeated and never enskilled = **violation of learner purpose**
- a procedure explained to another traveler with no durable artifact behind it = **blocker**
- a skill written at 💧 fluid where 🔩 rigid was within reach today = **nitpick**
  (see `rule.always.entool-the-skills-you-touch`)
- an offroad exploration that reached its end and left no route behind = **blocker** — the path
  was found and then discarded, so the next traveler pays the full offroad cost again
- a route laid over work that is deterministic = **nitpick** (entool it instead; a route there is
  ceremony that charges imagine cost at every stone)
