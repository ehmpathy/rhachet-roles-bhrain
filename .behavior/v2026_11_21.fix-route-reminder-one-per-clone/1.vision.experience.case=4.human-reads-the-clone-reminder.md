# case=4 — a human reads the clone's reminder

inventory rows: r9, r10, r11. feel: happy (r9, r10), sharp (r11). care: critipath (r9), alterpath (r10, r11).

## .narrative

a human suspects double pokes. inside the clone they run `rhx route.reminder.get`. it reads the clone handle, not a route's, and prints the pid and the focus route. one answer per clone, whatever the bind.

they run `rhx route.reminder.del`. the clone's one daemon stops. no `--route` is needed; there is no per-route daemon to pick.

from habit they type `rhx route.reminder.get --route .behavior/A`. the command refuses: the reminder is per clone, so `--route` names naught. the error names the fix — drop the flag, or pass `--clone-addr` to read another clone.

## .[tn] sketch

```ts
given('[case4] a clone with one live daemon, focus = B; route A also live', () => {
  when('[t0] the human runs route.reminder.get', () => {
    then('it reads the clone handle, never a per-route one');
    then('it prints the pid and focus = B, one line');
    then('A is not named');                      // the human sees one daemon, not one per route
  });
  when('[t1] the human runs route.reminder.del', () => {
    then('the one daemon receives SIGTERM');
    then('the clone pid handle is removed by compare-and-delete');
    then('a second get reports not live');
  });
  when('[t2] the human runs route.reminder.get --route .behavior/A', () => {
    then('it exits 2 with a ConstraintError');
    then('the error names the fix: drop --route, or pass --clone-addr');
    then('no handle is read or changed');        // a refusal before any i/o
  });
  when('[t3] the human runs route.reminder.del --route .behavior/A', () => {
    then('it exits 2 with the same ConstraintError, named for del');
    then('no daemon is signalled');              // a refusal on a destructive verb must not act
  });
});
```

## .the stdout, as a sketch

the `get` and `del` lines keep the extant prose of `route.reminder.ts`; `get` gains the focus.

```sh
$ rhx route.reminder.get
reminder is live — daemon pid 41123, focus .behavior/B

$ rhx route.reminder.del
reminder deregistered — live daemon stopped, handle cleared

$ rhx route.reminder.get --route .behavior/A
✋ ConstraintError: --route has no role on route.reminder.get
   ├─ why: one reminder per clone; it follows the route the clone drives
   └─ fix: drop --route, or pass --clone-addr <addr> to read another clone
```
