# case=2 — a top-up with no warrant is refused

feel: sharp · care: critipath

## .narrative

a driver has watched an urgent halt end in a self-served top-up. on the next stone, `mech-rules` runs dry on taste nitpicks, and the driver concedes them `better`. it reaches for the same top-up anyway.

the gate refuses it: no live urgent concession stands. the refusal names the moves that remain: fix what was conceded and pass, or grade a concern urgent if it names a real harm. the guard file is byte-identical, and exit is 2. the driver cannot buy a round with a wish to continue, so the halt that hands it the lever does not weaken the bound.
