wish =

a route whose stone gates on a peer review run via `rhx review.by --role learner --for term-application`.

this fixture exists to prove the integration between review.by and route.guard.review.peers — the
main consumer. the guard runs the learner's review.by wrapper with `--for`, which disintermediates
to the base review's stdout, so the guard captures a normal review and tallies off it.
