# domain.term.choice.reason: minutes

## .etymology
`minutes` is how the surf school books a lesson: a 60-minute or a 90-minute slot. chosen over
`duration` and `length`, which leave the unit unsaid, and `time`, which also names when the lesson
starts. the word carries its own unit, so the number beside it reads one way.

## .disputes
none.

## .evidence
- discovery: the surf school's quote — "a lesson's price is set by its minutes"
