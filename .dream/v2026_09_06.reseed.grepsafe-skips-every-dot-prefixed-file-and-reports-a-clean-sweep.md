# 🌙 dream: `grepsafe` skips every dot-prefixed file, and reports a clean sweep

- **kind** = reseed
- **owner** = `ehmpathy/rhachet-roles-ehmpathy` — `role=mechanic/skills/claude.tools/grepsafe.sh`
- **caught** = 2026-09-06

## .the cue that fired

a term sweep ran `rhx grepsafe --pattern 'fundamentalis' --path .agent` and returned 8 hits, exit 0.
**a ninth sat on disk** in `.agent/repo=.this/role=any/briefs/domain.terms/.readme.md:17`, and was
found only by a direct `Read` of that file, minutes later.

## .the gap, precisely

**`grepsafe` does not report a match inside a file whose name begins with `.`** — and it does not
say so. the sweep exits 0 with a partial result set.

isolated by a two-file fixture, 2026-09-06:

| the fixture | reported |
|---|---|
| `.agent/.notes/.probe/plain.md` — `ZQXB in a plain file` | yes |
| `.agent/.notes/.probe/.dotfile.md` — `ZQXB in a dotfile` | **no** |

two hypotheses were tested and refuted first, so the diagnosis is not a guess:

- **a line-length cap** — a fixture of 11 lines from 80 to 800 chars, each with the marker, reported
  all 11. the missed line was 380 chars / 390 bytes
- **a `.agent` → `dist` symlink** (`hazard.agent-brief-may-be-a-dist-symlink`) — `realpath` resolves
  inside the worktree, and `lstat` says it is not a link

⇒ the likely mechanism is ripgrep's default: an explicitly-passed search ROOT is descended, and
hidden FILES within it are skipped unless `--hidden` is set. the wrapper passes the root and not
the flag.

### the blast radius, measured against disk

**91 dot-prefixed markdown files in this repo are invisible to `grepsafe`.** the walk excluded
`node_modules`, `.git`, and `dist`.

the two that matter most are load-bear:

| file | what it is |
|---|---|
| `.agent/repo=.this/role=any/briefs/domain.terms/.readme.md` | **this repo's glossary census** — the gap table a term sweep exists to read |
| `.dream/.readme.md` | the dream queue's own contract |

plus ~60 `.behavior/*/.ref.[feedback].v1.[given].by_human.md` — every archived human feedback file
on every prior route, and ~25 `.readme.md` files under `thinker/`.

## 🟡 .why the silence is the defect, and not the skip

a skip that announced itself would be a scope choice a caller could correct. this one reports
`lines: 8` and exit 0, so:

> **a partial result and a complete one are the same screen.** a caller who greps for a term,
> reads 8 hits, and concludes *"that is the set"* is wrong and has no signal that they are.

⇒ that is `case=11`'s claim about a reviewer, reached on a different instrument: an unrun check
is indistinguishable from a clean one. and it is the third instance this route has measured of one
class — *an audit is evidence about its instrument until the instrument is verified*
(`.dream/v2026_09_05.enbrief.an-audit-is-evidence-about-its-instrument-until-the-instrument-is-verified.md`).

🟡 **the cost lands hardest on exactly the sweeps this repo runs most.** `rule.always.reuse-pavement-before-improvise`
names `grepsafe` as move 1 of the pavement check, and its own hazard note says a `0 matches` result
*"is indistinguishable from a genuine absence"*. that note bounds a `--glob` misuse. this is the
same failure from a second cause, and no note bounds it.

## .the shape of the fix

1. **pass `--hidden`** to the ripgrep call inside `grepsafe.sh`, and keep the extant `.gitignore`
   respect so `node_modules` and `dist` stay out
2. **or, if hidden files are meant to be out of scope, SAY SO in the output** — a `skipped: N hidden
   file(s)` line turns a silent partial into a stated one. that is the cheaper half and it closes
   the indistinguishability even if the default does not change
3. **clamp it** — a fixture test with one dot-prefixed file and one plain file, both with the same
   marker. it must go red under the current build (`rule.require.clamp-edge-cases`)

⇒ move 2 earns its place beside move 1, because a caller who passes an explicit `--path` into a
hidden tree has already declared intent, and the flag is all that reports whether it was honored.

## .why it is not done in this round

**safe? yes. clean? no — and it is not ours.**

`grepsafe` lives in `ehmpathy/rhachet-roles-ehmpathy`, a devDependency of this repo. per
`rule.always.scope-onetime-lessons-to-the-behavior`, a lesson whose home is another repo is
**re-seeded there, never adopted here** — a tree adopts only what is scoped to itself.

and the fix changes a tool every role in every consumer repo calls, so it wants that repo's own
clamp and its own release.

🟡 the probe that isolated it was deleted rather than kept, because it wrote a fixture into
`.agent/.notes/.probe/`. the fixture is reproducible from the table above in two files.

## .the fulcrum

> **a search tool that omits a file class without a word is not a slower search — it is a census
> instrument that reports a complete answer over an incomplete read.**
> rework: **clean** for the fix; the deferral is on OWNERSHIP, never on dirt.
