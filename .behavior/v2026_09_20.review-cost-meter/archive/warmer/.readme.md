# archive: the review cache warmer

a past attempt, retired 2026-10-14. kept for the record, never shipped from here — jest, tsc,
and biome all exclude `.behavior/`, so this code is inert.

## .what it was

a detached process, spawned after a review, that replayed the lane's prompt prefix on a timer
(a `poke` each ~15m, retired at +45m) so the next guard round would read it from cache.

## .why it was retired

it cost more than the most it could have saved. measured over 22 lanes on real guard rounds:
pokes cost $3.68, the 94 reviews that followed a warmed run saved at most $1.40, net -$2.28 — a
loss on 18 of 22. the pokes hit; the next round arrived 1h–3h later, past the window. the full
record is `research.review-cost-and-cache` ("the warmer on real guard rounds").

## .what survived

- the `poke` act, now sent once by a prime before a pour of partitions
  (`src/domain.operations/review/prime/poke/setOnePrefixPoke.ts`)
- `MINUTES_OF_CACHE_REACH`, which the meter's warm/cold lane grade reads

## .contents

- `src/` — the warmer's operations, tests, and snapshots, as they last stood
- `isReviewLanePrefixSuperseded.ts` — an orphan helper only the warmer read
- `briefs/` — the retired term clusters (`prompt.cache.warmer`, `.verdict`) and the `warmer`
  glyph axis
