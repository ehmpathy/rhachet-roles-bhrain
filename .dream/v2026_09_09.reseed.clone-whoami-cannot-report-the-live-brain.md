# 🌙 dream: `clone whoami` cannot report the live brain

**kind** = reseed · **owner** = `ehmpathy/rhachet` · **caught** 2026-09-09 ·
**status** = dispatched as `ehmpathy/rhachet#528`; ruled a todo 2026-09-13

## .the cue that fired

a prescribed brain per stone (`#377`) needs a driver to answer one question: **what brain do i run
under, right now?** no surface answers it.

## .the gap, precisely

`rhx clone whoami --output json` returns four fields, and no brain
(`rhachet/dist/contract/cli/invokeCloneWhoami.js:74-80`). `clone list` carries none either.

```json
{ "serial": "88412066-…", "slug": null, "reachState": "LIVE", "actorHash": "3fc30308" }
```

🟡 `slug` is nullable on a live, enrolled clone (measured 2026-09-13). `clone say` addresses
`@:<slug|serial>`, so both are first-class, but the payload does not say which is guaranteed. this
repo's applier read `slug` alone and would have refused every switch; `asCloneAddress` now reads
`slug ?? serial`. ⇒ a `brain` field beside a nullable `slug` inherits the trap unless its nullability
is declared.

what a caller can and cannot detect today:

| the refusal | `clone get` (the brain-cli's own transcript) | a live `brain` field |
|---|---|---|
| spoken — *"Unknown model: X"* | 🟡 caught for a peer; a self-read ties on a shared cwd and refuses (`#544`) | ✅ caught |
| silent — no word | 🔴 missed | ✅ caught |
| spoken, text drifts between releases | 🔴 missed, quietly | ✅ caught |

`clone say` proves **submit**, never **accept**: `delivered: true` means the transcript received
`/model <slug>` (`invokeCloneSay.js:107-123`).

## .the shape of the fix

`clone whoami` grows a `brain` field; `clone list` carries it per clone.

🟡 **the field must report the LIVE brain, never the one enroll launched with.** a `/model` typed by
hand moves the live brain and leaves the launch record stale. a launch-time field is strictly worse
than the shipped `clone get` for this caller.

⇒ if rhachet cannot observe the live brain, that is the honest answer to record.

## .why it is not done in this round

**home.** it is `ehmpathy/rhachet`'s contract, on its own cadence.

the wisher ruled it a todo, never a dependency:

> *"silent failure is fine for now. lets leave a todo to fix that once rhx whoami includes brain. it
> totally should."*

the silent corner costs no more than today: an undetected refusal leaves the stone on the inherited
brain, which is what every drive does without this feature. 🟡 the silent refusal is inferred, never
observed — the upstream ask says so.

⇒ fulcrum `F5`, ruled.
