# 🌙 dream: `clone whoami` cannot report the live brain

- **kind** = reseed
- **owner** = `ehmpathy/rhachet`
- **caught** = 2026-09-09

## .the cue that fired

the vision for a prescribed brain per stone (`ehmpathy/rhachet-roles-bhrain#377`) needs a driver to
answer one question: **what brain do i run under, right now?**

no surface answers it.

## .the gap, precisely

`rhx clone whoami --output json` returns four fields
(`rhachet/dist/contract/cli/invokeCloneWhoami.js:74-80`):

```json
{ "serial": "...", "slug": "...", "reachState": "LIVE", "actorHash": "..." }
```

**no brain.** and no other clone surface carries one — `clone list` groups by actor and reports
`serial`, `slug`, `reachState`, `spawnedAt`.

### 🔴 and `slug` is NULLABLE on a live clone — measured 2026-09-13

the shape above reads as though every field is populated. one is not:

```
$ rhx clone whoami --output json
{
  "serial": "88412066-5baa-47e3-b321-ea1b09ab3bf4",
  "slug": null,
  "reachState": "LIVE",
  "actorHash": "3fc30308"
}
```

⇒ **enrolled, reachable, and with no slug.** a caller that reads `slug` alone concludes *"not
enrolled"* about a clone that is plainly enrolled, and the conclusion is silent.

🟡 **the contract already anticipates this and the response shape does not advertise it.** `clone say`
declares its address as `@:<slug|serial>`, so both halves were first-class all along — but a reader
of the whoami payload cannot tell which field is guaranteed, and the obvious read picks the wrong one.

⇒ this bit **this route's own applier** (`setStoneBrain.ts`), which read `parsed.slug` and would have
refused every switch. the repair is `slug ?? serial`. worth a line in the upstream ask: a `brain`
field added beside a nullable `slug` inherits the same trap unless its nullability is declared.

⇒ the consequence is a real seam, and it is measured:

> **`clone say` proves SUBMIT, never ACCEPT.** `invokeCloneSay.js:107-123` polls the target's
> transcript until the message lands, then prints `delivered: true`. that proves the brain **submitted**
> `/model <slug>` — the brain-cli's own verdict on the slug comes back **in band**, in prose, in the
> transcript, and never reaches the caller.

so a caller that dispatches `/model claude-opus-5` into a clone gets a clean `delivered: true` when
the slug is rejected, and ~~has **no way to detect it**~~ — 🔴 **struck 2026-09-10.**

`rhx clone get @:<slug> --output json` reads the brain-cli's **own transcript** and returns
directioned messages (`invokeCloneGet.js:51-61` · `asCloneMessage.d.ts`). **the refusal that never
reaches the socket is on disk, and a caller can read it.**

⇒ so the caller has a way to detect a **spoken** refusal today. what it lacks is a read of the
brain's **state**, which is what a **silent** refusal — or a refusal whose text drifts — needs.

## .the shape of the fix

`clone whoami` grows a `brain` field, and `clone list` carries it per clone.

⚠️ **the design question that must be answered first:** does the field report the brain **enroll
launched with**, or the brain **live right now**?

they diverge exactly in the case that matters — a `/model` typed by hand, or dispatched by a
`clone say`, moves the live brain and leaves the launch record stale. a launch-time field would
answer the wrong question while it looked like the right one.

⇒ if rhachet cannot observe the live brain, that is the honest answer to record, and the caller needs
a different strategy. **a launch-time field labelled as a live one would be worse than no field.**

## .why it is not done in this round

**home.** it is `ehmpathy/rhachet`'s contract, on its own release cadence. a tree adopts only what is
scoped to itself.

## ~~🔴 .this is a dependency, not a nicety~~ → 🟡 it is an UPGRADE, and the ask is narrower

**re-graded 2026-09-10.** it read *"`#377`'s sharp critipath cannot be closed without it — the halt
has no fact to fire on."* **both clauses are false.** the halt fires on the refusal `clone get`
reads; what it lacks is a fact about the brain's **state**.

| the refusal | `clone get` | a `brain` field |
|---|---|---|
| spoken — the brain answers *"Unknown model: X"* | ✅ **caught today** | ✅ caught |
| **silent** — the brain declines with no word | 🔴 **missed** | ✅ caught |
| spoken, and the text drifts between releases | 🔴 **missed, quietly** | ✅ caught |

⇒ **so the ask is real and its scope changed.** it buys the two 🔴 rows rather than the whole check —
and a **launch-time** field buys neither of them, since it goes stale the moment a `/model` is typed.

🔴 **that sharpens the design question above rather than softens it.** a launch-time field is now
**strictly worse than the shipped `clone get`** for this caller: it answers a different question and
carries a staleness a transcript read does not. ⇒ **the field earns its cost only if it reports the
LIVE brain.**

⇒ recorded as fulcrum `F5` on
`.behavior/v2026_09_09.feat-prescribed-brain-per-stone/.fulcrums/`, confidence re-graded 70% → **45%**.
