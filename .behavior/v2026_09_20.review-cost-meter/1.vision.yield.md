# 1.vision.yield — the review prompt, priced AND tuned

## 🔴 .this work has TWO halves, and the instruments are the smaller one

the wish is **MEASURE → ATTRIBUTE → CHEAPEN**, in dependency order. the first two build
instruments; the third **changes the prompt** so it hits cache. a reader who takes this branch
for a metrics project has the smaller half.

| half | what it does | the bars |
|---|---|---|
| **measure + attribute** | build instruments that make the spend visible and per-input | 1–4, 8 |
| 🔴 **cheapen** | **tune `rhx review` itself** so its prompt reaches the cache | 5–7 |

⇒ the instruments exist **to serve the tune**. the 2.8% hit rate is the defect; the four
levers below are the repair; the meter is how we know a lever worked rather than merely
sounded right.

### the four levers that tune the prompt

each is a shipped change to what `rhx review` **sends**:

| # | the lever | the mechanism | measured |
|---|---|---|---|
| A | **the shared prefix leads, and is PINNED** | the static head (instructions + output format + rules + refs) goes first, byte-identical, and rides as the **system prompt** — because the affinity key derives from it, and a cache lives per-replica | 🔴 live: input `58,156` → `1`, cache.get `0` → `58,155` |
| B | **a new file's body is carried ONCE** | its `<target.diff>` and `<target.file>` are the same bytes — the diff is the body with a `+` per line. the diff is dropped | −792.7k chars, ~39.7% of the pre-lever prompt |
| C | **the corpus sorts by cache stability** | a repaired file sorts **last**, so the unchanged head of the target list stays byte-identical round over round | `getAllTargetsByCacheStability` |
| D | **the tail emits `target` then `conversation`** | so the shared prefix can reach *into* the target block rather than halt at its edge | +31.1pp on a 12-target corpus, 🔴 **−11.8pp on a 1-target one** |

⚠️ **A is the one that made the rest matter.** B, C, and D each shape the prefix; A is why a
request reaches the replica that holds it. a flawless prefix at the wrong desk cached **0.0%**.

🟡 **and two of the four ship ahead of their behavior evidence.** B and D are byte-argued and
behavior-unproven — caught as dreams with their A/Bs specified, never ridden along. ⇒ see
*"two levers shipped ahead of their evidence"*.

## .the outcome world

a driver finishes a stone and types `rhx review._.cost --of tree`. four seconds later they
know what their tree's reviews cost, how much came from cache, and which reviewer carried the
spend.

a wisher runs `--of grove` and gets the same picture across every tree on the machine — with a
census of how many runs could not be priced, stated beside the total rather than under it.

and every `rhx review` run writes a per-input census beside its output, so *"which input bought
this prompt?"* is read rather than estimated.

| | before | after |
|---|---|---|
| *"what did review cost?"* | unanswerable without a dashboard | `rhx review._.cost --of tree`, offline, no credential |
| *"across every tree?"* | unanswerable | `--of grove` |
| *"which input bought it?"* | unanswerable | nine named rows, each with its cache seam |
| *"which input, across a GROVE?"* | unanswerable | ✅ **answered 2026-09-22** — the by-input census on `--of grove`, with its `⚠️ UNATTRIBUTED` caveat |
| *"which input, across a TREE?"* | unanswerable | ✅ **answered** — the same by-input census on `--of tree`, one render shared with `--of grove` (`asPromptInputsCensusLines`) |
| *"does the cache work?"* | unanswerable | a share, with its denominator named |
| *"can we prove a lever worked?"* | no baseline | 🟡 **half** — `--trace`'s per-round cross-tab makes the step READABLE (2026-09-23); the live two-round measurement is still owed |

### the aha

**not `$151.92`. `2.8%`.**

a review prompt's static head — instructions, output format, rules, refs — is byte-identical
round over round by construction. a 2.8% cache hit rate against a prompt built that way is not
a fact about price. **it is a defect**, and the instrument turns a hunch into a claim somebody
can refute.

🟡 that figure is a **dated baseline** (2026-09-19), not a live reading. every use of it here
inherits that date. ⇒ `appendix/1.vision.groundwork.md`

the second aha is the one that genuinely surprised us:

> the prompt's layout was flawless and the hit rate was still **0.0%**, because the request
> never reached the replica that held the cache.

`briefs[]` was empty → the system prompt rendered `''` → `''` is falsy → no system message →
the affinity key was `null` → no `x-session-affinity` header → an arbitrary replica, every
time. **six hops, no buggy link, and the composition cached naught.**

### 🔴 the `agency` axis landed 2026-09-24, and the warmer is what made it visible

## .mental model

> *"it's an itemized receipt for the review bill. you can see which line bought what, and which
> lines we pay for twice."*

- **the itemized receipt** — the headline total is the least useful part. the value is the
  per-line attribution, and the line that says `other`
- **the shared prefix as a seat reservation** — the cache lives on the replica that served you,
  not in a shared pool. the affinity pin returns you to the same desk; a perfect prefix at the
  wrong desk is worth naught
- **the diff as a photocopy** — a new file's diff is its own body with a `+` on every line. we
  stapled the photocopy to the original and paid for both

### their words vs ours

| they say | we say | why ours |
|---|---|---|
| "the cached bit" | **shared prefix** | a byte prefix from token 0, not a bag of reused content |
| "the review cost" | **realized cost** | to part it from a declared or projected cost |
| "absent" | **`unknown`** | *"absent"* reads as absent-and-therefore-zero. `unknown` does not |
| "free" | **`refused`** | a true nil that is a FACT, never an absence |
| "every tree" | **grove** | `tree` is already ours; a grove is its container (`term=git.grove`) |
| "the rubric" | **rules** (glob) + **refs** | the guard's own vocabulary, so a lane cites guards verbatim |

## .evaluation

| desire | verdict |
|---|---|
| **1. measure** | ✅ every surface that ships reads a **measured** figure. the one that read an estimate had drifted, and is deleted (`F3`) |
| **2. attribute** | 🟡 ✅ at `run` breadth: **nine** named inputs, each with chars + count + cache seam, and **three** detectors — all of which run in the **shipped** path, never only under test. ✅ **and at `tree` and `grove`**: the same by-input census, summed, with an honesty caveat that names its denominator — one render at both breadths. 🔴 **absent as a series** — `chars × trace` at `tree` and `grove` stays unserved |
| **3. cheapen** | 🟡 **four levers shipped** (A–D above). the layout is clamped by BYTES, and the pin is proven LIVE against a real brain. 🔴 the grove-wide realized gain is **not yet measured**, and deliberately not claimed — a projection does not close bar 5 |

### pros

- every instrument reads **measured** figures; no rate card is applied to a total
- the honesty grade is first-class: `refused` (a fact) and `unknown` (an absence) never render alike
- one decision (`isTargetDiffSent`) is read by both the renderer and the `run` census, so they
  cannot disagree by construction rather than by vigilance
- the pin repair is verified against a **live brain**: input `58,156` → `1`, cache.get `0` →
  `58,155`, ~97% off the input spend

### cons

- 🔴 **`isTargetDiffSent` bound two of three call sites.** `review.corpus` re-derived the same
  decision and drifted — the exact defect the extraction was meant to make impossible, alive in
  the one surface nobody re-checked. the deletion removes the drift; **the lesson stands**: an
  extracted decision binds only the call sites someone remembered to wire
- 🔴 **three name defects shipped, and a glossary `grep` would have caught two.** `corpus` was
  already a forbidden synonym of `scope`; `fleet` broke the container pair `tree` had set. a
  new cli name is a contract, and no step checked it against `domain.terms/`
- the markup bound (`< 10%`) is a **heuristic**, not a proof. measured overhead runs ~1%, so
  the headroom is 10×, and a genuinely markup-heavy prompt would trip it falsely
- two shipped behaviors rest on byte counts with the behavior question open (the tail order,
  the new-file representation). both caught as dreams, not ridden along
- `review._.cost --of grove` walks the filesystem, so its figure is machine-local by construction

### edge cases, and the pit of success

| edge case | the guardrail |
|---|---|
| a run with no cost record | graded `unknown`, excluded from sums, rendered **absent** |
| a brain that truly charged nil | graded `refused`, renders `$0` — a distinct grade |
| 🔴 a run whose megabyte prompt was PRUNED for disk | still `unknown` — `refused` needs **two** witnesses, and a warmer file proves the brain was reached (`getOneReviewRunGrade`) |
| 🔴 a warmer poke that TIMED OUT, and may have billed | counted as a `fault` beside `cost`, never inside it — the warmer's spend renders as a **FLOOR**, and a fault forfeits the *"protected for free"* claim outright |
| 🔴 a review a guard drove through the `review.by` WRAPPER | the warmer declines, and the stdout states **why it could not know** (`no lane identity`) rather than a claim that no guard ran — which is false there, and was |
| a prompt input added with no row | the markup share trips; clamp **proven red** first |
| a diff counted but not rendered | one shared decision; the residual goes negative if they diverge |
| a lane whose glob matches no file | counted as a broken glob and reported, never dropped |
| a deleted target | renders a lone void tag; no diff, no content, no crash |
| an absent log dir | says so plainly, names the fix, exits **2** — a constraint, and never a **1**, because an absent log is not a malfunction. 🔴 this row read `exits 0` until 2026-09-25; the reason was always about **1**, and only a two-code world makes `0` the way to say it (`case=1 [t1]` carries the argument) |

## .open questions & assumptions

### assumptions made

1. **`metrics.realized.json` is trustworthy where present** — the meter grades its absence but
   does not re-derive its contents from the raw response
2. **the markup bound at 10% is generous enough** — measured overhead is ~1%
3. **the affinity key stays derived from the system prompt** — a provider implementation
   detail, not a contract they publish
4. **a shared prefix must be LARGE to pay** — ~5,800 tokens returned `cache.get: 0`; 58k hit at
   99.998%. the minimum is unpublished
5. **filesystem walk is the right membership rule for a grove**

### `[answered]`

- **does the pin work?** → **yes**, measured live

### the markup bound is a heuristic dressed as an invariant

`< 10%` reads like a law and is a measured guess. it is the **only** detector for an
unattributed input, so the whole exhaustiveness claim rests on a threshold nobody derived. 10×
headroom and a clamp proven red is honest mitigation — and it is mitigation, not proof.

🔴 **and this section once declared that gap at the WRONG GRAIN**, which is the failure a reader
cannot catch from the declaration. it graded the *threshold's* rigor — true — and from that
concluded the honest disposition was to declare the limit and ship. but a bound's **rigor** and
a detector's **reach** are two different quantities, and only the first was examined:
