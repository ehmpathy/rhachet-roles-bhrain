## .settled

a cache read is not a fixed fraction of input across models: it is 0.05× on opus 5.5 and sonnet
5.5, 0.1× on prior models. so every rate is read per model from its spec, never derived from the
input rate. at the cheaper read, cache writes can outweigh re-reads in price, which is why price
leads the rank.
