# case=8: a mod rhachet refuses holds graduation

inventory row: d6. feel: sharp. care: critipath — a refused mod blocks every actor that carries the role, and no fallback restores the role's boot but a hand repair. if this path broke (graduation passed over a refused mod), every mechanic session after it would fail to boot.

## .narrative

at `4.2.entool.execute` the student writes `briefs/rule.require.idempotency-key-at-external-boundaries.md` and its `.min` into the mechanic mod, and a second brief, `briefs/howto.replay-a-consumer-in-vitro.md`. it names the first in the mod `boot.yml` under `briefs.say`, and forgets the second.

at `4.graduate` it runs `education.pedigree set`, then `rhx init --hooks`. rhachet refuses the mod at once, and names the fix:

```
✋ ConstraintError: the mod of role=mechanic is refused: it holds briefs/howto.replay-a-consumer-in-vitro.md, a path the role does not hold, and no say or ref names it
   ├─ mod: .agent/repo=.mods/role=mechanic/
   └─ fix: to add, say it in the mod boot.yml (briefs.say: [briefs/howto.replay-a-consumer-in-vitro.md])
```

the student signals `--as passed` anyway. the guard holds, since the render did not exit clean:

```
✋ ConstraintError: 4.graduate holds: the mechanic mod does not render clean
   ├─ render: rhx init --hooks exited 2
   ├─ refusal: briefs/howto.replay-a-consumer-in-vitro.md is named by no say or ref
   └─ fix: name it in .agent/repo=.mods/role=mechanic/boot.yml, then rhx init --hooks
```

the student adds the line, re-renders clean, and passes. no mechanic session ever boots against the refused mod: the course does not graduate until the render is clean.

## .bdd sketch

```
given a course at 4.graduate whose mod holds a brief no say or ref names
  when [t0] the student runs education.pedigree set, then rhx init --hooks
    then the render exits 2
    then stderr opens with ✋ ConstraintError, names the unnamed path, and names the say line to add
  when [t1] the student signals 4.graduate --as passed
    then passage is refused
    then the refusal names the render failure, the path, and the fix
  when [t2] the student names the brief in the mod boot.yml, re-runs rhx init --hooks, then --as passed
    then the render exits clean
    then passage clears
```

the same fail-safe covers each refusal rhachet raises for a mod (an orphan `.md.min`, an add the role's own `not` drops): the render names it, and graduation holds until it clears.
