# case=2 · the yield arrives in one pass

**cell** = `author · brief · happy · complete · file`
**feel** = happy · **care** = critipath (`freq` = every stone that emits a yield · `cost` = a 35x amplification that overflows four reviewers)
**issues** = #415 · #416 · #417 · #418 · #419

## .the narrative

the author reaches `1.vision` and owes a yield. before the first line, it already knows the shape — telepath's canon booted with it, and it reads four constraints off its own context rather than off a style guide:

| what it knows | so it will not |
|---|---|
| the shape is `.what` + `.why` bullets | reach for a story |
| one sentence per bullet | fuse two claims with a `;` |
| the claim stays, the argument refs out | inline the argument |
| a `.why` states a present constraint | open with a hypothetical |

it types a `.why` — and stops itself mid-sentence:

> *"without the reviewer, a driver would append forever and the subject would grow"*

🟡 the catch is the experience, and it is a small unpleasant one. the sentence was true, it read well, and it was already half-written. the author has to delete a clause it liked. it restates the same fact in the present:

> *"an append is locally correct, so a per-edit check passes it"*

the second choice is the one that costs it more. it has a measured table it is proud of, and the shape rule says a measurement carries a time axis. the cheap move is to delete it and stay under the line.

⇒ instead it rehomes it — the table moves to `case=4`, a `.refs` line stays behind. **the author pays an extra file to keep evidence it could have quietly dropped**, and that is the whole difference between a terse artifact and a thin one.

it stops at 180 lines. what it notices is not the length — it is that it never re-read its own draft to find the cut. the constraints arrived before the prose did, so there was no second pass to make.

## .the bdd timeline

```
given [case2] a driver whose boot carries telepath's file-half canon
  and  a stone that demands a yield

when  [t0] the author writes a `.why` bullet
then       the bullet holds one sentence
 and       it carries no `;` and no `, and` that fuses two claims
 and       it wraps to no second line

when  [t1] the author writes `without this, X would happen`
then       `forbid.roundabouts` names it a hypothetical
 and       the author restates the present constraint direct

when  [t2] the author holds a dated measurement it wants to keep
then       it is NOT deleted
 and       it is rehomed to a `.demo=` or `case=N` peer file
 and       the parent cites that file by name in `.refs`

when  [t3] the author holds an argument too deep for a bullet
then       the claim stays in the parent as one bullet
 and       the argument goes to a brief, cited by `.refs`
 and       no inline expansion is written

when  [t4] the yield is complete
then       it states the outcome, never the path taken to it
 and       every decision is declared exactly once
```

## .the #417 reconciliation, applied

## .the success measure

`git diff --stat` on a densification pass, per #415:

| insert/delete ratio | verdict |
|---|---|
| near 1.0 | prose rewritten as prose. the pass did no work |
| under 0.6 | more deleted than written — a densification |
| near 0 | a measurement may have been cut. re-check the rehome |

🟡 **the ratio alone is not a bar.** #418 adds the clamp it omitted: `≤ 55% comment` **and** `≤ 250 lines` for a phase file; `≤ 40 comment lines` for a dispatcher. a ratio alone lets a 900-line file pass by growth of its code.
