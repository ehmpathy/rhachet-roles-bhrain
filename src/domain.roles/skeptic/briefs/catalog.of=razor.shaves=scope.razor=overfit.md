# razor: overfit

shaves: a claim at the wrong level (a case stated as a law) · settled by: observation (reads held apart before the claim was formed)

## .the question

> **was this claim fitted to the reads it now cites, and did it meet any read it was not fitted to?**

the reads that shaped a claim cannot also test it. a lesson drawn from one run and "confirmed" by the same run is untested.

## .the source

- statistics, no single author: an analysis that "corresponds too closely or exactly to a particular set of data", which may fail on new data
- "the optimal function usually needs verification on bigger or completely new datasets"
- read via the Wikipedia page on overfit (`guess:` the page summary only)

## .fails when

- no fresh reads exist. say so, and mark the claim a first case
- a hold-out reused many times becomes a train set (`guess:` not read at the page)
- overlaps `razor=popper` (was the refuter run) and `razor=feynman` (a test set before the look)
