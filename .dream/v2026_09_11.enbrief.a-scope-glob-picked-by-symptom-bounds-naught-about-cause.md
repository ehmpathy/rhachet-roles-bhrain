# 🌙 dream: a scope glob picked by SYMPTOM bounds naught about CAUSE

- **kind** = enbrief
- **owner** = `rhachet-roles-bhrain` — learner (a peer of `rule.require.enumerate-before-you-name`)
- **caught** = 2026-09-11

## .the cue that fired

a yield claimed *"eight moved snapshots, and it is a **measured** bound rather than an arithmetic
one"* — and named the measurement: `path://driver.route.peer`, **694 passed across 37 files**, every
one of the 36 frozen snapshots exercised.

**the first full-suite run then moved 15 more**, in six suites the glob never matched.

## .the gap, precisely

the glob was chosen because the **frozen snapshots** live under `driver.route.peer*`. the defect
under bound was a **render** — `genContextCliEmit` + `formatGuardReviewerTree`, which every guard
surface in the repo goes through.

| the question | the answer that was measured | the answer that was needed |
|---|---|---|
| where do the snapshots I promised not to move live? | `path://driver.route.peer` — 37 files | ✅ correct, and it was the wrong question |
| where does the code I changed get rendered? | **unmeasured** | 120 files — every acceptance suite that prints a guard tree |

⇒ **40 of 120 files measured, reported as a bound over the change.** the six suites that moved carry
no `peer` in their name: `driver.route.overrule` · `failsafe` · `malfunction` ·
`conversation-visibility` · `review.by.guard-peer` · `routeStoneSetContemplation`.

🔴 **and the failure is quiet in a specific way: the measurement was real.** 694 tests genuinely
passed over 37 real files. so the claim is *"a measurement"* by every ordinary standard, and it
survives every re-read — the number is true and the set it ranges over is the wrong set.

## .why the extant repairs do not catch it

| the extant rule | what it grades | why it passes this |
|---|---|---|
| `rule.forbid.absolutes` | a quantifier over an unwalked set | 🔴 the set **was** walked. 37 files, 694 tests |
| `rule.require.disputable-claims` | a claim with no named settler | the settler was named, and run |
| `…census-claim-is-verified-against-disk` (dream) | a count that disagrees with an inventory on disk | no inventory here — the subject is a **test scope**, and the counts agreed |
| `rule.require.enumerate-before-you-name` | a term proposed against one instance | no term is coined here |

⇒ every one of these asks *"did you measure?"*. **not one asks *"did you measure over the set your
CHANGE ranges over?"*** — which is the question, and it is a different question.

## .the shape of the fix

a rule, or a clause on `rule.forbid.absolutes`, whose test is a **two-set comparison**:

> **name the set your CHANGE ranges over. name the set you MEASURED. are they the same set?**

- same → the bound is measured
- the measured set is **smaller** → 🔴 the bound is an **inference**, and must say so
- you cannot name the change's set → that is the work, and it precedes the measurement

and the cue that fires it:

| when… | then… |
|---|---|
| you scope a test run by a glob, then state a bound from its result | 🔴 ask what the glob was chosen for. a glob picked for the **symptom** bounds naught about the **cause** |
| what you changed is shared — a renderer, a formatter, a parser | its blast radius is every caller, never the caller you had in view |
| you write *"a **measured** bound rather than an arithmetic one"* | the sharpest cue. a measurement over a subset is arithmetic dressed as a measurement |
| a scoped suite is green and you have not run the full one | the green is about the scope, never about the change |

🟡 **the mechanical check, where one exists:** the set a render change ranges over is the set of
files whose snapshots contain the render. that is a `grepsafe` over `__snapshots__`, and it costs
one call — against the 8482s the full suite cost to reach the same answer.

## .why it is not done in this round

**safe: yes. clean: no.**

- it amends the learner's or telepath's booted canon, and this behavior's declared scope is
  `runStoneGuardReviews` + the guard render — an edit to a published rule ripples into every role
  that boots it
- the honest fix owes a **sweep**: this yield is not the only artifact that states a bound from a
  scoped run, and that audit is dirty inside a stone that still awaits approval
- ⇒ the local instance **is** repaired — the yield now carries the corrected count (23), the six
  suites, and the reason the first bound was false, in the section that made the claim
