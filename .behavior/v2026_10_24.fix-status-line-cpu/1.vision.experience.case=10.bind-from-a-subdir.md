# case=10 — a bind set from a subdir shows at the root seat (sharp · critipath)

## .narrative

an operator stands in `src/` and runs `rhx route.bind.set --route .behavior/v…`. their claude seat
sits at the git root and its cache says "unbound", fresh, for up to 30s more. the bind drops that
root cache, never a cache under `src/`, since every cache anchors at the git root the seat reads.
so the next repaint at the root misses, finds the new flag, and shows the stone at once, not 30s
later.

## .bdd sketch

```
given('[case10] an unbound seat at the git root, its cache warm')
  when('[t0] a route is bound from a subdir of the repo')
    then('the root cache is dropped')
    then('the next repaint at the root renders the bound route')
```
