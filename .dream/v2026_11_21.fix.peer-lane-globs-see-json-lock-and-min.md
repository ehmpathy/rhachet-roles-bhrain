## .the gap, precisely

## .the shape of the fix

widen the default lane glob in the route template to include `*.min`, `package.json`, and `*.yml`, and exclude lockfiles by the polluter list (`rule.require.exclude-review-scope-polluters`) rather than by omission. clamp: a template test that a `.md.min` edit appears in the lane's scope.

## .why it is not done in this round

it is a template change for every route, outside this wish, and it moves review scope for every lane in flight.
