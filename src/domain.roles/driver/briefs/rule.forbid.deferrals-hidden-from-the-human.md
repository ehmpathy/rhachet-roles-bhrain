# rule.forbid.deferrals-hidden-from-the-human

> **never let a deferral sit where the human's gate does not name it.** a disputed or held concern is
> a named line in the halt, never a row in a list the gate counts as answered.

the forbid twin of `rule.require.deferrals-accrue-in-the-blocker-list`. the law:
`define.invariant.review.peer.dispute.deferrals-accrue-where-the-human-reads`.

## .the shapes it forbids

```
👎  a dispute backed by a fulcrum with no frontmatter       # the halt cannot read it, so it cannot name it
👎  a 400-row rename table held at one 0.90 confidence      # the weakest row was 0.55; the average hid it
👎  a deferral written into the yield and no fulcrum        # the halt derives from frontmatter, not prose
👎  an unreadable fulcrum skipped to keep the halt short    # a silent skip is the incident rebuilt
👎  an `owed: human` dispute dropped because no gate came   # the debt rides to a gate, or the last stone refuses
👍  a fulcrum with frontmatter; the halt names it by case, concerns held, confidence, lean
```

## .the cue

| when… | then… |
|---|---|
| you write a fulcrum with prose and no frontmatter | 🔴 the stop holds. add the block |
| you type `confidence` as the mean of the rows | set it to the weakest row |
| you grade 0.91 only to skip the human | the reflection costs a real upstream issue with a named rule. if you cannot name one, the call is not a misread, so it owes the human |
| you edit `verdict` in a fulcrum yourself | 🔴 only `rhx route.fulcrum.rule` writes it, and a human runs it. a forged verdict holds the stop |
| you tell the human in chat that a dispute stands | not enough. the halt names it, or it is hidden |
| a gate halts and lists no deferral where you know one stands | stop. a fulcrum is absent or unreadable. repair it before the human reads |

blocker: a deferral the gate does not name · a fulcrum a halt skips · a `verdict` written by a
driver · a dirty-ground dispute graded to reflect in order to avoid the human · an `owed: human`
dispute dropped at the end of a route.
nitpick: a `lean` so vague that the halt line gives the human no direction.
