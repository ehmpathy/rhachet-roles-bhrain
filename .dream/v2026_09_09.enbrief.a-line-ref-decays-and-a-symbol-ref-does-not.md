# 🌙 dream: a brief owes a rule that line-number citations decay, and symbol citations do not

**kind** — `enbrief` · **owner** — `rhachet-roles-bhrain` · **caught** 2026-09-09

## .the cue that fired

a vision artifact carried a research table whose first sentence was:

> *"every line reference below was **read in the current tree**, not inherited. the prior
> perspective's refs were weeks stale and several had moved."*

**one upstream rebase invalidated roughly a third of that table.** the sentence that boasted of
freshness became, verbatim, a description of its own defect.

⚠️ **the cue is the boast, not the staleness.** an author who writes *"I verified these"* has just
recorded the moment of verification as though it were a durable property. it is not — it is a
timestamp, and every ref beneath it now carries an expiry nobody wrote down.

## .the gap, precisely

a citation's job is to let a reader **dereference a claim**. two forms are available, and this repo
has no rule that parts them:

| form | survives a rewrite? | fails how? |
|---|---|---|
| `runStoneGuardReviews.ts:371` | ❌ **no** | 🔴 **silently, and WORSE than a broken link** — the line still exists and now says otherwise |
| `runStoneGuardReviews.ts` — `wasExhausted` | ✅ yes | loudly — a grep returns naught, and the reader knows at once |

🔴 **the asymmetry is the whole argument.** a stale symbol ref **cannot be misread**; the symbol is
either there or it is not. a stale line ref points at *real code that is not the code the claim was
about*, and a reader who follows it gets a confident wrong answer.

⚠️ **and it degrades a citation into an anti-citation.** an uncited claim makes a reader skeptical.
a claim cited to the wrong line makes them **credulous** — they check, they see code, they move on.

**measured here, 2026-09-09.** `runStoneGuardReviews.ts` was rewritten by 160 lines. every one of
these moved:

| the claim | old | new |
|---|---|---|
| the exhaustion predicate | `:371` | `:397` |
| `computeVerdicts` | `:356-386` | `:375-412` |
| the default timeout | `:71` | `:74` |
| the index assignment | `:329-337` | `:347` |
| the serial await | `:581` | `:624` |
| the emit points | five | 🔴 **six** — a count, not a line, and it still drifted |

⇒ **and one ref did not merely move — its FILE was deleted.** `getLatestReviewArtifactForIndex.ts`
became `…ForSlug.ts`. that one failed loudly, which is exactly the point: it was the only stale ref
in the set that announced itself.

## .the shape of the fix

a rule under the learner or the librarian — provisionally
`rule.prefer.cite-a-symbol-over-a-line-number`:

- **the claim** — cite the smallest **named** anchor that isolates the claim: a function, a const, a
  type, a test name, a docblock phrase. add a line number only where no symbol isolates it, and mark
  it as a courtesy rather than the anchor
- **the why** — a line ref decays **silently into a wrong answer**; a symbol ref decays **loudly
  into no answer**. prefer the failure a reader can see
- **the test** — *"if someone inserted twenty lines above this, would my citation still be true?"*
  no → it is a line ref, and it is owed a symbol
- **the carve-out** — a **snapshot** or a **fixture** is legitimately line-addressed, because the
  file is generated and its shape is the artifact
- **enforcement** — a line ref where a symbol was available = nitpick · a line ref used as the
  **sole evidence** for a load-bearing claim = blocker

⚠️ **it should also name the boast as a smell.** *"verified in the current tree"* is a claim with a
shelf life, and a doc that states it without a symbol anchor has recorded its own expiry with no
date attached.

## .why it is not done in this round

**safe?** yes. **clean?** 🔴 **no.**

it wants a new rule brief plus its `.min`, wired into a role's `boot.yml` — and the honest version
also wants a sweep of the extant corpus, which is repo-wide and far past this wish's diff. this
round's own repair (re-anchor one table) is in scope and is done; the **rule** is not.

⇒ per `rule.always.fix-forward-under-scouts-honor`, the in-scope half landed and the dirty half is
caught here.
