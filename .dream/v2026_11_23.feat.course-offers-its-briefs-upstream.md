# 🌙 dream: a course offers its briefs upstream, to the role's own package

- kind: feat
- owner: learner (rhachet-roles-bhrain)
- caught 2026-11-23

## .the cue that fired

the education suite vision lands a published role's course output in a repo-local rhachet mod (`.agent/repo=.mods/role=$role/`). the question arose whether a course should also offer those briefs to the role's own package, and it was out of scope.

## .the gap, precisely

a course's briefs reach only the repo that ran it. a lesson every repo needs (e.g. an idempotency rule for `ehmpathy/mechanic`) stays local; the next repo re-runs the course or goes without.

## .the shape of the fix

after `4.graduate`, an optional `5.offer` stone: for each brief the course added, `rhx radio.task.push --via gh.issues --into <role's package repo>` with the brief, its pedigree entry, and its citations, so the role's owner can adopt it upstream. the pedigree entry records the task exid.

## .why it is not done in this round

no done-line of the wish asks for it; the wish bounds this pr to medium size; and upstream adoption is the role owner's call, not the course's.
