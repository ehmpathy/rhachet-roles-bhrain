# case 2 — an untracked order reds the stop (clamp 1)

feel: sharp · care: critipath · actor: achiever · seams: talk hook, store, stop hook

## .narrative

the achiever is mid-work on a goal. the commander adds: "also rename the flag to --hour." the talk hook
records the message. the achiever, eager, does the rename at once and forgets the first goal's last
step. it also never sets a goal for the rename. it tries to stop.

the stop hook refuses, loud, with exit 2. it names the uncovered ask in the commander's own words and
the command to cover it. the achiever covers it, finishes both, and stops clean. the drop cost one hook
turn, not a commander turn.

## .[tn] — a sketch

```
given  an open goal, inflight
when   [t0] the commander submits a second order
then     the talk hook appends it to the inventory; no goal covers it
when   [t1] the achiever stops
then     goal.triage.infer --when hook.onStop exits 2
     and stderr reads:
           🦉 to forget an ask is to break a promise. remember.

           💎 goal.triage.infer --when hook.onStop
              ├─ uncovered asks = 1
              │  └─ "also rename the flag to --hour" ($hash)
              │
              └─ halted, triage required
                 └─ rhx goal.memory.set --slug $new --covers $hash
     (the extant render prints the count only, goal.ts:1408; the ask's words and hash are the change)
when   [t2] the ask is covered and both goals close by their checks
then     the stop passes
```

## .the clamp

an integration test writes an ask to the inventory, sets no goal, runs the onStop hook, and expects
exit 2. revert the onStop wire → the test goes green → it does not bite → so it must fail red.
