# rule.always.question-your-first-take

> **a claim is a hypothesis until a read tries to break it. this rule names the read owed per kind of claim, and why a correction owes more, not less.**

the move itself (counter-take, then one read that could break it) is `rule.always.trust-no-one-especially-not-yourself`. this rule is its table and its after-a-correction step, with the five cases of ehmpathy/rhachet-roles-bhrain#834.

## .the read owed per kind of claim

| the claim | the read owed first |
|---|---|
| a question to a peer | the read that answers it; if one exists, the question is yours to answer (`rule.always.skeptic-questions-all-questions`) |
| a step handed to a peer | the fact on the box that lets a tool take it; a hand step claims no such fact exists |
| a claim about how the system works | the code or brief that would refute it |
| a tool's fix-text, to relay | the seat, env, and path the tool assumed, against the one you stand on |
| a design that proves a peer is present | a tty, a prompt, or a pty proves no one is there |
| a place for a new artifact | the index that maps where its subject lives |

## .after a correction

the next claim owes more, never less:

1. name why the prior claim passed your check
2. name the read that would have caught it
3. run that read on the new claim before it leaves

## .the test

> **which read, owed by this kind of claim, did I run?**

## .enforcement

blocker: a corrected claim shipped with no new read behind it
nitpick: a claim of a kind in the table shipped with its owed read unrun

see also, the five cases:
- `….example=a-fix-text-for-another-seat.md`: a credential fix relayed for a box that never holds it
- `….example=a-claim-about-how-the-box-gets-its-code.md`: a false dependency on a merge to main
- `….example=a-hand-step-the-box-could-answer.md`: a table, a skill, and a tty check for what the token already said
- `….example=a-correction-shipped-untested.md`: the corrected claim, retracted one reply later
- `….example=a-brief-filed-by-reflex.md`: the rule itself, filed in the wrong cluster

forbid twin: `rule.forbid.first-thoughts-shipped-unquestioned`
