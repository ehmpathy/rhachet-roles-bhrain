## .the shape of the fix

🔴 **the grep is NOT the fix**, and this is the trap. `rhx grepsafe --pattern 'NEUTERED|TEMP|XXX'`
finds a proof whose author left a marker, and is blind to one who did not — the exact
citation-convention false negative `i015` already recorded against itself. a marker sweep would
report clean and mean naught.

the two honest options:

### A — make the strict gate the DEFAULT gate

`--what types` runs a looser tsconfig than `npm run build`. align it (or add
`allowUnreachableCode: false` to the dev config) so the cheap gate an author actually runs sees
what the build sees.

- ✅ cheap, and it would have caught THIS instance at the author's keyboard
- 🔴 it only covers the unreachable-code shape — one row of the five above

### B — a bite proof is a declared, expiring act

give the discipline an artifact: a proof is written as a marked edit, and a check refuses a commit
that still holds one.

- ✅ covers every shape, because it keys on the DECLARATION rather than the code shape
- 🔴 it only binds an author who declares — which is the same blindness as the grep, moved
- 🟡 ⇒ so B is worth a build **only** with A beneath it: A catches the un-declared common case, B
  catches the declared-and-forgotten one

⇒ **do A first.** it is a config line, it is verifiable against this very incident, and it makes
the cheap gate honest. B is a process change and wants the wisher.

## .why it is not done in this round

**SAFE, and not CLEAN.**

- ✅ **safe** — A is strictly more-strict: it can refuse code the build would have refused anyway,
  and can never accept code the build rejects
- 🔴 **not clean** — `tsconfig.json` governs every suite and every author in this repo. a strictness
  flip is a repo-wide gate change that will surface unrelated reds in files this branch never
  touched, inside a diff about review cost. that is the scope leak
  `rule.require.review-test-changes` forbids
- 🟡 **and its blast radius is unmeasured.** the honest first step is to *count* what
  `allowUnreachableCode: false` reds today, and that count is the dream's first task rather than a
  figure to guess at here
