# case 1: a tree without the guard works on

rows 1, 6, 9, 17, 19, 20.

## .narrative

a crew boots in a repo whose committed settings carry the learner's hook, but the learner is not linked here, and the repo may not even install rhx locally. the crew runs `ls`, then writes `src/a.ts`, then edits it. each call goes through. each one leaves a `memory.guard hook error` notice for the human: the guard could not run, the call was allowed, and here is the command that links it. the crew never stalls.

in the next tree over, the learner is linked but there is no `node_modules/.bin/rhx`. the crew's `ls`, `echo x > out.txt`, `cp a.md b.md`, Write and Edit all pass in silence — the guard ran, judged each call, and found no memory write.

## .bdd sketch

```
given a tree with the learner hook in settings and no learner link
  when [t0] a Bash `ls` fires the hook
    then the call proceeds (exit 1, a non-block notice)
    then stderr is one line:
      📜 memory.guard: could not run (skill not linked in this tree); call allowed. fix: npx rhachet roles link --repo bhrain --role learner
  when [t1] a Write to src/a.ts fires the hook
    then the call proceeds; stderr is the same one line
  when [t2] an Edit to src/a.ts fires the hook
    then the call proceeds; stderr is the same one line

given a tree with the learner linked and no node_modules/.bin/rhx
  when [t0] Bash `ls` fires the hook
    then exit 0, silent
  when [t1] Bash `echo x > out.txt`, then `cp a.md b.md`
    then exit 0, silent
  when [t2] a Write, then an Edit, of src/a.ts
    then exit 0, silent
```
