## .what

the reflector in `ehmpathy/rhachet-roles-bhrain` can read any claude transcript on the machine and
report where its tokens went — the full ask is ehmpathy/rhachet-roles-bhrain#532.

## .the outcome

- **efficiency:** tokens in and out, cache read vs cache write, and the context re-paid per turn
- **inventory:** what the tokens were spent ON, per category, each as a share of the whole
- a proposal of what to compress, ranked by the share it would save
- it works on any transcript on the machine, not only the current session

## .why now

clones re-pay large contexts every turn, and no instrument says which part of that spend is
waste — so no compression can be ranked by what it saves.
