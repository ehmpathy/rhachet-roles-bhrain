# razor: occam

shaves: a cause among rivals · settled by: rivals

## .the question

> **which parts does this explanation assume that a rival would not need?**

a tie-break only among rivals that fit the same reads equally. it never picks a rival that fits fewer reads.

## .the source

- William of Ockham, c. 1317-23, *Sentences*: "Pluralitas non est ponenda sine necessitate"; *Summa Logicae* i.12: "Frustra fit per plura quod potest fieri per pauciora"
- "entities must not be multiplied beyond necessity" is absent from his extant works; it traces to John Punch (`guess:` 1639)
- the name "razor": Froidmont, 1649
- read via https://en.wikipedia.org/wiki/Occam%27s_razor

## .fails when

- the simpler rival fits fewer reads: run `razor=anti-razor`
- several causes hold at once: run `razor=hickam`
- a rescue can always be built, however complex (Crabtree's bludgeon, R. V. Jones)
