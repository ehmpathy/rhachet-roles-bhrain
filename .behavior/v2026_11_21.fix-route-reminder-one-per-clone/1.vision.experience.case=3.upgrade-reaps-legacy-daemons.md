# case=3 — the upgrade reaps legacy daemons

inventory rows: r6 (happy, `[case3]`), r6b (sharp, `[case3b]`), r24 (happy, `[case3c]`). care: critipath (r6, r6b), alterpath (r24). the clean reap is the happy path; the fail-safe lives in `[case3b]`; `[case3c]` shows that the del arm leaves the sweep alone.

## .narrative

a seat upgrades bhrain while two old daemons run, one per route, each with a handle at `<root>/<route>/.route/daemon.of=reminder-driveon.session=<token>.pid`, where `<root>` is `.behavior` or `.route`. those processes run the old code and know naught of the clone handle.

the first drive after the upgrade that must spawn does two things before its spawn: it reads `.behavior/*/.route/` and `.route/*/.route/` at depth one for this token's pid file, stops each live pid it names, and removes each handle by compare-and-delete. then it spawns into the clone handle. one daemon remains. the reap writes one line per legacy pid into the clone's reminder log, so a human who wonders where the old daemons went can read it. a findsert hit spawns naught and sweeps naught.

if this sweep did not run, the two old daemons would nudge until their own routes died — the same double poke, a day later.

the sharp edge: a legacy handle names a pid that is alive but not ours (pid reuse → `EPERM`). the reap must not crash the drive and must not hide the fault. it surfaces the fault to the reminder log through the extant `surfaceRouteReminderFault`, leaves that handle in place, and the drive proceeds. the line names the pid and the manual fix.

## .[tn] sketch

```ts
given('[case3] two legacy per-route handles for this clone, both pids live', () => {
  when('[t0] the clone drives B', () => {
    then('each legacy pid receives SIGTERM');
    then('each legacy handle is removed');
    then('one clone handle exists');
    then('a handle of ANOTHER clone under the same route is untouched');
    then('the reminder log holds one reap line per legacy pid');
  });
  when('[t1] the clone drives again', () => {
    then('the sweep finds naught and reaps naught');   // idempotent
  });
});

given('[case3b] a legacy handle names a live pid we may not signal (EPERM)', () => {
  when('[t0] the clone drives', () => {
    then('the drive completes; the reminder sync is not the halt');
    then('the reminder log names the pid and the fix: kill <pid> by hand, then route.reminder.gen');
    then('that legacy handle stays; the others are reaped');
  });
});

given('[case3c] legacy handles live, and the focus route B is blocked', () => {
  when('[t0] the clone drives B', () => {
    then('synced = deregistered; no clone daemon spawns');
    then('the del arm sweeps naught: each legacy pid and handle is left');   // a hook each turn must not walk every route
    then('each legacy daemon exits through its own doors, or the next spawn or del reaps it');
  });
});
```
