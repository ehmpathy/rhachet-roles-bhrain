# case=7 — a warmer spends while nobody watches

- cell: `agency=engine × breadth=run × quantity=cost × intent=defend`
- feel × care: sharp × criti
- added when the wisher settled that a guard warms its own review caches

## .the narrative

a driver runs `rhx review` on a guard round. eleven lanes pour, the verdicts land, the process
exits, and the driver goes to read the feedback.

**the process exits, but its spend does not.** behind it, a detached warmer wakes every 15
minutes and pokes each lane whose budget has rounds left. three pokes, eleven lanes,
thirty-three calls — against an api, with a credential, on a clock nobody set and nobody can
see.

that is the good path. now the driver closes the laptop lid and takes the afternoon off. the
route is abandoned. the budget still says rounds are left, because a budget records intent
rather than fate. the warmer keeps its schedule against a round that will never come, and
every poke bills.

and no surface says so. `review._.cost --of run` prices one invocation, and the warmer is not
an invocation. `--of tree` walks `.log/bhrain/review/**`, and the warmer writes no run
directory. the spend is real, small, recurrent, and invisible to every instrument this branch
built.

the cell is not *"the warmer costs too much"* — worst measured case, $0.043. it is that **a
cost with no row is a cost nobody can govern**, and the party who would notice never invoked
a surface.

## .the bdd

```
[t0] given a guard round completes with rounds of budget left on 11 lanes
     when  the warmer is spawned
     then  the spawn is RECORDED — a driver can learn a warmer exists without a process list

[t1] given a warmer pokes a lane's prefix
     when  the poke returns
     then  its measured cost and its cache.get land in a durable row, keyed by lane

[t2] given a poke MISSES (measured: ~1 in 5, from replica dispatch)
     when  the row is written
     then  the miss is marked as such, never folded into a hit rate

[t3] given the driver abandons the route
     when  the warmer's budget of pokes is spent
     then  the warmer EXITS — it never polls for a round that may never come
     and   its total spend is bounded by a figure declared before it started

[t4] given a driver asks what this tree's review cost
     when  they run `review._.cost --of tree`
     then  the warmer's spend is included, or NAMED as excluded
     and   never silently omitted — an omitted cost reads as $0, which is the lie
           `case=2` forbids at driver agency and this case forbids at engine agency

[t5] given a warmer's log ends after its final poke
     when  a driver reads the rows mid-flight
     then  the record says WHICH end it was — a plan spent, or a fault
     and   a `poke, poke, fault` tail cannot read as both a retire and a death

[t6] given the per-attempt log cannot be written (a real fs errno)
     when  the warmer writes its row
     then  it completes the plan anyway — the LEDGER row governs the money and is
           written first, so a convenience-sink failure cannot cost the budget
     and   the lane is not left cold for the rest of its budget

[t7] given round two of a guard finds round one's warmer alive
     when  a driver prices round two with `review._.cost --of run`
     then  the row reports the RECORD it has and claims naught about COVER
     and   it never says the prefix was unprotected when a warmer booked to the
           round that spawned it is what protected it

[t8] given a warmer's plan did not finish — no terminator at the ledger's tail
     when  a driver PRICES that run with `review._.cost --of run`
     then  the sum is named a FLOOR, though none of its attempts faulted
     and   the render picks no cause between the two an absence admits — still
           awake, or killed — because the run dir holds no liveness signal

[t9] given a warmer whose pokes pinned a replica no review ever met
     when  a driver PRICES that run with `review._.cost --of run`
     then  the ledger must not read a well-formed but FALSE hit rate — the pokes
           share one head, so poke 1 warms a replica and pokes 2-3 read it, and
           the defence has to sit where the pin is DERIVED: one constructor
           builds both system prompts, so the review's and the poke's cannot
           diverge for a driver to be misled about

[t10] given the DEFAULT plan — 3 pokes, 15 minutes apart, a 45m coverage window
      when  a warmer runs it to completion
      then  the pokes land 15m apart on the wall clock, never bunched — because
            each gap must stay under the cache ttl on its own
      and   a collapsed cadence would warm one replica three times and leave the
            next round past the cliff to pay in full for a warmer that billed
            three times and protected naught real

[t11] given a driver asks for a plan that CANNOT work — a cadence past the ttl,
      an unreadable shape, or a poke count over the bound
      when  the round starts
      then  it REFUSES before the review runs, and spends naught — never a
            silent fallback to the default plan
      and   the refusal names the valid set and the bound it broke
      and   a refusal about some OTHER supply (an empty rules glob) stays about
            that supply, so `--warmer off` is never blamed for an unrelated stop

[t12] given a warmer mid-flight — one poke spent, the next cadence still to come
      when  a driver `cat`s the ledger to see what it has cost so far
      then  the pokes already sent are already on disk — a detached process has
            no terminal, so the file is its only voice while it runs
      and   a batched write would leave the spender invisible for its entire
            life, reporting only once it can no longer be stopped
```

### the reconciliation found four gaps, all now closed

`rule.require.experience-catalog-evolution` grades this catalog both ways: every sketch
owes a test (forward), and every test the suite reveals owes a sketch (backward). walking
the backward direction against this cell surfaced four sketches with no prior row —
`[t5]`/`[t6]` (a clamp against a live failure mode), `[t11]` (an acceptance-tier refusal
path no unit/integration case had touched), and `[t12]` (the inverse: a promise stated
three times in code comments, with no test that reached it). all four are itemized above
and proven below.

one finding is worth keeping on its own: `[t10]`'s first draft claimed a collapsed cadence
fires three pokes inside a minute. the clamp that tested it returned `waits = [15, 0, 15,
0, 15]` — unchanged — because the wake verdict's own `sinceTouch < cadence → defer` rule
independently restores the schedule. the cadence is defended twice, a property no artifact
had stated before the neuter revealed it. the sketch keeps the harm as written against a
single-guard warmer, since the second guard is a mitigation, not a reason to drop the bar.

`[t9]` is the one sketch whose defence is not a render: the pokes really were sent, really
cost that, really hit. the falsehood is in what a correct figure implies, so no stdout
assertion can catch it — the invariant lives between two files (`stepReview` and
`getOnePokeMeasured`) that share one derived value.

`[t8]` is `[t5]` finished: `[t5]` obliged the record to say which end it was; the reader
that could act on that record did not yet exist, so a killed warmer's incomplete sum
rendered as a total with `faults: 0`. an absent terminator has two causes, and the render
names both rather than picks one — a first draft wrote *"was STOPPED"*, the same
positive-claim-from-an-absence `[t7]` had just repaired one file over.

`[t4]` is the clause that makes this cell a `defend`: `[t0]`–`[t3]` all prove the warmer
records its spend; `[t4]` is the only one that proves a driver can ever read it. the cheapest
honest discharge accepted a caveat as well as a join — *"or NAMED as excluded"* — rather than
forcing a fold.

## .why this is criti and not alter

the wish's first claim is that an unattributed spend is a **defect**, never a fact about price:

> a 2.8% hit rate against a prompt whose static head repeats every round is not a pricing fact;
> it is a **defect**.

a warmer with no row would re-create that defect in the very branch built to end it, one
layer lower, where no meter looks. the sharpness is not the dollar figure — it is that every
other cost on this board attaches to an act a human took, so a human can always ask *"what
did I just spend?"*. this is the first cost with no act to attach it to, which is why the
`agency` axis had to exist before the cell could be named.

## .the bound

this case obliges a **row**, never a policy. whether the warmer is on by default, how many
pokes it takes, and whether a driver may disable it are all wish-level calls. what this cell
forbids is the one condition that would make those calls unanswerable: **spend with no
record.**
