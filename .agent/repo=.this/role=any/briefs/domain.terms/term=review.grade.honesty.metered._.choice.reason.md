# domain.term.choice.reason: metered

## .etymology

a run is `metered` because the `meter` (`term=review.meter`) read it — the position takes its
instrument's name, so a reader who knows the meter knows the grade with no gloss.

rejected:

| rejected | why |
|---|---|
| `measured` | every figure inside a metered run is measured; to use the same word for the run's grade blurs the figure with its grade, which is the split `grade` exists to keep |
| `priced` | a `refused` run is priced too, at `$0`. `priced` would admit two positions |
| `recorded` | names the act of the write, never what it proves |

## .the boundary

"metered, of WHAT?" — of a run's spend, by the honesty family. `review.grade.honesty` answers
it in one segment chain.

## .disputes

none.
