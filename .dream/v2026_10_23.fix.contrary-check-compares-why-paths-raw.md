## .the gap, precisely

`asAbsorptionIsNotContrary.ts` sets `isRecite = input.why !== (extant.fulcrum ?? null)`. a re-declare
whose `--why` names the same fulcrum file by a relative path where the record holds an absolute one
(or through a symlinked route) is refused as "a different --why". the same class as the stance-key
defect this route cured, at a second raw path compare.

## .the shape of the fix

compare fulcrums by a route-relative key — the same move `asReviewGivenKey` made for the given — via
one predicate, with a unit clamp for relative, absolute, and alias forms of one path.

## .why it is not done in this round

the failure is loud (a refusal that names both values) and the driver can retry with the recorded
path; no silent lapse. the key choice for a fulcrum (a basename is not unique across dirs) needs
its own design. fulcrum F4.
