# 🌙 dream: auto-partition an overflowed review along its codegraph, so each partition carries the context it needs

kind: feat · owner: rhachet-roles-bhrain (review) · caught 2026-10-06

## .the cue that fired

the wisher asked how a caller declares partitions and whether that is intuitive. the driver offered
an auto-split; the wisher asked how a split could know the interdependencies, then settled that
`--partitionable` stays caller-supplied exclusively — only the caller knows what is isolatable —
and that auto-partition is a future dream.

## .the gap, precisely

- today a split happens only when `--partitionable` is declared AND the whole run overflows
  (`isReviewOverflowSplittable` in `stepReview.ts`). with no declaration, an overflow refuses and
  prints a lever (`asReviewOverflowLeverLines.ts`) that suggests a `--partitionable` value
- the caller must guess subtrees, learn first-match order, and meet the flag only from a refusal
- a split by directory is a proxy for cohesion: a file can land in one partition while the file it
  imports, or the subject a test exercises, lands in another, and that reviewer grades a fragment

## .the shape of the fix

1. build the import graph over the targets (dpdm, or the ts compiler with the repo's path aliases)
2. take connected components; pack whole components into partitions under the window budget
3. colocate by convention where the graph is silent: a test with its subject, a snapshot with its
   test, prose grouped by directory
4. carry each partition's one-hop imports as read-only context (diff-free bodies), so a reviewer
   can read what its files call without grade duty over them
5. a component too large for one partition is a refusal, never a cut through its middle
6. keep `--partitionable` as the override, and `--partitionable off` to refuse; announce each
   partition's targets and token share on stderr

🟡 a graph narrows the guess and never closes it — a reviewer also needs rubrics, peer contracts,
docs the graph does not see. so auto-partition must stay opt-in until measured against declared
splits on real lanes: same blockers found, or fewer?

## .why it is not done in this round

not safe: a wrong split hides context from a reviewer, which reads as a clean verdict. not clean: a
new graph builder, a packer, a context tier in the prompt, and a measurement — none of it rides the
5.3 diff. and the wisher ruled it future work.
