# domain.term.choice.reason: owed

## .etymology

a dispute is a **debt** the drive carries forward until the right party settles it. **owed** names
the creditor, in the same vocabulary the review gates already use (a reviewer that *owes* a
`.taken`).

| word | what it loses |
|---|---|
| `assignee` | it implies a person chose who works it; the value is derived from ground and confidence |
| `route-to` | it names a transport, not an obligation that holds a gate |
| `escalation` | it reads as a step up from a failure; most owed disputes are routine |

## .evidence

the vision's decomposition (`1.vision.experience.dimensions.md`, D4 × D3) walked ground × confidence
and found three outcomes, which the four cells of the table in `.what` cover. the wisher ruled the
dirty row (S01): a dirty-ground dispute always goes to the human.

## .the invariant

`owed` in a file must equal `asFulcrumOwed({ ground, confidence })` — a file that disagrees is
refused at dispute time, so the gate never trusts a hand-picked creditor.
