# 1.vision.experience.dimensions — the urgent budget lever

## .the dimensions

| axis | positions | why it varies the experience |
|---|---|---|
| **A. surface** | `judge.reviewed` (urgent halt) · `drive.exhaustion` (remedy groups) · `judge.approved` · `briefs` (the driver and reviewer briefs) | each names an owner for the lever; only `judge.reviewed` and the briefs were wrong. `judge.approved` shares the label const. `briefs` is read before any halt, so it sets what each halt is checked against |
| **B. warrant** | `urgent.live` · `urgent.lapsed` · `better-only` · `none` | the gate's first conjunct; also decides which remedy each surface prints |
| **C. moment** | `dry` · `rounds-left` · `unread` · `—` | the gate's second conjunct. `unread` = the lane has no meter, so its spend is unknown. scoped to A, see below |
| **D. lanes** | `one` · `many` | one scoped command per urgent lane |
| **F. urgent lane level** | `latest` · `lower` | a bare `--add` lands on the latest level alone, so each command carries `--peer` to land on the urgent lane's own level |
| **E. act** | `driver.top-up+note` · `driver.top-up-no-note` · `driver.escalates` · `driver.no-act` · `driver.tries-approval` · `driver.reads-briefs` · `human.runs-top-up` · `human.reads-note` · `human.approves` | one axis: who acts, and how. act and actor are not separate axes, since every act has exactly one actor. a refused top-up is an *outcome* of a top-up act, not an act of its own |
| **G. halts per re-arrive** | `one` · `two` | `two` = the exhaustion gate halts beside the judge in one re-arrive, and both print a top-up. a cell's A names the surface it centers on; `G = two` carries the second |

stone scope (the gate's third conjunct) is **not** an axis: every halt prints the exact matched stone name, so `stone-matched-many` cannot arise from a pasted command. no cell is drawn on it.

## .the one latent structure: C is scoped to A

| A | C |
|---|---|
| `judge.reviewed` | varies: `dry`, `rounds-left`, or `unread`. the judge halts on any of them; it reads the meters only to pick the remedy |
| `drive.exhaustion` | fixed at `dry`. the halt IS the exhaustion |
| `judge.approved` | `—`. an approval halt has no meter |
| `briefs` | `—`. a brief is prose, read before any meter exists |

## .the walked product, and how it collapses

each collapse names its class and why:

1. **A = `judge.approved`**: B, C, D, and G do not apply. the cells are its acts alone: `driver.tries-approval` (refused, no TTY), `driver.escalates`, `human.approves`. the budget acts do not apply there. → three cells
2. **A = `judge.reviewed`, B ∈ {`better-only`, `none`}, E = `driver.no-act`**: the judge holds, prints the residual lines, exits 2, no budget remedy. C and D do not change it. → one cell
3. **A = `drive.exhaustion`**: the remedy is set by B alone (`asBudgetHaltRemedyGroup`), with C fixed at `dry`. → one cell per B value, at the act the remedy invites
4. **A = `judge.reviewed`, C = `rounds-left`**: the gate refuses `rounds-remain` before the act matters beyond the attempt, for any D. → one cell
5. **D = `many`**: changes only the count of rendered commands. → one cell, the render
6. **E = `human.runs-top-up`**: the command checks no actor, so the human meets the same gate with the same outcome as `driver.top-up+note` in the same cell. → one cell
7. **B ∈ {`better-only`, `none`}, E = `driver.top-up+note`**: the gate is blind to which surface printed what. a top-up with no warrant is refused `no-warrant` on every surface. → **one class, one care**. demoed once (row 2); each other surface is itemized at the same care
8. **G = `two`**: only `judge.reviewed` + `drive.exhaustion` on `urgent.live · dry` both print a top-up. → one cell
9. **driver deviations off the urgent.live slice** — E ∈ {`driver.top-up-no-note`, `driver.escalates`, `driver.no-act`} where B ≠ `urgent.live`: the render does not depend on the act, and the act's outcome matches its `urgent.live` row. `no-act` stalls with no harm (row 10). `escalates` hands a human a command that the gate judges the same for it (row 9, collapse 6). `top-up-no-note` is refused on any B without a live warrant, so no spend exists for a note to explain. → no new cell; each reads off rows 8–10, or off collapse 7

10. **F = `lower`**: the `--peer` scope already lands the top-up on the lane's own level; the owner label, the note, and the gate are the same as at `latest`. → one cell, the render
11. **A = `briefs`**: B, C, D, F, and G do not apply; the one act is `driver.reads-briefs`, booted or on demand, and both read one corpus. → one cell, plus its forbidden twin (a brief that names a human as the grantor)
12. **C = `unread`**: the remedy is the same as `rounds-left` (no grant, the fix), and only the row's words differ: an unread lane is named unread, never in hand. D and the act do not change it. → one cell

the cells left after the collapse are walked in `1.vision.experience.case=_.md`.
