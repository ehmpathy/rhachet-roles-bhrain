# 🌙 dream: countInterleavedBlocks is a stdout-regex clamp that duplicates the leaf clamp with a false-positive surface

- **kind** = fix
- **owner** = `ehmpathy/rhachet-roles-bhrain`
- **caught** = 2026-09-13

## .the cue that fired

peer review i020/r007 (`arch-hazards-behavior`), nitpick.2, paraphrased:

> a reviewer whose body legitimately contains a line prefixed with an `r<N>:` marker
> is split into an extra block and flips the count. the ordered-release invariant is
> already clamped structurally at the leaf (`genReviewWaveBuffer.test.ts`), so this
> acceptance-level regex duplicates it with a false-positive surface.

## .the gap, precisely

`blackbox/driver.route.peer-concurrency.acceptance.test.ts` asserts `[case8] each
block is emitted whole` through a stdout regex. a nondeterministic LLM reviewer whose
body happens to match `/[├└]─ r\d+: /` trips the split and flips the count — a red
suite for a reason unrelated to the invariant. raised i017/r6, i018/r1/r2/r6.

**checkable evidence:** the leaf test `genReviewWaveBuffer.test.ts` already asserts
ordered, whole-block release structurally, so the acceptance regex is redundant.

## .why it is not done in this round

- **SAFE:** yes — removal/demotion of a redundant detector cannot lose the invariant,
  because the leaf clamp carries it.
- **CLEAN:** the edit lands in `blackbox` → churns the artifact hash → re-runs every
  l1 lane fresh, and this round already carries that churn from two real repairs.
- it is a nitpick because the false-positive is a flaky-red risk, never a false-green:
  the invariant is not lost, only re-tested at a grain that can misfire.

## .the shape of the fix

demote the acceptance-level `countInterleavedBlocks` assertion to a secondary signal
(or remove it), and rely on the structural leaf clamp `genReviewWaveBuffer.test.ts`
as the authoritative ordered-release oracle. if an acceptance-level echo is wanted,
key it on a delimiter the reviewer body cannot emit (a sentinel the renderer writes),
never a regex over free-form review prose.
