# domain.term.choice.reason: cold

## .etymology

the pair of `warm` — see `term=review.grade.cache.warm._.choice.reason.md` for the shared
etymology and the `hot` rejection, which binds both words.

rejected, for this word alone:

| rejected | why |
|---|---|
| `empty` | describes the cache's contents, which the meter never sees. it sees only the reviewer ordinal |
| `fresh` | reads as a virtue. a cold bucket is neither good nor bad, only unable to hit |
| `first` | names the evidence, never the grade. a bucket is cold because every run was first; to name the grade `first` hides that the claim is over the whole bucket |

## .the evidence

`cold` is the stricter position. it must be earned by every metered run in the bucket, and a
run whose ordinal is unknown counts against it (`getOneCacheGrade`, `isReviewerRepeat`). so a
`cold` grade is never a guess: each run in the bucket was placed, and each was first.

## .disputes

none.
