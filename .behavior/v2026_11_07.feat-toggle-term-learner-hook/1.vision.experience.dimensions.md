# 1.vision.experience.dimensions

the experience space of `rhx learn.terms.hook enable | disable | get`, factored into orthogonal
axes. the inventory (`1.vision.experience.case=_.md`) walks their product.

## .the axes

| axis | key | positions | why it is an axis |
|---|---|---|---|
| verb | **V** | `get` · `enable` · `disable` · (bad: absent / unknown / extra args — two verbs, or a verb with a flag) | the three faces of the contract; a bad verb is the input sharp edge |
| prior state of the hook in the target | **S** | `off` (no entry) · `on` (our entry, current) · `on-drift` (our command, older body — e.g. another timeout) · `on-rhachet-authored` (the command under a `repo=…/role=learner` author, a hand copy of the withdrawn hook) | what the verb finds decides whether it writes |
| target file | **T** | `present` · `absent` · `link` (the settings file is a symlink) · `dir` (a directory sits at the settings path) · `outside-repo` (the `.claude` dir resolves out of the repo) · `unreadable` (a real file the caller may not read) · `not-a-dir` (`.claude` is a plain file) · `malformed` (not json, or json but not an object) · `unwalkable` (a json object whose `hooks` shape no verb can walk, e.g. `{ "hooks": { "Stop": "x" } }`) | the boundary to the settings file; each failure position must fail safe, each with its own fix |
| layout | **L** | `split` (`.claude/settings.of.repo.json`) · `old` (`.claude/settings.json` is the real file) | picks the target, the same way `init.claude.status-line.sh` does |
| caller | **K** | `human` at a terminal · `clone` in a session | who runs a verb; both may (fulcrum F4) |
| session role | **R** | `repo actor` (holds every ambient role) · `peer actor with the learner` · `peer actor without the learner` · `plain session` (a bare `claude`, no enroll) | whose stops the hook reaches: rhachet's peer-actor derive keeps a hook only for actors that hold its author's role; a plain session reads the repo file only on the old layout, since the split layout passes it as `--settings` on enroll alone |
| concurrency | **X** | `solo` · `concurrent toggle` (two verbs on one file at once) · `concurrent rhachet write` (an `rhx init --hooks` or `rhx enroll` mid-verb) | the verb is a read-modify-write of a file other writers also rewrite whole |
| after-event | **E** | `none` · `live session` (the session that ran the verb keeps its old settings) · `next session stop` (stale / fresh) · `rhx init --hooks` or `rhx enroll` (re-sync + derive) · `learner unlinked` | what happens to the toggle after the verb; the re-sync is the boundary that can silently revert it |

## .orthogonality, pair by pair

each axis varies with the others held fixed, save the pairs below, which are correlated by
nature and recorded as impossible cells in the inventory:

| pair | the correlation | kind | inventory |
|---|---|---|---|
| S × T | `S ≠ off` requires `T = present`: an absent file holds no entry, and each refused or faulted position (link, dir, outside-repo, unreadable, not-a-dir, malformed, unwalkable) stops the verb before S is read | nature | `S≠off · T=absent` → impossible |
| L × T | `L = old` means `.claude/settings.json` is the real file, so `T = link` cannot be the old layout | nature | `L=old · T=link` → impossible |
| L × X | the layout can flip from `old` to `split` only under a `concurrent rhachet write` — an `rhx init` mid-verb is the one writer that splits it | nature | walked: the flip while the toggle waits on the lock |
| K × R | none expected: `rhx` is believed to look up a skill among the repo's linked roles, not the actor's, so a clone of any session role may run a verb; R decides only whose stops the entry reaches. the belief is Q7 [research] | — | walked: a peer actor without the learner runs `enable` |
| V × E | `V = get` writes naught, so no after-event follows from it | nature | E collapses to `none` for `get` |

## .the walked product

V × S × T × L × K × R × X × E is 4 × 4 × 9 × 2 × 2 × 4 × 3 × 5 = 34,560 raw cells. most collapse:

- **K** changes no verdict — a human and a clone see the same output and write the same file. walked
  once per verb (case=1 a human, case=2 a clone)
- **R** matters only after an `enable`, at the derive and at a stop: walked for all three positions
  (case=3)
- **L** changes only the target path; `old` is walked once per verb class and else collapses to `split`
- **T ∈ {link, dir, outside-repo, unreadable, not-a-dir, malformed, unwalkable}** stops the verb before **S** is read, so S
  collapses there, and every verb meets the same refusal
- **X** matters only for the two write verbs; walked once per concurrent position
- **E** matters only after an `enable` that wrote, or a `disable` that removed

what stands after collapse is the inventory's cell table, each cell verdicted, with the impossible
cells above recorded beside their reason.

## .the densest walk

`enable` (human, split) → commit → `rhx init --hooks` (re-sync, prune, derive) → a learner clone's
stop with a stale distillation → nudge. five boundaries: the cli, the settings file, git, rhachet's
hook sync, and Claude Code's Stop event. demoed as case=3.
