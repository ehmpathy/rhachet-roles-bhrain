# 🌙 dream: live-brain integration suites run with no named flag that targets them

- kind: fix
- owner: rhachet-roles-bhrain (test infra)
- caught 2026-11-03

## .the cue that fired

`stepReview.caseBrain.claude-sonnet` and `stepReview.casePromptCache` turned PR #661 red: one on
an anthropic billing refusal, one on a provider cache that read warm. the rule they broke: no test
makes a live brain call unless a named flag targets it. live calls belong to the precommit safety
guards and the rhachet acceptance smoke tests alone.

## .the gap, precisely

both suites, plus this branch's `genReviewBrainSupply` clamp, are gated now
(`BHRAIN_TEST_LIVE_BRAIN_SONNET`, `BHRAIN_TEST_LIVE_BRAIN_CACHE`, `BHRAIN_TEST_LIVE_BRAIN_TALLY`).
22 more integration suites build a test brain via `genTestBrainContext` and run on every default
integration run, e.g. `stepReview.integration`, `stepReview.caseBrain.deepseek-flash.case1..3`,
`stepReflect.*`, `getOneReviewCounts`, `setOnePrefixPoke`, `setOneReviewLanePrime`.
`git grep -l genTestBrainContext -- 'src/**/*.integration.test.ts'` lists them. some may only build
a context and never call it; each needs a read.

## .the shape of the fix

one gate helper in `src/.test/infra/` (e.g. `describeIfLiveBrainTargeted({ flag })`) that the
three gated suites adopt, then a sweep: each suite that makes a live call takes a named flag; a
suite that builds a brain and never calls it stays. a lint or a test that greps for a live brain
build outside a gate keeps the rule from regressions.

## .why it is not done in this round

safe, not clean: 22 suites of main's code, outside the token inventory's diff. the three gated here
are the ones that broke #661 or that this branch added.
