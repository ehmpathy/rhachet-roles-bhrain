## rung 34 — the ledger drain

rung 33 found the route `blocked` on `blockers exceed threshold (5 > 0)` with nine reviews and zero
takens. this rung drained it, and the drain taught two things the takens alone did not.

### the command was the hard part, and that is itself the finding

🔴 **four probes failed before the right one.** `rhx route.pass` and `rhx route.mark` do not exist;
`route.mutate` is grant-only; `route.review` reviews artifacts rather than records verdicts. the
command is `route.stone.set --as conceded --with <lane> --about <concern> --severity <sev>`, then
`--as absorbed --that <lane>`.

⇒ so the duty was booted, the artifacts were written, and **the verb to record them was unknown to
the driver holding them.** that is the gap between rung 33 and this one: a taken on disk that the
ledger has never seen is a taken nobody downstream can read.

🟡 **and a concession exits 2, not 0.** `--as conceded` prints `the hold stands. fix, then re-arrive`
and returns 2 — correct, because a concession is a promise rather than a discharge. a driver who
reads exit 2 as failure would retry, or conclude the record did not land. it lands.

### the tally was WIDER than the block said

| the block said | the judge said, once blockers cleared |
|---|---|
| `blockers exceed threshold (5 > 0)` | `nitpicks exceed threshold (8 > 0)` |

🔴 **the blocker count named 5 and the real debt was 13.** the halt reports only the bar it tripped
on, so a driver who answers exactly what the halt named is still held — and learns the rest only on
the next judge. the eight nitpicks sat in four lanes, three of which had no taken at all.

⇒ **read the JUDGE, never the halt, to size the work.** the halt is a trigger; the judge is a census.

| lane | concern | disposition |
|---|---|---|

#### 🔴 the ergo conflict is the rung worth keeping

two peer lanes reached opposite verdicts on one render, three rounds apart:

- `ergo-friction-hazards` (i002, i005) wants the repeated `found` tree collapsed
- the round behind `emitReviewWarmerSpawn.test.ts` `[case2]` asserts the bound must print each round,

🟡 **the stale-taken case is the mirror lesson:** a taken is written at a moment and the branch moves

## rung 35 — the census, re-aimed at a PATTERN rather than a directory

rung 34's coverage census walked a **directory** and asked *"which file has no test?"* — one hit. this
rung kept the instrument and re-aimed it at a **pattern**: `const unhandled: never`, across the whole
review subsystem. **two hits**, and the second was the one that mattered.

| the gate | its status | why it is unreachable from its caller |
|---|---|---|
| `isWarmerRowTerminal` | rung 34 clamped it | every row carries a declared act **by construction** |
| 🔴 `getOneWarmerCost` · `asSpendGrade` | **unproven** | same — and it is the repair for a defect that ACTUALLY SHIPPED (`fault` absorbed by a `measured !== null` filter, bar 4's inversion) |

⇒ **the start set is the instrument.** rung 34's own lesson was *"the blind spot was never a weak
instrument; it was a fixed START SET"* — and rung 34 then re-used its own start set. one directory
finds absent FILES; one pattern finds absent BRANCHES, and a branch can be absent inside a file that
carries 20 tests.

### 🔴 the clamp was 1-of-3, and no assertion could say so

`[case7]` reaches the gate by a real forward-compat path — a ledger row a *newer* warmer wrote. under
a neuter it went **1 of 3 red**. the two survivors read a **second** `never` gate: `asSpendGrade` runs
in a filter, `isWarmerRowTerminal` runs on the tail, so an unknown act at the tail is refused by
whichever survives the neuter.

⇒ the repair is **one fixture row** — a terminal `retire` at the tail, so the second gate cannot fire.
then **3 of 3 red**, restored **21 of 21 green**.

🟡 **a clamp on *"some gate rejects"* is a clamp on neither mechanism.** `rule.require.clamp-edge-cases`
says prove the clamp bites; this rung adds the second half — **prove it bites the mechanism you aimed
it at.** two gates in series will absorb each other's neuter and report a pass.

### and the two rungs close one mechanism from both ends

rung 34 said gate B is unreachable **by construction**. this rung measured the sharper reason: it is
unreachable **by PREEMPTION** — gate A runs first and refuses the identical input. so rung 34's
collocated unit test is not merely *a* path to gate B; it is the **only** path to it in the repo.

## rung 36 — the census, widened from a GATE to a REFUSAL, and it found a live defect

rung 34 walked a directory. rung 35 searched one pattern. this rung widened the pattern from
`const unhandled: never` to **every refusal in the warmer** — five sites across four files — and asked
of each whether a test proves it fires. **four were clamped. one was not**, and the unclamped one is a
bar-16 defence whose harm is money:

> *a swallowed EACCES reads as "this reviewer never ran", so the warmer spends a poke on a fact it
> never established* — `getOneReviewerLastRunAt`, in its own words

⇒ `[case3]` already proved the two BENIGN faults read as "no match". **no case proved the rest fail
loud**, so the allowlist that parts a cheap DEFER from an expensive POKE had never been exercised in
the direction that costs.

### 🔴 the clamp found the defect BEFORE any neuter — which is this rung's whole lesson

the third assertion asked the fault to name its path, and it could not:

```
Expected: "input.args.json"
Received: "Error: EISDIR: illegal operation on a directory, read"
```

the rethrow was bare, and node's `read` fault names no path — so an operator whose log root holds one
dir per run learned that *a* file was unreadable and never *which*. repaired to an
`UnexpectedCodePathError` that carries `at: argsPath`, exactly as its peer `getOneWarmerRunArtifacts`
already did.

🟡 **rungs 34 and 35 each proved a gate that already worked. this one proved a claim HALF-met** — the
refusal fired and could not say where. ⇒ **a clamp's value is not the coverage line; it is what the
clamp refuses to accept.** an assertion written to the operation's own stated promise is what caught
it, and an assertion written to the code's observed behaviour would have passed.

### the disposition written down rather than left for rung 37

one refusal in the same file is **deliberately unclamped**: the non-`SyntaxError` parse throw is
unreachable without a stub, since `readFileSync(path, 'utf8')` answers a string and `JSON.parse` of a
string raises `SyntaxError` and no other class. that argument now sits beside the case, so the next
census reads it rather than re-derives it.

## rung 37 — the repair was blind to its own twin, and the instrument is why

rung 36 repaired a bare rethrow and reported the refusal census closed. **it was not.** the census had
been aimed at `throw new UnexpectedCodePathError` — the shape a *wrapped* refusal takes — so it could
see every refusal that already named its subject and **could not see a bare `throw error` at all.**

🔴 **the instrument was blind to exactly the defect it had just found**, because the shape it searched
for is the shape the repair produces.

⇒ re-aimed from the THROW to the `catch`: **ten sites**, and the first was the twin —
`getOneReviewWarmerPid:50`, the same bare rethrow, and it defends **bar 14**:

> *an EACCES here is a DEFECT, and a swallowed one would report "no warmer" on every round — so each
> round would spawn another, and the lock this serves would never hold*

spawn is a findsert keyed on that read, so a fault that arrives as an absence makes the lock report
**vacant forever**. clamped by `[case5]` (a real `EISDIR` from a pid path that is a directory), wrapped
to carry `reviewer` as well as `at`, **2 of 9 red** under neuter.

### 🟡 the third assertion is green under the neuter, and that is correct

`[case5]`'s third `then` asserts the fault is **per-lane** — true whether the subject throws or
swallows. so it is a *scope* clamp rather than a *fail-loud* clamp, and the note now says so beside
it. rung 35's lesson applied forward: **a reader who counts reds would otherwise grade it a false
green.**

### 🟡 and one bare rethrow is CORRECT — the census must not sweep

| the fault | names its path? | a wrap adds |
|---|---|---|
| `readFileSync` → `read` | ❌ no | the whole actionable fact |
| `openSync` → `open` (`genReviewWarmer:172`) | ✅ yes | a layer, and no fact |

⇒ **`rule.prefer.helpful-error-wrap` earns its keep on a PATHLESS fault, never on every rethrow.** a
sweep of all three would have been a uniform diff and a worse codebase.

that site is also **unclamped on purpose**: every reachable fault needs a write-denied parent, which
means a `chmod`, and **root ignores mode bits** — so the clamp would pass locally and stop to exercise
the branch in a root container. caught as
`.dream/v2026_09_25.verify.the-warmer-locks-write-side-refusal-is-unclamped-because-root-ignores-mode-bits.md`,
whose own fulcrum widens it: **`isErrorOfAbsence` exists to part a permission fault from an absence,
and a suite that may run as root cannot produce a permission fault at all.**

### the rung, as a table — four aims, four different finds

| the census, aimed at | found |
|---|---|
| a directory (rung 34) | 1 absent test FILE |
| `const unhandled: never` (rung 35) | 1 unproven GATE |
| `throw new UnexpectedCodePathError` (rung 36) | 1 unclamped refusal — **already wrapped-shaped** |
| 🔴 `catch` (rung 37) | **the bare rethrows the prior pattern could not see** |

⇒ **a repair that does not name its class is a repair that leaves twins.** rung 36 fixed an instance
and never asked what class it belonged to, so the twin survived a rung whose stated subject was that
exact class.

## rung 38 — the DIRECTORY was the fixed term all along, and a neuter that lied

rungs 34–37 re-aimed the census's **pattern** four times and never once its **directory**: every one
started at `warmer/`. so bar 13's refusal — the `--warmer` flag parser — sat outside every start set,

by three suites. ⇒ the answer was good, and it only counts because someone looked.

### 🟡 the filter needed a SECOND term

`asWarmerCaveat.ts` has no collocated test, which by rung 34's rule reads as a gap. it is not: all
three branches are reachable from its callers and all three are clamped — `0` by two negative
assertions, `1` and `>1` by the grove suite.

> **a gap is *no collocated test* AND *a branch unreachable from its callers*.** one term over-reports:
> `isWarmerRowTerminal`'s `never` gate could not be reached at any input; this operation's cannot be
> missed. the absent file is a grain nitpick, never an unproven branch.

### 🔴 the find — silent defaults, the last uncensused family

two live `??` in the warmer; one unclamped — `args.output ?? ''`. reachable from a file with no cast
(an args file with no `output` key), and it is minted LATEST of `[case3]`'s noise set, so a fallback
that named a lane would beat the real run on recency and the warmer would **defer forever on a touch
that never happened**. clamped as `[case3]`'s fifth shape.

### 🔴 the neuter was GREEN on its first attempt — the rung's whole lesson

the fabricated path used a plausible basename rather than the grammar `asPeerReviewOutputParts` parses,
so it answered `null` **for the same reason `''` does.** 12 of 12 green: the neuter changed a line and
reproduced no defect, and that green is indistinguishable from a clamp that proves naught.

re-neutered with `asGuardReviewOutputPath`'s real shape: **2 of 12 red.** restored green.

🟡 the third clause `rule.require.clamp-edge-cases` now owes, after rung 35's second:

> **a neuter must reproduce the DEFECT, never merely edit the line.**

⚠️ and the tell was cheap: **a neuter whose value must satisfy a grammar is built from that grammar's
constructor**, never typed from memory.
