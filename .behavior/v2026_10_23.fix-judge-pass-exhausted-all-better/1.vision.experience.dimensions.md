# 1.vision.experience.dimensions

the encounter: a lane's concerns meet the `reviewed?` judge at a stone's close. six axes decide
what the judge must say.

| axis | positions | why it varies the experience |
|---|---|---|
| **lane** — the lane's budget at judge time | `live` · `exhausted` | a live lane re-runs and re-mints its given; an exhausted one freezes it |
| **stance** — the lane's disposition, folded by precedence (below) | `undeclared` · `urgent` · `disputed` · `all-better` | decides shed vs hold, and which lever the halt names |
| **path** — the absolute path each reader builds for the route, vs the one the stances were written under | `same` · `moved` (every reader sees the new path) · `split` (the driver's process and the judge subprocess see different paths) | the root cause: an absolute key orphans a stance for whichever reader's path differs. `moved` trips the entrance gate first; `split` slips past it to the judge |
| **row** — the form of the stance's `given` on disk | `absolute` (written ≤ 0.42.1) · `filename` (written after the cure) | an absolute row is the one a path change breaks; the cure must read both |
| **given** — the state of the given file the stance names | `present` · `deleted` · `re-minted` (by a rewind over an unchanged artifact) | decides whether a stance has a live given to key to at all |
| **level** — whether a human has overruled the lane's level | `held` · `overruled` (`--as overruled`) | an overruled level leaves the tally whole, so its lane holds naught and its stances must shed naught — else a shed would subtract from a sum the lane is no longer in |

## .why each axis is orthogonal to the rest

each pair can vary independently; an **interaction** in the outcome is not a **correlation** in the
occurrence.

| axis | set by | independent of the rest because |
|---|---|---|
| lane | the guard's budget and the round count | any stance, path, row, or given state can meet a spent or an unspent budget |
| stance | the driver's declarations | the driver declares per concern, regardless of budget, path, or bhrain version |
| path | the environment at **read** time (cwd, `$route`, worktree, machine) | no write-time fact constrains where a later reader stands |
| row | the bhrain version at **write** time | a ledger's row form is fixed when written; any later read environment can meet it. 🟡 its outcome effect is conditional on `path` (a filename row is path-invariant) — an interaction, not a dependence of one axis's values on the other's. so it stays an axis rather than fold into `path`, where it would hide the legacy case (case=5) the cure must heal |
| given | a rewind or a hand delete | a given can vanish or re-mint under any budget, stance, path, or row — in **occurrence** a driver can hold an `all-better` ledger and then rewind. 🟡 in **outcome**, `given ≠ present` makes every declared stance read as `undeclared`; that is an interaction (the outcome of `all-better × deleted` equals the outcome of `undeclared × present`), not a dependence of one axis's values on the other's. it stays an axis so the re-minted cell, the one the cure could break, is walked rather than hidden inside `stance` |
| level | a human's `--as overruled` | a human may overrule a level under any budget, stance, path, row, or given state. 🟡 in **outcome**, `overruled` fixes the lane's result whatever the other five read — an interaction, not a dependence. it stays an axis so the one cell the cure could break — a stance shed from a lane already out of the sum — is walked |

## .the stance fold — why one value per lane suffices

a lane may carry several dispositions at once (one `urgent`, one undeclared). the gates rank them
in a fixed order, so the lane's outcome is set by the highest present:

1. **`undeclared`** — the entrance gate fires first and names each undeclared concern; the judge is
   never reached on `--as passed`
2. **`urgent`** — the judge keeps it in the tally and names the budget lever
3. **`disputed`** — shed; the council rules later
4. **`all-better`** — shed; the floor is met

a mixed lane (`urgent` + undeclared) thus reads as `undeclared` on `--as passed`, and as `urgent` once
the driver declares the rest — two cells of this table, walked in sequence. no mixed value is owed.

the axes describe ONE lane. a stone of N lanes is N cells read at once, and its outcome is the
highest-precedence lane's. so *two lanes urgent* is not a new cell — it is two `urgent` cells side by
side; all it varies is the render, which names one budget command per urgent lane
(`asJudgeUrgentHaltLines` case2). a render, not an experience the space must hold.

## .feel — why it is not an axis

the inventory carries a `feel` column, but feel is fixed by `stance`: `undeclared` and `urgent` are
sharp (the stone must hold), `disputed` and `all-better` are happy (the stone must clear). a value of
one fixes the other, so per the orthogonality test it folds into `stance` rather than stand as a
sixth axis. the column records the derived value per row for the reader.

## .the actor — why it is not an axis

the **driver** meets every cell. the **human** meets the `level = overruled` cells — the overrule is
theirs to declare — and the `urgent` cells at one step: the budget grant the halt names. that step continues the driver's `urgent` cell, not a distinct
cell — the outcome the human sees (the grant admitted or refused) is fixed by the same stance read.
so the human rides the `urgent` cell rather than a product axis — and still gets an actor-side
demonstration of that one step, in case=6.

## .product, and how it collapses

product = 2 × 4 × 3 × 2 × 3 × 2 = **288 cells**. four collapse rules, each argued:

- **`level = overruled`** — the human's overrule takes the lane out of the tally whole, so no stance,
  path, row, or given state changes what the judge reads: it holds naught for the lane and sheds
  naught from it. all 144 `overruled` cells read as one. the 144 `held` cells collapse by the three
  rules below

- **`row` under `path = same`** — an absolute row still matches; a filename row matches by
  construction. both read as one cell
- **`row = filename` under `moved` or `split`** — path-invariant by construction once the cure ships;
  reads as the `path = same` cell
- **`given ≠ present`** — a `deleted` given leaves no latest given to key to, so every stance on it
  lapses (`getLiveReviewAbsorptions` finds no match), today and after the cure alike. a `re-minted`
  given follows a rewind, and the rewind voids every stance declared before it
  (`getPassageReportsSinceLastRewind` slices on the `rewound` row, not the key — so a filename key
  that re-matches the re-minted given still finds no stance). both collapse onto the
  `stance = undeclared` cells, independent of path and row. 🔴 the `re-minted` cell is the one the
  cure must not break: a filename key re-matches a re-minted given exactly as an absolute key did, so
  the rewind slice is still what voids it. clamped today by
  `setStoneAsRewound.absorption.integration.test.ts`

the inventory lists the cells that remain distinct after the collapse, and counts every cell back to
288.

## .invariants — the forbidden (nurture) cells

each cell below can occur, and the driver may attempt `--as passed` on it; the behavior must reject
the passage. per the decompose taxonomy that makes each a **forbidden (nurture)** cell. none is a
nature impossibility.

- `stance = undeclared` → the stone never passes on that lane's unanswered concerns (nurture: the gate
  and the judge reject)
- `stance = urgent` → never shed; the judge holds, names the budget lever, and the lever is admitted
  (nurture: the judge rejects passage)
- `given ≠ present` → no stance from before the given vanished or re-minted sheds a concern (nurture:
  the stance lapses, or the rewind voids it)
- the outcome of a cell must not depend on `path` or `row` (nurture: the invariant this behavior
  installs; today it is violated)
- `level = overruled` → no stance on that lane sheds from the tally (nurture: the lane already left
  the sum; a shed there would subtract from lanes that still count)
