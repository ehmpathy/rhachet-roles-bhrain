# case 6 — the-brain-is-already-right

**actor** = driver-clone · **feel** = happy · **care** = alterpath
**cell** = `driver-clone × apply × same-as-live × live`

> 🔴 **REWRITTEN 2026-09-11. this case demoed a compare-before-dispatch; the build has none.**
>
> the wisher challenged the premise on 2026-09-10 — *"why do we care what model we are at if we know
> we can just enforce the model desired at every stone boundary?"* — and answered the one fact it
> turned on a day later: *"it preserves the conversation, no worries."*
>
> ⇒ `rule.require.fewer-paths-via-idempotency` then fires on the **branch**: a compare kept to skip a
> benign idempotent re-run is the defect. **the collapse is mandatory rather than preferred.** ⇒ `F14`.

## .the narrative

i am the driver, already on opus, because the stone i just passed prescribed it. the next stone
prescribes opus too — most of a phase group does.

the hook fires, reads `brain: claude-opus-5[1m]`, and dispatches it. it does not ask what i run now.
it holds no belief about me at all.

that reads wasteful, and the r1 draft of this case argued exactly that: a redundant `/model` costs a
turn of context and adds a transcript line a later reader must discount. **the wisher settled the
cost, and it is not one** — a brain switch changes the engine, never the session, so a re-assert
forfeits no conversation.

and the redundancy buys a property the compare could never have:

> **an applier that compares can SKIP. an applier that converges cannot.**

a compare reads a belief about my current brain. the moment that belief is stale — a human typed
`/model sonnet` by hand two stones ago — the compare reads a match, skips, and skips again at every
later boundary. **the drift it cannot see is the drift it will never repair.**

⇒ 🔴 **the "aha" inverts.** this case once argued *"the cheap check is the one that runs first."* the
correct lesson is **"the cheap check is the one you delete."**

the record still speaks, on every stone:

```
🗿 5.2.execution.phase3
   └─ brain set claude-opus-5[1m]   (prescribed by guard)
```

🟡 **a line on every stone is a stronger guarantee than the *already* line it replaces.** with no
no-ops in the design, an **absent** line is unambiguously a dead hook — the indistinguishability this
case exists to refuse is removed by construction rather than by a message.

## .the bdd `[tn]` timeline

```
given a driver enrolled as @:driver, reach=LIVE, live brain = claude-opus-5[1m]
  and  a stone whose guard declares `brain: claude-opus-5[1m]` — the same value

  when [t0] the driver enters the stone
    then the hook dispatches `/model claude-opus-5[1m]` — unconditionally
    and  it reads no live brain, holds no belief, and runs no compare

  when [t1] the brain receives a value it already runs
    then it converges to the same end state
    and  the conversation is preserved — the switch changes the engine, never the session

  when [t2] the driver takes its first turn on the stone
    then it runs on claude-opus-5[1m], as the guard declares

  when [t3] a reader asks whether the guard was honored
    then the record names the stone, the brain, and the guard that prescribed it
    and  it reads `set`, never `already` — there are no no-ops to part from

  when [t4] a human typed `/model sonnet` by hand two stones ago
    then the same unconditional dispatch at [t0] restores the declared brain
    and  🔴 the drift is repaired with NO detection — the applier never knew it happened
```

## .why alterpath — and the REASON changed, not the grade

per the severity law, `freq × cost`:

- **freq** is high — most stones in a phase group share one brain
- **cost is near zero, and there is a workable route around it**

⇒ tolerable cost with a workable fallback = **alterpath**, as before. what changed is why:

| | why it was an alterpath |
|---|---|
| r1 | a cheap optimization was **optional** |
| 🔴 now | there is **no decision here at all** — the happy path and the drift path run the identical act |

### 🔴 that grade was this case's own refutation, and it went unread for four rounds

*"cost is near zero, and there is a workable route around it"* is the exact test
`rule.require.fewer-paths-via-idempotency` applies — and its verdict on a near-zero cost with a
workable route is **delete the branch**, never *demo it as an alterpath*.

⇒ **the case graded the optimization as optional and then walked it as though it were required.** a
`[t1]` that read *"it dispatches no `/model`"* is a design commitment, whatever the `care` field
above it says.

🟡 **and an alterpath is where this defect hides best.** a critipath's design gets argued; an
alterpath's gets demoed and passed over, because the grade already said it does not matter much.

## 🔴 .what the collapse deletes from this file

| what goes | why |
|---|---|
| the `[t0]` compare | there is naught to compare |
| the two-spellings hazard on the happy path | a compare that does not exist cannot misfire |
| the mirror table — *the compare says "differs", and they match* | that row cannot occur |
| the *already* / *switched* distinction | no no-ops exist, so the record has no two words to pick between |
| the *"`[t0]` needs no vocabulary bridge"* argument | the bridge is `case=3`'s question now, and only in the `F5` build |

⚠️ **one claim is struck rather than moved: *"the cheap defect and the sharp one are one defect."***
this case's `[t0]` and `case=3`'s `[t2]` are **two compares**, and only the second survives:

| | this case's `[t0]` | `case=3`'s `[t2]` |
|---|---|---|
| when | **before** the dispatch | **after** it |
| it asks | *"need I dispatch?"* | *"did the brain take it?"* |
| under `F14` | 🔴 **deleted** | ✅ **kept, whole** |

⇒ so *"the two stand or fall together"* was false, and the sharp defect is untouched by the
disappearance of the cheap one.

## .what survives — `[t3]`, and it carries more than it did

the record must still state what happened. that clause is the whole of this case now, and it is
`case=8`'s to enforce.

🔴 **and the one fact that settled it arrived in seven words, after five review rounds on a
`[research]` list graded *nice to know*.** *"it preserves the conversation, no worries"* was
answerable from a live session the entire time, and the design was built around its unknown answer.

⇒ **before a compare-before-act is designed, ask whether the re-run it skips is benign.** the answer
deletes the whole read path or justifies it — and it is usually cheaper to obtain than the compare is
to build.
