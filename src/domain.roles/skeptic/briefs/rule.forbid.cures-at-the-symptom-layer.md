# rule.forbid.cures-at-the-symptom-layer

> **no cure lands at the layer where the symptom shows, unless a read shows the cause starts there too.**

twin of `rule.always.skepticize-the-layer-of-a-cure`. razors: `razor=instrument` · `razor=leaky-abstraction` · `razor=hume-proportion`.

## .the shape

| 👎 | 👍 |
|---|---|
| a test flakes on a timeout; the timeout is raised | the slow call found and fixed, or the timeout raised with the cause named and handed to its owner |
| a bad value in the ui; the ui clamps it | the api that sent it fixed; the clamp kept only as a stated stopgap |
| a copy of a published file patched in place | the edit sent to the file's publisher |

## .the test

> **where does the cause start, by what read, and does the cure sit there?**

## .enforcement

blocker: a cure at the symptom layer with no read of where the cause starts · a patch to a copy of a published file
nitpick: a stopgap at the symptom layer with no hand-off to the cause's owner
false positive: the cause and the symptom share a layer (shown by a read)
