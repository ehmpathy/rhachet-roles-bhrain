# case=1 — audit one finished transcript

cell 1: any selector · one (here via path) · metered · flat · finished · well-formed · feel = happy · care = critipath · boundaries = 6

## .narrative

the foreman suspects a clone's last session was bloated. they copy the transcript path from the
`reflect.snapshot` output and run `rhx reflect.on.token.spend --from <path>`.

within seconds the tree shows 1,059 calls and 393M cache-read tokens — 90.8% of the bill. the
foreman expected the cache to be the problem; the efficiency section shows it is fine. the
inventory says why the number is huge anyway: `boot.instructions` is 46.1% of every call's
context, tagged `[exact]`, and `tool.result` is 38%, of which `git.repo.test` alone is 71%.

then the `repaid` section lands: one `git.repo.test` log at call 12 was re-paid 988 times —
39.5M tokens for a log read once. the proposal ranks it second, below the boot. the foreman
now has two cuts, each with an upper bound on what it could save, and a dispatch to write.

## .timeline

```ts
given('[case1] a finished transcript with 1,059 metered calls, no compaction', () => {
  when('[t0] the foreman runs `rhx reflect.on.token.spend --from <path>`', () => {
    then('exit 0');
    then('efficiency shows input.raw, cache.read, cache.write, output — each with a share');
    then('cache.read and cache.write render as separate rows, never merged');
    then('calls = the count of distinct requestId values, not of assistant records');
    then('context.per-call shows median and peak of (input + cache.read + cache.write)');
  });
  when('[t1] the foreman reads the inventory', () => {
    then('each row carries a share of the last-call context, and a tier tag [measured|exact|apportioned]');
    then('assistant.own is sized by prior-call output_tokens, never by stored thought text');
    then('the rows sum to the measured last-call context, to the token');
    then('unattributed renders with its share, and names what it holds');
    then('tool.result breaks down per tool name, each as a share of tool.result');
  });
  when('[t2] the foreman reads repaid and the proposal', () => {
    then('repaid = each block tokens × the calls it stayed in context, per category');
    then('the single heaviest blocks are named with the call they entered at');
    then('the proposal ranks cuts by the share of repaid each would save, as an upper bound');
  });
});
```
