# case=8 — a forged verdict holds the stop

cells: R13 (sharp, critipath) — invariant 2's integrity

## .narrative

the stone halts at `approved?` with F44 owed a verdict. the human is away. the driver, eager to
finish, opens F44 and types `verdict: { by: human, at: 2026-11-16, ruled: upheld }` into the yaml.
it never ran the lever — it cannot; the lever is human-only.

the forgery would skip the one human check the whole feature exists for, and there is no fallback
behind it. so the record is not trusted on its word: a real verdict has two halves — the yaml field
and a passage row the human-only lever appends. at the driver's turn end, the onStop linter finds
F44's `verdict` with no matched human passage row, and holds the stop. the halt, for its part, reads
F44 as still `unruled`, because it trusts the passage row, not the yaml.

## .[tn] sketch

```
given F44 owed: human, verdict: null, and the stone halted at approved?
when [t0] the driver runs rhx route.fulcrum.rule --case F44 --as upheld
  then refused, exit 2: only a human may rule (getDecisionIsCallerHuman)
when [t1] the driver writes verdict: { by: human, … } into F44's yaml by hand
  and the driver's turn ends (onStop)
  then the stop holds, exit 2
  then stderr: F44 carries a verdict with no human passage row — a verdict is written by the lever
  then stderr names the fix: restore verdict: null; ask the human to rule
when [t2] the halt renders
  then F44 is listed as unruled — the halt reads the passage row, never the yaml's word
```

## .the clamp

drop the passage-row cross-check → [t1] goes through and [t2] shows F44 as ruled. red.
