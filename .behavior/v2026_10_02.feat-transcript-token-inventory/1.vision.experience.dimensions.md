# 1.vision.experience.dimensions — reflect.on.token.spend

## .the dimensions

each axis is a small closed set. where one value on an axis bars a value on another, the
orthogonality check below names it and the walk verdicts the barred cells `impossible`.

| # | dimension | values | why it varies the experience |
|---|---|---|---|
| A | **actor** | `human` (foreman audits a clone) · `clone` (a driver audits its own session) · `machine` (the future `clone-token-meter` gate, which imports the reader) | the clone reads the stdout as input to its next act; the human reads it to rank a cut; the machine reads a shape, never a render |
| B | **selector** | `path` · `uuid` · `glob` (corpus) · `@current` (no arg) | each locates a transcript by a different route, and fails differently |
| C | **match** | `one` · `none` · `many` | a selector can match zero, one, or several files (a uuid under two roots; a glob) |
| D | **content** | `metered` · `metered-no-boot` (usage present, no `instructions` record — an older harness) · `unmetered` (no `usage` records — fixture, crash at boot) | without `usage` there is no measured total; without `instructions` the boot cannot be named and lands in `unattributed` |
| E | **shape** | `flat` · `compacted` · `with-subagents` · `compacted-with-subagents` | compaction shrinks the context mid-session; subagents live in peer files; a long driver session often has both |
| F | **liveness** | `finished` · `live` (still appended) | a live file may end mid-line — at its final line only |
| G | **integrity** | `well-formed` · `malformed-mid-file` (a line before the last does not parse — a truncated copy, disk fault) | a gap the tool cannot see past; it must never be read as a smaller session |
| H | **reader** | `whole` (reads stdout to its end) · `early-close` (`\| head`, a pager quit — the pipe shuts before the tree is written) | a closed pipe is the reader's choice; read as a fault, it turns a clean audit into a node stack and a `💥` |
| I | **invocation** | `valid` · `unknown-flag` (`--form`) · `flag-no-value` (`--from` with naught after it) · `help` (`--help`, `-h`) | an argv slip must halt before any read; a silent fall back to `@current` would audit the wrong session and look like success |
| J | **rates** | `priced` (every token kind has a rate in the installed specs) · `unpriced` (some or all lack one — today every opus 5.x model) | a rate is never guessed: an unpriced count must read `unpriced`, and the proposal ranks by tokens where price is absent |

### orthogonality check

- **B × C**: `path` matches `none` (absent file) or `one`; never `many` → `path × many` is
  **impossible**. `glob` and `uuid` reach all three. `@current` reaches `none` (no transcript
  yet) and `one`; its `many` is narrowed to `one` by `$CLAUDE_CODE_SESSION_ID` (exported by the
  harness), and by mtime only when that var is unset.
- **C × D/E/F/G**: when `C = none`, there is no file, so D/E/F/G do not apply → those cells
  collapse into one `none` experience per selector.
- **D × E — correlated, and kept apart on purpose.** `unmetered` bars `compacted` and
  `with-subagents`: both require at least one call, and `unmetered` means no call was made. so
  `content = unmetered ⇒ shape = flat`. the latent rule is *"a shape is grown by calls"*. the two
  are not merged because the rest of the grid is independent — `metered` and `metered-no-boot`
  reach every shape — and a merged axis would have to list 7 tuples to say what 3 × 3 says with 2
  impossible cells. the barred cells are walked and verdicted `impossible` in walk 2.
- **F × G**: a partial line at the END of a `live` file is the live shape (tolerated, case=3);
  a bad line BEFORE the end is `malformed-mid-file` whatever the liveness. so G is checked on every
  line but the last, and F governs only the last — the two never overlap.
- **E — two features, enumerated as four values.** compaction and subagents are independent, so
  E is the product `compacted? × subagents?` written out in full. a split into two binary axes
  would say the same with one more column; the four values keep walk 2 one table.
- **B arity — `--from` is repeatable.** several selectors are a union: each is looked up on its
  own (so each can hit its own `none` → exit 2 for that selector, cell 27), then the matched
  files are read as one corpus — the `glob · many` grain, walks 4 and 5. so arity folds into
  `many` rather than add an eighth axis.
- **F × B**: `live` is reached by any selector that names the active file; `@current` reaches it
  always.
- **A**: `human` and `clone` read one surface (the tree). A changes the *care* (a clone runs it
  often, a human runs it for a decision) more than the path — folded where the path is equal.
  `machine` reads a different surface (the operations' return shapes and thrown errors), so it is
  walked on its own in walk 3.
- **I × all else**: any `I ≠ valid` halts (or prints usage) before a selector is read, so B–H and
  J do not apply → one cell per invalid value, walk 7.
- **J × D**: rates apply only where a call was metered; `unmetered` has no count to price → J
  folds into the content cells there. J is otherwise independent of shape, liveness, and selector,
  so it is walked against the one outcome it changes — the report — in walk 8.

## .the walked product

full product = 3 × 4 × 3 × 3 × 4 × 2 × 2 × 2 × 4 × 2 = 27,648 (A–J; A–G alone = 1,728). axes H, I, and J were
found after the vision (5.3 walk and peer review) and fold by the walks 6–8 below; the collapses
for A–G apply in order:

1. `C = none` → D/E/F/G void → **4 selector cells, 3 rows**: `path · none` and `uuid · none`
   render the same error (both name the roots searched) and share cell 4; `glob · none` is cell
   8, `@current · none` is cell 9. actor folded: same error to all
2. `path × many` → **impossible** (a path names one file)
3. `unmetered × {compacted, with-subagents, compacted-with-subagents}` → **impossible** (a shape
   is grown by calls)
4. `metered-no-boot × E × F` (8 cells) → **cell 20** — the boot's absence moves one row into
   `unattributed` and adds one note; it does not vary the verdict by shape or liveness
5. `G = malformed-mid-file` → the read halts at the bad line before content or shape is known,
   so D/E/F fold for a single transcript (walk 5); only the corpus grain differs
6. actor folded where the path is identical; graded on care instead
7. `B × C = one` → once one file is matched, the selector is spent: `path · one`, `uuid · one`,
   `glob · one` and `@current · one` read that file identically, so walk 2 is selector-agnostic.
   each walk-2 cell is demoed through one selector (case=1 via path, case=3 via `@current`) and
   stands for all four; a live file reached by path, uuid or glob takes case=3's read (the
   partial final line is tolerated) — only the lookup differs, and that is walk 1's

the space left is walked as **selector × match**, then **content × shape × liveness** for every
well-formed matched file, then **integrity** across selector grain, then the machine.
