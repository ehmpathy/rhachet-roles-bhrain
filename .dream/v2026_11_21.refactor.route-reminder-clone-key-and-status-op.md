## .the shape of the fix

- declare `RouteReminderCloneKey` (a domain literal) and compute it once per edge (sync, cli, daemon); pass it to `surfaceRouteReminderFault`
- extract one `setRouteReminderForRoute` orchestrator both callers use, which returns a union outcome; decide the cell above once, inside it
- move the `get` ladder into `getRouteReminderStatus`, a union; the cli only renders. add a read-only count of this clone's legacy pid files, with a line that names `del`
- move the session-dead crash log to the clone home
- give `genRouteReminder` a `context.beforeSpawn` seam (fired only on a miss) and drop `legacyOutcomes`; the drive passes a log-write hook, the cli a stdout hook. the sweep's sunset is then two call arguments and a dir
- weigh a machine-scope home keyed on `cloneAddr` alone (env override for hermetic tests); it retires `getRouteReminderRepoRoot` and the `repoRoot` thread, and needs the session sunset of the trail dream first
- add a `blackbox/driver.route.reminder` case: a legacy handle reaped on the first real `route.drive` (acceptance case21 covers the reap through `del`)
- add a `stepRouteDrive` integration case that drives two routes and asserts the focus the sync wrote, so a drive that hands the sync the wrong route goes red
- snap at the shell what is snapped only in process (the list above); the focus-write fault and a mid-drive fault reuse case16's blocked clone home
- reframe the nine reminder unit suites in `given` / `when` / `then`
- share the repeated `getRouteReminder` / file-present reads in `RouteReminder.lifecycle.integration` through one `useThen` per when
- state each refusal's fix once, in one quote style; mask case16's frames as `<frame>` and keep the branches; give the root-route fixtures a named route dir; regroup `--help` per verb

## .why it is not done in this round

the type and the folds are refactors across many files with no behavior change; the shared orchestrator forces a policy choice on a cell where each side serves a reason today. the clamps that prove the wish already run on real fs and real pids.
