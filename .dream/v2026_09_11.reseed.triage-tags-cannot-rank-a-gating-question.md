- the question *"does a `/model` switch preserve the conversation?"* sat five review rounds
  tagged `[research]`, read as nice to know

- one turn in a live session answered it; the round after, a triage table gave it an owner

## .the gap, precisely

the `has-triaged-questions` self-review (`1.vision.guard:122-125`) declares three tags:

```
- [answered] — resolved now
- [research] — to be answered in the research phase
- [wisher]   — requires wisher input
```

every tag names **who** answers. none names what the answer decides, so these two shared a tag:

| the question | what its answer decides |
|---|---|
| does a `/model` switch preserve the conversation? | 🔴 the architecture |
| what is the `clone say` round-trip latency? | one timeout value |

🟡 a fourth value is owed on the who axis: *"what fraction of drives run unenrolled?"* has no
observation that could close it, and `[research]` promises one exists.

## .the shape of the fix

| axis | values |
|---|---|
| who can close it | `[answered]` · `[research]` · `[wisher]` · `[unanswerable]` |
| what it decides | `gates` — the design branches on it; run it before the design is drawn · `tunes` — a value moves · `informs` — no choice changes |

⇒ a `[research]·gates` item outranks every `[wisher]` item.

the smallest version that works: one rubric sentence — *"for each question, also state what its
answer DECIDES; a question the design branches on is run before the design is drawn."*

  patch fixes one route's copy and every future route re-stamps the defect
