# 🌙 dream: an audit is evidence about its INSTRUMENT until the instrument is verified

- **kind** = enbrief
- **owner** = `ehmpathy/rhachet-roles-bhrain`, learner role
- **caught** = 2026-09-05

## .the cue that fired

a directive fired nine times verbatim, unchanged, while four audits read zero. the ninth fire was
taken as a signal rather than as noise, and the question it prompted was not *"what else is
defective?"* but *"which instrument have I never run?"*

⇒ that question found a tool that reported **200 false positives**, every one of them the shape the
booted rule names as a PASS.

## .the gap, precisely

`rule.forbid.obfuscation` already names the **weak settler** — *"you name what would settle it, and
pick the cheapest one."* what it does not say is that an audit tool IS a settler, and a cheap one.

the defect wears five faces, and every one produced a green board:

| the face | what was cheap about it | what it hid |
|---|---|---|
| the MEASURE | four emphasis audits, easy to run | word volume +12.8%, 19 restated claims |
| the SCOPE | one tree, already clean | 32 briefs in the same diff, at 59 sections |
| the AUDIT SET | four tools of ~30 | one that disagreed with the rule it enforced |
| the DENOMINATOR | no defective predicate needed at all | a walk that entered zero files, printed as a clean tree |
| the FILTER | the instrument under it was correct | a hit the LENS dropped — see below |
| the PURPOSE-BUILT | it was written for this one question | a column off by 18x, on its first run — see below |

🟡 **each is internally consistent and externally false**, which is the class `declare-once`'s
enumeration repair cannot catch either. a re-read confirms them; only a check against the artifact
set refutes them.

⇒ the first three are wrong about their VERDICT. the fourth is wrong about its SCOPE, which makes it
the cheapest of the four to commit and the hardest to see — a wrong verdict needs a defective
predicate, and an empty scope needs only a default nobody read.

### the checkable evidence — a wrong VERDICT

🟡 two of the three instruments below have since been retired rather than promoted, precisely
because a superseded predicate that still runs is a false board on demand. the measurement stands;
the tool does not.

- a glyph-stack detector — written, never invoked. first run: 200 hits, 103 of them in a tree four
  peer audits had just read clean. every one was the shape `rule.forbid.emphasis-noise` passes
- an emphasis-line dump — a FETCH that named 4 sections its own detector reported clean
- `review.for.diffusion.needleless.js` — required a bold at the LEAD where the rule it cites asks
  only whether a reader can point at the line

⇒ three of four instruments were wrong, and all three read green.

### the checkable evidence — a silent DENOMINATOR

| the tool | what it printed | what it had scanned |
|---|---|---|
| `review.for.emphasis-noise.spans.js` at `.agent` | no output at all | **0 files** — its default root was `src/domain.roles` |
| `review.for.emphasis-noise.spans.js` at `.behavior` | no output at all | 0 files, same cause |
| the glyph-stack detector, any scope | `0 stacks in 0 files` | 46, and the `0 files` counted files WITH HITS |

🟡 **an empty report and an empty scope render identically**, and the first reads as the second's
opposite. the true board was `106 stacks · 141 columns across 189 files`.

### the checkable evidence — a correct instrument, read through a defective LENS

measured 2026-09-07. `tool.show-hits-for.js` runs a checker at repo root and prints only the blocks
that cite a subtree. it split each block at a fixed indent — *"≤ 3 spaces is a head"* — and the
checkers do not agree on one:

| checker | heads its block at | prints its hits at |
|---|---|---|
| `emphasis-noise.spans` | 0 — a file path | **3** |
| `declare-once.claims` | 3 — a quote | 5 |

⇒ so a spans FILE was split from its own hits, and the file rendered as an **empty block** — which
reads as *"named, and clean"*. it hid a live `[COLUMN]` hit at `catalog.of=glyph.axis=vibe.md:109`,
and the hit surfaced only when the checker beneath was run directly.

🟡 **the instrument was right and the lens was wrong**, which is the face hardest to suspect: every
other row above is repaired by a check of the tool against the rule, and this one passes that check.
the fix is relative indent — a block is a head plus every line indented *more* than it.

### the checkable evidence — a PURPOSE-BUILT tool, wrong on its first run

measured 2026-09-07. a board tool was written to answer one question — *how much of the deferred
emphasis backlog is this round's own?* — and it re-parsed two checkers' stdout to tally by scope:

| the column | it read | the checker beneath read |
|---|---|---|
| stacks · columns | plausible, and unverified | — |
| **sections over the density bar**, at `src/domain.roles` | **8** | **144** |

⇒ the parse matched a section line by indent, and the checker prints its file line and its section
line at indents the parse never tested against a known answer.

🟡 **the face is that a tool written FOR one question feels pre-verified by its own purpose.** every
row above is a tool inherited, borrowed, or superseded — this one was authored minutes earlier by the
reader who then trusted it, which removes the one cue that fires on the others.

⇒ the claim it produced held, and only because a second instrument reported the same absence. the
tool was deleted rather than repaired: the need was already covered, so a repair would have kept a
redundant predicate alive to go stale.

⇒ so the rule owes a second clause, and it is mechanical rather than a discipline:

> **every audit states its DENOMINATOR — how many files it scanned, not how many it flagged.**

- a numerator alone cannot part *"the tree is clean"* from *"the walk was empty"*
- ⇒ and a caller who narrows by an argument the tool silently ignores gets a green board for a
  scope the instrument never entered
- 🟡 a hit count is not a denominator. `0 files` meant *files with hits* in one of the three above,
  which is the same string a zero-scope walk prints

⇒ the peer clause: a default scope is the whole tree. a narrow default is a baked-in claim the
caller cannot see, and the glyph-stack detector carried a banner against exactly that while its own
default was narrow.

## .the shape of the fix

a rule in the learner role, at `say` tier, whose claim is one line:

> **an audit's report is evidence about its instrument until the instrument has been verified
> against the rule it claims to enforce.**

the cues it owes:

| when… | then… |
|---|---|
| an audit reads zero and a directive re-fires | the strongest cue. the board is suspect, never the directive |
| you are about to trust a tool you have not run before | verify a sample against the RULE TEXT first |
| a tool reports a tree at zero that a peer tool reports at N | one of the two encodes a superseded law |
| an audit's predicate is a REGEX and its law is PROSE | nobody re-reads a regex against a rule. make the regex cite the law |
| an audit prints no output at all | 🔴 read its denominator. no output and no scope render identically |
| you narrow a tool by an argument | check it took the argument. a silently ignored scope is a green board |
| a tool's summary says *"N in M files"* | which M — scanned, or flagged? they differ by the whole tree |
| you read a tool through a **filter** you also wrote | 🔴 the lens is an instrument too. run the tool raw once, and diff |
| you write a tool FOR the question you are about to answer | 🔴 its purpose does not verify it. check one column against the checker beneath |
| a tool re-parses another tool's stdout | the parse is a claim about a FORMAT nobody re-reads. test it against one known answer |
| a filtered report names a file and lists not one hit under it | that is not a clean file. it is a split block |
| you would answer *"but the audits are green"* | that is this rule's premise, never a defense |

🟡 **it is a peer of `rule.require.a-cue-is-not-a-claim`, never a duplicate** — that one grades a
CUE against `declare-once`, this grades an INSTRUMENT against the rule it enforces. the two cannot
disagree, so both are owed (`S24`, *"as many angles as it takes"*).

of exactly the kind `Q16` already routed to the wisher.
