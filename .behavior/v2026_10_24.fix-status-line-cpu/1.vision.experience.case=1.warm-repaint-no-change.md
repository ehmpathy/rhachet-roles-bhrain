# case=1 — a warm repaint with no change (happy · critipath)

## .narrative

a driver sits at `3.blueprint`, its peer review under way. the seat streams a long reply, so the
harness repaints the status line three times a second for a minute. none of the route's files
moved. each repaint stats a handful of paths, finds the fingerprint equal and the cache younger
than 30s, prints `🗿 3.blueprint, review.peer, l2@i001 🔍`, and exits. `top` shows no node
process above a blip. the crew's test suite on the same box finishes inside its timeout.

## .bdd sketch

```
given('[case1] a bound route at 3.blueprint, peer review under way, cache warm')
  when('[t0] the line repaints 10 times, no route file written between')
    then('every repaint prints the identical line it printed before the change')
    then('the render (stepRouteStatusLine) runs zero times')
    then('the cpu per repaint is within a small margin of bare node boot')
```
