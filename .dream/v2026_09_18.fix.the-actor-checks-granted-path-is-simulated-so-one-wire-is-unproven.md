## 🔴 .what was consumed, and by what

the dream's headline gap was:

> | 🔴 `isTTY === true` ⇒ **the flag is written** | **nowhere.** it is simulated by a direct `fs.writeFile` |

**that row is now green.** `setRoutePrivilegeAsGranted.integration.test.ts` `[case1]` drives
`isTTY: true` against the real operation, asserts the flag on disk, and pins the granted render byte
for byte.

🔴 **and it did NOT take the fix this dream proposed.** the shape below argued for a pty, at the cost
of a native dependency and a platform branch. the repair that actually landed was cheaper by an order
of magnitude:

| this dream proposed | what landed |
|---|---|
| a pty on the harness, so a **spawn** could be a human | 🔴 make the **actor injectable** — `context: { isTTY }` |
| `node-pty`, a native build, CI risk | no dependency at all |
| a new blackbox case per lever | one integration test per operation |

⇒ **the lesson, and it outlives the dream:** the gap read as a *harness* limit — *"spawn cannot
allocate a pty"* — and it was a **contract** defect. the grant read `process.stdin.isTTY` inline at
the cli while its three peer human-only levers took an injectable context, so the only way in was
through a spawn. a dream that names the obstacle it hit can fix the obstacle in view and miss the
one behind it.

## 🟡 .the residual, and it is much narrower

what no test drives is now **one line per lever** — the cli's read of the process, handed to the
injectable leaf:

```ts
// route.ts — the grant
{ isTTY: process.stdin.isTTY === true }

// route.ts:1034-1036 — the three stone levers
const isTestEnv = process.env.NODE_ENV === 'test' || process.env.CI === 'true';
const isTTY = isTestEnv || (process.stdout.isTTY ?? false);
```

⚠️ **and the two are not the same line.** the stone levers carry a **test escape** — under
`NODE_ENV=test` or `CI=true` they report human regardless of the tty. the grant deliberately does
not, which is why its refusal is drivable in acceptance at all. a reader who assumes one shape from
the other will mis-read both.

this section read: *"a refactor that dropped the cli's read and passed a constant `true` would ship

🔴 **the first sentence is false, and a peer reviewer quoted it back as evidence** (i003/r004 n1 on
`5.3.verification`). it was written from a model of the gap rather than from a read of the corpus,
and it **overstates** the exposure. the corrected measurement, for the **grant** lever:

> **a spawned skill has a pipe on stdin, so `process.stdin.isTTY` is `undefined`.**

| the regression | what a pipe then reads | ships green? |

⇒ **the two that fail OPEN are held; the one that ships green fails closed.** the two assertions that

🟡 **the second sentence stands** — the operation's own clamp cannot see its caller, which is why the

dangerous failures are proven and its safe failure is not."*

⚠️ **and the three stone levers are NOT measured here.** they carry a test escape, so a spawn reports

## .the shape of the fix, for what remains

a pty is still the only way to prove a **cli** wire end to end, so the plan below stands for the
residual — at a materially lower value now, since the decision, the effect, and the render are all
clamped.

1. add `invokeRouteSkillOnATty` beside `invokeRouteSkill` in `blackbox/.test/invokeRouteSkill.ts`
2. the pty needs `node-pty` (a real dependency, a native build in CI) or the unix `script` command
   (no dependency, and flags that DIVERGE between linux and macOS — a platform branch the harness has
   no precedent for, and `rule.forbid.bare-host-deps` forbids the bare host reach)
3. one case per human-only lever: spawn on the pty, assert exit 0 and the flag present

## .why it is not done in this round

the SAFE/CLEAN test (`rule.always.fix-forward-under-scouts-honor`), re-run against the residual:

- **safe?** 🟡 a new acceptance case is safe. the dependency is not — `node-pty` builds natively, so
  it can break CI on a box this route cannot test
- **clean?** 🔴 **no.** a harness change plus a dependency plus cases across two suites, for a
  one-line wire per lever

⇒ **defer, and the deferral is now cheap.** it owes no fulcrum: the call is about SIZE, never a
judgment about ripple.
