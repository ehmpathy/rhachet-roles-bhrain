# case 12 — an order given on main fails loud, never lost

feel: sharp · care: critipath (a fresh clone or a human session often starts on main) · actor: commander, achiever · seams: talk hook, store, stop hook

## .narrative

the clone sits on `main`. the commander types an order. today the store refuses main
(`getScopeDir`, `src/contract/cli/goal.ts:472-476`), so the talk hook throws before it writes; the
order is never recorded. at stop, the next-goal hook catches the same refusal and exits 0
(`goal.ts:1649-1655`). the order is lost and every gate is green: the exact lossy failure duty 1
exists to kill.

with this role, the talk hook never drops an order in silence. on a forbidden scope it parks the
order in a hold file the stop can read (goals stay forbidden on main; the hold is a queue, not a
store), and prints, into the clone's context, the order, why, and the fix: branch first. the stop
hook, on a forbidden scope with a non-empty hold, exits 2 with the same fix. the clone runs
`git checkout -b`, and the held order moves into the branch's store. the order survived because the hook said so.

## .[tn] — a sketch

```
given  the clone on main, achiever enrolled
when   [t0] the commander submits an order
then     the talk hook appends the order to the hold (e.g. .goals/.hold/asks.inventory.jsonl)
     and exits 0 (it never blocks the commander's prompt), and prints to the clone:
           ✋ ConstraintError: this order was not recorded — the goal store forbids main
              ├─ order: "<the commander's words>"
              └─ fix: branch first; the held order moves to the branch's store at the next triage
                 └─ git checkout -b <branch> && rhx goal.triage.infer
when   [t1] the clone tries to stop with the order unrecorded
then     goal.triage.next --when hook.onStop exits 2 with the same fix (today: exit 0, silent)
when   [t2] the clone branches; the next triage moves the hold into the branch scope's inventory
then     the order is an ordinary uncovered ask (case 2), and the stop holds until it is covered and closed
```
