# case 9: a relative redirect is placed by the cwd, and a write the guard cannot place halts

rows 50, 51, 52, 54, 57 (rows 53, 55, 56, 58 itemized).

proof: `src/domain.operations/memory/getMemoryGuardVerdict.test.ts` (case descriptions quoted below), `asToolInvocation.test.ts` ("carries the harness cwd"), `asBashCwdAfterSegment.test.ts`, and `src/domain.roles/learner/getLearnerRoleHookCommand.integration.test.ts` `[caseA]` `[t1]` (the `$var` nudge).

## .narrative

a clone reads a note and keeps a copy: `cat ~/.claude/projects/p/memory/a.md > out.txt`. the redirect names no directory, so where it lands depends on the shell's cwd. the harness sends that cwd with each call. with the cwd at the repo, the copy lands in the repo and passes in silence. with the cwd at the memory dir, the same words write into memory, and halt. a `cd` earlier in the command moves the cwd: `cd ~/.claude/projects/p/memory && echo x > a.md` writes into memory and halts, while `cd /tmp && cat …/memory/a.md > out.txt` lands in `/tmp` and passes.

when the guard does not know the cwd, it cannot place a relative redirect that sits beside a memory path. it does not guess. it halts, and the nudge says the guard could not place the write, and shows the route: redirect to an absolute path outside memory. the same holds for a redirect through a `$var` set under `.claude/`: `D=~/.claude/projects/p/memory; echo x > $D/a.md` is a write the guard cannot place, beside memory, so it halts with the same nudge. a `$var` with no var set under `.claude/` (`D=/tmp/x; echo x > $D/a.md`) has no memory beside it, so it passes.

## .bdd sketch

```
given a Bash payload whose harness cwd is the repo
  when [t0] `cat ~/.claude/projects/p/memory/a.md > out.txt`
    then allowed   (verdict: "allows a memory read redirected to a relative path, cwd known")

given a Bash payload whose harness cwd is the memory dir
  when [t0] `echo x > a.md`
    then blocked   (verdict: "blocks a relative redirect when the cwd is memory")

given a Bash payload whose harness cwd is the repo
  when [t0] `cd ~/.claude/projects/p/memory && echo x > a.md`
    then blocked   (verdict: "blocks a relative redirect after a cd into memory, cwd known")

given a Bash payload with no harness cwd
  when [t0] `cat ~/.claude/projects/p/memory/a.md > out.txt`
    then blocked, act unplaced   (verdict: "blocks a redirect to a relative path beside a memory path")

given [caseA] a linked learner (hook suite)
  when [t1] `D=/home/agent/.claude/projects/p/memory; echo x > $D/a.md` fires the hook
    then exit 2
    then stderr holds `✋ blocked: an unplaced write beside claude native memory` and `$var`
```
