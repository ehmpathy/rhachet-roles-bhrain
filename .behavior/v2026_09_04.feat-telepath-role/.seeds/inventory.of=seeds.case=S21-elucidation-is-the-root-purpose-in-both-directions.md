# S21 · elucidation is the ROOT purpose — in both directions

## .said

verbatim, 2026-09-04, mid-drive at `1.vision`:

> and last, we need to enbrief and enrule elucidation. the fundamental purpose of the telepath is elucidation. elucidation into peers it needs to give concepts into (i.e. give answers). elucidation from peers it needs to gain concepts from. (i.e., ask question)

## .settled

**elucidation is the ROOT the whole role stands on** — *"the fundamental purpose of the telepath"*,
in the wisher's own words. every other rule in the canon is one surface of it.

### two directions, and the second is the one that gets dropped

| direction | the act | the artifact |
|---|---|---|
| **into** a peer | **give** a concept | an **answer** |
| **from** a peer | **gain** a concept | a **question** |

⇒ **a question is an act of elucidation, not a failure to perform one.** that is the settlement, and
it is what an author loses by default: a question feels like a gap in the answer, so it gets
suppressed, and the concept never transfers in either direction.

### a question is PROSE, so every output rule binds it

the consequence nobody states: if elucidation runs both ways, then **the rules that grade an answer
grade a question too**.

- a rambled question is a subversive question
- an unbulletized question is an unbulletized passage
- a question with no established purpose fails `purpose-first` exactly as an answer does

⇒ so the canon does not need a second rule set for the input direction. **it needs the extant set
declared to bind both.**

### it names the target `forbid.subversive-prose` was already measured against

S19 settles that subversive prose *"aims to **tire** the reader into submission, **rather than
elucidate**"* — so `elucidate` already carried weight in that rule before it had a brief.

⇒ this closes that: the forbid names the anti-target, and this names the target.

## .landed

- `define.elucidation` (ref) — owed
- `rule.require.elucidation` (say) — owed
- ⇒ it is the **root** of the canon pipeline: `purpose-first` → `fundamentalism` → `bulletize` →
  `condensation`, graded by `subversive-prose` / `narration` / `place-a-passage` — **all seven serve
  this one**
- 🟡 the extant `rule.require.answer-what-they-meant` is telepath's **input face** and it is the
  nearest peer: it grades whether you read the concept correctly; this grades whether you **ask** for
  the concept you lack
