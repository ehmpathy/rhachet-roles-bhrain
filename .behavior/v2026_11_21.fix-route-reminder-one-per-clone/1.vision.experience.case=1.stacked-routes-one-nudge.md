# case=1 — stacked routes, one nudge

inventory rows: r1, r2, r3, r19, plus the dense journey (r2 → r1 → r3 → r4 → r4b → r18). feel: happy, with one sharp seam (r19). care: critipath.

## .narrative

a clone drives `.behavior/A`. its drive hook spawns one reminder daemon and writes focus = A. mid-route, the director stacks a second task: the clone binds `.behavior/B` and drives it. A stays live — its last passage reads `passed`, mid-route.

the next drive hook finds the clone's handle live. it rewrites focus = B and spawns none. twenty minutes later one poke lands: `🗿 you can do it! drive on, fulcrum, and converge`. the daemon read focus = B, saw B active, and said it once. A's passage was never read.

the seam: the focus write is the handoff from the drive to the daemon. if it faults (disk full, a read-only dir), the live daemon still holds focus = A and would poke about the route the clone left. so a focus write fault reaps the daemon, surfaces the fault to the clone's reminder log, and the drive proceeds. the next drive that can write focus spawns fresh. silence beats a poke about the wrong route.

## .[tn] sketch — the spotlight

```ts
given('[case1] one clone, two live routes A and B', () => {
  // two temp routes, each with a live passage tail; one clone addr in env
  when('[t0] the clone drives A', () => {
    then('spawnDaemon runs once');
    then('the clone handle names that pid');
    then('focus = A');
  });
  when('[t1] the clone drives B, A still live', () => {
    then('spawnDaemon has still run once');          // 🔴 red before the fix: twice
    then('one clone handle exists, none under A or B');
    then('focus = B');
  });
  when('[t2] the clone drives B again, the daemon still live', () => {
    then('spawnDaemon has still run once');          // the findsert hits; the common turn
    then('focus stays B, its file unchanged');       // no rewrite when the content is the same
  });
  when('[t3] one daemon tick runs', () => {
    then('sayToClone ran once');                     // 🔴 red before the fix: once per daemon
    then('the tick read the activity of B, not A');
  });
});

given('[case1b] the focus write faults on a switch to B', () => {
  when('[t0] the clone drives B', () => {
    then('the daemon that held focus = A is reaped');
    then('the clone reminder log names the write fault');
    then('the drive itself proceeds');
    then('no tick can nudge about A');
  });
});
```

## .[tn] sketch — the dense journey

one walk, six boundaries: first spawn, switch, same-route re-drive, halt, the human's read, re-arm.

```ts
given('[journey] one clone; routes A and B, both live', () => {
  when('[t0] drive A')                 then('one spawn, focus = A');                 // r2
  when('[t1] bind + drive B')          then('no spawn, focus = B');                  // r1
  when('[t2] drive B again')           then('no spawn, focus stays B');              // r3
  when('[t3] one tick')                then('one nudge, about B');                   // r1
  when('[t4] B turns blocked; drive')  then('daemon reaped; A gets no nudge');       // r4
  when('[t5] route.reminder.get')      then('names B and its halt, not "never registered"'); // r4b
  when('[t6] bind + drive A')          then('one fresh spawn, focus = A; one nudge per tick'); // r18 — switched, daemon absent
});
```
