# razor: base rate

shaves: a number or a sample · settled by: observation (of the reference class, never of this one case)

## .the question

> **how often does this kind of case hold across the whole class?**

start from the class rate, then move by the case at hand. "when you hear hoofbeats, think horses, not zebras."

## .the source

- Kahneman and Tversky, "On the psychology of prediction", *Psychological Review* 80(4): 237-251, 1973
- Theodore Woodward, University of Maryland, late 1940s: "When you hear hoofbeats behind you, don't expect to see a zebra"
- read via https://en.wikipedia.org/wiki/Base_rate_fallacy and https://en.wikipedia.org/wiki/Zebra_(medicine)

## .fails when

- the class is ill-chosen (the reference-class problem): name the class
- strong case-specific evidence beats a weak prior. a zebra does occur: the base rate orders the reads, it never skips one

## .run by

`rule.always.weigh-a-read-by-what-it-rules-out`
