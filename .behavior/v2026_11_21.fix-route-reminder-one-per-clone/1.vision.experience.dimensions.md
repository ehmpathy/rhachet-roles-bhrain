# 1.vision.experience.dimensions

## .the actors

- **clone** — the enrolled driver session; it receives the nudge
- **human** — reads or manages the reminder by hand (`route.reminder.get|gen|del`)

## .the dimensions

each axis has a closed value set. each is read at one moment, named in the last column.

| # | dimension | positions | read at |
|---|---|---|---|
| D1 | live routes the clone has driven | `one` · `many` | the drive |
| D2 | the focus route's activity | `active` · `not-live` (blocked, rewound, exhausted, malfunction) · `complete` | the drive, and each tick |
| D3 | the drive's route vs the clone's prior focus | `same` · `switched` (prior focus live or not) · `none` (no prior focus) | the drive |
| D4 | the clone's daemon state | `absent` · `live` · `stale` (dead pid) · `legacy` (a per-route daemon from before the fix, under `.behavior/*/` or `.route/*/`) · `orphan` (a live daemon the clone's handle does not name) · `torn` (a clone handle whose body is not a pid) | the drive |
| D5 | the session | `alive` · `dead` | each tick |
| D6 | the entry | `auto` (route.drive hook) · `manual drive` (`route.drive --route <x>`, a route other than the bind) · `tick` (the daemon's own wake) · `manual get` · `manual gen` · `manual del` | — |
| D7 | concurrency / time | `first` · `race` (two drives at once on one clone) · `retried` (a respawn after a crash on arrival) | the drive |
| D8 | the focus pointer on disk | `present` · `absent` · `unwritable` | the drive writes it; each tick reads it |
| D9 | clones on the focus route | `one` · `many` | — |
| D10 | the args a manual verb receives | `full` · `--route absent, bound` · `--route absent, unbound` · `--clone-addr absent` (the env serial names the clone) · `--clone-addr bare` (a serial with no `@:`) · `--repo-root absent` (daemon) · `stray positional` · `--help` | the verb's arg parse |

### .orthogonality

- **D1 vs D3.** D3 compares against the clone's prior focus, whatever its liveness. so `D1 = one` × `D3 = switched` is real: the clone drove A to completion, then drives B. no cell of D1 × D3 is barred
- **D3 vs D8.** D3 is history the drive knows (its own route vs the last it wrote). D8 is the file at read time. a prior focus can exist and its file be deleted later, so `D3 = same` × `D8 = absent` is real (the tick reads absent until the next drive writes it)
- **D7 vs D4.** a race can start from any D4; a retry implies a prior crash, which leaves D4 = `stale` or `absent`. `retried` × `live` is barred: a live daemon means the last spawn survived, so there is no retry
- **D6 vs D4.** a `tick` runs inside a live daemon, so `tick` × D4 ≠ `live` is barred
- **D10 vs D6.** only a `manual` entry (and the daemon entrypoint for `--repo-root`) parses args, so D10 ≠ `full` × D6 `auto` / `tick` is barred. every D10 value other than `full` is read before any other axis, so each collapses to one row whatever D1–D9 hold (rows r47–r53)

## .the walk

the full product is 2 × 3 × 3 × 4 × 2 × 5 × 3 × 3 × 2 = 12,960 cells. they collapse by five rules, each a property of the design:

1. **the verdict reads only the focus route.** D1 and D9 never change what the one daemon of one clone does. D1 = `one` vs `many` is the wish's equality, walked as a pair. D9 = `many` multiplies by clone key and changes naught per clone (r14)
2. **a dead session runs no drive.** D5 = `dead` × D4 = `live` → the next tick's say fails, exit `session-dead` (r8). D5 = `dead` × D4 ≠ `live` → no daemon, no drive, no tick: silence (r21)
3. **the sync has two arms, keyed on D2.** D2 = `active` → findsert by D4 (r1, r2, r3, r6, r7); the legacy sweep runs only before a spawn. D2 ∈ {`not-live`, `complete`} → del by D4, gated on the focus still on this route (r4, r5, r22, r23, r24, r37); this arm sweeps naught, since a blocked route fires a hook each turn
4. **D8 is the seam.** `present` is the default of every other row. `absent` → the tick exits (r15). `unwritable` → the sync reaps (r19), and a manual gen fails loud (r41). with D8 `present`, the tick reads D2 of the focus route: `active` → nudge; `not-live` / `complete` → re-read the focus once (r36), then exit with that reason, before the next drive reaps (r28); a daemon that exits drops its own handle (r39)
5. **the manual verbs act through the same leaves as the drive.** `gen` is the findsert, on a live route alone; on a dead route it spawns none, and with a live daemon it keeps the focus (r26, r35). `del` sweeps the legacy handles first and prints each outcome on stdout (r32, r32b), then reaps the clone handle. `get` is read-only: it reads the clone handle alone and reaps naught, and names a live daemon on a halted focus as live for now (r38). get and del refuse `--route` and `--repo-root` (r11, r40); gen refuses a `--route` that is not a dir (r44). a `torn` handle makes get and gen refuse with the fix, and `del` clears it (r43). so each verb × D4 maps to one row (r9, r10, r12, r25, r26, r29–r33)

D7 adds the race and retry rows. the collapse yields the rows of `1.vision.experience.case=_.md`; every cell maps to one row or to a barred pair named above.
