read 2026-11-24, via websearch + webfetch. 🟡 per `rule.forbid.websearch-and-webfetch`, every row is a **pointer**, not evidence: most pages are secondary (wikipedia, teacher-center pages), quotes passed through a fetch summarizer, and primary papers for merrill, 4c/id, roediger, ericsson were not read. a bhrowser read of each primary source is owed before any of this lands in a brief. model and stage names below are the canon's own words, kept verbatim.

## .what nearly every model shares

1. outcomes stated up front
2. prior knowledge checked
3. an expert model shown
4. practice on a realistic task, with feedback
5. assessment apart from practice
6. transfer and reflection

the draft held 3 and part of 4.

## .what the evidence argues against

- a read + distill pass as the main act (dunlosky: low utility unless a test follows)
- a one-way route with no loop back (bloom, addie revisions)
- isolated toy practice (4c/id: whole, varied tasks)
- a single assessment (gagné)

## .caveat

all of it is about human learners. none of it tests an llm agent.
