# rule.always.test-a-claim-against-the-whole-it-speaks-for.example=the-marketplace-web-retirement

> row: "this system retires". 2026-11-16, the salespages prerender crew of a consumer director (#49). source: inbox 2026-11-16-salespages-defects-skeptic.

## .the shape, in any life

a town closes the old post office and calls it "just a mail hall". it was also the only place for bus tickets and the town notice board. what else does this place do, and for whom?

## .the miss

row D2 of the yield read "retires ... the repo archives" for marketplace-web. the human asked whether it must still exist, since it holds the dns entries.

## .the roles the system played

| role | the retire claim covered it? |
|---|---|
| the next.js app | yes: this is the part the change replaces |
| the www front door: distribution, aliases, path map | no |
| the www dns record | no |

## .the cost

an archive of the repo would have orphaned the www distribution, its aliases, its path map, and its dns record.

## .the cure in the tree

the crew route states two rules: marketplace-web is the www front door (it stays and owns www distribution, aliases, and the path map; only the next.js app retires), and it owns the www dns record.

## .the law it proves

`rule.always.test-a-claim-against-the-whole-it-speaks-for` (the row for a retire claim): the claim "it retires" is true only of the roles that have an heir.
