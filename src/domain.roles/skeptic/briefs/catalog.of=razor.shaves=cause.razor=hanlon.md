# razor: hanlon

shaves: a cause among rivals · settled by: rivals

## .the question

> **before I named a motive, did a slip, a gap, or a default already explain it?**

motive, slip, gap, default: each a rival, weighed on the same reads. the razor orders them; it never removes the motive rival.

## .the source

- "Robert J. Hanlon" as submitted to Bloch, *Murphy's Law Book Two*, 1980; the name is not secure
- precursor: Heinlein, "Logic of Empire", March 1941: "You have attributed conditions to villainy that simply result from stupidity"
- "slip, gap, default" is this role's widened gloss of "stupidity"
- read via https://en.wikipedia.org/wiki/Hanlon%27s_razor

## .fails when

- an adversary is real. the razor then excuses it
- incompetence that recurs past correction acts as malice in effect (Grey's law)

## .run by

`rule.always.trust-but-verify`
